WhatsApp-familiar, Token-first

The structure borrows WhatsApp's muscle memory — messaging-first landing, four bottom tabs, a corner action button — but every borrowed slot is repurposed around Token's core promise. Grey boxes are placeholders; the v4 colour system (cobalt accent, pass-card gradients, holo line) carries over unchanged. Blue elements mark where this design deliberately departs from WhatsApp.
