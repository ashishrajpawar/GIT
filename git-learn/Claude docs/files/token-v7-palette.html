What's carried over, and what changed

Unchanged from v7: four tabs — Chats, Tokens, Circles, Calls. Seal strip at the top of Chats with Manage. Labelled action button, bottom-right, clear of the tab bar. Two-tap mint with the same four template names. TOKN- codes. Pause and Revoke on the token bar. v7's own seeded data throughout.

Changed: colour now carries meaning instead of branding. Black is the brand, so buttons, codes and your own messages are all ink. Green marks an open door, ochre one that's closing, slate one that's paused, brick the revoke action — and nothing else in the app is ever coloured. The gradient survives from the version you liked, but only inside the life bar and seal ring, where it means time remaining.

Also folded in: Noto Sans, so Hindi and every other script render in one voice — visible in the thread screen. Lock-to-first-opener on by default in the mint sheet. The four token states are all shown, including Paused, which v7 had but never displayed distinctly.
