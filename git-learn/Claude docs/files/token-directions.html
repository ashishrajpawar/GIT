Token · visual direction · pick one

Five ways this app could look.

Same skeleton throughout — the v7 structure stays exactly as it is: four tabs (Chats, Tokens, Circles, Calls), the seal strip, per-tab action button, two-tap mint, confirm-before-close. Only the surface changes. Each specimen below shows the Tokens tab so you can compare like for like.

01

Obsidian

The closest to Antigravity. Near-black with a cool cast, hairline borders, generous air, and no brand colour at all — white is the accent. Colour appears only to report a door's state, so a green dot actually means something. Reads as professional tooling rather than a consumer app.

02

Arctic

Light, but cold light — blue-white, never cream. Institutional navy, IBM Plex throughout, tight alignment and real hairlines. This is what a Swiss private bank or a medical device would look like. Feels trustworthy through precision rather than atmosphere, and it photographs well for the App Store.

03

Steel

Cool grayscale with a machined feel. The app itself is flat and quiet; the token is the only object with weight — a milled plate with the code etched into it and a small status lamp. Borrowed from hardware security keys and studio equipment: nothing glows, nothing gradients, everything looks like it was made on a lathe.

04

Blueprint

Deep drafting navy with cyan line work on a faint grid. Every token is drawn as a schematic rather than a card — corner ticks, dimension marks, a part number. The boldest of the five and the most memorable, but it commits hard: if the drafting idea doesn't land with a mainstream Indian consumer, there's no half-way version of it.

05

Mono

Pure black and white. One colour exists in the entire app — a single red, and only for closing a door. State is carried by weight, fill and rule instead of hue: a live token is solid black, a paused one is outlined, a closed one is struck. Maximum discipline, zero decoration, ages extremely well.

What I'd pick, and why

01 Obsidian is the safest strong answer and the closest to Antigravity — it will look current for years, it makes the state colours meaningful because nothing else is coloured, and dark reads as secure to most people without trying. 03 Steel is the same idea with more personality: only the token has physical weight, which suits a product whose whole point is that the token is an object you own and can destroy.

If you want the app to be unmistakable and you're willing to take a real risk, 04 Blueprint is the one nobody else will have. If you want it to feel like a bank, 02 Arctic. If you want it to still look right in ten years, 05 Mono.

The button overlap is a bug, not a style
In v8 the action button was centred over the tab bar. It goes back to bottom-right with proper clearance above the tabs, and the list gets padding so the last row is never hidden underneath it.
v7 skeleton is preserved
Four tabs — Chats, Tokens, Circles, Calls. Seal strip in the same place, per-tab action button, two-tap mint, confirm before closing a door, fingerprint before revealing your number.
Everything agreed still ships
Voice and video over the internet, no SMS, no KYC, locked-to-first-device, vague notifications, real send states, offline handling, block the person not the door.
