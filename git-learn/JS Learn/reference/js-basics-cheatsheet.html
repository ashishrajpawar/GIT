JavaScript Basics
Cheatsheet

Quick Reference Print-friendly

A scannable reference for every foundational JavaScript concept. Keep this open while you work through the lessons.

1. Variables

Variables are named boxes that hold values.

let

Declares a variable whose value can change. Preferred for values that update.

let score = 0;
score = 10;       // OK — changed it
score = score + 5; // Now 15

const

Declares a variable whose value cannot be reassigned. Use by default unless you need to change it.

const appName = "ChatApp";
// appName = "Other"; // ERROR!

var Old — avoid

The original way to declare variables. Has confusing scoping rules. You'll see it in old code, but use let/const instead.

var name = "Ashish"; // works, but
                     // avoid in new code

2. Data Types

The kinds of values JavaScript can work with.

String

Text, always in quotes (single, double, or backtick).

let name = "Ashish";
let msg  = 'Hello!';
let full = `Hi, ${name}`; // "Hi, Ashish"

Number

Any numeric value — integers or decimals. No quotes.

let age    = 25;
let rating = 4.5;
let total  = age + 10; // 35

Boolean

Only two possible values: true or false.

let isOnline  = true;
let hasRead   = false;
let isAdmin   = true;

null

Intentionally empty — "there is no value here on purpose".

let profilePhoto = null;
// user hasn't uploaded one yet

undefined

A variable that was declared but never given a value.

let lastSeen;
console.log(lastSeen); // undefined

Array

An ordered list of values. Items are accessed by index (starting at 0).

let messages = ["Hi", "Hey", "Yo"];
messages[0]; // "Hi"
messages[2]; // "Yo"

Object

A collection of key-value pairs — like a contact card.

let user = {
  name: "Ashish",
  age: 25,
  online: true
};
user.name; // "Ashish"

3. String Methods

.length

How many characters in a string.

let msg = "Hello";
msg.length; // 5

.toUpperCase()

Returns the string in all uppercase letters.

"hello".toUpperCase(); // "HELLO"

.includes()

Returns true if the string contains the given text.

"Hello Ashish".includes("Ashish"); // true
"Hello".includes("bye");           // false

.split()

Splits a string into an array at every occurrence of a separator.

"a,b,c".split(","); // ["a", "b", "c"]
"hi there".split(" "); // ["hi", "there"]

4. Array Methods

.push()

Adds an item to the end of an array.

let msgs = ["Hi"];
msgs.push("Hey!");
// msgs is now ["Hi", "Hey!"]

.pop()

Removes and returns the last item of an array.

let msgs = ["Hi", "Bye"];
msgs.pop(); // "Bye"
// msgs is now ["Hi"]

.map()

Creates a new array by transforming every item.

let names = ["ash", "bob"];
let upper = names.map(n => n.toUpperCase());
// ["ASH", "BOB"]

.filter()

Creates a new array with only items that pass a test.

let nums = [1, 2, 3, 4, 5];
let evens = nums.filter(n => n % 2 === 0);
// [2, 4]

.find()

Returns the first item that passes a test (or undefined).

let users = [{id:1,name:"Ash"},{id:2,name:"Bob"}];
let found = users.find(u => u.id === 2);
// {id:2, name:"Bob"}

5. Functions

Function Declaration

The classic way to define a reusable block of code.

function greet(name) {
  return "Hello, " + name + "!";
}

greet("Ashish"); // "Hello, Ashish!"

Arrow Function

A shorter syntax — very common in modern JS and React Native.

const greet = (name) => {
  return "Hello, " + name + "!";
};

// One-liner (implicit return):
const greet = name => "Hello, " + name;

6. Template Literals

Embed variables directly into strings using backticks and ${}.

Template Literal

Cleaner than string concatenation with +.

const user = "Ashish";
const msgs = 5;

// Old way (concatenation):
"Hi " + user + ", you have " + msgs + " messages."

// New way (template literal):
`Hi ${user}, you have ${msgs} messages.`

7. Conditionals

if / else

Run different code depending on whether a condition is true.

let isOnline = true;

if (isOnline) {
  console.log("User is online");
} else {
  console.log("User is offline");
}

Ternary Operator

A compact one-liner version of if/else: condition ? ifTrue : ifFalse.

let status = isOnline ? "Online" : "Offline";
// "Online"

let label = unread > 0 ? "New messages" : "All read";

8. Common Operators

Comparison

Always use === (strict equality) rather than ==.

5 === 5     // true  (strict equal)
5 !== 3     // true  (strict not equal)
5 > 3       // true
5 >= 5      // true
3 < 10      // true

Logical

Combine boolean conditions.

true && true   // true  (AND — both must be true)
true || false  // true  (OR — at least one true)
!true          // false (NOT — flips it)

9. console.log()

Your most important debugging tool. Prints values to the developer console so you can see what's happening in your code.

console.log()

Print anything — strings, numbers, variables, objects.

console.log("Hello, Ashish!");    // Hello, Ashish!
console.log(42);                   // 42
console.log(2 + 2);               // 4

let user = { name: "Ashish" };
console.log(user);                 // {name: "Ashish"}
console.log("User:", user.name);   // User: Ashish
