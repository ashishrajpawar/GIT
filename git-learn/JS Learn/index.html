Build a WhatsApp Clone

9 modules ~3 months JavaScript → React Native → Ship → Scale
Your goal

Go from basic HTML/CSS knowledge to a fully working WhatsApp clone on both Android and iOS — with real-time chat, group messaging, audio and video calls, store compliance, production scaling, and advanced features. Each module builds directly on the last.
