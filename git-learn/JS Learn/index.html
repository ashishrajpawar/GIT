Build Token

Two tracks ~3–4 months Mobile + Web + Backend from scratch
Your goal

Build Token — a privacy-first mobile app where users issue revocable capability tokens instead of sharing phone numbers or emails. You'll build the React Native app, the redemption web page, and the entire Node.js + PostgreSQL backend from scratch. Published on both stores, with real users.
