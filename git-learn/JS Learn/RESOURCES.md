# JavaScript + React Native Resources

## Knowledge

- [The Modern JavaScript Tutorial (javascript.info)](https://javascript.info)  
  The single best free resource for learning JavaScript from scratch. Thorough, well-organised, beginner-friendly. Use for: any JS concept lesson.

- [React Native Official Docs](https://reactnative.dev/docs/getting-started)  
  Primary source for React Native APIs, components, and setup guides. Use for: every React Native lesson.

- [Expo Documentation](https://docs.expo.dev)  
  Expo wraps React Native for faster development. Use for: project setup, camera, notifications, linking.

- [Firebase Documentation](https://firebase.google.com/docs)  
  Use for: real-time database (Firestore), authentication, storage — the backend for the WhatsApp clone.

- [Agora React Native SDK](https://docs.agora.io/en/video-calling/get-started/get-started-sdk?platform=react-native)  
  Use for: audio and video call features.

- [freeCodeCamp: JavaScript Algorithms and Data Structures](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures/)  
  Free, interactive JS fundamentals course. Use for: practice exercises and self-testing.

## Wisdom (Communities)

- [r/reactnative](https://www.reddit.com/r/reactnative/)  
  Active community for React Native developers. Good for troubleshooting and architecture questions.

- [Expo Discord](https://chat.expo.dev)  
  Fast help from Expo maintainers and community. Use for: Expo-specific issues.

- [Stack Overflow — react-native tag](https://stackoverflow.com/questions/tagged/react-native)  
  Reliable for specific code errors and library issues.
