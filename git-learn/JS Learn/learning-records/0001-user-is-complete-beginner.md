# User Starts as a Complete JavaScript Beginner

User self-identified as a complete beginner with no prior JavaScript or programming experience. Goal is to build a WhatsApp clone with React Native. Teaching must start from absolute foundations: variables, data types, functions, and control flow, before moving to React Native concepts.

**Implications:** Do not assume any prior knowledge of programming. Use concrete, real-world analogies. Tie every concept to the WhatsApp app they want to build.
