Module 9: Advanced Features

6 lessons • ~3 weeks • Nice-to-have features for a polished, professional app

Why this module exists: These features separate a "working app" from a "professional app." End-to-end encryption builds user trust, CI/CD prevents broken releases, accessibility opens your app to everyone, and i18n lets you reach users worldwide. Build these when you're ready to level up.

Lessons

  1. End-to-End Encryption

    Signal Protocol concepts (Diffie-Hellman key exchange, double ratchet), generating and storing keys with expo-secure-store, encrypting/decrypting message payloads client-side, "Messages are end-to-end encrypted" indicator UI, key verification between users.

  2. CI/CD Pipeline

    GitHub Actions workflow for automated testing on PR, EAS Build triggered from CI, environment variables and secrets management, staged rollouts (internal → beta → production), automated version bumping.

  3. Deep Linking & OTA Updates

    expo-linking for opening specific chats from notifications or shared URLs, universal links (iOS) and app links (Android), expo-updates configuration, update strategies (force update, soft prompt, silent), rollback on crash.

  4. Internationalization (i18n)

    expo-localization for detecting device language, i18next + react-i18next setup, extracting all strings to translation files, RTL layout support, pluralization rules, number/date formatting per locale.

  5. Accessibility

    accessibilityLabel and accessibilityRole on every interactive element, dynamic font scaling (allowFontScaling), minimum 44x44pt touch targets, colour contrast compliance (WCAG AA), screen reader testing (VoiceOver + TalkBack), accessibilityLiveRegion for new messages.

  6. Feature Flags & Staged Rollout

    Firebase Remote Config for feature flags, enabling features for percentage of users, A/B testing a new UI, kill switch for broken features, reading flag values in React Native, updating flags without a new build.

Prerequisites

  • Module 8 complete (app is running at scale with monitoring)
  • Comfortable with the full Firebase stack
  • App has real users and you want to level up

By the end of this module you will have

  • Messages encrypted end-to-end (like real WhatsApp)
  • Automated build and deploy pipeline
  • Deep links that open the right screen from anywhere
  • App available in multiple languages
  • Full accessibility for screen reader users
  • Feature flags for safe, gradual rollouts
