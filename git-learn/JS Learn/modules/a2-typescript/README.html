TypeScript

3 lessons Phase 1 — Foundation
Module goal

Learn TypeScript — the language Token is written in. After this module, you can type any component, API response, or shared data structure. The compiler catches bugs at write-time instead of runtime.

Lessons

  1. Types and Interfaces — primitives, objects, unions, functions, narrowing
  2. Generics & Utility Types — Partial, Pick, Omit, Record, generic functions
  3. TypeScript with React Native — typed props, state, navigation, events, FlatList

After this module

You'll be able to:

  • Define Token's data model in shared/types.ts
  • Type API responses with generics (ApiResponse<Token>)
  • Use utility types for partial updates and list views
  • Type React Native components, hooks, and navigation
