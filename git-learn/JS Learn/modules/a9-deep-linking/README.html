Track A

Deep Linking & Routing

2 lessons Phase 5 — The Second Client
Module goal

Make tokn.app/t/CODE work seamlessly — open the app if installed, web page if not. Handle the incoming URL inside the app and navigate directly to the right screen.

Lessons

  1. Universal Links & App Links — AASA, assetlinks.json, .well-known hosting, Expo config, OS routing logic
  2. In-App Deep Link Handling — Linking API, React Navigation config, URL parsing, cold vs warm start

What you'll build

  • An apple-app-site-association file that claims tokn.app/t/* for iOS
  • An assetlinks.json that claims the same paths for Android
  • Expo linking configuration that registers the app for these URLs
  • A React Navigation deep linking config that maps /t/:code to the redemption screen
  • Cold-start and warm-start handling so the token code always reaches the right screen

Prerequisites

  • A8 — Redemption Web Page (the fallback page users see without the app)
  • Expo linking basics (covered in Module 02)
  • React Navigation setup with nested stacks (covered in A4)
