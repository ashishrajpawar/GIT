WhatsApp Features · Lesson 2

Group Chats

Group creation · Members array · Admin roles · Add/remove members · Group info screen ~60 min Hands-on
Why this matters for your WhatsApp clone

Group chats are how families, friend circles, and work teams communicate on WhatsApp. A group has a name, an optional avatar, a list of members, and one or more admins who control who can join or be removed. Messages sent to the group appear for all members in real time. This lesson builds the Firestore data model for groups, the "Create Group" flow (pick members, set name), admin permissions, and the group info screen where you manage members — the same screens you use every day in the real WhatsApp.

1. Group chat data model

A group chat is a document in the /chats collection (same collection as 1:1 chats from Module 3) but with extra fields to mark it as a group:

// Firestore document: /chats/groupChat123
{
  id: 'groupChat123',
  type: 'group',                    // 'private' for 1:1, 'group' for groups
  name: 'Family Group',
  photoURL: null,                   // optional group avatar
  members: ['uid1', 'uid2', 'uid3', 'uid4'],
  admins: ['uid1'],                 // subset of members who can manage the group
  createdBy: 'uid1',
  createdAt: Timestamp,
  lastMessage: {
    text: 'Priya: See you at dinner!',
    timestamp: Timestamp,
  },
}

Key design decisions:

  • Same /chats collection — both 1:1 and group chats live in one collection. The type field distinguishes them. This means your existing chat list query already picks up group chats.
  • members array — stores UIDs of everyone in the group. Firestore's array-contains query lets you find all chats a user belongs to.
  • admins array — a subset of members. The creator is always the first admin. Admins can add/remove members and change the group name/photo.
  • lastMessage — for group chats, the text is prefixed with the sender's name so the chat list shows "Priya: See you at dinner!" instead of just the message.

2. Creating a group

The flow is: user taps "New Group" → selects members from contacts → sets a group name → done. Here's the Firestore write:

import { collection, doc, setDoc, serverTimestamp } from 'firebase/firestore';
import { db, auth } from './firebaseConfig';

async function createGroup(groupName, selectedMemberUids) {
  const currentUid = auth.currentUser.uid;

  // Always include the creator in the members list
  const allMembers = [currentUid, ...selectedMemberUids];

  // Generate a new document ID
  const chatRef = doc(collection(db, 'chats'));

  await setDoc(chatRef, {
    id: chatRef.id,
    type: 'group',
    name: groupName,
    photoURL: null,
    members: allMembers,
    admins: [currentUid],   // creator is the first admin
    createdBy: currentUid,
    createdAt: serverTimestamp(),
    lastMessage: {
      text: `${groupName} created`,
      timestamp: serverTimestamp(),
    },
  });

  return chatRef.id;
}

Why doc(collection(db, 'chats'))? This generates a new document reference with an auto-generated ID — but doesn't write yet. You then pass it to setDoc so you can include the ID inside the document itself (useful for navigation later).

3. Querying groups the current user belongs to

Your existing chat list from Module 3 already queries chats. You just need to make sure it uses array-contains on the members field — this returns both 1:1 and group chats:

import { collection, query, where, orderBy, onSnapshot } from 'firebase/firestore';

function useMyChatList(uid) {
  const [chats, setChats] = useState([]);

  useEffect(() => {
    if (!uid) return;

    const q = query(
      collection(db, 'chats'),
      where('members', 'array-contains', uid),
      orderBy('lastMessage.timestamp', 'desc')
    );

    const unsub = onSnapshot(q, (snapshot) => {
      const list = [];
      snapshot.forEach((docSnap) => list.push(docSnap.data()));
      setChats(list);
    });

    return unsub;
  }, [uid]);

  return chats;
}

This single query returns everything — private chats and group chats mixed together, sorted by most recent message. In your chat list UI, you can tell them apart by checking chat.type === 'group' to show the group name/avatar instead of the other user's info.

4. Sending messages to a group

Sending a message to a group is almost identical to a 1:1 chat (Module 3 Lesson 4). The only difference is updating lastMessage with the sender's name prefixed:

import { collection, addDoc, doc, updateDoc, serverTimestamp } from 'firebase/firestore';

async function sendGroupMessage(chatId, text, senderName) {
  // 1. Add message to the /chats/{chatId}/messages subcollection
  await addDoc(collection(db, 'chats', chatId, 'messages'), {
    text: text,
    senderId: auth.currentUser.uid,
    senderName: senderName,   // stored so we can display it in the bubble
    timestamp: serverTimestamp(),
    type: 'text',
  });

  // 2. Update lastMessage on the chat document (for chat list preview)
  await updateDoc(doc(db, 'chats', chatId), {
    lastMessage: {
      text: `${senderName}: ${text}`,
      timestamp: serverTimestamp(),
    },
  });
}

Why store senderName in each message? In a group, messages from different people appear in the same thread. You need to show "Priya" or "Rahul" above each bubble. Storing the name avoids an extra Firestore read per message to look up the sender's profile.

5. Displaying group messages with sender names

In a 1:1 chat, you only show "me" (right) or "them" (left). In a group chat, each left-side bubble also needs the sender's name in a distinct colour:

// Simple colour assignment based on sender
const SENDER_COLOURS = ['#075E54', '#E91E63', '#9C27B0', '#FF5722', '#3F51B5', '#009688'];

function getSenderColour(senderId, membersList) {
  const index = membersList.indexOf(senderId);
  return SENDER_COLOURS[index % SENDER_COLOURS.length];
}

// Inside your message bubble component:
function MessageBubble({ message, isMe, chatType, members }) {
  const showSenderName = chatType === 'group' && !isMe;

  return (
    <View style={[styles.bubble, isMe ? styles.sentBubble : styles.receivedBubble]}>
      {showSenderName && (
        <Text style={[styles.senderName, { color: getSenderColour(message.senderId, members) }]}>
          {message.senderName}
        </Text>
      )}
      <Text style={styles.messageText}>{message.text}</Text>
      <Text style={styles.timestamp}>
        {message.timestamp?.toDate().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })}
      </Text>
    </View>
  );
}

This matches WhatsApp exactly — each sender gets a consistent colour so you can visually track who's saying what without reading the name every time.

6. Admin permissions — add and remove members

Only admins can modify the group. Before any admin action, check the current user is in the admins array:

import { doc, updateDoc, arrayUnion, arrayRemove } from 'firebase/firestore';

// Add a member to the group
async function addMember(chatId, newMemberUid, currentUid, admins) {
  if (!admins.includes(currentUid)) {
    throw new Error('Only admins can add members');
  }
  await updateDoc(doc(db, 'chats', chatId), {
    members: arrayUnion(newMemberUid),
  });
}

// Remove a member from the group
async function removeMember(chatId, memberUid, currentUid, admins) {
  if (!admins.includes(currentUid)) {
    throw new Error('Only admins can remove members');
  }
  // Also remove from admins if they were one
  await updateDoc(doc(db, 'chats', chatId), {
    members: arrayRemove(memberUid),
    admins: arrayRemove(memberUid),
  });
}

// Make someone an admin
async function makeAdmin(chatId, memberUid, currentUid, admins) {
  if (!admins.includes(currentUid)) {
    throw new Error('Only admins can promote members');
  }
  await updateDoc(doc(db, 'chats', chatId), {
    admins: arrayUnion(memberUid),
  });
}

// Update group name (admin only)
async function updateGroupName(chatId, newName, currentUid, admins) {
  if (!admins.includes(currentUid)) {
    throw new Error('Only admins can change the group name');
  }
  await updateDoc(doc(db, 'chats', chatId), {
    name: newName,
  });
}

arrayUnion and arrayRemove are Firestore helpers that add/remove a value from an array field without overwriting the whole array. They're atomic — if two admins add members at the same instant, both additions succeed without conflicts.

Client-side vs server-side checks

The admin check above is client-side — a malicious user could bypass it. For a production app, you'd use Firestore Security Rules to enforce it server-side. For now, client-side checks are fine for learning. We'll cover security rules when we polish the app in Module 6.

7. Leaving a group

Any member can leave a group. If the last admin leaves, the next member becomes admin automatically:

async function leaveGroup(chatId, currentUid, members, admins) {
  const updates = {
    members: arrayRemove(currentUid),
    admins: arrayRemove(currentUid),
  };

  // If current user is the only admin and there are other members,
  // promote the next member to admin
  if (admins.includes(currentUid) && admins.length === 1 && members.length > 1) {
    const nextAdmin = members.find((uid) => uid !== currentUid);
    updates.admins = arrayUnion(nextAdmin);
    // Note: we need two writes because arrayRemove and arrayUnion
    // on the same field in one call conflict
    await updateDoc(doc(db, 'chats', chatId), { admins: arrayRemove(currentUid) });
    await updateDoc(doc(db, 'chats', chatId), {
      members: arrayRemove(currentUid),
      admins: arrayUnion(nextAdmin),
    });
    return;
  }

  await updateDoc(doc(db, 'chats', chatId), updates);
}

8. The "Create Group" flow — selecting members

WhatsApp's create-group flow has two steps: (1) select members, (2) set the group name. Here's the member selection screen:

function SelectMembersScreen({ navigation }) {

  const [selected, setSelected] = useState([]);

                <Text style={styles.avatarLetter}>

}

// ─── Set Group Name Screen ──────────────────────────────────────────
function SetGroupNameScreen({ route, navigation }) {
  const { memberUids } = route.params;
  const [groupName, setGroupName] = useState('');
  const [creating, setCreating] = useState(false);

  async function handleCreate() {
    if (groupName.trim() === '') {
      Alert.alert('Error', 'Please enter a group name');
      return;
    }
    setCreating(true);

    const currentUid = auth.currentUser.uid;
    const allMembers = [currentUid, ...memberUids];
    const chatRef = doc(collection(db, 'chats'));

    await setDoc(chatRef, {
      id: chatRef.id,
      type: 'group',
      name: groupName.trim(),
      photoURL: null,
      members: allMembers,

      createdBy: currentUid,
      createdAt: serverTimestamp(),

        text: `Group "${groupName.trim()}" created`,
        timestamp: serverTimestamp(),

    navigation.popToTop();

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Pressable onPress={() => navigation.goBack()}>
          <Text style={styles.backBtn}>←</Text>
        </Pressable>

// ─── Group Thread Screen ────────────────────────────────────────────
function GroupThreadScreen({ route, navigation }) {
  const { chat } = route.params;
  const [messages, setMessages] = useState([]);
  const [text, setText] = useState('');
  const [myName, setMyName] = useState('');

  useEffect(() => {
    // Get current user's display name
    async function loadName() {
      const snap = await getDoc(doc(db, 'users', auth.currentUser.uid));
      if (snap.exists()) setMyName(snap.data().displayName);
    }
    loadName();

    // Listen to messages
    const q = query(
      collection(db, 'chats', chat.id, 'messages'),
      orderBy('timestamp', 'asc')
    );
    const unsub = onSnapshot(q, (snapshot) => {
      const msgs = [];
      snapshot.forEach((docSnap) => msgs.push({ id: docSnap.id, ...docSnap.data() }));
      setMessages(msgs);
    });
    return unsub;
  }, []);

  async function sendMessage() {
    if (text.trim() === '') return;
    const messageText = text.trim();
    setText('');

    await addDoc(collection(db, 'chats', chat.id, 'messages'), {
      text: messageText,
      senderId: auth.currentUser.uid,
      senderName: myName,
      timestamp: serverTimestamp(),
      type: 'text',
    });

    await updateDoc(doc(db, 'chats', chat.id), {
      lastMessage: {
        text: `${myName}: ${messageText}`,
        timestamp: serverTimestamp(),
      },
    });
  }

  const currentUid = auth.currentUser.uid;

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Pressable onPress={() => navigation.goBack()}>
          <Text style={styles.backBtn}>←</Text>
        </Pressable>
        <Pressable
          style={{ flex: 1 }}
          onPress={() => navigation.navigate('GroupInfo', { chat })}
        >
          <Text style={styles.headerTitle}>{chat.name}</Text>
          <Text style={styles.headerSubtitle}>
            {chat.members.length} members
          </Text>
        </Pressable>
      </View>

      <FlatList
        data={messages}
        keyExtractor={(item) => item.id}
        style={styles.messageList}
        renderItem={({ item }) => {
          const isMe = item.senderId === currentUid;
          return (
            <View style={[styles.bubble, isMe ? styles.sentBubble : styles.receivedBubble]}>
              {!isMe && (
                <Text style={[styles.senderLabel, { color: getSenderColour(item.senderId, chat.members) }]}>
                  {item.senderName}
                </Text>
              )}
              <Text style={styles.messageText}>{item.text}</Text>
              <Text style={styles.timeText}>
                {item.timestamp?.toDate().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })}
              </Text>
            </View>
          );
        }}
        ListEmptyComponent={
          <Text style={styles.emptyText}>No messages yet. Say hello!</Text>
        }
      />

      <View style={styles.inputBar}>
        <TextInput
          style={styles.messageInput}
          value={text}
          onChangeText={setText}
          placeholder="Type a message"
          multiline
        />
        <Pressable style={styles.sendBtn} onPress={sendMessage}>
          <Text style={styles.sendBtnText}>Send</Text>
        </Pressable>
      </View>
    </View>
  );
}

// ─── Group Info Screen ──────────────────────────────────────────────
function GroupInfoScreen({ route, navigation }) {
  const { chat } = route.params;
  const [memberProfiles, setMemberProfiles] = useState([]);
  const currentUid = auth.currentUser.uid;
  const isAdmin = chat.admins.includes(currentUid);

  useEffect(() => {
    async function loadMembers() {
      const profiles = [];
      for (const uid of chat.members) {
        const snap = await getDoc(doc(db, 'users', uid));
        if (snap.exists()) profiles.push(snap.data());
      }
      setMemberProfiles(profiles);
    }
    loadMembers();
  }, []);

  async function handleRemove(uid) {
    Alert.alert('Remove member', 'Are you sure?', [
      { text: 'Cancel' },
      {
        text: 'Remove',
        style: 'destructive',
        onPress: async () => {
          await updateDoc(doc(db, 'chats', chat.id), {
            members: arrayRemove(uid),
            admins: arrayRemove(uid),
          });
          setMemberProfiles((prev) => prev.filter((p) => p.uid !== uid));
        },
      },
    ]);
  }

  async function handleLeave() {
    Alert.alert('Leave group', 'Are you sure you want to leave?', [
      { text: 'Cancel' },
      {
        text: 'Leave',
        style: 'destructive',
        onPress: async () => {
          await updateDoc(doc(db, 'chats', chat.id), {
            members: arrayRemove(currentUid),
            admins: arrayRemove(currentUid),
          });
          navigation.popToTop();
        },
      },
    ]);
  }

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Pressable onPress={() => navigation.goBack()}>
          <Text style={styles.backBtn}>←</Text>
        </Pressable>
        <Text style={styles.headerTitle}>Group Info</Text>
      </View>

      <View style={styles.groupInfoTop}>
        <View style={styles.bigAvatarPlaceholder}>
          <Text style={styles.bigAvatarLetter}>{chat.name.charAt(0).toUpperCase()}</Text>
        </View>
        <Text style={styles.groupInfoName}>{chat.name}</Text>
        <Text style={styles.groupInfoSub}>Group · {chat.members.length} members</Text>
      </View>

      <Text style={styles.sectionTitle}>Members</Text>
      <FlatList
        data={memberProfiles}
        keyExtractor={(item) => item.uid}
        renderItem={({ item }) => (
          <View style={styles.memberRow}>
            <View style={styles.avatarPlaceholder}>
              <Text style={styles.avatarLetter}>
                {item.displayName.charAt(0).toUpperCase()}
              </Text>
            </View>
            <View style={styles.contactInfo}>
              <Text style={styles.contactName}>
                {item.displayName}
                {item.uid === currentUid ? ' (You)' : ''}
              </Text>
              <Text style={styles.contactAbout}>
                {chat.admins.includes(item.uid) ? 'Admin' : 'Member'}
              </Text>
            </View>
            {isAdmin && item.uid !== currentUid && (
              <Pressable onPress={() => handleRemove(item.uid)}>
                <Text style={styles.removeBtn}>Remove</Text>
              </Pressable>
            )}
          </View>
        )}
      />

      <Pressable style={styles.leaveBtn} onPress={handleLeave}>
        <Text style={styles.leaveBtnText}>Leave Group</Text>
      </Pressable>
    </View>
  );
}
