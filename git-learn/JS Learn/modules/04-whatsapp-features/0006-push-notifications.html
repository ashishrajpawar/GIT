WhatsApp Features · Lesson 6

Push Notifications

expo-notifications · FCM (Android) · APNs (iOS) · Token storage · Navigate on tap ~55 min Hands-on
Why this matters for your WhatsApp clone

When someone sends you a WhatsApp message and your phone is locked, you still see "Priya: Hey, are you free tonight?" on your lock screen. That's a push notification — delivered by Google (FCM) on Android and Apple (APNs) on iOS even when the app is closed. Without push notifications, your users would never know they received a message until they manually open the app. This lesson sets up expo-notifications, stores device tokens in Firestore, sends notifications when new messages arrive, and navigates to the correct chat when the user taps the notification.

1. How push notifications work

The flow involves three parties: your app, a push service (FCM or APNs), and the recipient's device:

┌─────────────┐     ┌─────────────────────┐     ┌──────────────┐
│  Sender's   │     │  Push Service        │     │  Recipient's │
│  device     │────▶│  (FCM for Android,   │────▶│  device      │
│             │     │   APNs for iOS)      │     │              │
└─────────────┘     └─────────────────────┘     └──────────────┘
      │                                                │
      │  1. Send message to Firestore                  │
      │  2. Trigger notification (Cloud Function       │
      │     or REST API call)                          │
      │  3. Push service delivers to device            │
      │  4. Device shows lock-screen notification      │
      └────────────────────────────────────────────────┘

Key concepts:

  • Push token — a unique string identifying a specific device. Each device gets its own token. You store it in Firestore so you know where to send notifications.
  • FCM (Firebase Cloud Messaging) — Google's free push service. Handles Android natively and can also relay to APNs for iOS.
  • APNs (Apple Push Notification service) — Apple's push service. On iOS, FCM talks to APNs behind the scenes.
  • Expo Push Service — a free proxy from Expo that lets you send to both FCM and APNs with one API call using Expo push tokens.

2. Installing and configuring expo-notifications

npx expo install expo-notifications expo-device expo-constants

Add notification configuration to your app.json:

// app.json (inside "expo" key)
{
  "expo": {
    "plugins": [
      [
        "expo-notifications",
        {
          "icon": "./assets/notification-icon.png",
          "color": "#075E54"
        }
      ]
    ],
    "android": {
      "useNextNotificationsApi": true
    },
    "ios": {
      "bundleIdentifier": "com.yourname.whatsappclone"
    }
  }
}
Platform requirements

Android: Push notifications work on physical devices and emulators with Google Play Services. No extra setup needed for FCM — Expo handles it.
iOS: Push notifications do NOT work in the iOS Simulator. You must test on a physical iPhone. You also need an Apple Developer account ($99/year) and must configure APNs credentials in your Expo dashboard.

3. Requesting permission and getting the push token

Before you can receive notifications, you must ask the user for permission and get their device's push token:

import * as Notifications from 'expo-notifications';
import * as Device from 'expo-device';
import Constants from 'expo-constants';
import { Platform } from 'react-native';

async function registerForPushNotifications() {
  // Push notifications only work on physical devices
  if (!Device.isDevice) {
    Alert.alert('Error', 'Push notifications require a physical device');
    return null;
  }

  // Check existing permission
  const { status: existingStatus } = await Notifications.getPermissionsAsync();
  let finalStatus = existingStatus;

  // If not granted, ask for permission
  if (existingStatus !== 'granted') {
    const { status } = await Notifications.requestPermissionsAsync();
    finalStatus = status;
  }

  if (finalStatus !== 'granted') {
    Alert.alert('Permission denied', 'Enable notifications in Settings to receive messages');
    return null;
  }

  // Get the Expo push token
  const tokenData = await Notifications.getExpoPushTokenAsync({
    projectId: Constants.expoConfig?.extra?.eas?.projectId,
  });

  // Android: set up notification channel
  if (Platform.OS === 'android') {
    await Notifications.setNotificationChannelAsync('messages', {
      name: 'Messages',
      importance: Notifications.AndroidImportance.HIGH,
      vibrationPattern: [0, 250, 250, 250],
      lightColor: '#25D366',
      sound: 'default',
    });
  }

  return tokenData.data; // e.g. "ExponentPushToken[xxxxxxxxxxxxxxxxxxxxxx]"
}

What is an Expo push token? It's a wrapper around the native FCM/APNs token. Expo's push service accepts this token and routes the notification to the correct platform. You don't need to handle FCM and APNs separately.

4. Storing the push token in Firestore

Once you have the token, store it in the user's profile document so you can look it up when sending notifications to them:

import { doc, updateDoc, arrayUnion } from 'firebase/firestore';

async function savePushToken(uid, token) {
  // Store as an array — a user might have multiple devices
  await updateDoc(doc(db, 'users', uid), {
    pushTokens: arrayUnion(token),
  });
}

// Call after login/register:
async function setupNotifications(uid) {
  const token = await registerForPushNotifications();
  if (token) {
    await savePushToken(uid, token);
  }
}

Why an array? A user might be logged in on both their phone and tablet. Each device has a different push token. When a message arrives, you send notifications to ALL their devices.

5. Sending a push notification

When a message is sent, you trigger a notification to the recipient. The simplest approach uses the Expo Push API directly from the sender's device:

async function sendPushNotification(recipientTokens, senderName, messageText, chatId) {
  // Build the notification payload for each device token
  const messages = recipientTokens.map((token) => ({
    to: token,
    sound: 'default',
    title: senderName,
    body: messageText,
    data: { chatId: chatId, type: 'new_message' },
  }));

  // Send to Expo's push service
  await fetch('https://exp.host/--/api/v2/push/send', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
    },
    body: JSON.stringify(messages),
  });
}

The data field is crucial — it carries metadata that your app reads when the user taps the notification. Here we include chatId so we know which chat to open.

Client-side vs Cloud Function

Sending from the client works for learning but has issues: (1) the sender needs the recipient's push tokens, (2) if the sender's app closes before the fetch completes, the notification won't send. In production, you'd use a Firebase Cloud Function triggered by a Firestore write — when a new message document is created, the function sends the push. We'll cover Cloud Functions in Module 6.

6. Integrating with your message-send flow

Here's how to trigger a notification after sending a message:

async function sendMessageWithNotification(chatId, text, senderName, recipientUids) {
  // 1. Save message to Firestore (existing code from Module 3)
  await addDoc(collection(db, 'chats', chatId, 'messages'), {
    text: text,
    senderId: auth.currentUser.uid,
    senderName: senderName,
    timestamp: serverTimestamp(),
    type: 'text',
    readBy: [auth.currentUser.uid],
    reactions: {},
    deletedFor: [],
    deletedForEveryone: false,
  });

  // 2. Update lastMessage
  await updateDoc(doc(db, 'chats', chatId), {
    lastMessage: { text: `${senderName}: ${text}`, timestamp: serverTimestamp() },
  });

  // 3. Get recipient push tokens and send notifications
  const currentUid = auth.currentUser.uid;
  const recipients = recipientUids.filter((uid) => uid !== currentUid);

  for (const uid of recipients) {
    const userSnap = await getDoc(doc(db, 'users', uid));
    if (userSnap.exists()) {
      const tokens = userSnap.data().pushTokens || [];
      if (tokens.length > 0) {
        await sendPushNotification(tokens, senderName, text, chatId);
      }
    }
  }
}

7. Handling notifications when the app is open

When a notification arrives and the app is in the foreground, you probably don't want to show a banner (since the user is already looking at the chat). Configure this behaviour:

import * as Notifications from 'expo-notifications';

// Set how notifications behave when app is in foreground
Notifications.setNotificationHandler({
  handleNotification: async (notification) => {
    // You can check if user is already viewing this chat
    const chatId = notification.request.content.data?.chatId;

    // For now: show the notification if user is NOT in that chat
    return {
      shouldShowAlert: true,    // show banner
      shouldPlaySound: true,    // play sound
      shouldSetBadge: true,     // update app badge count (iOS)
    };
  },
});

In a polished app, you'd suppress the notification if the user is currently viewing the exact chat that the message was sent to. You can track which chat screen is open using a global ref or context.

8. Navigating to the chat when user taps a notification

This is the critical part — when the user taps a notification on their lock screen, your app should open directly to the relevant chat:

import * as Notifications from 'expo-notifications';
import { useRef, useEffect } from 'react';
import { useNavigation } from '@react-navigation/native';

function useNotificationNavigation() {
  const navigationRef = useRef(null);

  useEffect(() => {
    // Handle notification tap when app was in background/closed
    const subscription = Notifications.addNotificationResponseReceivedListener(
      (response) => {
        const data = response.notification.request.content.data;

        if (data?.chatId && data?.type === 'new_message') {
          // Navigate to the message thread
          navigationRef.current?.navigate('MessageThread', { chatId: data.chatId });
        }
      }
    );

    return () => subscription.remove();
  }, []);

  return navigationRef;
}

// In your App component, pass the ref to NavigationContainer:
function App() {
  const navigationRef = useNotificationNavigation();

  return (
    <NavigationContainer ref={navigationRef}>
      {/* ... your navigator stack */}
    </NavigationContainer>
  );
}

Two listener types:

  • addNotificationReceivedListener — fires when a notification arrives (even if user doesn't tap it). Use for updating badge counts or in-app indicators.
  • addNotificationResponseReceivedListener — fires when the user taps the notification. This is where you navigate.

9. Handling the "app was closed" case

If the app was completely closed when the notification arrives, the response listener won't fire immediately. You need to check for a "last notification response" on startup:

useEffect(() => {
  // Check if app was opened from a notification tap
  Notifications.getLastNotificationResponseAsync().then((response) => {
    if (response) {
      const data = response.notification.request.content.data;
      if (data?.chatId) {
        // Delay navigation slightly to let the navigator mount
        setTimeout(() => {
          navigationRef.current?.navigate('MessageThread', { chatId: data.chatId });
        }, 500);
      }
    }
  });
}, []);

10. Removing tokens on logout

When a user logs out, remove their push token so they stop receiving notifications on that device:

import { doc, updateDoc, arrayRemove } from 'firebase/firestore';
import * as Notifications from 'expo-notifications';

async function logout() {
  const uid = auth.currentUser.uid;

  // Get the current device's token
  const tokenData = await Notifications.getExpoPushTokenAsync({
    projectId: Constants.expoConfig?.extra?.eas?.projectId,
  });

  // Remove this device's token from Firestore
  await updateDoc(doc(db, 'users', uid), {
    pushTokens: arrayRemove(tokenData.data),
  });

  // Sign out
  await auth.signOut();
}

11. Badge count management (iOS)

On iOS, the red badge number on the app icon shows unread messages. Manage it with:

import * as Notifications from 'expo-notifications';

// Set badge count (e.g. when new messages arrive)
await Notifications.setBadgeCountAsync(5);

// Clear badge when user opens the app
await Notifications.setBadgeCountAsync(0);

// Typically clear in your App component:
useEffect(() => {
  // Clear badge every time app comes to foreground
  const subscription = AppState.addEventListener('change', (state) => {
    if (state === 'active') {
      Notifications.setBadgeCountAsync(0);
    }
  });
  return () => subscription.remove();
}, []);
Android badges

Android doesn't have a universal badge API — it depends on the launcher. Some launchers (Samsung, Huawei) support badges via notification channels. The shouldSetBadge: true in the notification handler is the best you can do on Android.

// ─── Send push notification ─────────────────────────────────────────
async function sendPushNotification(tokens, title, body, data) {
  const messages = tokens.map((token) => ({
    to: token,
    sound: 'default',
    title,
    body,
    data,
    channelId: 'messages',
  }));

  try {
    await fetch('https://exp.host/--/api/v2/push/send', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify(messages),
    });
  } catch (err) {
    console.log('Failed to send push:', err);
  }
}

// ─── Chat List Screen ───────────────────────────────────────────────
function ChatListScreen({ navigation }) {
  const [chats, setChats] = useState([]);
  const currentUid = auth.currentUser.uid;

  useEffect(() => {
    const q = query(
      collection(db, 'chats'),
      where('members', 'array-contains', currentUid),
      orderBy('lastMessage.timestamp', 'desc')
    );
    const unsub = onSnapshot(q, (snapshot) => {
      const list = [];
      snapshot.forEach((docSnap) => list.push(docSnap.data()));
      setChats(list);
    });
    return unsub;
  }, []);

  async function handleLogout() {
    try {
      const tokenData = await Notifications.getExpoPushTokenAsync({
        projectId: Constants.expoConfig?.extra?.eas?.projectId,
      });
      await updateDoc(doc(db, 'users', currentUid), {
        pushTokens: arrayRemove(tokenData.data),
        online: false,
        lastSeen: serverTimestamp(),
      });
    } catch (e) {}
    await signOut(auth);
  }

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Chats</Text>
        <Pressable onPress={handleLogout}>
          <Text style={styles.logoutBtn}>Logout</Text>
        </Pressable>
      </View>

      <FlatList
        data={chats}
        keyExtractor={(item) => item.id}
        renderItem={({ item }) => (
          <Pressable
            style={styles.chatRow}
            onPress={() => navigation.navigate('MessageThread', { chatId: item.id, chat: item })}
          >
            <View style={styles.avatarCircle}>
              <Text style={styles.avatarLetter}>
                {(item.name || 'C').charAt(0).toUpperCase()}
              </Text>
            </View>
            <View style={styles.chatInfo}>
              <Text style={styles.chatName}>{item.name || 'Chat'}</Text>
              <Text style={styles.chatPreview} numberOfLines={1}>
                {item.lastMessage?.text || 'No messages'}
              </Text>
            </View>
          </Pressable>
        )}
        ListEmptyComponent={
          <Text style={styles.emptyText}>No chats yet</Text>
        }
      />
    </View>
  );
}

// ─── Message Thread Screen ──────────────────────────────────────────
function MessageThreadScreen({ route }) {
  const { chatId, chat } = route.params;
  const [messages, setMessages] = useState([]);
  const [text, setText] = useState('');
  const [myName, setMyName] = useState('');
  const currentUid = auth.currentUser.uid;
  const flatListRef = useRef(null);

  useEffect(() => {
    async function loadName() {
      const snap = await getDoc(doc(db, 'users', currentUid));
      if (snap.exists()) setMyName(snap.data().displayName);
      else setMyName('User');
    }
    loadName();

    const q = query(
      collection(db, 'chats', chatId, 'messages'),
      orderBy('timestamp', 'asc')
    );
    const unsub = onSnapshot(q, (snapshot) => {
      const msgs = [];
      snapshot.forEach((docSnap) => msgs.push({ id: docSnap.id, ...docSnap.data() }));
      setMessages(msgs);
    });
    return unsub;
  }, []);

  async function sendMessage() {
    if (text.trim() === '') return;
    const msgText = text.trim();
    setText('');

    await addDoc(collection(db, 'chats', chatId, 'messages'), {
      text: msgText,
      senderId: currentUid,
      senderName: myName,
      timestamp: serverTimestamp(),
      type: 'text',
      readBy: [currentUid],
      reactions: {},
      deletedFor: [],
      deletedForEveryone: false,
    });

    await updateDoc(doc(db, 'chats', chatId), {
      lastMessage: { text: `${myName}: ${msgText}`, timestamp: serverTimestamp() },
    });

    // Send push to other members
    const members = chat?.members || [];
    const recipients = members.filter((uid) => uid !== currentUid);
    for (const uid of recipients) {
      const userSnap = await getDoc(doc(db, 'users', uid));
      if (userSnap.exists()) {
        const tokens = userSnap.data().pushTokens || [];
        if (tokens.length > 0) {
          await sendPushNotification(
            tokens,
            myName,
            msgText,
            { chatId: chatId, type: 'new_message' }
          );
        }
      }
    }
  }

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.headerTitle}>{chat?.name || 'Chat'}</Text>
      </View>

      <FlatList
        ref={flatListRef}
        data={messages}
        keyExtractor={(item) => item.id}
        style={styles.messageList}
        onContentSizeChange={() => flatListRef.current?.scrollToEnd()}
        renderItem={({ item }) => {
          const isMe = item.senderId === currentUid;
          return (
            <View style={[styles.bubble, isMe ? styles.sent : styles.received]}>
              {!isMe && <Text style={styles.senderLabel}>{item.senderName}</Text>}
              <Text style={styles.msgText}>{item.text}</Text>
              <Text style={styles.timeText}>
                {item.timestamp?.toDate().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })}
              </Text>
            </View>
          );
        }}
        ListEmptyComponent={
          <Text style={styles.emptyText}>Send the first message!</Text>
        }
      />

      <View style={styles.inputBar}>
        <TextInput
          style={styles.input}
          value={text}
          onChangeText={setText}
          placeholder="Type a message"
          multiline
        />
        <Pressable style={styles.sendBtn} onPress={sendMessage}>
          <Text style={styles.sendText}>Send</Text>
        </Pressable>
      </View>
    </View>
  );
}

// ─── App Entry ──────────────────────────────────────────────────────
const Stack = createNativeStackNavigator();

export default function App() {
  const [user, setUser] = useState(null);
  const navigationRef = useRef(null);

  // Auth listener
  useEffect(() => {
    const unsub = onAuthStateChanged(auth, (u) => setUser(u));
    return unsub;
  }, []);

  // Register push token after login
  useEffect(() => {
    if (!user) return;

    async function setup() {
      const token = await registerForPushNotifications();
      if (token) {
        await updateDoc(doc(db, 'users', user.uid), {
          pushTokens: arrayUnion(token),
        });
      }
    }
    setup();
  }, [user]);

  // Clear badge when app becomes active
  useEffect(() => {
    const sub = AppState.addEventListener('change', (state) => {
      if (state === 'active') {
        Notifications.setBadgeCountAsync(0);
      }
    });
    return () => sub.remove();
  }, []);

  // Handle notification tap → navigate to chat
  useEffect(() => {
    const subscription = Notifications.addNotificationResponseReceivedListener(
      (response) => {
        const data = response.notification.request.content.data;
        if (data?.chatId && data?.type === 'new_message') {
          setTimeout(() => {
            navigationRef.current?.navigate('MessageThread', {
              chatId: data.chatId,
              chat: { id: data.chatId, name: 'Chat', members: [] },
            });
          }, 300);
        }
      }
    );
    return () => subscription.remove();
  }, []);

  // Check if app was opened from notification (cold start)
  useEffect(() => {
    Notifications.getLastNotificationResponseAsync().then((response) => {
      if (response) {
        const data = response.notification.request.content.data;
        if (data?.chatId) {
          setTimeout(() => {
            navigationRef.current?.navigate('MessageThread', {
              chatId: data.chatId,
              chat: { id: data.chatId, name: 'Chat', members: [] },
            });
          }, 1000);
        }
      }
    });
  }, []);

  if (!user) {
    return (
      <View style={[styles.container, { justifyContent: 'center', alignItems: 'center' }]}>
        <Text style={{ fontSize: 18, color: '#667781' }}>
          Please log in (Module 3 Lesson 2)
        </Text>
      </View>
    );
  }

  return (
    <NavigationContainer ref={navigationRef}>
      <Stack.Navigator screenOptions={{ headerShown: false }}>
        <Stack.Screen name="ChatList" component={ChatListScreen} />
        <Stack.Screen name="MessageThread" component={MessageThreadScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}
