WhatsApp Features · Lesson 5

Status (Stories)

24-hour expiry · Image/text status · Viewer list · Status ring · Auto-advance ~55 min Hands-on
Why this matters for your WhatsApp clone

WhatsApp Status is the app's version of Stories — post a photo or text that disappears after 24 hours. Your contacts see a coloured ring around your avatar on the Status tab, tap to view, and you can see who viewed it. It's one of WhatsApp's most-used features with over 450 million daily users. This lesson builds the Firestore data model with automatic 24-hour expiry, the status posting flow (image upload or text card), the viewing screen with auto-advance timer, and the "seen by" list.

1. Status data model

Each status post is a document in a /statuses collection. A user can have multiple active statuses (like multiple story slides):

// Firestore document: /statuses/status123
{
  id: 'status123',
  uid: 'uid_priya',
  displayName: 'Priya Sharma',
  photoURL: 'https://...avatar.jpg',  // poster's avatar (for the ring)

  type: 'image',                       // 'image' or 'text'
  imageURL: 'https://...status.jpg',   // for image statuses
  caption: 'Beautiful sunset! 🌅',     // optional caption on images
  text: null,                          // for text statuses
  backgroundColor: null,               // for text statuses (e.g. '#075E54')

  createdAt: Timestamp,
  expiresAt: Timestamp,                // createdAt + 24 hours
  viewedBy: ['uid_rahul', 'uid_amit'], // who has seen this status
}

Key design decisions:

  • Flat collection — all statuses from all users in one /statuses collection. Query by UID to get one person's statuses.
  • expiresAt field — calculated at creation time (now + 24 hours). Your query filters out expired ones.
  • viewedBy array — tracks who tapped to view. The poster can see this list.
  • Two types — image statuses (photo + optional caption) and text statuses (coloured background + text). Same as WhatsApp.

2. Posting an image status

The flow: pick an image → upload to Firebase Storage → create a status document with 24-hour expiry:

import { collection, doc, setDoc, serverTimestamp, Timestamp } from 'firebase/firestore';
import { ref, uploadBytesResumable, getDownloadURL } from 'firebase/storage';

async function postImageStatus(localImageUri, caption) {
  const currentUser = auth.currentUser;

  // 1. Upload image to Storage
  const response = await fetch(localImageUri);
  const blob = await response.blob();
  const filename = `status_${Date.now()}.jpg`;
  const storageRef = ref(storage, `statuses/${currentUser.uid}/${filename}`);

  const uploadTask = uploadBytesResumable(storageRef, blob);
  await new Promise((resolve, reject) => {
    uploadTask.on('state_changed', null, reject, resolve);
  });
  const imageURL = await getDownloadURL(uploadTask.snapshot.ref);

  // 2. Calculate expiry: 24 hours from now
  const now = new Date();
  const expiresAt = Timestamp.fromDate(new Date(now.getTime() + 24 * 60 * 60 * 1000));

  // 3. Create the status document
  const statusRef = doc(collection(db, 'statuses'));
  await setDoc(statusRef, {
    id: statusRef.id,
    uid: currentUser.uid,
    displayName: currentUser.displayName || 'User',
    photoURL: currentUser.photoURL || null,
    type: 'image',
    imageURL: imageURL,
    caption: caption || null,
    text: null,
    backgroundColor: null,
    createdAt: serverTimestamp(),
    expiresAt: expiresAt,
    viewedBy: [],
  });
}

4. Querying active statuses

The Status tab shows contacts who have posted in the last 24 hours. You query for statuses that haven't expired yet:

import { collection, query, where, orderBy, onSnapshot, Timestamp } from 'firebase/firestore';

function useActiveStatuses() {
  const [statusGroups, setStatusGroups] = useState([]);

  useEffect(() => {
    const now = Timestamp.now();

    const q = query(
      collection(db, 'statuses'),
      where('expiresAt', '>', now),
      orderBy('expiresAt'),
      orderBy('createdAt', 'asc')
    );

    const unsub = onSnapshot(q, (snapshot) => {
      const allStatuses = [];
      snapshot.forEach((docSnap) => allStatuses.push(docSnap.data()));

      // Group statuses by user
      const grouped = {};
      allStatuses.forEach((status) => {
        if (!grouped[status.uid]) {
          grouped[status.uid] = {
            uid: status.uid,
            displayName: status.displayName,
            photoURL: status.photoURL,
            statuses: [],
            hasUnviewed: false,
          };
        }
        grouped[status.uid].statuses.push(status);
        if (!status.viewedBy.includes(auth.currentUser.uid)) {
          grouped[status.uid].hasUnviewed = true;
        }
      });

      // Convert to array, current user's status first
      const currentUid = auth.currentUser.uid;
      const myStatus = grouped[currentUid] || null;
      const otherStatuses = Object.values(grouped)
        .filter((g) => g.uid !== currentUid)
        .sort((a, b) => {
          // Unviewed statuses first
          if (a.hasUnviewed && !b.hasUnviewed) return -1;
          if (!a.hasUnviewed && b.hasUnviewed) return 1;
          return 0;
        });

      setStatusGroups({ myStatus, otherStatuses });
    });

    return unsub;
  }, []);

  return statusGroups;
}
Firestore composite index required

This query filters on expiresAt and sorts by createdAt. Firestore will show an error with a clickable link to create the composite index automatically. Click the link and wait ~1 minute for it to build.

6. The status viewer — auto-advancing slides

When you tap a contact's status, it opens full-screen and auto-advances every 5 seconds (like Instagram Stories). A progress bar at the top shows time remaining on each slide:

function StatusViewer({ statuses, onClose, currentUid }) {
  const [currentIndex, setCurrentIndex] = useState(0);
  const [progress, setProgress] = useState(0);
  const timerRef = useRef(null);
  const DURATION = 5000; // 5 seconds per status
  const INTERVAL = 50;   // update progress every 50ms

  const currentStatus = statuses[currentIndex];

  useEffect(() => {
    // Mark as viewed
    if (!currentStatus.viewedBy.includes(currentUid)) {
      updateDoc(doc(db, 'statuses', currentStatus.id), {
        viewedBy: arrayUnion(currentUid),
      });
    }

    // Start timer
    setProgress(0);
    let elapsed = 0;
    timerRef.current = setInterval(() => {
      elapsed += INTERVAL;
      setProgress(elapsed / DURATION);
      if (elapsed >= DURATION) {
        // Move to next or close
        if (currentIndex < statuses.length - 1) {
          setCurrentIndex((i) => i + 1);
        } else {
          onClose();
        }
      }
    }, INTERVAL);

    return () => clearInterval(timerRef.current);
  }, [currentIndex]);

  function goNext() {
    clearInterval(timerRef.current);
    if (currentIndex < statuses.length - 1) {
      setCurrentIndex((i) => i + 1);
    } else {
      onClose();
    }
  }

  function goPrev() {
    clearInterval(timerRef.current);
    if (currentIndex > 0) {
      setCurrentIndex((i) => i - 1);
    }
  }

  return (
    <View style={viewerStyles.container}>
      {/* Progress bars at top */}
      <View style={viewerStyles.progressRow}>
        {statuses.map((_, idx) => (
          <View key={idx} style={viewerStyles.progressTrack}>
            <View style={[
              viewerStyles.progressFill,
              {
                width: idx < currentIndex ? '100%'
                     : idx === currentIndex ? `${progress * 100}%`
                     : '0%',
              },
            ]} />
          </View>
        ))}
      </View>

      {/* Header: name + close */}
      <View style={viewerStyles.header}>
        <Text style={viewerStyles.name}>{currentStatus.displayName}</Text>
        <Pressable onPress={onClose}>
          <Text style={viewerStyles.closeBtn}>✕</Text>
        </Pressable>
      </View>

      {/* Content */}
      {currentStatus.type === 'image' ? (
        <Image source={{ uri: currentStatus.imageURL }} style={viewerStyles.image} resizeMode="contain" />
      ) : (
        <View style={[viewerStyles.textCard, { backgroundColor: currentStatus.backgroundColor }]}>
          <Text style={viewerStyles.statusText}>{currentStatus.text}</Text>
        </View>
      )}

      {/* Caption for images */}
      {currentStatus.caption && (
        <View style={viewerStyles.captionBox}>
          <Text style={viewerStyles.captionText}>{currentStatus.caption}</Text>
        </View>
      )}

      {/* Tap zones: left = prev, right = next */}
      <View style={viewerStyles.tapZones}>
        <Pressable style={viewerStyles.tapLeft} onPress={goPrev} />
        <Pressable style={viewerStyles.tapRight} onPress={goNext} />
      </View>
    </View>
  );
}

  progressTrack: { flex: 1, height: 3, backgroundColor: 'rgba(255,255,255,0.3)', borderRadius: 2, overflow: 'hidden' },
  progressFill: { height: '100%', backgroundColor: '#FFFFFF', borderRadius: 2 },

7. The "Seen by" list

When you view your own status, a swipe-up or eye icon shows who viewed it:

function SeenByList({ viewedBy }) {
  const [viewers, setViewers] = useState([]);

  useEffect(() => {
    async function loadViewers() {
      const profiles = [];
      for (const uid of viewedBy) {
        const snap = await getDoc(doc(db, 'users', uid));
        if (snap.exists()) profiles.push(snap.data());
      }
      setViewers(profiles);
    }
    if (viewedBy.length > 0) loadViewers();
  }, [viewedBy]);

  return (
    <View style={seenStyles.container}>
      <Text style={seenStyles.title}>Viewed by {viewedBy.length}</Text>
      {viewers.map((user) => (
        <View key={user.uid} style={seenStyles.row}>
          <View style={seenStyles.avatar}>
            <Text style={seenStyles.letter}>{user.displayName.charAt(0)}</Text>
          </View>
          <Text style={seenStyles.name}>{user.displayName}</Text>
        </View>
      ))}
      {viewedBy.length === 0 && (
        <Text style={seenStyles.empty}>No views yet</Text>
      )}
    </View>
  );
}

8. Cleaning up expired statuses

Expired statuses are filtered out by the query (where('expiresAt', '>', now)), but the documents still exist. For a production app you'd use a Cloud Function to delete them. For now, a simple cleanup function you can call periodically:

import { collection, query, where, getDocs, deleteDoc, Timestamp } from 'firebase/firestore';

async function cleanupExpiredStatuses() {
  const now = Timestamp.now();
  const q = query(
    collection(db, 'statuses'),
    where('expiresAt', '<=', now)
  );
  const snapshot = await getDocs(q);
  const deletePromises = [];
  snapshot.forEach((docSnap) => {
    deletePromises.push(deleteDoc(docSnap.ref));
  });
  await Promise.all(deletePromises);
  console.log(`Cleaned up ${deletePromises.length} expired statuses`);
}
Production approach

In Module 6 (Polish & Publish), you'll deploy a Firebase Cloud Function that runs on a schedule (every hour) to automatically delete expired statuses and their images from Storage. For now, the client-side query filter is sufficient — expired statuses simply won't appear.

        </Pressable>
      </View>

      {/* Viewer modal */}
      <Modal visible={viewingStatuses !== null} animationType="fade">
        {viewingStatuses && (
          <StatusViewer statuses={viewingStatuses} onClose={() => setViewingStatuses(null)} />
        )}
      </Modal>

      {/* Text composer modal */}
      <Modal visible={showComposer} animationType="slide">
        <View style={[styles.composer, { backgroundColor: composerBg }]}>
          <View style={styles.composerHeader}>
            <Pressable onPress={() => setShowComposer(false)}>
              <Text style={styles.composerClose}>✕</Text>
            </Pressable>
            <Pressable onPress={postTextStatus}>
              <Text style={styles.composerSend}>Post</Text>
            </Pressable>
          </View>

          <TextInput
            style={styles.composerInput}
            value={composerText}
            onChangeText={setComposerText}
            placeholder="Type a status..."
            placeholderTextColor="rgba(255,255,255,0.6)"
            multiline
            autoFocus
          />

          <View style={styles.colourRow}>
            {STATUS_COLOURS.map((colour) => (
              <Pressable
                key={colour}
                style={[styles.colourDot, { backgroundColor: colour }, composerBg === colour && styles.colourDotActive]}
                onPress={() => setComposerBg(colour)}
              />
            ))}
          </View>
        </View>
      </Modal>
    </View>
  );
}
