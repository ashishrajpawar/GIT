WhatsApp Features · Lesson 3

Message Features

Reply to message · Delete for me/everyone · Emoji reactions · Read receipts ~60 min Hands-on
Why this matters for your WhatsApp clone

Open any WhatsApp conversation and long-press a message — you get options to reply, react with an emoji, or delete. Swipe right on a message to quote-reply it. These aren't luxury features — they're what makes group conversations followable and what lets you unsend that embarrassing typo. This lesson adds reply-to-message (with the quoted bubble), delete for me vs delete for everyone, emoji reactions that appear below the bubble, and read receipts (blue ticks) so senders know their message was seen.

1. Message document — extended data model

We extend the message document from Module 3 with new fields for replies, reactions, and read tracking:

// Firestore document: /chats/{chatId}/messages/{messageId}
{
  id: 'msg123',
  text: 'See you at 7!',
  senderId: 'uid_priya',
  senderName: 'Priya',
  timestamp: Timestamp,
  type: 'text',

  // Reply fields (null if not a reply)
  replyTo: {
    messageId: 'msg100',
    text: 'What time should we meet?',
    senderName: 'Rahul',
  },

  // Reactions: { emoji: [uid, uid, ...] }
  reactions: {
    '👍': ['uid_rahul', 'uid_amit'],
    '❤️': ['uid_priya'],
  },

  // Read receipts (group chats)
  readBy: ['uid_priya', 'uid_rahul'],

  // Deletion
  deletedFor: ['uid_amit'],       // "delete for me" — hide from specific users
  deletedForEveryone: false,      // "delete for everyone" — show placeholder
}

Key decisions:

  • replyTo — stores a snapshot of the original message text and sender. We don't just store the ID because if the original is deleted, the quote should still show what was said.
  • reactions — a map of emoji → array of UIDs. This lets you show counts and who reacted.
  • readBy — tracks which members have seen the message. For 1:1 chats, a single boolean would suffice, but an array works for both 1:1 and groups.
  • deletedFor — "delete for me" doesn't touch the message for others, it just adds your UID to this array so your client filters it out.

2. Reply to a message

When the user swipes or long-presses a message and taps "Reply", you store a reference to the original message. The input bar shows a preview of what they're replying to:

import { addDoc, collection, doc, updateDoc, serverTimestamp } from 'firebase/firestore';

// Send a reply message
async function sendReply(chatId, text, senderName, originalMessage) {
  await addDoc(collection(db, 'chats', chatId, 'messages'), {
    text: text,
    senderId: auth.currentUser.uid,
    senderName: senderName,
    timestamp: serverTimestamp(),
    type: 'text',
    replyTo: {
      messageId: originalMessage.id,
      text: originalMessage.text.substring(0, 100), // cap at 100 chars
      senderName: originalMessage.senderName,
    },
    reactions: {},
    readBy: [auth.currentUser.uid],
    deletedFor: [],
    deletedForEveryone: false,
  });

  // Update lastMessage on the chat
  await updateDoc(doc(db, 'chats', chatId), {
    lastMessage: { text: `${senderName}: ${text}`, timestamp: serverTimestamp() },
  });
}

3. Delete for me / Delete for everyone

WhatsApp gives two delete options:

  • Delete for me — the message disappears from your device only. Others still see it.
  • Delete for everyone — the message shows "This message was deleted" for all participants. Only available within a time window (WhatsApp uses ~1 hour).
import { doc, updateDoc, arrayUnion, deleteDoc } from 'firebase/firestore';

// Delete for me — add current user to deletedFor array
async function deleteForMe(chatId, messageId) {
  const msgRef = doc(db, 'chats', chatId, 'messages', messageId);
  await updateDoc(msgRef, {
    deletedFor: arrayUnion(auth.currentUser.uid),
  });
}

// Delete for everyone — mark the message as deleted
async function deleteForEveryone(chatId, messageId, senderId) {
  // Only the sender can delete for everyone
  if (senderId !== auth.currentUser.uid) {
    throw new Error('Only the sender can delete for everyone');
  }
  const msgRef = doc(db, 'chats', chatId, 'messages', messageId);
  await updateDoc(msgRef, {
    deletedForEveryone: true,
    text: '',           // clear the text
    reactions: {},      // clear reactions
  });
}

In your message list, filter and transform messages before rendering:

function filterMessages(messages, currentUid) {
  return messages
    // Remove messages deleted for the current user
    .filter((msg) => !msg.deletedFor?.includes(currentUid))
    // Transform "deleted for everyone" messages
    .map((msg) => {
      if (msg.deletedForEveryone) {
        return { ...msg, text: '🚫 This message was deleted', isDeleted: true };
      }
      return msg;
    });
}

4. Emoji reactions

WhatsApp shows a row of quick-react emojis when you long-press. Tapping one adds your UID to that emoji's array. Tapping the same emoji again removes it (toggle):

import { doc, updateDoc, arrayUnion, arrayRemove } from 'firebase/firestore';

async function toggleReaction(chatId, messageId, emoji, currentUid) {
  const msgRef = doc(db, 'chats', chatId, 'messages', messageId);

  // Check if user already reacted with this emoji
  // (you'd pass the current reactions from local state)
  const currentReactors = message.reactions?.[emoji] || [];

  if (currentReactors.includes(currentUid)) {
    // Remove reaction
    await updateDoc(msgRef, {
      [`reactions.${emoji}`]: arrayRemove(currentUid),
    });
  } else {
    // Add reaction
    await updateDoc(msgRef, {
      [`reactions.${emoji}`]: arrayUnion(currentUid),
    });
  }
}

The bracket notation trick: [`reactions.${emoji}`] lets you update a nested field dynamically. Firestore interprets dots in field paths as nested access, so reactions.👍 updates the 👍 key inside the reactions map.

Display reactions below the bubble:

5. Read receipts — blue ticks

WhatsApp's tick system: one grey tick (sent) → two grey ticks (delivered) → two blue ticks (read). For simplicity, we implement sent + read:

  • Sent — the message document exists in Firestore (single grey tick ✓)
  • Read — the recipient's UID is in the readBy array (blue ticks ✓✓)
// Mark messages as read when the user opens a chat
async function markMessagesAsRead(chatId, messages, currentUid) {
  const unreadByMe = messages.filter(
    (msg) => msg.senderId !== currentUid && !msg.readBy?.includes(currentUid)
  );

  // Batch update — mark each unread message as read
  const promises = unreadByMe.map((msg) =>
    updateDoc(doc(db, 'chats', chatId, 'messages', msg.id), {
      readBy: arrayUnion(currentUid),
    })
  );
  await Promise.all(promises);
}

// Call this in useEffect when the thread screen opens:
useEffect(() => {
  if (messages.length > 0) {
    markMessagesAsRead(chatId, messages, auth.currentUser.uid);
  }
}, [messages]);

Display the tick status in the message bubble:

function TickStatus({ message, chatMembers }) {
  // Only show ticks on messages I sent
  if (message.senderId !== auth.currentUser.uid) return null;

  const otherMembers = chatMembers.filter((uid) => uid !== auth.currentUser.uid);
  const allRead = otherMembers.every((uid) => message.readBy?.includes(uid));

  return (
    <Text style={{ fontSize: 14, marginLeft: 4 }}>
      {allRead ? (
        <Text style={{ color: '#53BDEB' }}>✓✓</Text>  // blue ticks
      ) : (
        <Text style={{ color: '#667781' }}>✓</Text>   // grey tick
      )}
    </Text>
  );
}
Group read receipts

In a group, tapping the blue ticks shows who has read it and when — that's what the readBy array enables. In 1:1 chats, a single member in the array is enough for blue ticks. In groups, all members must be in the array for the ticks to turn blue.

6. The long-press action menu

WhatsApp shows options when you long-press a message. Here's the pattern using React Native's built-in Alert for simplicity:

function showMessageOptions(message, chatId, navigation) {
  const isMe = message.senderId === auth.currentUser.uid;
  const options = [];

  // Reply — always available
  options.push({
    text: 'Reply',
    onPress: () => setReplyingTo(message),
  });

  // React — always available
  options.push({
    text: 'React',
    onPress: () => showReactionPicker(message),
  });

  // Delete for me — always available
  options.push({
    text: 'Delete for me',
    onPress: () => deleteForMe(chatId, message.id),
  });

  // Delete for everyone — only if I sent it
  if (isMe) {
    options.push({
      text: 'Delete for everyone',
      style: 'destructive',
      onPress: () => deleteForEveryone(chatId, message.id, message.senderId),
    });
  }

  options.push({ text: 'Cancel', style: 'cancel' });

  Alert.alert('Message', message.text.substring(0, 50), options);
}

9. Full runnable App.js — Messages with reply, reactions, delete & ticks

Copy this entire file and replace your App.js. It shows a message thread with long-press actions: reply (with quoted bubble), react with emojis, delete for me/everyone, and read receipt ticks.

// App.js — Full runnable example: Message Features
import React, { useState, useEffect, useRef } from 'react';
import {
  View, Text, TextInput, FlatList, Pressable,
  StyleSheet, Alert, KeyboardAvoidingView, Platform
} from 'react-native';

// Firebase imports
import { initializeApp } from 'firebase/app';
import { getAuth, onAuthStateChanged } from 'firebase/auth';
import {
  getFirestore, doc, getDoc, addDoc, updateDoc,
  collection, query, orderBy, onSnapshot,
  serverTimestamp, arrayUnion, arrayRemove
} from 'firebase/firestore';

// Navigation
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';

// ─── Firebase config ────────────────────────────────────────────────
const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',
  authDomain: 'YOUR_PROJECT.firebaseapp.com',
  projectId: 'YOUR_PROJECT_ID',
  storageBucket: 'YOUR_PROJECT.appspot.com',
  messagingSenderId: '123456789',
  appId: '1:123456789:web:abcdef',
};
const app = initializeApp(firebaseConfig);
const auth = getAuth(app);
const db = getFirestore(app);

const QUICK_REACTIONS = ['👍', '❤️', '😂', '😮', '😢', '🙏'];
const DEMO_CHAT_ID = 'demo-chat-001';
const DEMO_MEMBERS = ['user1', 'user2'];

// ─── Message Thread Screen ──────────────────────────────────────────
function MessageThreadScreen() {
  const [messages, setMessages] = useState([]);
  const [text, setText] = useState('');
  const [replyingTo, setReplyingTo] = useState(null);
  const [reactionTarget, setReactionTarget] = useState(null);
  const [myName, setMyName] = useState('');
  const flatListRef = useRef(null);

  const currentUid = auth.currentUser?.uid || 'user1';

  useEffect(() => {
    async function loadName() {
      const snap = await getDoc(doc(db, 'users', currentUid));
      if (snap.exists()) setMyName(snap.data().displayName);
      else setMyName('You');
    }
    loadName();

    const q = query(
      collection(db, 'chats', DEMO_CHAT_ID, 'messages'),
      orderBy('timestamp', 'asc')
    );
    const unsub = onSnapshot(q, (snapshot) => {
      const msgs = [];
      snapshot.forEach((docSnap) => msgs.push({ id: docSnap.id, ...docSnap.data() }));
      setMessages(msgs);
    });
    return unsub;
  }, []);

  // Mark as read
  useEffect(() => {
    if (messages.length === 0) return;
    const unread = messages.filter(
      (m) => m.senderId !== currentUid && !m.readBy?.includes(currentUid)
    );
    unread.forEach((m) => {
      updateDoc(doc(db, 'chats', DEMO_CHAT_ID, 'messages', m.id), {
        readBy: arrayUnion(currentUid),
      });
    });
  }, [messages]);

  // Filter deleted messages
  const visibleMessages = messages
    .filter((m) => !m.deletedFor?.includes(currentUid))
    .map((m) => m.deletedForEveryone ? { ...m, text: '🚫 This message was deleted', isDeleted: true } : m);

  async function sendMessage() {
    if (text.trim() === '') return;
    const msgText = text.trim();
    setText('');

    const msgData = {
      text: msgText,
      senderId: currentUid,
      senderName: myName,
      timestamp: serverTimestamp(),
      type: 'text',
      reactions: {},
      readBy: [currentUid],
      deletedFor: [],
      deletedForEveryone: false,
    };

    if (replyingTo) {
      msgData.replyTo = {
        messageId: replyingTo.id,
        text: replyingTo.text.substring(0, 100),
        senderName: replyingTo.senderName,
      };
      setReplyingTo(null);
    }

    await addDoc(collection(db, 'chats', DEMO_CHAT_ID, 'messages'), msgData);
    await updateDoc(doc(db, 'chats', DEMO_CHAT_ID), {
      lastMessage: { text: `${myName}: ${msgText}`, timestamp: serverTimestamp() },
    });
  }

  function handleLongPress(message) {
    if (message.isDeleted) return;
    const isMe = message.senderId === currentUid;
    const buttons = [
      { text: 'Reply', onPress: () => setReplyingTo(message) },
      { text: 'React', onPress: () => setReactionTarget(message) },
      { text: 'Delete for me', onPress: () => handleDeleteForMe(message) },
    ];
    if (isMe) {
      buttons.push({
        text: 'Delete for everyone',
        style: 'destructive',
        onPress: () => handleDeleteForEveryone(message),
      });
    }
    buttons.push({ text: 'Cancel', style: 'cancel' });
    Alert.alert('Message options', message.text.substring(0, 50), buttons);
  }

  async function handleDeleteForMe(message) {
    await updateDoc(doc(db, 'chats', DEMO_CHAT_ID, 'messages', message.id), {
      deletedFor: arrayUnion(currentUid),
    });
  }

  async function handleDeleteForEveryone(message) {
    await updateDoc(doc(db, 'chats', DEMO_CHAT_ID, 'messages', message.id), {
      deletedForEveryone: true,
      text: '',
      reactions: {},
    });
  }

  async function handleReaction(emoji) {
    if (!reactionTarget) return;
    const msgRef = doc(db, 'chats', DEMO_CHAT_ID, 'messages', reactionTarget.id);
    const currentReactors = reactionTarget.reactions?.[emoji] || [];

    if (currentReactors.includes(currentUid)) {
      await updateDoc(msgRef, { [`reactions.${emoji}`]: arrayRemove(currentUid) });
    } else {
      await updateDoc(msgRef, { [`reactions.${emoji}`]: arrayUnion(currentUid) });
    }
    setReactionTarget(null);
  }

  return (
    <KeyboardAvoidingView
      style={styles.container}
      behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
    >
      {/* Header */}
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Chat Thread</Text>
        <Text style={styles.headerSubtitle}>Long-press any message for options</Text>
      </View>

      {/* Messages */}
      <FlatList
        ref={flatListRef}
        data={visibleMessages}
        keyExtractor={(item) => item.id}
        style={styles.messageList}
        onContentSizeChange={() => flatListRef.current?.scrollToEnd()}
        renderItem={({ item }) => {
          const isMe = item.senderId === currentUid;
          return (
            <Pressable onLongPress={() => handleLongPress(item)}>
              <View style={[styles.bubble, isMe ? styles.sent : styles.received]}>
                {/* Reply quote */}
                {item.replyTo && (
                  <View style={styles.replyBox}>
                    <View style={styles.replyBar} />
                    <View style={styles.replyContent}>
                      <Text style={styles.replySender}>{item.replyTo.senderName}</Text>
                      <Text style={styles.replyText} numberOfLines={2}>{item.replyTo.text}</Text>
                    </View>
                  </View>
                )}
                {/* Message text */}
                <Text style={[styles.msgText, item.isDeleted && { fontStyle: 'italic', color: '#667781' }]}>
                  {item.text}
                </Text>
                {/* Timestamp + ticks */}
                <View style={styles.metaRow}>
                  <Text style={styles.timeText}>
                    {item.timestamp?.toDate().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })}
                  </Text>
                  {isMe && !item.isDeleted && (
                    <Text style={{
                      fontSize: 14,
                      marginLeft: 4,
                      color: DEMO_MEMBERS.filter(u => u !== currentUid)
                        .every(u => item.readBy?.includes(u)) ? '#53BDEB' : '#667781'
                    }}>
                      {DEMO_MEMBERS.filter(u => u !== currentUid)
                        .every(u => item.readBy?.includes(u)) ? '✓✓' : '✓'}
                    </Text>
                  )}
                </View>
                {/* Reactions */}
                {item.reactions && Object.keys(item.reactions).length > 0 && (
                  <View style={styles.reactionsRow}>
                    {Object.entries(item.reactions).map(([emoji, uids]) =>
                      uids.length > 0 ? (
                        <View key={emoji} style={styles.reactionPill}>
                          <Text style={{ fontSize: 14 }}>{emoji}</Text>
                          <Text style={styles.reactionCount}>{uids.length}</Text>
                        </View>
                      ) : null
                    )}
                  </View>
                )}
              </View>
            </Pressable>
          );
        }}
        ListEmptyComponent={
          <Text style={styles.emptyText}>No messages yet. Start the conversation!</Text>
        }
      />

      {/* Reply preview */}
      {replyingTo && (
        <View style={styles.replyPreview}>
          <View style={styles.replyBar} />
          <View style={{ flex: 1 }}>
            <Text style={styles.replySender}>{replyingTo.senderName}</Text>
            <Text style={styles.replyText} numberOfLines={1}>{replyingTo.text}</Text>
          </View>
          <Pressable onPress={() => setReplyingTo(null)}>
            <Text style={{ fontSize: 20, color: '#667781', paddingHorizontal: 8 }}>✕</Text>
          </Pressable>
        </View>
      )}

      {/* Input bar */}
      <View style={styles.inputBar}>
        <TextInput
          style={styles.input}
          value={text}
          onChangeText={setText}
          placeholder="Type a message"
          multiline
        />
        <Pressable style={styles.sendBtn} onPress={sendMessage}>
          <Text style={styles.sendText}>Send</Text>
        </Pressable>
      </View>

      {/* Reaction picker overlay */}
      {reactionTarget && (
        <Pressable style={styles.overlay} onPress={() => setReactionTarget(null)}>
          <View style={styles.picker}>
            {QUICK_REACTIONS.map((emoji) => (
              <Pressable key={emoji} style={styles.emojiBtn} onPress={() => handleReaction(emoji)}>
                <Text style={{ fontSize: 28 }}>{emoji}</Text>
              </Pressable>
            ))}
          </View>
        </Pressable>
      )}
    </KeyboardAvoidingView>
  );
}
