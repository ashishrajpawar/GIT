WhatsApp Features · Lesson 1

User Profiles & Contacts

Firestore /users collection · Search by name · Online/last-seen · Contact list screen ~55 min Hands-on
Why this matters for your WhatsApp clone

Open WhatsApp and tap the new-chat icon — you see a list of contacts with names, profile photos, and "about" text. Tap any contact to start a conversation. That entire flow depends on a user profiles system: every registered user stores their display name, photo URL, about text, and online status in Firestore. Without this, your app can only show raw email addresses — no photos, no names, no way to find someone new to chat with. This lesson builds the /users/{uid} collection, writes a profile on sign-up, adds a search screen to find people, and shows online/last-seen status — the foundation every other feature in this module depends on.

1. The /users collection — data model

Every time a user registers, you create a document in Firestore at /users/{uid}. The document ID is the Firebase Auth UID — this makes lookups instant because you always know the current user's UID.

// Firestore document: /users/abc123xyz
{
  uid: 'abc123xyz',
  displayName: 'Priya Sharma',
  email: 'priya@example.com',
  photoURL: 'https://firebasestorage.googleapis.com/.../avatar.jpg',
  about: 'Hey there! I am using WhatsApp',
  online: true,
  lastSeen: Timestamp,       // Firestore server timestamp
  createdAt: Timestamp,
  searchName: 'priya sharma' // lowercase copy for case-insensitive search
}

Key design decisions:

  • uid as document ID — Firebase Auth already gives you the UID; no need for a separate lookup
  • searchName — Firestore queries are case-sensitive, so we store a lowercase copy of the display name for searching
  • online + lastSeen — two fields work together: online: true means they're in the app right now; lastSeen stores when they last closed the app
  • about — defaults to "Hey there! I am using WhatsApp" just like the real app

2. Creating a user profile on sign-up

In Module 3 Lesson 2, you used createUserWithEmailAndPassword to register users. Now you add one extra step — immediately write a profile document to Firestore:

import { createUserWithEmailAndPassword } from 'firebase/auth';
import { doc, setDoc, serverTimestamp } from 'firebase/firestore';
import { auth, db } from './firebaseConfig';

async function registerUser(email, password, displayName) {
  // 1. Create the Firebase Auth account
  const { user } = await createUserWithEmailAndPassword(auth, email, password);

  // 2. Write the profile document to /users/{uid}
  await setDoc(doc(db, 'users', user.uid), {
    uid: user.uid,
    displayName: displayName,
    email: email,
    photoURL: null,
    about: 'Hey there! I am using WhatsApp',
    online: true,
    lastSeen: serverTimestamp(),
    createdAt: serverTimestamp(),
    searchName: displayName.toLowerCase(),
  });

  return user;
}

Why setDoc instead of addDoc? Because you want the document ID to be the user's UID (not a random auto-generated ID). setDoc lets you choose the document ID; addDoc always generates a random one.

3. Reading and updating the current user's profile

Once logged in, you need to fetch and display the profile, and let the user edit it:

import { doc, getDoc, updateDoc, serverTimestamp } from 'firebase/firestore';

// Fetch current user's profile
async function getMyProfile(uid) {
  const snap = await getDoc(doc(db, 'users', uid));
  if (snap.exists()) {
    return snap.data();
  }
  return null;
}

// Update display name
async function updateDisplayName(uid, newName) {
  await updateDoc(doc(db, 'users', uid), {
    displayName: newName,
    searchName: newName.toLowerCase(),
  });
}

// Update "about" text
async function updateAbout(uid, newAbout) {
  await updateDoc(doc(db, 'users', uid), {
    about: newAbout,
  });
}

// Update profile photo URL (after uploading to Storage)
async function updateProfilePhoto(uid, photoURL) {
  await updateDoc(doc(db, 'users', uid), {
    photoURL: photoURL,
  });
}

Notice each update function only changes the fields it needs — updateDoc merges, it doesn't overwrite the entire document.

4. Searching for users by name

WhatsApp lets you search for contacts. Firestore doesn't have full-text search built in, but for a contacts list a prefix query works well — as the user types "pri", you find all names starting with "pri":

import { collection, query, where, getDocs, orderBy, limit } from 'firebase/firestore';

async function searchUsers(searchText, currentUid) {
  const lower = searchText.toLowerCase();
  // Firestore range trick: 'pri' matches everything from 'pri' up to 'pri'
  const q = query(
    collection(db, 'users'),
    where('searchName', '>=', lower),
    where('searchName', '<=', lower + ''),
    orderBy('searchName'),
    limit(20)
  );

  const snapshot = await getDocs(q);
  const results = [];
  snapshot.forEach((docSnap) => {
    const data = docSnap.data();
    // Don't show the current user in search results
    if (data.uid !== currentUid) {
      results.push(data);
    }
  });
  return results;
}

How the range trick works:

  • >= "pri" — matches "priya", "prince", "priti" (anything starting with "pri")
  • <= "pri" — the character  is the highest Unicode character, so this catches everything starting with "pri" and nothing else
  • This is the standard Firestore pattern for prefix search — it's fast and uses no external services
Firestore index needed

This query uses where + orderBy on the same field (searchName), so Firestore handles it automatically — no composite index required. If you ever filter on one field and sort by another, Firebase will show an error with a link to create the index.

5. Online / last-seen status

WhatsApp shows "online" or "last seen today at 2:34 PM" under a contact's name. You need two things:

  1. Set online when the app opens
  2. Set offline + lastSeen when the app closes
import { AppState } from 'react-native';
import { doc, updateDoc, serverTimestamp } from 'firebase/firestore';

function usePresence(uid) {
  useEffect(() => {
    if (!uid) return;

    const userRef = doc(db, 'users', uid);

    // Mark online immediately
    updateDoc(userRef, { online: true });

    // Listen for app going to background/foreground
    const subscription = AppState.addEventListener('change', (state) => {
      if (state === 'active') {
        updateDoc(userRef, { online: true });
      } else {
        // 'background' or 'inactive'
        updateDoc(userRef, { online: false, lastSeen: serverTimestamp() });
      }
    });

    return () => {
      // Cleanup: mark offline when component unmounts (logout)
      updateDoc(userRef, { online: false, lastSeen: serverTimestamp() });
      subscription.remove();
    };
  }, [uid]);
}

How AppState works:

  • 'active' — the app is in the foreground, user is looking at it
  • 'background' — user pressed home or switched apps
  • 'inactive' — iOS only: transitional state (e.g. pulling down notification center)

To display another user's status, listen to their profile document in real time:

import { doc, onSnapshot } from 'firebase/firestore';

function useUserStatus(otherUid) {
  const [status, setStatus] = useState({ online: false, lastSeen: null });

  useEffect(() => {
    if (!otherUid) return;

    const unsub = onSnapshot(doc(db, 'users', otherUid), (snap) => {
      if (snap.exists()) {
        const data = snap.data();
        setStatus({ online: data.online, lastSeen: data.lastSeen });
      }
    });

    return unsub;
  }, [otherUid]);

  return status;
}

6. Formatting "last seen" for display

Firestore timestamps need to be converted to readable text like "last seen today at 2:34 PM":

function formatLastSeen(timestamp) {
  if (!timestamp) return '';

  const date = timestamp.toDate(); // Firestore Timestamp → JS Date
  const now = new Date();
  const diffMs = now - date;
  const diffMins = Math.floor(diffMs / 60000);

  if (diffMins < 1) return 'last seen just now';
  if (diffMins < 60) return `last seen ${diffMins} min ago`;

  // Check if same day
  const isToday = date.toDateString() === now.toDateString();
  const timeStr = date.toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' });

  if (isToday) return `last seen today at ${timeStr}`;

  // Check if yesterday
  const yesterday = new Date(now);
  yesterday.setDate(yesterday.getDate() - 1);
  if (date.toDateString() === yesterday.toDateString()) {
    return `last seen yesterday at ${timeStr}`;
  }

  // Older: show date
  const dateStr = date.toLocaleDateString([], { day: 'numeric', month: 'short' });
  return `last seen ${dateStr} at ${timeStr}`;
}

7. The Contact List screen

This is the screen users see when they tap the "new chat" floating button. It shows a search bar and a list of all registered users they can start a conversation with:

import React, { useState, useEffect } from 'react';
import {
  View, Text, TextInput, FlatList, Image, Pressable, StyleSheet, ActivityIndicator
} from 'react-native';
import { collection, query, orderBy, limit, getDocs, where } from 'firebase/firestore';
import { db, auth } from './firebaseConfig';

function ContactListScreen({ navigation }) {
  const [searchText, setSearchText] = useState('');
  const [contacts, setContacts] = useState([]);
  const [loading, setLoading] = useState(false);

  // Load all users initially (up to 50)
  useEffect(() => {
    loadAllUsers();
  }, []);

  async function loadAllUsers() {
    setLoading(true);
    const q = query(
      collection(db, 'users'),
      orderBy('searchName'),
      limit(50)
    );
    const snapshot = await getDocs(q);
    const users = [];
    snapshot.forEach((docSnap) => {
      const data = docSnap.data();
      if (data.uid !== auth.currentUser.uid) {
        users.push(data);
      }
    });
    setContacts(users);
    setLoading(false);
  }

  // Search as user types (with debounce in the full app)
  async function handleSearch(text) {
    setSearchText(text);
    if (text.trim() === '') {
      loadAllUsers();
      return;
    }
    setLoading(true);
    const lower = text.toLowerCase();
    const q = query(
      collection(db, 'users'),
      where('searchName', '>=', lower),
      where('searchName', '<=', lower + ''),
      orderBy('searchName'),
      limit(20)
    );
    const snapshot = await getDocs(q);
    const results = [];
    snapshot.forEach((docSnap) => {
      const data = docSnap.data();
      if (data.uid !== auth.currentUser.uid) {
        results.push(data);
      }
    });
    setContacts(results);
    setLoading(false);
  }

  function startChat(contact) {
    // Navigate to MessageThread with the selected contact's info
    navigation.navigate('MessageThread', {
      chatId: null,  // will be created or looked up
      otherUser: contact,
    });
  }

  return (
    <View style={styles.container}>
      {/* Custom green header */}
      <View style={styles.header}>
        <Pressable onPress={() => navigation.goBack()}>
          <Text style={styles.backBtn}>← Back</Text>
        </Pressable>
        <Text style={styles.headerTitle}>Select contact</Text>
      </View>

      {/* Search bar */}
      <View style={styles.searchBox}>
        <TextInput
          style={styles.searchInput}
          placeholder="Search by name..."
          value={searchText}
          onChangeText={handleSearch}
          autoCapitalize="none"
        />
      </View>

      {/* Contact list */}
      {loading ? (
        <ActivityIndicator size="large" color="#25D366" style={{ marginTop: 40 }} />
      ) : (
        <FlatList
          data={contacts}
          keyExtractor={(item) => item.uid}
          renderItem={({ item }) => (
            <Pressable style={styles.contactRow} onPress={() => startChat(item)}>
              <Image
                source={
                  item.photoURL
                    ? { uri: item.photoURL }
                    : require('./assets/default-avatar.png')

                style={styles.avatar}
              />
              <View style={styles.contactInfo}>
                <Text style={styles.contactName}>{item.displayName}</Text>
                <Text style={styles.contactAbout} numberOfLines={1}>
                  {item.about}
                </Text>
              </View>
              {item.online && <View style={styles.onlineDot} />}
            </Pressable>
          )}
          ListEmptyComponent={
            <Text style={styles.emptyText}>No contacts found</Text>
          }
        />
      )}
    </View>
  );
}

8. Profile settings screen

WhatsApp's Settings tab shows your photo, name, and about text — all editable. Here's the screen pattern:

import React, { useState, useEffect } from 'react';
import {
  View, Text, TextInput, Image, Pressable, StyleSheet, Alert
} from 'react-native';
import { doc, getDoc, updateDoc } from 'firebase/firestore';
import { db, auth } from './firebaseConfig';

function ProfileScreen() {
  const [profile, setProfile] = useState(null);
  const [editingName, setEditingName] = useState(false);
  const [newName, setNewName] = useState('');

  useEffect(() => {
    loadProfile();
  }, []);

  async function loadProfile() {
    const snap = await getDoc(doc(db, 'users', auth.currentUser.uid));
    if (snap.exists()) {
      setProfile(snap.data());
      setNewName(snap.data().displayName);
    }
  }

  async function saveName() {
    if (newName.trim() === '') {
      Alert.alert('Error', 'Name cannot be empty');
      return;
    }
    await updateDoc(doc(db, 'users', auth.currentUser.uid), {
      displayName: newName.trim(),
      searchName: newName.trim().toLowerCase(),
    });
    setProfile((prev) => ({ ...prev, displayName: newName.trim() }));
    setEditingName(false);
  }

  if (!profile) return null;

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Profile</Text>
      </View>

      <View style={styles.avatarSection}>
        <Image
          source={
            profile.photoURL
              ? { uri: profile.photoURL }
              : require('./assets/default-avatar.png')
          }
          style={styles.bigAvatar}
        />
      </View>

      <View style={styles.fieldRow}>
        <Text style={styles.fieldLabel}>Name</Text>
        {editingName ? (
          <View style={styles.editRow}>
            <TextInput
              style={styles.editInput}
              value={newName}
              onChangeText={setNewName}
              autoFocus
            />
            <Pressable onPress={saveName}>
              <Text style={styles.saveBtn}>Save</Text>
            </Pressable>
          </View>
        ) : (
          <Pressable onPress={() => setEditingName(true)}>
            <Text style={styles.fieldValue}>{profile.displayName} ✏️</Text>
          </Pressable>
        )}
      </View>

      <View style={styles.fieldRow}>
        <Text style={styles.fieldLabel}>About</Text>
        <Text style={styles.fieldValue}>{profile.about}</Text>
      </View>

      <View style={styles.fieldRow}>
        <Text style={styles.fieldLabel}>Email</Text>
        <Text style={styles.fieldValue}>{profile.email}</Text>
      </View>
    </View>
  );
}

              <Text style={styles.saveBtn}>Save</Text>
            </Pressable>
          </View>
        ) : (
          <Pressable onPress={() => setEditingName(true)}>
            <Text style={styles.fieldValue}>{profile.displayName}</Text>
          </Pressable>
        )}
      </View>

      <View style={styles.fieldRow}>
        <Text style={styles.fieldLabel}>About</Text>
        <Text style={styles.fieldValue}>{profile.about}</Text>
      </View>

      <View style={styles.fieldRow}>
        <Text style={styles.fieldLabel}>Email</Text>
        <Text style={styles.fieldValue}>{profile.email}</Text>
      </View>

      <View style={styles.fieldRow}>
        <Text style={styles.fieldLabel}>Status</Text>
        <Text style={[styles.fieldValue, { color: '#25D366' }]}>online</Text>
      </View>
    </View>
  );
}
