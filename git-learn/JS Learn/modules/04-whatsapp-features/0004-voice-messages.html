WhatsApp Features · Lesson 4

Voice Messages

expo-av recording · Upload to Storage · Audio message bubble · Play/pause · Duration display ~55 min Hands-on
Why this matters for your WhatsApp clone

Voice messages are WhatsApp's second most popular message type after text. Hold the mic button, speak, release to send — it's faster than typing and more personal. Under the hood: the phone records audio using expo-av, uploads the file to Firebase Storage, saves the download URL as a message in Firestore, and the recipient streams playback with a progress bar. This lesson builds the complete voice message flow — recording, uploading, the green audio bubble with play/pause button and duration, and smooth playback.

1. Installing expo-av

expo-av is Expo's audio/video library. It handles recording microphone input and playing audio files — both local and remote URLs.

npx expo install expo-av

You also need to request microphone permission on both platforms:

import { Audio } from 'expo-av';

async function requestMicPermission() {
  const { status } = await Audio.requestPermissionsAsync();
  if (status !== 'granted') {
    Alert.alert('Permission needed', 'Microphone access is required for voice messages');
    return false;
  }
  return true;
}
Platform note

On iOS, the first time your app requests the mic, the system shows a permission dialog. On Android 13+, the RECORD_AUDIO permission is also prompted at runtime. Both are handled by Audio.requestPermissionsAsync() automatically.

2. Recording audio

The recording flow: user presses the mic button → recording starts → user releases → recording stops → you get a local file URI.

import { Audio } from 'expo-av';

let recording = null;

async function startRecording() {
  const hasPermission = await requestMicPermission();
  if (!hasPermission) return;

  // Configure audio mode for recording
  await Audio.setAudioModeAsync({
    allowsRecordingIOS: true,
    playsInSilentModeIOS: true,
  });

  // Create and start the recording
  const { recording: newRecording } = await Audio.Recording.createAsync(
    Audio.RecordingOptionsPresets.HIGH_QUALITY
  );
  recording = newRecording;
}

async function stopRecording() {
  if (!recording) return null;

  await recording.stopAndUnloadAsync();

  // Reset audio mode so playback works
  await Audio.setAudioModeAsync({
    allowsRecordingIOS: false,
  });

  const uri = recording.getURI(); // e.g. file:///data/.../recording.m4a
  const { durationMillis } = await recording.getStatusAsync();

  recording = null;
  return { uri, durationMillis };
}

Key points:

  • Audio.RecordingOptionsPresets.HIGH_QUALITY — records in AAC/M4A format, which is small and plays on both iOS and Android
  • allowsRecordingIOS: true — must be set before recording starts on iOS
  • allowsRecordingIOS: false — must be reset after recording, or playback won't work on iOS (common gotcha!)
  • getURI() — returns the local file path of the recorded audio

3. Uploading audio to Firebase Storage

Same pattern as image upload from Module 3 Lesson 5 — convert to blob, upload, get download URL:

import { ref, uploadBytesResumable, getDownloadURL } from 'firebase/storage';
import { storage } from './firebaseConfig';

async function uploadVoiceMessage(localUri, chatId) {
  // Convert local file to blob
  const response = await fetch(localUri);
  const blob = await response.blob();

  // Create a unique path in Storage
  const filename = `voice_${Date.now()}.m4a`;
  const storageRef = ref(storage, `chats/${chatId}/voice/${filename}`);

  // Upload with progress tracking
  return new Promise((resolve, reject) => {
    const uploadTask = uploadBytesResumable(storageRef, blob);

    uploadTask.on('state_changed',
      (snapshot) => {
        const progress = (snapshot.bytesTransferred / snapshot.totalBytes) * 100;
        console.log(`Upload: ${progress.toFixed(0)}%`);
      },
      (error) => reject(error),
      async () => {
        const downloadURL = await getDownloadURL(uploadTask.snapshot.ref);
        resolve(downloadURL);
      }
    );
  });
}

4. Saving the voice message to Firestore

A voice message is a regular message document with type: 'audio' and extra audio-specific fields:

import { addDoc, collection, doc, updateDoc, serverTimestamp } from 'firebase/firestore';

async function sendVoiceMessage(chatId, audioURL, durationMs, senderName) {
  await addDoc(collection(db, 'chats', chatId, 'messages'), {
    type: 'audio',
    audioURL: audioURL,
    duration: durationMs,  // duration in milliseconds
    text: '🎤 Voice message',  // fallback for notifications/preview
    senderId: auth.currentUser.uid,
    senderName: senderName,
    timestamp: serverTimestamp(),
    reactions: {},
    readBy: [auth.currentUser.uid],
    deletedFor: [],
    deletedForEveryone: false,
  });

  await updateDoc(doc(db, 'chats', chatId), {
    lastMessage: {
      text: `${senderName}: 🎤 Voice message`,
      timestamp: serverTimestamp(),
    },
  });
}

5. Playing back audio

To play a voice message, create a Sound object from the remote URL and control playback:

import { Audio } from 'expo-av';

async function playAudio(audioURL, onProgress, onFinish) {
  const { sound } = await Audio.Sound.createAsync(
    { uri: audioURL },
    { shouldPlay: true }   // start playing immediately
  );

  // Track playback progress
  sound.setOnPlaybackStatusUpdate((status) => {
    if (status.isLoaded) {
      if (status.didJustFinish) {
        onFinish();
        sound.unloadAsync();  // free memory
      } else if (status.isPlaying) {
        const progress = status.positionMillis / status.durationMillis;
        onProgress(progress); // 0 to 1
      }
    }
  });

  return sound;
}

// Pause/resume
async function togglePlayback(sound, isPlaying) {
  if (isPlaying) {
    await sound.pauseAsync();
  } else {
    await sound.playAsync();
  }
}

Memory management: Always call sound.unloadAsync() when playback finishes or the component unmounts. Leaked Sound objects cause memory issues, especially if the user scrolls through many voice messages.

6. Formatting duration

Voice messages show duration like "0:34" or "1:05". Here's the formatter:

function formatDuration(millis) {
  if (!millis || millis <= 0) return '0:00';
  const totalSeconds = Math.floor(millis / 1000);
  const minutes = Math.floor(totalSeconds / 60);
  const seconds = totalSeconds % 60;
  return `${minutes}:${seconds.toString().padStart(2, '0')}`;
}

// Examples:
// formatDuration(34000)  → '0:34'
// formatDuration(65000)  → '1:05'
// formatDuration(125000) → '2:05'

7. The voice message bubble component

WhatsApp's audio bubble has: play/pause button, a progress bar, and the duration. Here's the component:

function VoiceMessageBubble({ message, isMe }) {
  const [isPlaying, setIsPlaying] = useState(false);
  const [progress, setProgress] = useState(0);
  const [sound, setSound] = useState(null);

  // Cleanup on unmount
  useEffect(() => {
    return () => {
      if (sound) sound.unloadAsync();
    };
  }, [sound]);

  async function handlePlay() {
    if (isPlaying && sound) {
      await sound.pauseAsync();
      setIsPlaying(false);
      return;
    }

    if (sound) {
      await sound.playAsync();
      setIsPlaying(true);
      return;
    }

    // First play — load the audio
    const { sound: newSound } = await Audio.Sound.createAsync(
      { uri: message.audioURL },
      { shouldPlay: true }
    );
    setSound(newSound);
    setIsPlaying(true);

    newSound.setOnPlaybackStatusUpdate((status) => {
      if (status.isLoaded) {
        if (status.didJustFinish) {
          setIsPlaying(false);
          setProgress(0);
        } else {
          setProgress(status.positionMillis / status.durationMillis);
        }
      }
    });
  }

  return (
    <View style={[audioBubbleStyles.container, isMe ? audioBubbleStyles.sent : audioBubbleStyles.received]}>
      {/* Play/Pause button */}
      <Pressable style={audioBubbleStyles.playBtn} onPress={handlePlay}>
        <Text style={audioBubbleStyles.playIcon}>
          {isPlaying ? '⏸' : '▶️'}
        </Text>
      </Pressable>

      {/* Progress bar + duration */}
      <View style={audioBubbleStyles.trackArea}>
        <View style={audioBubbleStyles.track}>
          <View style={[audioBubbleStyles.trackFill, { width: `${progress * 100}%` }]} />
        </View>
        <Text style={audioBubbleStyles.duration}>
          {formatDuration(message.duration)}
        </Text>
      </View>
    </View>
  );
}

8. The recording button with hold-to-record

WhatsApp uses press-and-hold for recording. In React Native, you use onPressIn (finger down) and onPressOut (finger up):

function RecordButton({ onRecordingComplete }) {
  const [isRecording, setIsRecording] = useState(false);
  const [recordingDuration, setRecordingDuration] = useState(0);
  const timerRef = useRef(null);

  async function handlePressIn() {
    const started = await startRecording();
    if (!started) return;
    setIsRecording(true);
    setRecordingDuration(0);

    // Update duration display every second
    timerRef.current = setInterval(() => {
      setRecordingDuration((prev) => prev + 1000);
    }, 1000);
  }

  async function handlePressOut() {
    if (!isRecording) return;
    clearInterval(timerRef.current);
    setIsRecording(false);

    const result = await stopRecording();
    if (result && result.durationMillis > 1000) {
      // Only send if recording is longer than 1 second
      onRecordingComplete(result);
    }
  }

  return (
    <View style={recordStyles.wrapper}>
      {isRecording && (
        <View style={recordStyles.indicator}>
          <Text style={recordStyles.recordingDot}>●</Text>
          <Text style={recordStyles.timerText}>
            {formatDuration(recordingDuration)}
          </Text>
        </View>
      )}
      <Pressable
        onPressIn={handlePressIn}
        onPressOut={handlePressOut}
        style={[recordStyles.micBtn, isRecording && recordStyles.micBtnActive]}
      >
        <Text style={recordStyles.micIcon}>🎤</Text>
      </Pressable>
    </View>
  );
}

const recordStyles = StyleSheet.create({
  wrapper: { flexDirection: 'row', alignItems: 'center' },
  indicator: { flexDirection: 'row', alignItems: 'center', marginRight: 8 },
  recordingDot: { color: '#FF0000', fontSize: 12, marginRight: 4 },
  timerText: { fontSize: 14, color: '#667781' },
  micBtn: {
    width: 44,
    height: 44,
    borderRadius: 22,
    backgroundColor: '#25D366',
    justifyContent: 'center',
    alignItems: 'center',
  },
  micBtnActive: { backgroundColor: '#FF0000' },
  micIcon: { fontSize: 20 },
});
The 1-second minimum

We discard recordings shorter than 1 second — these are accidental taps, not intentional messages. WhatsApp does the same thing.

9. Full runnable App.js — Voice messages with record, upload & playback

Copy this entire file and replace your App.js. It shows a chat thread where you can hold the mic button to record, release to send, and tap play on received voice messages.

// App.js — Full runnable example: Voice Messages
import React, { useState, useEffect, useRef } from 'react';
import {
  View, Text, TextInput, FlatList, Pressable,
  StyleSheet, Alert, KeyboardAvoidingView, Platform
} from 'react-native';
import { Audio } from 'expo-av';

// Firebase imports
import { initializeApp } from 'firebase/app';
import { getAuth, onAuthStateChanged } from 'firebase/auth';
import {
  getFirestore, doc, getDoc, addDoc, updateDoc,
  collection, query, orderBy, onSnapshot, serverTimestamp
} from 'firebase/firestore';
import { getStorage, ref, uploadBytesResumable, getDownloadURL } from 'firebase/storage';

// ─── Firebase config ────────────────────────────────────────────────
const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',

const app = initializeApp(firebaseConfig);
const auth = getAuth(app);

const DEMO_CHAT_ID = 'demo-chat-001';

// ─── Voice Message Bubble ───────────────────────────────────────────
function VoiceMessageBubble({ message, isMe }) {
  const [isPlaying, setIsPlaying] = useState(false);
  const [progress, setProgress] = useState(0);
  const soundRef = useRef(null);

  useEffect(() => {
    return () => { if (soundRef.current) soundRef.current.unloadAsync(); };
  }, []);

  async function handlePlay() {
    if (isPlaying && soundRef.current) {
      await soundRef.current.pauseAsync();
      setIsPlaying(false);
      return;
    }
    if (soundRef.current) {
      await soundRef.current.playAsync();
      setIsPlaying(true);
      return;
    }

    const { sound } = await Audio.Sound.createAsync(
      { uri: message.audioURL },
      { shouldPlay: true }
    );
    soundRef.current = sound;
    setIsPlaying(true);

    sound.setOnPlaybackStatusUpdate((status) => {
      if (status.isLoaded) {
        if (status.didJustFinish) {
          setIsPlaying(false);
          setProgress(0);
          soundRef.current = null;
          sound.unloadAsync();
        } else {
          setProgress(status.positionMillis / (status.durationMillis || 1));
        }
      }
    });
  }

  return (
    <View style={[styles.audioBubble, isMe ? styles.sent : styles.received]}>
      <Pressable style={styles.playBtn} onPress={handlePlay}>
        <Text style={styles.playIcon}>{isPlaying ? '⏸' : '▶️'}</Text>
      </Pressable>
      <View style={styles.trackArea}>
        <View style={styles.track}>
          <View style={[styles.trackFill, { width: `${progress * 100}%` }]} />
        </View>
        <Text style={styles.durationText}>{formatDuration(message.duration)}</Text>
      </View>
    </View>
  );
}

// ─── Main Chat Screen ───────────────────────────────────────────────
function ChatScreen() {
  const [messages, setMessages] = useState([]);
  const [text, setText] = useState('');
  const [myName, setMyName] = useState('You');
  const [isRecording, setIsRecording] = useState(false);
  const [recordTime, setRecordTime] = useState(0);
  const [uploading, setUploading] = useState(false);
  const recordingRef = useRef(null);
  const timerRef = useRef(null);
  const flatListRef = useRef(null);

  const currentUid = auth.currentUser?.uid || 'user1';

  useEffect(() => {
    async function loadName() {
      const snap = await getDoc(doc(db, 'users', currentUid));
      if (snap.exists()) setMyName(snap.data().displayName);
    }
    loadName();

    const q = query(
      collection(db, 'chats', DEMO_CHAT_ID, 'messages'),
      orderBy('timestamp', 'asc')
    );
    const unsub = onSnapshot(q, (snapshot) => {
      const msgs = [];
      snapshot.forEach((docSnap) => msgs.push({ id: docSnap.id, ...docSnap.data() }));
      setMessages(msgs);
    });
    return unsub;
  }, []);

  // ── Text message ──
  async function sendTextMessage() {
    if (text.trim() === '') return;
    const msgText = text.trim();
    setText('');

    await addDoc(collection(db, 'chats', DEMO_CHAT_ID, 'messages'), {
      type: 'text',
      text: msgText,
      senderId: currentUid,
      senderName: myName,
      timestamp: serverTimestamp(),
      reactions: {},
      readBy: [currentUid],
      deletedFor: [],
      deletedForEveryone: false,
    });
    await updateDoc(doc(db, 'chats', DEMO_CHAT_ID), {
      lastMessage: { text: `${myName}: ${msgText}`, timestamp: serverTimestamp() },
    });
  }

  // ── Recording ──
  async function handleRecordStart() {
    const { status } = await Audio.requestPermissionsAsync();
    if (status !== 'granted') {
      Alert.alert('Permission needed', 'Microphone access is required');
      return;
    }

    await Audio.setAudioModeAsync({ allowsRecordingIOS: true, playsInSilentModeIOS: true });
    const { recording } = await Audio.Recording.createAsync(
      Audio.RecordingOptionsPresets.HIGH_QUALITY
    );
    recordingRef.current = recording;
    setIsRecording(true);
    setRecordTime(0);
    timerRef.current = setInterval(() => setRecordTime((p) => p + 1000), 1000);
  }

  async function handleRecordStop() {
    if (!recordingRef.current) return;
    clearInterval(timerRef.current);
    setIsRecording(false);

    await recordingRef.current.stopAndUnloadAsync();
    await Audio.setAudioModeAsync({ allowsRecordingIOS: false });

    const uri = recordingRef.current.getURI();
    const status = await recordingRef.current.getStatusAsync();
    recordingRef.current = null;

    if (status.durationMillis < 1000) return; // too short

    // Upload and send
    setUploading(true);
    try {
      const response = await fetch(uri);
      const blob = await response.blob();
      const filename = `voice_${Date.now()}.m4a`;
      const storageRef = ref(storage, `chats/${DEMO_CHAT_ID}/voice/${filename}`);

      const uploadTask = uploadBytesResumable(storageRef, blob);
      await new Promise((resolve, reject) => {
        uploadTask.on('state_changed', null, reject, resolve);
      });
      const downloadURL = await getDownloadURL(uploadTask.snapshot.ref);

      await addDoc(collection(db, 'chats', DEMO_CHAT_ID, 'messages'), {
        type: 'audio',
        audioURL: downloadURL,
        duration: status.durationMillis,
        text: '🎤 Voice message',
        senderId: currentUid,
        senderName: myName,
        timestamp: serverTimestamp(),
        reactions: {},
        readBy: [currentUid],
        deletedFor: [],
        deletedForEveryone: false,
      });
      await updateDoc(doc(db, 'chats', DEMO_CHAT_ID), {
        lastMessage: { text: `${myName}: 🎤 Voice message`, timestamp: serverTimestamp() },
      });
    } catch (err) {
      Alert.alert('Error', 'Failed to send voice message');
    }
    setUploading(false);
  }

  return (
    <KeyboardAvoidingView
      style={styles.container}
      behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
    >
      {/* Header */}
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Voice Messages Demo</Text>
        <Text style={styles.headerSubtitle}>Hold mic button to record</Text>
      </View>

      {/* Messages */}
      <FlatList
        ref={flatListRef}
        data={messages}
        keyExtractor={(item) => item.id}
        style={styles.messageList}
        onContentSizeChange={() => flatListRef.current?.scrollToEnd()}
        renderItem={({ item }) => {
          const isMe = item.senderId === currentUid;
          if (item.type === 'audio') {
            return <VoiceMessageBubble message={item} isMe={isMe} />;
          }
          return (
            <View style={[styles.bubble, isMe ? styles.sent : styles.received]}>
              <Text style={styles.msgText}>{item.text}</Text>
              <Text style={styles.timeText}>
                {item.timestamp?.toDate().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' })}
              </Text>
            </View>
          );
        }}
        ListEmptyComponent={
          <Text style={styles.emptyText}>Send a voice message!</Text>
        }
      />

      {/* Recording indicator */}
      {isRecording && (
        <View style={styles.recordingBar}>
          <Text style={styles.recordingDot}>● </Text>
          <Text style={styles.recordingText}>Recording {formatDuration(recordTime)}</Text>
        </View>
      )}

      {uploading && (
        <View style={styles.recordingBar}>
          <Text style={styles.recordingText}>Uploading voice message...</Text>
        </View>
      )}

      {/* Input bar */}
      <View style={styles.inputBar}>
        <TextInput
          style={styles.input}
          value={text}
          onChangeText={setText}
          placeholder="Type a message"
          multiline
        />
        {text.trim().length > 0 ? (
          <Pressable style={styles.sendBtn} onPress={sendTextMessage}>
            <Text style={styles.sendText}>Send</Text>
          </Pressable>
        ) : (
          <Pressable
            style={[styles.micBtn, isRecording && styles.micBtnActive]}
            onPressIn={handleRecordStart}
            onPressOut={handleRecordStop}
          >
            <Text style={styles.micIcon}>🎤</Text>
          </Pressable>
        )}
      </View>
    </KeyboardAvoidingView>
  );
}
