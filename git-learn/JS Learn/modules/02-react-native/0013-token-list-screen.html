Build the Token List Screen

Capstone · Combines lessons 2–12 ~50 min Hands-on
Why this matters for Token

The token list is the first screen users see after logging in, and it is the whole product in one view: every token they have issued, what it is for, whether it still works, and whether anyone has used it. This capstone combines everything in Module 2 — FlatList, navigation, useState, useEffect, loading skeletons, error handling, pull-to-refresh and search. The result is the screen you will wire directly to the Token API in A3.

2. Data shape

This is the shape of a single token object. In A3 this comes from an API call — for now we use local data with the same shape so the switch requires zero UI changes.

// One token object — matches the JSON the API will return in A3
{
  id:         '1',                    // primary key from the database
  label:      'Flipkart delivery',    // what YOU called it, when you issued it
  code:       'KART-4KN9-RT2M',       // shown on this screen, never passed as a route param
  status:     'active',               // 'active' | 'paused' | 'revoked'
  lastUsedAt: 1755400000000,          // ms since epoch, or null if never redeemed
  unread:     2,                      // unread messages on this token (0 = no badge)
  iconColor:  '#2F9E7E',              // category tint for the row icon
}

// Note what is NOT here: anything about the holder. No name, no avatar, no
// "online" dot. The list is a list of YOUR tokens, not of people.

3. State design

Plan state before writing JSX. This screen needs:

const [allTokens,  setAllTokens]  = useState([]);    // full list from the API
const [loading,    setLoading]    = useState(true);
const [error,      setError]      = useState(null);
const [refreshing, setRefreshing] = useState(false);
const [query,      setQuery]      = useState('');    // search input text

// Derived — never stored in state, computed inline.
// Label only: the code is capability material, and nobody finds a token by
// typing a fragment of one into a search box.
const filteredTokens = query.trim()
  ? allTokens.filter(t =>
      t.label.toLowerCase().includes(query.toLowerCase())
    )
  : allTokens;

filteredTokens is derived from allTokens and query — recomputed on every render, no extra useEffect needed. If query is empty, show everything.

4. The token row component

Extract the row into its own component so the FlatList renderItem stays clean. Components defined outside the screen function avoid being re-created on every render.

4b. Ordering the list

Six rows in the order the API happened to return them is not a screen. The list has to have an order, and the order carries meaning: a revoked token is dead and belongs at the bottom, an active one you used an hour ago belongs at the top.

Try it yourself — this one is broken on purpose

This sorts the list before rendering it. Watch what it does to the array it was given:

Array.prototype.sort sorts in place and returns the same array. Called on the array held in state, it reorders that array — so React compares the new value to the old one, finds the identical object, and concludes nothing changed. The data is now in a different order and the screen is not.

The two ways this shows up

Sometimes the list simply does not re-order until something else forces a render, and you blame the sort comparator. Sometimes it re-orders later, when an unrelated state change re-renders the screen, and the rows appear to shuffle themselves for no reason.

Copy first: [...tokens].sort(…). It is one character of punctuation and it is the difference between a pure function and a bug you will chase twice.

// ── Skeleton ──────────────────────────────────────────────────────────────────
function SkeletonBlock({ width, height, borderRadius, style }) {
  const opacity = useRef(new Animated.Value(0.4)).current;
  useEffect(() => {
    Animated.loop(
      Animated.sequence([
        Animated.timing(opacity, { toValue: 1,   duration: 700, useNativeDriver: true }),
        Animated.timing(opacity, { toValue: 0.4, duration: 700, useNativeDriver: true }),
      ])
    ).start();
  }, []);
  return (
    <Animated.View
      style={[{ backgroundColor: '#e0e0e0' }, { width, height, borderRadius }, { opacity }, style]}
    />
  );
}

// ── Token List Screen ─────────────────────────────────────────────────────────
function TokenListScreen({ navigation }) {
  const [allTokens,   setAllTokens]   = useState([]);
  const [loading,    setLoading]    = useState(true);
  const [error,      setError]      = useState(null);
  const [refreshing, setRefreshing] = useState(false);
  const [query,      setQuery]      = useState('');
  const [showSearch, setShowSearch] = useState(false);

  // Derived — filtered list, never stored in state
  const filteredTokens = query.trim()
    ? allTokens.filter(c =>
        c.name.toLowerCase().includes(query.toLowerCase()) ||
        c.preview.toLowerCase().includes(query.toLowerCase())
      )
    : allTokens;

  // Total unread for tab badge
  useEffect(() => {
    const total = allTokens.reduce((sum, c) => sum + c.unread, 0);
    navigation.setOptions({
      tabBarBadge: total > 0 ? total : undefined,
    });
  }, [allTokens, navigation]);

  // Initial load
  async function loadTokens() {
    setLoading(true);
    setError(null);
    try {
      // TODO A3: replace with a call to the Token API
      // const { data } = await api.get('/tokens');
      // const snap = await getDocs(q);
      // setAllTokens(snap.docs.map(d => ({ id: d.id, ...d.data() })));
      await new Promise(r => setTimeout(r, 1200));
      setAllTokens(SAMPLE_TOKENS);
    } catch {
      setError('Could not load your tokens. Check your connection.');
    } finally {
      setLoading(false);
    }
  }

  // Pull-to-refresh
  async function onRefresh() {
    setRefreshing(true);
    try {
      await new Promise(r => setTimeout(r, 900));
      setAllTokens(SAMPLE_TOKENS);
    } catch {
      // Non-fatal — list stays, show nothing (toast could go here)
    } finally {
      setRefreshing(false);
    }
  }

  useEffect(() => { loadTokens(); }, []);

  // ── Loading state ───────────────────────────────────────────────────────────
  if (loading) {
    return (
      <View style={styles.screen}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>My tokens</Text>
        </View>
        {[1,2,3,4,5,6].map(i => <TokenRowSkeleton key={i} />)}
      </View>
    );
  }

  // ── Error state ─────────────────────────────────────────────────────────────
  if (error) {
    return (
      <View style={styles.screen}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>My tokens</Text>
        </View>
        <View style={styles.centre}>
          <Text style={styles.errorIcon}>⚠️</Text>
          <Text style={styles.errorTitle}>Something went wrong</Text>
          <Text style={styles.errorMessage}>{error}</Text>
          <Pressable style={styles.retryBtn} onPress={loadTokens}>
            <Text style={styles.retryText}>Try again</Text>
          </Pressable>
        </View>
      </View>
    );
  }

  // ── Data state (including empty) ────────────────────────────────────────────
  return (
    <View style={styles.screen}>

      {/* Header */}
      <View style={styles.header}>
        {showSearch ? (
          <TextInput
            style={styles.searchInput}
            value={query}
            onChangeText={setQuery}
            placeholder="Search your tokens..."
            placeholderTextColor="#b2dfdb"
            autoFocus
            returnKeyType="search"
            onSubmitEditing={() => Keyboard.dismiss()}
          />
        ) : (
          <Text style={styles.headerTitle}>My tokens</Text>
        )}
        <Pressable
          style={styles.searchIconBtn}
          onPress={() => {
            setShowSearch(s => !s);
            if (showSearch) setQuery('');
          }}
        >
          <Text style={styles.searchIconText}>{showSearch ? '✕' : '🔍'}</Text>
        </Pressable>
      </View>

      {/* Search result count */}
      {showSearch && query.trim() ? (
        <View style={styles.resultBar}>
          <Text style={styles.resultText}>
            {filteredTokens.length === 0
              ? 'No tokens match'
              : `${filteredTokens.length} result${filteredTokens.length !== 1 ? 's' : ''}`}
          </Text>
        </View>
      ) : null}

      {/* List */}
      <FlatList
        data={filteredTokens}
        keyExtractor={item => item.id}
        refreshing={refreshing}
        onRefresh={onRefresh}
        keyboardShouldPersistTaps="handled"
        ItemSeparatorComponent={() => <View style={styles.sep} />}
        ListEmptyComponent={
          <View style={styles.emptyState}>
            {query.trim() ? (
              // Empty because search found nothing
              <>
                <Text style={styles.emptyIcon}>🔍</Text>
                <Text style={styles.emptyTitle}>No results for "{query}"</Text>
                <Text style={styles.emptySub}>Try a different name or message.</Text>
              </>
            ) : (
              // Empty because there are genuinely no tokens
              <>
                <Text style={styles.emptyIcon}>💬</Text>
                <Text style={styles.emptyTitle}>No tokens yet</Text>
                <Text style={styles.emptySub}>
                  Tap the pencil icon to start your first conversation.
                </Text>
              </>
            )}
          </View>
        }
        renderItem={({ item }) => (
          <TokenRow
            token={item}
            onPress={() => {
              Keyboard.dismiss();
              navigation.navigate('TokenDetail', {
                tokenId:    item.id,
                tokenLabel: item.label,
                status:     item.status,
              });
            }}
          />
        )}
      />

    </View>
  );
}

The three lines that change in Module 3

The entire screen stays identical. Only the inside of loadTokens changes — the fake await new Promise becomes a real API call. And in A6 you'll add a WebSocket subscription so the list updates the instant a new message arrives, without the user needing to pull to refresh.

Now build it yourself

The screen is React Native; the ordering is not. This is the last plain function of the module, and it is the one the whole list screen is arranged around.

Anything unclear? Ask your teacher. Common issues: (1) Tab badge doesn't appear — make sure you're calling navigation.setOptions from inside the TokenListScreen component that is registered directly in the Tab.Navigator (not from inside the Stack). The navigation prop in TokenListScreen belongs to the Tokens tab — it can set tabBarBadge. (2) Search doesn't filter — confirm filteredTokens is the variable passed to FlatList's data prop, not allTokens. (3) Keyboard hides the search input — add keyboardShouldPersistTaps="handled" to the FlatList so tapping a row while the keyboard is open works correctly.
