React Native · Lesson 8

React Navigation

Stack · Bottom Tabs · Nested navigators ~40 min Hands-on
Why this matters for your WhatsApp clone

Right now all your code lives in one App.js file. A real app has multiple screens — a chat list, a message thread, a profile page, a login screen — and users move between them by tapping. React Navigation is the library that handles all of this: sliding screens in and out, the back button, the bottom tab bar with Chats / Calls / Status / Settings, and passing data from one screen to another.

1. How navigation works in React Native

On the web, navigation is handled by the browser — URLs, the back button, the history stack. React Native has no browser, so you manage navigation yourself using a library. The standard library used by almost every React Native app is React Navigation.

React Navigation gives you two main navigator types you'll use constantly:

  • Stack Navigator — screens stack on top of each other. Tap a chat row → message thread slides in from the right. Press back → it slides back out. This is the standard mobile navigation pattern.
  • Bottom Tab Navigator — a tab bar at the bottom with icons. WhatsApp's Chats / Calls / Status / Settings tabs are a bottom tab navigator.

In your WhatsApp clone the two are nested — the bottom tabs sit inside the stack. Tapping a chat row from the Chats tab pushes the message thread onto the stack on top of everything.

2. Installation

React Navigation is not built into React Native — install it in your whatsapp-clone project:

# Core library
npm install @react-navigation/native

# Required peer dependencies
npx expo install react-native-screens react-native-safe-area-context

# Stack navigator
npm install @react-navigation/native-stack

# Bottom tab navigator
npm install @react-navigation/bottom-tabs
Use npx expo install for Expo-managed dependencies

npx expo install (not plain npm install) picks the version of a package that is compatible with your current Expo SDK version. Use it for any package that has native code — like react-native-screens. Use plain npm install for pure JS packages like @react-navigation/native-stack.

3. Setting up the NavigationContainer

Every React Navigation app needs a NavigationContainer at the root — it manages the navigation state for the whole app. Wrap your entire app in it inside App.js.

// App.js — the root of your app
import { NavigationContainer } from '@react-navigation/native';

export default function App() {
  return (
    <NavigationContainer>
      {/* All your navigators and screens go inside here */}
    </NavigationContainer>
  );
}

4. Stack Navigator — pushing and popping screens

A stack navigator lets you push screens on top of each other and pop them off when pressing back — exactly like a stack of cards.

import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { View, Text, Pressable, StyleSheet } from 'react-native';

const Stack = createNativeStackNavigator();

// ── Screen components ──────────────────────────────────────────────────────

function ChatListScreen({ navigation }) {
  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Chat List</Text>
      <Pressable
        style={styles.button}
        onPress={() => navigation.navigate('MessageThread')}
      >
        <Text style={styles.buttonText}>Open Priya's chat</Text>
      </Pressable>
    </View>
  );
}

function MessageThreadScreen({ navigation }) {
  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Message Thread</Text>
      <Pressable
        style={styles.button}
        onPress={() => navigation.goBack()}
      >
        <Text style={styles.buttonText}>← Go back</Text>
      </Pressable>
    </View>
  );
}

// ── Navigator ─────────────────────────────────────────────────────────────

export default function App() {
  return (
    <NavigationContainer>
      <Stack.Navigator initialRouteName="ChatList">
        <Stack.Screen name="ChatList"      component={ChatListScreen} />
        <Stack.Screen name="MessageThread" component={MessageThreadScreen} />
      </Stack.Navigator>
    </NavigationContainer>
  );
}

const styles = StyleSheet.create({
  screen:     { flex: 1, alignItems: 'center', justifyContent: 'center', backgroundColor: '#fff' },
  title:      { fontSize: 24, fontWeight: '700', marginBottom: 24 },
  button:     { backgroundColor: '#075E54', paddingHorizontal: 24, paddingVertical: 12, borderRadius: 8 },
  buttonText: { color: '#fff', fontSize: 16, fontWeight: '600' },
});

Run this. Tap the button — the message thread screen slides in from the right. Press the hardware back button (Android) or swipe right (iOS) — it slides back. React Navigation handles the animation and back gesture automatically.

The navigation prop

Every screen component registered in a navigator automatically receives a navigation prop. The key methods are:
navigation.navigate('ScreenName') — go to a screen
navigation.goBack() — go back one screen
navigation.push('ScreenName') — push a new instance even if already in the stack
navigation.replace('ScreenName') — replace current screen (useful for login → home)

5. Passing data between screens — route params

When the user taps a chat row, you need to tell the message thread screen which chat to show. You pass data via route params.

// Sending params — from ChatListScreen
function ChatListScreen({ navigation }) {
  const chats = [
    { id: '1', name: 'Priya Sharma', lastMessage: 'Perfect, see you!' },
    { id: '2', name: 'Rahul Mehta',  lastMessage: 'Check this out' },
  ];

  return (
    <View style={styles.screen}>
      {chats.map(chat => (
        <Pressable
          key={chat.id}
          style={styles.row}
          onPress={() => navigation.navigate('MessageThread', {
            chatId:   chat.id,       // pass any data you need
            chatName: chat.name,
          })}
        >
          <Text style={styles.name}>{chat.name}</Text>
          <Text style={styles.preview}>{chat.lastMessage}</Text>
        </Pressable>
      ))}
    </View>
  );
}

// Receiving params — in MessageThreadScreen
function MessageThreadScreen({ route, navigation }) {
  const { chatId, chatName } = route.params;  // destructure what was passed

  return (
    <View style={styles.screen}>
      <Text style={styles.title}>Chat with {chatName}</Text>
      <Text style={styles.sub}>Chat ID: {chatId}</Text>
    </View>
  );
}
Only pass plain serialisable data as params

Route params must be serialisable — strings, numbers, booleans, plain objects, arrays. Don't pass class instances, functions, or React components. Pass the ID and fetch the full data inside the target screen using useEffect. This keeps navigation fast and avoids bugs when the app is backgrounded.

6. Customising the header

// Option 1 — set title per screen in the navigator
<Stack.Screen
  name="MessageThread"
  component={MessageThreadScreen}
  options={{ title: 'Priya Sharma' }}
/>

// Option 2 — dynamic title from route params
<Stack.Screen
  name="MessageThread"
  component={MessageThreadScreen}
  options={({ route }) => ({ title: route.params.chatName })}
/>

// Option 3 — set options from inside the screen using navigation.setOptions
function MessageThreadScreen({ route, navigation }) {
  const { chatName } = route.params;

  useEffect(() => {
    navigation.setOptions({
      title: chatName,
      headerStyle:     { backgroundColor: '#075E54' },
      headerTintColor: '#fff',         // back button and title colour
      headerTitleStyle:{ fontWeight: '700' },
    });
  }, [chatName]);

  return <View>...</View>;
}

// Hide the header entirely — for screens with custom headers
<Stack.Screen
  name="ChatList"
  component={ChatListScreen}
  options={{ headerShown: false }}
/>
headerShown: false for your main screens

Your chat list and message thread screens have custom green headers you built in earlier lessons. Set headerShown: false on those screens so React Navigation's default header doesn't appear on top of yours.

7. Bottom Tab Navigator — the WhatsApp tab bar

WhatsApp has four tabs at the bottom: Chats, Calls, Status, Settings. This is a bottom tab navigator.

import { createBottomTabNavigator } from '@react-navigation/bottom-tabs';
import { Text } from 'react-native';

const Tab = createBottomTabNavigator();

// Placeholder screen components
function ChatsScreen()    { return <Text>Chats</Text>; }
function CallsScreen()    { return <Text>Calls</Text>; }
function StatusScreen()   { return <Text>Status</Text>; }
function SettingsScreen() { return <Text>Settings</Text>; }

function TabNavigator() {
  return (
    <Tab.Navigator
      screenOptions={{
        tabBarActiveTintColor:   '#075E54',
        tabBarInactiveTintColor: '#667781',
        tabBarStyle:             { backgroundColor: '#fff' },
        headerShown:             false,
      }}
    >
      <Tab.Screen
        name="Chats"
        component={ChatsScreen}
        options={{
          tabBarIcon: ({ color }) => <Text style={{ color, fontSize: 20 }}>💬</Text>,
          tabBarBadge: 3,   // unread count badge on the tab icon
        }}
      />
      <Tab.Screen
        name="Calls"
        component={CallsScreen}
        options={{
          tabBarIcon: ({ color }) => <Text style={{ color, fontSize: 20 }}>📞</Text>,
        }}
      />
      <Tab.Screen
        name="Status"
        component={StatusScreen}
        options={{
          tabBarIcon: ({ color }) => <Text style={{ color, fontSize: 20 }}>⊙</Text>,
        }}
      />
      <Tab.Screen
        name="Settings"
        component={SettingsScreen}
        options={{
          tabBarIcon: ({ color }) => <Text style={{ color, fontSize: 20 }}>⚙</Text>,
        }}
      />
    </Tab.Navigator>
  );
}
Use react-native-vector-icons for real tab icons

The emoji approach above works for learning, but your real app should use proper icons. Install @expo/vector-icons (already included in Expo) for sharp, scalable icons: import { Ionicons } from '@expo/vector-icons'. Then use <Ionicons name="chatbubbles" size={24} color={color} /> as the tabBarIcon.

8. Nested navigators — the full WhatsApp structure

The complete WhatsApp navigation structure nests a stack inside the Chats tab — so tapping a chat row pushes the message thread on top of the tab bar.

import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator }  from '@react-navigation/native-stack';
import { createBottomTabNavigator }    from '@react-navigation/bottom-tabs';

const Stack = createNativeStackNavigator();
const Tab   = createBottomTabNavigator();

// ── Placeholder screens ────────────────────────────────────────────────────
function ChatListScreen({ navigation }) {
  return /* your chat list from Lesson 7 */;
}

function MessageThreadScreen({ route }) {
  const { chatId, chatName } = route.params;
  return /* your message thread from Lesson 5 */;
}

function CallsScreen()    { /* calls list */ }
function StatusScreen()   { /* status updates */ }
function SettingsScreen() { /* settings */ }

// ── Chats stack — chat list + message thread ──────────────────────────────
function ChatsStack() {
  return (
    <Stack.Navigator screenOptions={{ headerShown: false }}>
      <Stack.Screen name="ChatList"      component={ChatListScreen} />
      <Stack.Screen name="MessageThread" component={MessageThreadScreen} />
    </Stack.Navigator>
  );
}

// ── Root tab navigator ─────────────────────────────────────────────────────
function RootTabs() {
  return (
    <Tab.Navigator
      screenOptions={{
        headerShown:             false,
        tabBarActiveTintColor:   '#075E54',
        tabBarInactiveTintColor: '#667781',
      }}
    >
      <Tab.Screen name="Chats"    component={ChatsStack} />
      <Tab.Screen name="Calls"    component={CallsScreen} />
      <Tab.Screen name="Status"   component={StatusScreen} />
      <Tab.Screen name="Settings" component={SettingsScreen} />
    </Tab.Navigator>
  );
}

// ── Root — auth stack wraps everything ────────────────────────────────────
// Login and Register screens are outside the tabs so they have no tab bar
function RootStack() {
  return (
    <Stack.Navigator screenOptions={{ headerShown: false }}>
      <Stack.Screen name="Login"    component={LoginScreen} />
      <Stack.Screen name="Register" component={RegisterScreen} />
      <Stack.Screen name="Main"     component={RootTabs} />
    </Stack.Navigator>
  );
}

// ── Entry point ───────────────────────────────────────────────────────────
export default function App() {
  return (
    <NavigationContainer>
      <RootStack />
    </NavigationContainer>
  );
}

This is the complete navigation structure for your WhatsApp clone. The flow is:

  1. App opens → Login screen (no tab bar)
  2. User logs in → navigation.replace('Main') → Bottom tabs appear
  3. User taps a chat row → navigation.navigate('MessageThread', { chatId, chatName }) → Message thread slides in over the tabs
  4. User presses back → Returns to chat list with tabs

9. Full working example — WhatsApp navigation shell

This is the complete navigation skeleton for your app. Every screen is a placeholder for now — you'll fill them in across the next lessons and modules. Replace your entire App.js with this.

import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator }  from '@react-navigation/native-stack';
import { createBottomTabNavigator }    from '@react-navigation/bottom-tabs';
import {
  View, Text, FlatList, Pressable,
  TextInput, StyleSheet, Platform
} from 'react-native';

const Stack = createNativeStackNavigator();
const Tab   = createBottomTabNavigator();

// ── Screen: Chat List ──────────────────────────────────────────────────────
const CHATS = [
  { id: '1', name: 'Priya Sharma',  preview: 'Perfect, see you then!',    time: '10:32', unread: 2 },
  { id: '2', name: 'Rahul Mehta',   preview: 'Check out this article',    time: '09:15', unread: 0 },
  { id: '3', name: 'Family Group',  preview: 'Mom: Dinner at 7!',         time: 'Yesterday', unread: 5 },
  { id: '4', name: 'Work Team',     preview: 'Meeting moved to 3pm',      time: 'Yesterday', unread: 0 },
];

function ChatListScreen({ navigation }) {
  return (
    <View style={styles.screen}>
      <View style={styles.header}>
        <Text style={styles.headerTitle}>WhatsApp</Text>
      </View>
      <FlatList
        data={CHATS}
        keyExtractor={item => item.id}
        renderItem={({ item }) => (
          <Pressable
            style={({ pressed }) => [styles.row, pressed && styles.rowPressed]}
            onPress={() => navigation.navigate('MessageThread', {
              chatId:   item.id,
              chatName: item.name,
            })}
          >
            <View style={styles.avatarCircle}>
              <Text style={styles.avatarLetter}>{item.name[0]}</Text>
            </View>
            <View style={styles.middle}>
              <Text style={styles.name}>{item.name}</Text>
              <Text style={styles.preview} numberOfLines={1}>{item.preview}</Text>
            </View>
            <View style={styles.right}>
              <Text style={[styles.time, item.unread > 0 && styles.timeGreen]}>{item.time}</Text>
              {item.unread > 0 && (
                <View style={styles.badge}>
                  <Text style={styles.badgeText}>{item.unread}</Text>
                </View>
              )}
            </View>
          </Pressable>
        )}
        ItemSeparatorComponent={() => <View style={styles.sep} />}
      />
    </View>
  );
}

// ── Screen: Message Thread ─────────────────────────────────────────────────
function MessageThreadScreen({ route, navigation }) {
  const { chatId, chatName } = route.params;

  // Set the header once the screen mounts
  useEffect(() => {
    navigation.setOptions({ headerShown: false });

  return (
    <View style={styles.screen}>
      <View style={styles.header}>
        <Pressable onPress={() => navigation.goBack()} style={styles.backBtn}>
          <Text style={styles.backArrow}>←</Text>
        </Pressable>
        <View>
          <Text style={styles.headerTitle}>{chatName}</Text>
          <Text style={styles.headerSub}>online</Text>
        </View>
      </View>
      <View style={styles.threadBody}>
        <Text style={styles.placeholder}>Messages for {chatName} (chat {chatId})</Text>
        <Text style={styles.placeholderSub}>Full message thread coming in Lesson 14</Text>
      </View>
    </View>
  );
}
