Build the Chat List Screen

Capstone · Combines lessons 2–12 ~50 min Hands-on
Why this matters for your WhatsApp clone

The chat list is the first screen users see after logging in. It's the heart of WhatsApp — a scrollable list of every conversation, sorted by most recent, with unread counts, contact names, message previews, and a search bar. This capstone lesson combines everything you've learned in Module 2: FlatList, navigation, useState, useEffect, loading skeletons, error handling, pull-to-refresh, and search filtering. The result is a production-quality screen you'll wire directly to Firebase in Module 3.

2. Data shape

This is the shape of a single chat object. In Module 3 this comes from a Firestore query — for now we use local data with the same shape so the switch requires zero UI changes.

// One chat object — matches the Firestore document shape you'll use in Module 3
{
  id:          '1',              // Firestore document ID
  name:        'Priya Sharma',   // contact's display name
  preview:     'See you then!',  // last message text
  time:        '10:32',          // last message time, formatted string
  unread:      2,                // unread message count (0 = no badge)
  avatarColor: '#128C7E',        // fallback colour when no photo
  isGroup:     false,            // group vs direct message
  online:      true,             // show online indicator dot
}

Plan state before writing JSX. This screen needs:

const [allChats,   setAllChats]   = useState([]);    // full list from Firebase

const [error,      setError]      = useState(null);
const [refreshing, setRefreshing] = useState(false);

// Derived — never stored in state, computed inline
const filteredChats = query.trim()
  ? allChats.filter(c =>
      c.name.toLowerCase().includes(query.toLowerCase()) ||
      c.preview.toLowerCase().includes(query.toLowerCase())
    )
  : allChats;

filteredChats is derived from allChats and query — recomputed on every render, no extra useEffect needed. If query is empty, show everything.

Extract the row into its own component so the FlatList renderItem stays clean. Components defined outside the screen function avoid being re-created on every render.

5. The search bar

The search bar lives inside the header — same dark green background. It appears when the user taps a search icon. Use a simple showSearch boolean to toggle it.

const [showSearch, setShowSearch] = useState(false);

// Inside the header:
{showSearch ? (
  <TextInput

6. Total unread count in the tab bar badge

WhatsApp shows the total unread count as a badge on the Chats tab icon. Pass it up to the navigator using navigation.setOptions.

// Inside ChatListScreen, after allChats is loaded:
useEffect(() => {
  const totalUnread = allChats.reduce((sum, c) => sum + c.unread, 0);
  navigation.setOptions({
    tabBarBadge: totalUnread > 0 ? totalUnread : undefined,
    //                                          ↑ undefined removes the badge
  });
}, [allChats, navigation]);

// ── Skeleton ──────────────────────────────────────────────────────────────────
function SkeletonBlock({ width, height, borderRadius, style }) {
  const opacity = useRef(new Animated.Value(0.4)).current;
  useEffect(() => {
    Animated.loop(
      Animated.sequence([
        Animated.timing(opacity, { toValue: 1,   duration: 700, useNativeDriver: true }),
        Animated.timing(opacity, { toValue: 0.4, duration: 700, useNativeDriver: true }),
      ])
    ).start();
  }, []);
  return (
    <Animated.View
      style={[{ backgroundColor: '#e0e0e0' }, { width, height, borderRadius }, { opacity }, style]}
    />
  );
}

// ── Chat List Screen ──────────────────────────────────────────────────────────
function ChatListScreen({ navigation }) {
  const [allChats,   setAllChats]   = useState([]);
  const [loading,    setLoading]    = useState(true);
  const [error,      setError]      = useState(null);
  const [refreshing, setRefreshing] = useState(false);
  const [query,      setQuery]      = useState('');
  const [showSearch, setShowSearch] = useState(false);

  // Derived — filtered list, never stored in state
  const filteredChats = query.trim()
    ? allChats.filter(c =>
        c.name.toLowerCase().includes(query.toLowerCase()) ||
        c.preview.toLowerCase().includes(query.toLowerCase())
      )
    : allChats;

  // Total unread for tab badge
  useEffect(() => {
    const total = allChats.reduce((sum, c) => sum + c.unread, 0);
    navigation.setOptions({
      tabBarBadge: total > 0 ? total : undefined,
    });
  }, [allChats, navigation]);

  // Initial load
  async function loadChats() {
    setLoading(true);
    setError(null);
    try {
      // TODO Module 3: replace with Firebase query
      // const q = query(collection(db, 'chats'), orderBy('lastMessageAt', 'desc'));
      // const snap = await getDocs(q);
      // setAllChats(snap.docs.map(d => ({ id: d.id, ...d.data() })));
      await new Promise(r => setTimeout(r, 1200));
      setAllChats(SAMPLE_CHATS);
    } catch {
      setError('Could not load chats. Check your connection.');
    } finally {
      setLoading(false);
    }
  }

  // Pull-to-refresh
  async function onRefresh() {
    setRefreshing(true);
    try {
      await new Promise(r => setTimeout(r, 900));
      setAllChats(SAMPLE_CHATS);
    } catch {
      // Non-fatal — list stays, show nothing (toast could go here)
    } finally {
      setRefreshing(false);
    }
  }

  useEffect(() => { loadChats(); }, []);

  // ── Loading state ───────────────────────────────────────────────────────────
  if (loading) {
    return (
      <View style={styles.screen}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>WhatsApp</Text>
        </View>
        {[1,2,3,4,5,6].map(i => <ChatRowSkeleton key={i} />)}
      </View>
    );
  }

  // ── Error state ─────────────────────────────────────────────────────────────
  if (error) {
    return (
      <View style={styles.screen}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>WhatsApp</Text>
        </View>
        <View style={styles.centre}>
          <Text style={styles.errorIcon}>⚠️</Text>
          <Text style={styles.errorTitle}>Something went wrong</Text>
          <Text style={styles.errorMessage}>{error}</Text>
          <Pressable style={styles.retryBtn} onPress={loadChats}>
            <Text style={styles.retryText}>Try again</Text>
          </Pressable>
        </View>
      </View>
    );
  }

  // ── Data state (including empty) ────────────────────────────────────────────
  return (
    <View style={styles.screen}>

      {/* Header */}
      <View style={styles.header}>
        {showSearch ? (
          <TextInput
            style={styles.searchInput}
            value={query}
            onChangeText={setQuery}
            placeholder="Search chats..."
            placeholderTextColor="#b2dfdb"
            autoFocus
            returnKeyType="search"
            onSubmitEditing={() => Keyboard.dismiss()}
          />
        ) : (
          <Text style={styles.headerTitle}>WhatsApp</Text>
        )}
        <Pressable
          style={styles.searchIconBtn}
          onPress={() => {
            setShowSearch(s => !s);
            if (showSearch) setQuery('');
          }}
        >
          <Text style={styles.searchIconText}>{showSearch ? '✕' : '🔍'}</Text>
        </Pressable>
      </View>

      {/* Search result count */}
      {showSearch && query.trim() ? (
        <View style={styles.resultBar}>
          <Text style={styles.resultText}>
            {filteredChats.length === 0
              ? 'No chats match'
              : `${filteredChats.length} result${filteredChats.length !== 1 ? 's' : ''}`}
          </Text>
        </View>
      ) : null}

      {/* List */}
      <FlatList
        data={filteredChats}
        keyExtractor={item => item.id}
        refreshing={refreshing}
        onRefresh={onRefresh}
        keyboardShouldPersistTaps="handled"
        ItemSeparatorComponent={() => <View style={styles.sep} />}
        ListEmptyComponent={
          <View style={styles.emptyState}>
            {query.trim() ? (
              // Empty because search found nothing
              <>
                <Text style={styles.emptyIcon}>🔍</Text>
                <Text style={styles.emptyTitle}>No results for "{query}"</Text>
                <Text style={styles.emptySub}>Try a different name or message.</Text>
              </>
            ) : (
              // Empty because there are genuinely no chats
              <>
                <Text style={styles.emptyIcon}>💬</Text>
                <Text style={styles.emptyTitle}>No chats yet</Text>
                <Text style={styles.emptySub}>
                  Tap the pencil icon to start your first conversation.
                </Text>
              </>
            )}
          </View>
        }
        renderItem={({ item }) => (
          <ChatRow
            chat={item}
            onPress={() => {
              Keyboard.dismiss();
              navigation.navigate('MessageThread', {
                chatId:   item.id,
                chatName: item.name,
                isGroup:  item.isGroup,
              });
            }}
          />
        )}
      />

    </View>
  );
}

The three lines that change in Module 3

The entire screen stays identical. Only the inside of loadChats changes — the fake await new Promise becomes a real Firestore query. And in Module 3 you'll also add a real-time listener with onSnapshot so the list updates instantly when a new message arrives — without the user needing to pull to refresh.

Anything unclear? Ask your teacher. Common issues: (1) Tab badge doesn't appear — make sure you're calling navigation.setOptions from inside the ChatListScreen component that is registered directly in the Tab.Navigator (not from inside the Stack). The navigation prop in ChatListScreen belongs to the Chats tab — it can set tabBarBadge. (2) Search doesn't filter — confirm filteredChats is the variable passed to FlatList's data prop, not allChats. (3) Keyboard hides the search input — add keyboardShouldPersistTaps="handled" to the FlatList so tapping a row while the keyboard is open works correctly.
