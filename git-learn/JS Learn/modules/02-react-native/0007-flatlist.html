FlatList

Performant lists · keyExtractor · ListEmptyComponent ~30 min Hands-on
Why this matters for your WhatsApp clone

Your chat list could have hundreds of conversations. A message thread could have thousands of messages. If you render all of them at once with ScrollView, the app becomes slow and eats memory — you'd feel it on a mid-range Android phone immediately. FlatList solves this by only rendering the items currently visible on screen, recycling off-screen items as the user scrolls. It's the component behind every performant list in every serious React Native app.

1. ScrollView vs FlatList — when to use each

ScrollView FlatList
Renders All children at once Only visible items (+ a small buffer)
Performance Fine for <20 items Handles thousands of items smoothly
Memory Keeps all items in memory Recycles off-screen items
Built-in features None Pull-to-refresh, load more, empty state, headers, separators
Use for Settings screens, profile forms, short static content Chat list, message thread, contacts, search results

Rule of thumb: if the number of items can grow (comes from a database, a search result, user-generated), use FlatList. If it's a fixed short form, use ScrollView.

2. Basic FlatList

FlatList needs three required props: data, renderItem, and keyExtractor.

import { FlatList, View, Text, StyleSheet } from 'react-native';

const chats = [
  { id: '1', name: 'Priya Sharma',  preview: 'Perfect, see you then!' },
  { id: '2', name: 'Rahul Mehta',   preview: 'Check out this article' },
  { id: '3', name: 'Family Group',  preview: 'Dinner at 7!' },
];

export default function App() {
  return (
    <FlatList
      data={chats}
      keyExtractor={item => item.id}
      renderItem={({ item }) => (
        <View style={styles.row}>
          <Text style={styles.name}>{item.name}</Text>
          <Text style={styles.preview}>{item.preview}</Text>
        </View>
      )}
    />
  );
}

const styles = StyleSheet.create({
  row:     { padding: 16, borderBottomWidth: 1, borderBottomColor: '#f0f2f5' },
  name:    { fontSize: 16, fontWeight: '600' },
  preview: { fontSize: 14, color: '#667781', marginTop: 2 },
});

Breaking down the three required props:

  • data — the array to render. When this array changes (new message arrives), FlatList re-renders only the affected rows.
  • keyExtractor — a function that returns a unique string key for each item. React Native uses this to track which items changed. Always use a stable unique ID — never the array index.
  • renderItem — a function that receives { item, index } and returns the JSX for one row.
Never use the array index as a key

Using keyExtractor={(item, index) => index.toString()} seems harmless but causes subtle bugs — when items are added, removed, or reordered, React Native gets confused about which component is which and can render stale data. Always use a stable unique ID from your data: item.id, item.uid, doc.id from Firestore.

4. Pull-to-refresh

WhatsApp lets you pull down to refresh the chat list. FlatList has this built in — no extra library needed.

import { useState } from 'react';

export default function ChatListScreen() {
  const [chats, setChats]           = useState([]);
  const [isRefreshing, setIsRefreshing] = useState(false);

  async function handleRefresh() {
    setIsRefreshing(true);
    try {
      const fresh = await fetchChats();
      setChats(fresh);
    } finally {
      setIsRefreshing(false);
    }
  }

  return (
    <FlatList
      data={chats}
      keyExtractor={item => item.id}
      renderItem={({ item }) => <ChatRow chat={item} />}
      refreshing={isRefreshing}
      onRefresh={handleRefresh}
      {/* Pull down → shows spinner → calls handleRefresh → updates list */}
    />
  );
}

5. inverted — for message threads

WhatsApp message threads show the newest messages at the bottom and scroll up to see older ones. The cleanest way to achieve this is the inverted prop — it flips the list so the last item appears first, and you reverse your data array.

// Pass messages in reverse order + inverted prop
<FlatList
  data={[...messages].reverse()}   // newest first in the array
  keyExtractor={item => item.id}
  renderItem={({ item }) => <MessageBubble message={item} />}
  inverted={true}                   // flips the list visually
  contentContainerStyle={{ paddingVertical: 8 }}
/>

{/* Result: newest message appears at the bottom — exactly like WhatsApp */}
{/* New messages added to the messages array automatically appear at the bottom */}
{/* No need to scroll to end programmatically — it starts there */}
inverted is the professional way to build chat threads

Using inverted with a reversed array is simpler and more reliable than trying to scrollToEnd manually every time a new message arrives. It also handles the keyboard appearing correctly — the list stays anchored to the bottom when the keyboard opens.

6. onEndReached — loading more messages

In a real chat app you don't load all messages at once — you load the last 20, then load more as the user scrolls up (pagination). onEndReached fires when the user scrolls near the end of the list.

export default function MessageThread({ chatId }) {
  const [messages, setMessages]     = useState([]);
  const [isLoadingMore, setIsLoadingMore] = useState(false);
  const [hasMore, setHasMore]       = useState(true);

  async function loadMoreMessages() {
    if (isLoadingMore || !hasMore) return;
    setIsLoadingMore(true);

    try {
      const older = await fetchOlderMessages(chatId, messages[messages.length - 1]?.id);
      if (older.length === 0) {
        setHasMore(false);  // no more messages to load
      } else {
        setMessages(prev => [...prev, ...older]);
      }
    } finally {
      setIsLoadingMore(false);
    }
  }

  return (
    <FlatList
      data={[...messages].reverse()}
      keyExtractor={item => item.id}
      renderItem={({ item }) => <MessageBubble message={item} />}
      inverted
      onEndReached={loadMoreMessages}
      onEndReachedThreshold={0.3}  // trigger when 30% from the end
      ListFooterComponent={isLoadingMore ? (
        <ActivityIndicator style={{ padding: 16 }} color="#075E54" />
      ) : null}
    />
  );
}
onEndReachedThreshold

A value between 0 and 1. 0.3 means "trigger when the user is 30% of the list height from the bottom". Lower values trigger later (closer to the end). 0.3 is a good default — it starts loading before the user actually hits the end, so they never see a gap.

7. Performance tips

For a smooth 60fps scroll on mid-range Android phones — the ones most of your users will have — keep these in mind:

Extract renderItem into a separate component

// BAD — inline renderItem creates a new function on every render
<FlatList
  data={chats}
  renderItem={({ item }) => <View><Text>{item.name}</Text></View>}
/>

// GOOD — separate named component
function ChatRow({ item }) {
  return <View><Text>{item.name}</Text></View>;
}

<FlatList
  data={chats}
  renderItem={({ item }) => <ChatRow item={item} />}
/>

getItemLayout — for fixed-height rows

{/* If every row is the same height, tell FlatList upfront */}
{/* This lets it skip measuring and makes scrolling much faster */}
const ITEM_HEIGHT = 72;

<FlatList
  data={chats}
  keyExtractor={item => item.id}
  renderItem={({ item }) => <ChatRow chat={item} />}
  getItemLayout={(data, index) => ({
    length: ITEM_HEIGHT,
    offset: ITEM_HEIGHT * index,
    index,
  })}
/>

removeClippedSubviews

{/* On Android — detaches off-screen views from the native view hierarchy */}
{/* Small memory and performance win for very long lists */}
<FlatList
  data={messages}
  keyExtractor={item => item.id}
  renderItem={({ item }) => <MessageBubble message={item} />}
  removeClippedSubviews={true}
/>

This combines everything: FlatList with separators, empty state, pull-to-refresh, and live search filter from Lesson 6. Replace your App.js and run it.

function fetchChats() {
  return new Promise(resolve => setTimeout(() => resolve(ALL_CHATS), 800));
}

// ── ChatRow component ──────────────────────────────────────────────────────
const ITEM_HEIGHT = 76;

function ChatRow({ chat, onPress }) {
  return (
    <Pressable
      style={({ pressed }) => [styles.row, pressed && styles.rowPressed]}
      onPress={() => onPress(chat)}
    >
      <Image
        source={{ uri: chat.avatar }}
        style={styles.avatar}
        resizeMode="cover"
      />
      <View style={styles.middle}>
        <Text style={styles.name} numberOfLines={1}>{chat.name}</Text>
        <Text style={styles.preview} numberOfLines={1}>{chat.preview}</Text>
      </View>
      <View style={styles.right}>
        <Text style={[styles.time, chat.unread > 0 && styles.timeUnread]}>
          {chat.time}
        </Text>
        {chat.unread > 0 && (
          <View style={styles.badge}>
            <Text style={styles.badgeText}>
              {chat.unread > 99 ? '99+' : chat.unread}
            </Text>
          </View>
        )}
      </View>
    </Pressable>
  );
}

// ── Main App ───────────────────────────────────────────────────────────────
export default function App() {
  const [chats, setChats]               = useState([]);
  const [isLoading, setIsLoading]       = useState(true);
  const [isRefreshing, setIsRefreshing] = useState(false);
  const [searchQuery, setSearchQuery]   = useState('');

  // Load on mount
  useEffect(() => {
    loadChats();
  }, []);

  async function loadChats() {
    try {
      setIsLoading(true);
      const data = await fetchChats();
      setChats(data);
    } finally {
      setIsLoading(false);
    }
  }

  async function handleRefresh() {
    setIsRefreshing(true);
    try {
      const data = await fetchChats();
      setChats(data);
    } finally {
      setIsRefreshing(false);
    }
  }

  function handleChatPress(chat) {
    console.log('Opening chat:', chat.name);
    // Navigation to message thread — covered in Lesson 8
  }

  // Derived — filter as user types
  const filteredChats = chats.filter(c =>
    c.name.toLowerCase().includes(searchQuery.toLowerCase()) ||
    c.preview.toLowerCase().includes(searchQuery.toLowerCase())
  );

  if (isLoading) {
    return (
      <View style={styles.screen}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>WhatsApp</Text>
        </View>
        <View style={styles.centre}>
          <ActivityIndicator size="large" color="#075E54" />
        </View>
      </View>
    );
  }

  return (
    <View style={styles.screen}>

      {/* Header */}
      <View style={styles.header}>
        <Text style={styles.headerTitle}>WhatsApp</Text>
        <Text style={styles.headerSub}>{chats.length} chats</Text>
      </View>

      {/* Search */}
      <View style={styles.searchWrap}>
        <TextInput
          style={styles.searchInput}
          placeholder="Search or start new chat"
          placeholderTextColor="#667781"
          value={searchQuery}
          onChangeText={setSearchQuery}
          returnKeyType="search"
        />
      </View>

      {/* List */}
      <FlatList
        data={filteredChats}
        keyExtractor={item => item.id}
        renderItem={({ item }) => (
          <ChatRow chat={item} onPress={handleChatPress} />
        )}
        ItemSeparatorComponent={() => (
          <View style={styles.separator} />
        )}
        ListEmptyComponent={() => (
          <View style={styles.centre}>
            {searchQuery
              ? <Text style={styles.emptyText}>No results for "{searchQuery}"</Text>
              : <Text style={styles.emptyText}>No chats yet</Text>
            }
          </View>
        )}
        refreshing={isRefreshing}
        onRefresh={handleRefresh}
        getItemLayout={(_, index) => ({
          length: ITEM_HEIGHT,
          offset: ITEM_HEIGHT * index,
          index,
        })}
        removeClippedSubviews={true}
        keyboardShouldPersistTaps="handled"

}
