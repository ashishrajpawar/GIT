Images & ImagePicker

expo-image-picker · Permissions · Gallery & Camera · Avatar upload preview ~40 min Hands-on
Why this matters for your WhatsApp clone

WhatsApp lets users set a profile photo, send images in chats, and update their status with a picture. All of these start the same way: pick an image from the gallery or take a photo with the camera. This lesson teaches you how to do that with expo-image-picker, how to handle the permissions the OS requires, and how to display the chosen image as a rounded avatar — the exact building block you'll reuse in the profile screen, the chat input bar, and the status screen.

1. Installing expo-image-picker

Run this in your whatsapp-clone project terminal. Use npx expo install — it picks the version compatible with your Expo SDK.

npx expo install expo-image-picker

No other installation step is needed for Expo Go or EAS Build — Expo bundles the native camera and photo library modules automatically.

2. Permissions — asking before accessing the camera roll

Both iOS and Android require explicit user permission before your app can access the camera or photo library. expo-image-picker gives you a hook for each.

import * as ImagePicker from 'expo-image-picker';

// Hook — gives you the current permission status + a function to request it
const [mediaPermission, requestMediaPermission] =
  ImagePicker.useMediaLibraryPermissions();

const [cameraPermission, requestCameraPermission] =
  ImagePicker.useCameraPermissions();

The permission object has a status field:

status valueMeaning
'granted'User allowed it — proceed
'denied'User explicitly denied — show a message, don't ask again
'undetermined'Never asked yet — call the request function
 
async function checkAndRequestPermission() {
  if (mediaPermission?.status === 'granted') {
    return true;   // already have it
  }

  if (mediaPermission?.status === 'denied') {
    // Can't ask again — direct the user to Settings
    Alert.alert(
      'Permission required',
      'Please allow photo access in your device Settings to choose a profile photo.',
      [{ text: 'OK' }]
    );
    return false;
  }

  // First time asking
  const result = await requestMediaPermission();
  return result.status === 'granted';
}
iOS vs Android permission behaviour

On iOS, once the user taps "Don't Allow", you can never show the system permission dialog again — you must direct them to Settings. On Android, you can ask twice before it becomes permanently denied. Always handle the 'denied' case gracefully — never silently fail.

3. Picking from the gallery

Call ImagePicker.launchImageLibraryAsync() to open the system photo picker. The user picks a photo and the function returns a result object.

async function pickFromGallery() {
  const hasPermission = await checkAndRequestPermission();
  if (!hasPermission) return;

  const result = await ImagePicker.launchImageLibraryAsync({
    mediaTypes: ['images'],        // only photos, not videos
    allowsEditing: true,           // shows a crop UI after selection
    aspect: [1, 1],                // square crop — good for avatars
    quality: 0.8,                  // 0 = most compressed, 1 = original
  });

  if (!result.canceled) {
    // result.assets is an array — [0] is the selected image
    const uri = result.assets[0].uri;
    setAvatarUri(uri);             // store the local file URI in state
    console.log('Picked:', uri);
  }
  // If result.canceled is true, the user closed the picker — do nothing
}
result.assets[0].uri

The uri is a local file path on the device, like file:///var/mobile/Containers/... on iOS or content://... on Android. You can pass it directly to an <Image source={{ uri }}> component. In Module 3 you'll upload this URI to Firebase Storage to get a permanent download URL.

4. Taking a photo with the camera

Call ImagePicker.launchCameraAsync() — it opens the device camera directly. The API is nearly identical to the gallery picker.

async function takePhoto() {
  // Camera needs its own permission — separate from photo library
  if (cameraPermission?.status !== 'granted') {
    const result = await requestCameraPermission();
    if (result.status !== 'granted') {
      Alert.alert('Camera access denied', 'Enable camera access in Settings.');
      return;
    }
  }

  const result = await ImagePicker.launchCameraAsync({
    allowsEditing: true,
    aspect: [1, 1],
    quality: 0.8,
  });

  if (!result.canceled) {
    setAvatarUri(result.assets[0].uri);
  }
}

The camera requires a separate permission from the photo library. Always request the right one — useCameraPermissions() for the camera, useMediaLibraryPermissions() for the gallery.

5. Displaying the image — Image component

React Native's built-in Image component handles both local URIs (from the picker) and remote URLs (from Firebase Storage). Use borderRadius equal to half the width/height to make it a circle.

import { Image, View, StyleSheet } from 'react-native';

// Circular avatar — local URI or remote URL both work
function Avatar({ uri, size = 80 }) {
  if (!uri) {
    // Fallback when no photo is set yet
    return (
      <View style={[styles.avatarFallback, { width: size, height: size, borderRadius: size / 2 }]}>
        <Text style={{ color: '#fff', fontSize: size * 0.4 }}>A</Text>
      </View>
    );
  }

  return (
    <Image
      source={{ uri }}
      style={{
        width:        size,
        height:       size,
        borderRadius: size / 2,   // circle
      }}
    />
  );
}

const styles = StyleSheet.create({
  avatarFallback: {
    backgroundColor: '#075E54',
    alignItems: 'center',
    justifyContent: 'center',
  },
});
Always set explicit width and height on Image

Unlike web, React Native images have no intrinsic size — they will render as 0×0 and be invisible unless you give them explicit width and height (or flex: 1). This is one of the most common beginner traps.

6. Showing a choice: gallery or camera

WhatsApp shows an action sheet when you tap the avatar — "Take photo" or "Choose from library". Use Alert.alert with multiple buttons to replicate this simply, or use a bottom sheet modal in a later lesson.

import { Alert } from 'react-native';

function showImageOptions() {
  Alert.alert(
    'Profile photo',
    'How would you like to set your photo?',
    [
      { text: 'Take photo',           onPress: takePhoto },
      { text: 'Choose from library',  onPress: pickFromGallery },
      { text: 'Cancel', style: 'cancel' },
    ]
  );
}

7. Full working example — profile photo picker

This is a complete profile photo picker screen — the same component you'll use in your Settings / Profile screen. Tap the avatar circle to pick a photo from gallery or camera. The image previews immediately as a rounded avatar. Replace your entire App.js with this.

import { useState } from 'react';
import {
  View, Text, Image, Pressable,
  StyleSheet, Alert, Platform, ScrollView,
} from 'react-native';
import * as ImagePicker from 'expo-image-picker';

export default function App() {
  const [avatarUri, setAvatarUri] = useState(null);
  const [name,      setName]      = useState('Ashish');

  const [mediaPermission,  requestMediaPermission]  = ImagePicker.useMediaLibraryPermissions();
  const [cameraPermission, requestCameraPermission] = ImagePicker.useCameraPermissions();

  // ── Permission helpers ──────────────────────────────────────────────────────
  async function ensureMediaPermission() {
    if (mediaPermission?.status === 'granted') return true;
    if (mediaPermission?.status === 'denied') {
      Alert.alert(
        'Permission required',
        'Please allow photo library access in Settings to choose a photo.',
        [{ text: 'OK' }]
      );
      return false;
    }
    const result = await requestMediaPermission();
    return result.status === 'granted';
  }

  async function ensureCameraPermission() {
    if (cameraPermission?.status === 'granted') return true;
    if (cameraPermission?.status === 'denied') {
      Alert.alert(
        'Permission required',
        'Please allow camera access in Settings to take a photo.',
        [{ text: 'OK' }]
      );
      return false;
    }
    const result = await requestCameraPermission();
    return result.status === 'granted';
  }

  // ── Pickers ─────────────────────────────────────────────────────────────────
  async function pickFromGallery() {
    const ok = await ensureMediaPermission();
    if (!ok) return;

    const result = await ImagePicker.launchImageLibraryAsync({
      mediaTypes: ['images'],
      allowsEditing: true,
      aspect: [1, 1],
      quality: 0.8,
    });

    if (!result.canceled) {
      setAvatarUri(result.assets[0].uri);
    }
  }

  async function takePhoto() {
    const ok = await ensureCameraPermission();
    if (!ok) return;

    const result = await ImagePicker.launchCameraAsync({
      allowsEditing: true,
      aspect: [1, 1],
      quality: 0.8,
    });

    if (!result.canceled) {
      setAvatarUri(result.assets[0].uri);
    }
  }

  function showImageOptions() {
    Alert.alert(
      'Profile photo',
      'How would you like to update your photo?',
      [
        { text: 'Take photo',          onPress: takePhoto },
        { text: 'Choose from library', onPress: pickFromGallery },
        { text: 'Cancel', style: 'cancel' },
      ]
    );
  }

  // ── UI ───────────────────────────────────────────────────────────────────────
  return (
    <ScrollView contentContainerStyle={styles.container}>

      {/* Green header bar */}
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Profile</Text>
      </View>

      {/* Avatar — tap to change */}
      <View style={styles.avatarSection}>
        <Pressable onPress={showImageOptions} style={styles.avatarWrap}>
          {avatarUri ? (
            <Image source={{ uri: avatarUri }} style={styles.avatar} />
          ) : (
            <View style={styles.avatarFallback}>
              <Text style={styles.avatarLetter}>{name[0]?.toUpperCase()}</Text>
            </View>
          )}
          {/* Camera icon overlay */}
          <View style={styles.cameraOverlay}>
            <Text style={styles.cameraIcon}>📷</Text>
          </View>
        </Pressable>

        <Text style={styles.tapHint}>Tap to change photo</Text>
      </View>

      {/* Name display */}
      <View style={styles.infoSection}>
        <Text style={styles.infoLabel}>Name</Text>
        <Text style={styles.infoValue}>{name}</Text>
      </View>

      {/* Upload note */}
      <View style={styles.noteBox}>
        <Text style={styles.noteText}>
          📦 Selected image URI is stored locally for now.{'\n'}
          In Module 3 you'll upload it to Firebase Storage and save the download URL to Firestore.
        </Text>
      </View>

      {/* Show the raw URI so you can see what was picked */}
      {avatarUri ? (
        <View style={styles.uriBox}>
          <Text style={styles.uriLabel}>Local URI:</Text>
          <Text style={styles.uriText} numberOfLines={3}>{avatarUri}</Text>
        </View>
      ) : null}

      {/* Permission status — useful while developing */}
      <View style={styles.permBox}>
        <Text style={styles.permTitle}>Permission status (dev info)</Text>
        <Text style={styles.permText}>
          Media library: {mediaPermission?.status ?? 'not checked'}{'\n'}
          Camera: {cameraPermission?.status ?? 'not checked'}
        </Text>
      </View>

    </ScrollView>
  );
}

// ── Styles ────────────────────────────────────────────────────────────────────
const styles = StyleSheet.create({
  container:      { flexGrow: 1, backgroundColor: '#fff', paddingBottom: 40 },
  header:         { backgroundColor: '#075E54', paddingTop: 48, paddingBottom: 16, paddingHorizontal: 20 },
  headerTitle:    { color: '#fff', fontSize: 20, fontWeight: '700' },

  avatarSection:  { alignItems: 'center', paddingTop: 36, paddingBottom: 20 },
  avatarWrap:     { position: 'relative' },
  avatar:         { width: 120, height: 120, borderRadius: 60 },
  avatarFallback: { width: 120, height: 120, borderRadius: 60, backgroundColor: '#075E54', alignItems: 'center', justifyContent: 'center' },
  avatarLetter:   { color: '#fff', fontSize: 48, fontWeight: '700' },
  cameraOverlay:  { position: 'absolute', bottom: 0, right: 0, backgroundColor: '#25D366', width: 36, height: 36, borderRadius: 18, alignItems: 'center', justifyContent: 'center', borderWidth: 2, borderColor: '#fff' },
  cameraIcon:     { fontSize: 16 },
  tapHint:        { marginTop: 10, fontSize: 13, color: '#667781' },

  infoSection:    { paddingHorizontal: 24, paddingVertical: 16, borderBottomWidth: 1, borderBottomColor: '#f0f2f5' },
  infoLabel:      { fontSize: 13, color: '#25D366', fontWeight: '600', marginBottom: 4 },
  infoValue:      { fontSize: 17, color: '#111' },

  noteBox:        { margin: 20, backgroundColor: '#e8f5e9', borderRadius: 10, padding: 14 },
  noteText:       { fontSize: 13, color: '#2e7d32', lineHeight: 20 },

  uriBox:         { marginHorizontal: 20, marginTop: 4, backgroundColor: '#f5f5f5', borderRadius: 8, padding: 12 },
  uriLabel:       { fontSize: 11, color: '#999', marginBottom: 4, fontWeight: '600' },
  uriText:        { fontSize: 11, color: '#333', fontFamily: Platform.OS === 'ios' ? 'Courier' : 'monospace' },

  permBox:        { marginHorizontal: 20, marginTop: 16, backgroundColor: '#f5f5f5', borderRadius: 8, padding: 12 },
  permTitle:      { fontSize: 11, color: '#999', fontWeight: '600', marginBottom: 4 },
  permText:       { fontSize: 12, color: '#555', lineHeight: 20 },
});

Run this. Tap the avatar circle — an alert sheet asks "Take photo" or "Choose from library". Grant permission when asked. The selected photo appears immediately as a rounded avatar with the camera icon overlay. The raw local URI is shown below so you can see what the picker returned.

What Module 3 adds to this screen

Two lines in pickFromGallery and takePhoto change. After getting the URI, you call:
const downloadUrl = await uploadAvatarToFirebase(uri, userId);
Then save that URL to the user's Firestore document. Every other screen in the app that shows the user's avatar just reads user.avatarUrl from Firestore — the photo automatically appears everywhere.

Anything unclear? Ask your teacher. Common issues: (1) Image shows nothing — you forgot explicit width and height on the Image component. (2) Permission dialog never appears — you called launchImageLibraryAsync without calling requestMediaPermission first, or the simulator doesn't have photos; test on a real device. (3) Camera doesn't work in Expo Go on iOS simulator — the simulator has no camera; use a physical device or the gallery picker instead. (4) result.assets is undefined — you may be using an older version of expo-image-picker; run npx expo install expo-image-picker again to get the current SDK-compatible version.
