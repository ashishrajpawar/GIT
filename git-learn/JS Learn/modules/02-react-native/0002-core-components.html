React Native · Lesson 2

Core Components

View · Text · Image · ScrollView · Pressable ~35 min Hands-on
Why this matters for your WhatsApp clone

Every screen in your app — the chat list, the message thread, the profile page — is built from a small set of core components. These are the building blocks of all React Native UIs, the same way <div>, <p>, and <img> are the building blocks of web pages. Learn these five and you can build any screen layout.

1. What is a component?

A component is a reusable piece of UI. In React Native, everything on screen is a component — a box of content, a line of text, a button, an image. You nest components inside each other to build layouts, exactly like nesting HTML tags.

Here is how HTML compares to React Native:

HTML (web) React Native (mobile) What it does
<div> <View> A container box — holds other components
<p>, <span>, <h1> <Text> Displays text — all text must be inside Text
<img> <Image> Displays an image
<div style="overflow:scroll"> <ScrollView> A scrollable container
<button> <Pressable> Responds to taps — the modern button
You cannot use HTML tags in React Native

<div>, <p>, <button> do not exist in React Native — your app runs on a phone, not in a browser. Use View, Text, and Pressable instead. If you accidentally use an HTML tag, React Native will throw an error or silently render nothing.

What is JSX?

The HTML-looking syntax you saw in Lesson 1 (<View>, <Text>) is called JSX. It is JavaScript with an XML-like syntax extension that lets you describe UI in a readable way. Under the hood, JSX is just JavaScript function calls — but you never have to think about that. Write it like HTML, with a few differences:

  • Every tag must be closed — <View></View> or self-closing <Image />
  • Use className → style in React Native (no CSS classes)
  • Embed JavaScript inside JSX with curly braces: {variableName}

2. View — the container

View is the most fundamental component. It is a rectangular box that holds other components. Think of it as the <div> of React Native.

import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <View style={styles.box}>
        <Text>I am inside a box</Text>
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#fff',
    padding: 16,
  },
  box: {
    backgroundColor: '#DCF8C6',  // WhatsApp message green
    padding: 12,
    borderRadius: 8,
  },
});

By itself View is invisible — it only becomes visible when you give it a background colour or border. Its main job is to group and position other components.

In your WhatsApp clone

Every chat bubble, every list row, every header bar, every screen background — all View components. When you look at the WhatsApp UI and wonder "how is that laid out?", the answer is almost always nested Views.

3. Text — displaying words

Text is the only component that can display text. Unlike HTML where you can put text almost anywhere, in React Native all text must be inside a Text component.

import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  const senderName = "Priya";
  const messageText = "Hey! Still on for tonight?";
  const timeStamp = "10:32 AM";

  return (
    <View style={styles.container}>

      {/* Embedding JavaScript variables inside JSX using {} */}
      <Text style={styles.sender}>{senderName}</Text>
      <Text style={styles.message}>{messageText}</Text>
      <Text style={styles.time}>{timeStamp}</Text>

      {/* Nesting Text inside Text — for mixed styles */}
      <Text style={styles.message}>
        Message from <Text style={styles.bold}>Priya</Text>: Hey!
      </Text>

    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 20, backgroundColor: '#fff' },
  sender:  { fontSize: 14, fontWeight: '600', color: '#075E54' },
  message: { fontSize: 16, color: '#303030', marginTop: 2 },
  time:    { fontSize: 11, color: '#999', marginTop: 4, alignSelf: 'flex-end' },
  bold:    { fontWeight: 'bold' },
});
JSX comments use {/* */} not //

Inside JSX (between component tags), you must use {/* comment */} for comments, not //. Outside JSX, in regular JavaScript, // works fine. You'll get an error if you use // inside a JSX block.

numberOfLines — truncating long text

In a chat list, you only want to show a preview of the last message — not the full text. Use numberOfLines to cap it:

<Text numberOfLines={1} style={styles.preview}>
  Hey! Are you coming tonight? I've been waiting for your reply all day...
</Text>
{/* Shows: "Hey! Are you coming tonight? I've been waiting for..." */}

4. Image — showing pictures

Image displays images. It can show images from the internet (a URL) or from local files inside your project.

import { View, Image, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>

      {/* Image from the internet */}
      <Image
        source={{ uri: 'https://i.pravatar.cc/100?img=5' }}
        style={styles.avatar}
      />

      {/* Local image from your assets folder */}
      <Image
        source={require('./assets/icon.png')}
        style={styles.icon}
      />

      <Text>Profile photo</Text>

    </View>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, alignItems: 'center', justifyContent: 'center' },
  avatar: {
    width: 60,
    height: 60,
    borderRadius: 30,   // half of width/height = perfect circle
    marginBottom: 8,
  },
  icon: {
    width: 40,
    height: 40,
  },
});
Image always needs explicit width and height

Unlike HTML where images size themselves automatically, React Native images show nothing if you don't give them a width and height. Always set both. Use borderRadius equal to half the width/height to make a circular avatar — this is how WhatsApp contact photos are displayed.

resizeMode — controlling how images fit

<Image
  source={{ uri: 'https://i.pravatar.cc/300' }}
  style={{ width: 100, height: 100 }}
  resizeMode="cover"   // crop to fill — most common for avatars
/>

{/* resizeMode options:
  'cover'   — fills the box, crops if needed (default, use for avatars)
  'contain' — fits the whole image in the box, may leave gaps
  'stretch' — distorts the image to fill exactly
*/}

5. ScrollView — making content scrollable

By default, if content is taller than the screen, it gets cut off. ScrollView makes its contents scrollable — the user can swipe up and down to see everything.

import { ScrollView, View, Text, StyleSheet } from 'react-native';

export default function App() {
  // Simulate a list of messages
  const messages = [
    { id: 1, sender: 'Priya',  text: 'Hey!' },
    { id: 2, sender: 'Ashish', text: 'Hi! How are you?' },
    { id: 3, sender: 'Priya',  text: 'I\'m good, thanks!' },
    { id: 4, sender: 'Ashish', text: 'Great to hear.' },
    { id: 5, sender: 'Priya',  text: 'Are you free tonight?' },
    { id: 6, sender: 'Ashish', text: 'Yes, 8pm works?' },
    { id: 7, sender: 'Priya',  text: 'Perfect!' },
    { id: 8, sender: 'Ashish', text: 'See you then.' },
  ];

  return (
    <ScrollView style={styles.container}>
      {messages.map(msg => (
        <View key={msg.id} style={styles.bubble}>
          <Text style={styles.sender}>{msg.sender}</Text>
          <Text>{msg.text}</Text>
        </View>
      ))}
    </ScrollView>
  );
}

const styles = StyleSheet.create({
  container: { flex: 1, padding: 16, backgroundColor: '#ECE5DD' },
  bubble: {
    backgroundColor: '#fff',
    padding: 10,
    borderRadius: 8,
    marginBottom: 8,
    maxWidth: '80%',
  },
  sender: { fontWeight: '600', color: '#075E54', marginBottom: 2 },
});
ScrollView vs FlatList — important difference

ScrollView renders all its children at once — even the ones off screen. For short content (a settings page, a profile form) this is fine. But for long lists like a message thread with hundreds of messages, it's slow and uses too much memory. For lists, use FlatList (covered in Lesson 7) — it only renders what's visible. For now, use ScrollView to get things on screen, and you'll upgrade to FlatList later.

6. Pressable — handling taps

Pressable is the modern way to make anything tappable in React Native. Wrap any component in Pressable and give it an onPress handler — that function runs when the user taps it.

import { View, Text, Pressable, StyleSheet, Alert } from 'react-native';

export default function App() {
  function handleSend() {
    Alert.alert('Message sent!', 'Your message was delivered.');
  }

  function handleChatPress(chatName) {
    Alert.alert('Opening chat with ' + chatName);
  }

  return (
    <View style={styles.container}>

      {/* Basic button */}
      <Pressable style={styles.sendButton} onPress={handleSend}>
        <Text style={styles.sendButtonText}>Send</Text>
      </Pressable>

      {/* Pressable with visual feedback — changes style when pressed */}
      <Pressable
        style={({ pressed }) => [
          styles.chatRow,
          pressed && styles.chatRowPressed   // apply extra style while finger is down
        ]}
        onPress={() => handleChatPress('Priya')}
      >
        <Text style={styles.chatName}>Priya Sharma</Text>
        <Text style={styles.preview}>Hey! Still on for tonight?</Text>
      </Pressable>

    </View>
  );
}

const styles = StyleSheet.create({
  container:       { flex: 1, padding: 20, backgroundColor: '#fff' },
  sendButton:      { backgroundColor: '#25D366', padding: 14, borderRadius: 8, alignItems: 'center' },
  sendButtonText:  { color: '#fff', fontWeight: '700', fontSize: 16 },
  chatRow:         { padding: 16, borderBottomWidth: 1, borderBottomColor: '#f0f0f0' },
  chatRowPressed:  { backgroundColor: '#f5f5f5' },
  chatName:        { fontSize: 16, fontWeight: '600' },
  preview:         { fontSize: 14, color: '#666', marginTop: 2 },
});
({ pressed }) — destructuring in action

Notice style={({ pressed }) => [...]} — that's the destructuring from Module 1 Lesson 11. Pressable passes an object { pressed: true/false } to the style function. You destructure pressed right in the parameter to use it. This is exactly the kind of place modern JS syntax clicks into place.

onLongPress — handling hold gestures

<Pressable
  onPress={() => openChat(chat.id)}
  onLongPress={() => showMessageOptions(chat.id)}
>
  {/* chat row content */}
</Pressable>
{/* In WhatsApp: tap opens the chat, long-press shows delete/pin options */}

7. Putting it together — a WhatsApp chat list row

Let's combine all five components to build something that looks like a real WhatsApp chat list row — avatar, name, message preview, and timestamp side by side.

Replace your entire App.js with this and run it on your phone:

import { View, Text, Image, ScrollView, Pressable, StyleSheet } from 'react-native';

// Sample data — this will come from Firebase in Module 3
const chats = [
  {
    id: '1',
    name: 'Priya Sharma',
    avatar: 'https://i.pravatar.cc/100?img=5',
    lastMessage: 'Perfect, see you then!',
    time: '10:32',
    unread: 2,
  },
  {
    id: '2',
    name: 'Rahul Mehta',
    avatar: 'https://i.pravatar.cc/100?img=12',
    lastMessage: 'Check out this link I sent',
    time: '09:15',
    unread: 0,
  },
  {
    id: '3',
    name: 'Family Group',
    avatar: 'https://i.pravatar.cc/100?img=20',
    lastMessage: 'Mom: Dinner at 7, don\'t be late',
    time: 'Yesterday',
    unread: 5,
  },
  {
    id: '4',
    name: 'Work Team',
    avatar: 'https://i.pravatar.cc/100?img=30',
    lastMessage: 'The meeting is moved to 3pm',
    time: 'Yesterday',
    unread: 0,
  },
];

// A single chat row component
function ChatRow({ chat, onPress }) {
  return (
    <Pressable
      style={({ pressed }) => [styles.row, pressed && styles.rowPressed]}
      onPress={() => onPress(chat)}
    >
      {/* Avatar */}
      <Image
        source={{ uri: chat.avatar }}
        style={styles.avatar}
        resizeMode="cover"
      />

      {/* Middle — name and preview */}
      <View style={styles.middle}>
        <Text style={styles.name} numberOfLines={1}>{chat.name}</Text>
        <Text style={styles.preview} numberOfLines={1}>{chat.lastMessage}</Text>
      </View>

      {/* Right — time and unread badge */}
      <View style={styles.right}>
        <Text style={styles.time}>{chat.time}</Text>
        {chat.unread > 0 && (
          <View style={styles.badge}>
            <Text style={styles.badgeText}>{chat.unread}</Text>
          </View>
        )}
      </View>
    </Pressable>
  );
}

// Main app
export default function App() {
  function handleChatPress(chat) {
    // In Module 8 (Navigation) this will open the message thread
    console.log('Tapped:', chat.name);
  }

  return (
    <View style={styles.screen}>
      {/* Header */}
      <View style={styles.header}>
        <Text style={styles.headerTitle}>WhatsApp</Text>
      </View>

      {/* Chat list */}
      <ScrollView>
        {chats.map(chat => (
          <ChatRow key={chat.id} chat={chat} onPress={handleChatPress} />
        ))}
      </ScrollView>
    </View>
  );
}

const styles = StyleSheet.create({
  screen:       { flex: 1, backgroundColor: '#fff' },

  // Header
  header:       { backgroundColor: '#075E54', paddingTop: 48, paddingBottom: 12, paddingHorizontal: 16 },
  headerTitle:  { color: '#fff', fontSize: 20, fontWeight: '700' },

  // Chat row
  row:          { flexDirection: 'row', alignItems: 'center', paddingHorizontal: 16, paddingVertical: 12, borderBottomWidth: 1, borderBottomColor: '#f0f0f0' },
  rowPressed:   { backgroundColor: '#f5f5f5' },
  avatar:       { width: 52, height: 52, borderRadius: 26 },
  middle:       { flex: 1, marginLeft: 12, marginRight: 8 },
  name:         { fontSize: 16, fontWeight: '600', color: '#111' },
  preview:      { fontSize: 14, color: '#666', marginTop: 2 },
  right:        { alignItems: 'flex-end' },
  time:         { fontSize: 12, color: '#999' },

  // Unread badge
  badge:        { backgroundColor: '#25D366', borderRadius: 10, minWidth: 20, height: 20, alignItems: 'center', justifyContent: 'center', marginTop: 4, paddingHorizontal: 5 },
  badgeText:    { color: '#fff', fontSize: 11, fontWeight: '700' },
});

Run this on your phone. You should see a working WhatsApp-style chat list — green header, avatars, names, message previews, timestamps, and unread count badges. All five core components working together.

Notice what you just learned without realising it
  • Custom components — ChatRow is a function you wrote that returns JSX. This is how React Native apps are structured: small reusable components composed together.
  • Props — ChatRow receives chat and onPress as inputs (called props). This is how parent components pass data down to children.
  • Conditional rendering — {chat.unread > 0 && (...)} only renders the badge if there are unread messages. The && short-circuit pattern is the standard way to conditionally show/hide UI in React Native.

You'll use all three of these patterns in every screen you build.
