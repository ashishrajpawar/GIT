Module 2

React Native

~6 lessons coming ~2 weeks Unlocks after Module 1
Goal of this module

Set up Expo and build your first real screens. By the end you'll have a working app shell with navigation — a token list, a token detail screen, and a message thread — running on hardcoded data and ready to wire up to the Token API in Track A.

Lessons

  1. Expo Setup & EAS Build
  2. Core Components — View, Text, Image, ScrollView, Pressable
  3. Styling with StyleSheet & Flexbox
  4. TextInput & Keyboard Handling
  5. useState — Managing Screen State
  6. useEffect — Side Effects & Lifecycle
  7. FlatList — Performant Lists
  8. React Navigation — Stack & Bottom Tabs
  9. Passing Data Between Screens
  10. Forms — Login & Register Screens
  11. Images & ImagePicker
  12. Loading States & Error States
  13. Build the Token List Screen capstone
  14. Build the Message Thread Screen capstone
