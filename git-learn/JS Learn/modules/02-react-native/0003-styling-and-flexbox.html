React Native · Lesson 3

Styling & Flexbox

StyleSheet · Flexbox · Layout ~35 min Hands-on
Why this matters for your WhatsApp clone

Every layout decision in your app — chat bubbles aligned left or right, a header bar pinned to the top, an input bar fixed to the bottom, an avatar sitting next to a name — is solved with Flexbox. React Native uses Flexbox as its only layout system. Once you understand it, you can build any screen layout you can imagine.

1. StyleSheet — how styling works in React Native

In React Native there are no CSS files. Styles are written as JavaScript objects and applied via the style prop. The StyleSheet.create() function takes an object of style definitions and returns them back — it also validates your style names in development so you catch typos early.

import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.heading}>WhatsApp Clone</Text>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#075E54',
    padding: 16,
  },
  heading: {
    fontSize: 24,
    fontWeight: 'bold',
    color: '#ffffff',
  },
});

CSS vs React Native styles — key differences

CSS (web) React Native
background-color: #fff backgroundColor: '#fff' (camelCase)
font-size: 16px fontSize: 16 (number, no 'px')
border-radius: 8px borderRadius: 8
margin: 8px 16px marginVertical: 8, marginHorizontal: 16
display: flex Everything is flex by default — no need to set it
Class names, IDs, cascading No classes — styles are objects applied directly per component
All property names are camelCase and numbers have no units

The two rules that catch everyone: font-size becomes fontSize, background-color becomes backgroundColor. And sizes are plain numbers — 16 not '16px'. React Native uses density-independent pixels (dp) automatically, so your layout looks consistent across different screen sizes.

Inline styles vs StyleSheet

// Inline style — fine for one-off overrides
<Text style={{ color: 'red', fontSize: 14 }}>Error message</Text>

// StyleSheet — preferred for reusable styles
<Text style={styles.error}>Error message</Text>

// Combining styles — pass an array
<Text style={[styles.text, styles.bold, { color: 'red' }]}>
  Bold red text
</Text>

2. Flexbox — the layout system

Flexbox is how you control where things appear on screen — side by side, stacked, centred, spread out. In React Native, every View is a flex container by default. You don't need to write display: flex.

There are three properties you use constantly:

  • flexDirection — which way children stack
  • justifyContent — spacing along the main axis
  • alignItems — alignment on the cross axis

3. flexDirection — row or column

flexDirection controls which direction children are laid out inside a View.

  • 'column' (default) — children stack top to bottom
  • 'row' — children line up left to right
import { View, Text, StyleSheet } from 'react-native';

export default function App() {
  return (
    <View style={styles.screen}>

      {/* column — default, items stack vertically */}
      <View style={styles.columnBox}>
        <Text style={styles.item}>Message 1</Text>
        <Text style={styles.item}>Message 2</Text>
        <Text style={styles.item}>Message 3</Text>
      </View>

      {/* row — items sit side by side horizontally */}
      <View style={styles.rowBox}>
        <Text style={styles.item}>Avatar</Text>
        <Text style={styles.item}>Name & Preview</Text>
        <Text style={styles.item}>Time</Text>
      </View>

    </View>
  );
}

const styles = StyleSheet.create({
  screen:    { flex: 1, padding: 16, backgroundColor: '#fff' },
  columnBox: { backgroundColor: '#DCF8C6', padding: 8, marginBottom: 16, flexDirection: 'column' },
  rowBox:    { backgroundColor: '#ECE5DD', padding: 8, flexDirection: 'row' },
  item:      { backgroundColor: '#fff', margin: 4, padding: 8, borderRadius: 4 },
});
In your WhatsApp clone

flexDirection: 'column' — used for the overall screen layout (header on top, list in middle, input bar at bottom).
flexDirection: 'row' — used for every chat list row (avatar on the left, name and preview in the middle, time on the right).

4. justifyContent — spacing along the main axis

When flexDirection is 'column', justifyContent controls vertical spacing. When it's 'row', it controls horizontal spacing.

// flex-start  — pack children at the START (default)
// flex-end    — pack children at the END
// center      — centre children
// space-between — first at start, last at end, equal gaps between
// space-around  — equal space around each child
// space-evenly  — equal space between AND around all children

<View style={{ flex: 1, flexDirection: 'column', justifyContent: 'space-between' }}>
  <View style={styles.header}>
    <Text style={styles.headerText}>WhatsApp</Text>
  </View>

  <View style={styles.chatList}>
    {/* messages here */}
  </View>

  <View style={styles.inputBar}>
    {/* input + send button */}
  </View>
</View>
{/* space-between pushes header to top, input bar to bottom, chat list in middle */}
space-between is how every chat screen is built

The classic chat screen layout — header pinned to top, message list in the middle taking all available space, input bar pinned to bottom — is achieved with justifyContent: 'space-between' on the outer container. You'll use this in Lesson 14.

5. alignItems — alignment on the cross axis

alignItems controls alignment on the axis perpendicular to flexDirection.

  • In a column container — controls horizontal alignment
  • In a row container — controls vertical alignment
// stretch  — children fill the full cross-axis width/height (default)
// center   — children centred on the cross axis
// flex-start — children aligned to the start
// flex-end   — children aligned to the end

// Example: centre content on screen
<View style={{ flex: 1, justifyContent: 'center', alignItems: 'center' }}>
  <Text>I am perfectly centred</Text>
</View>

// Example: chat row — avatar, name, and time vertically centred
<View style={{ flexDirection: 'row', alignItems: 'center' }}>
  <Image style={styles.avatar} source={{ uri: '...' }} />
  <Text style={styles.name}>Priya Sharma</Text>
</View>

6. flex — controlling how much space a child takes

The flex property on a child controls how much of the parent's remaining space it claims. Think of it as shares — a child with flex: 2 gets twice as much space as a child with flex: 1.

// The most common pattern in React Native:
<View style={{ flex: 1 }}>       {/* takes all available space */}
  <Text>I fill the screen</Text>
</View>

// Chat row: name/preview takes all middle space, time is fixed width
<View style={{ flexDirection: 'row', alignItems: 'center' }}>
  <Image style={styles.avatar} source={{ uri: '...' }} />

  <View style={{ flex: 1 }}>   {/* takes all remaining space */}
    <Text numberOfLines={1}>Priya Sharma</Text>
    <Text numberOfLines={1}>Perfect, see you then!</Text>
  </View>

  <Text style={{ width: 50, textAlign: 'right' }}>10:32</Text>
  {/* fixed width — doesn't shrink or grow */}
</View>
flex: 1 is the most-written style in any React Native app

flex: 1 on the top-level container means "fill the whole screen". flex: 1 on a middle child means "take all the remaining space that siblings don't need". You'll write it dozens of times.

7. Spacing — margin and padding

Margin and padding work the same as CSS, but use camelCase and numbers.

// All four sides at once
margin: 16          // 16dp on all sides
padding: 16

// Individual sides
marginTop: 8
marginBottom: 8
marginLeft: 16
marginRight: 16

// Shorthand axes (very common in React Native)
marginVertical: 8      // top + bottom
marginHorizontal: 16   // left + right
paddingVertical: 12
paddingHorizontal: 16

// Example: a message bubble
const styles = StyleSheet.create({
  bubble: {
    backgroundColor: '#DCF8C6',
    paddingVertical: 8,
    paddingHorizontal: 12,
    borderRadius: 8,
    marginVertical: 2,
    marginHorizontal: 8,
    maxWidth: '75%',    // bubble can't be wider than 75% of the screen
  },
});

8. position: 'absolute' — overlapping elements

By default all components are positioned in the normal flow. position: 'absolute' takes a component out of the flow so it can sit on top of other components — useful for badges, floating buttons, and overlays.

// Unread badge positioned over the avatar — like WhatsApp's notification dot
<View style={{ position: 'relative' }}>
  <Image style={styles.avatar} source={{ uri: '...' }} />

  {/* Badge overlaps the avatar in the bottom-right corner */}
  <View style={styles.onlineDot} />
</View>

const styles = StyleSheet.create({
  avatar: { width: 52, height: 52, borderRadius: 26 },
  onlineDot: {
    position: 'absolute',
    bottom: 2,
    right: 2,
    width: 12,
    height: 12,
    borderRadius: 6,
    backgroundColor: '#25D366',  // WhatsApp green
    borderWidth: 2,
    borderColor: '#fff',
  },
});

9. Putting it all together — the WhatsApp message bubble layout

The most important layout in your entire app: chat bubbles that sit on the right for your messages and on the left for the other person's. This uses everything from this lesson.

Replace your App.js with this and run it:

import { View, Text, ScrollView, StyleSheet } from 'react-native';

const MY_USER_ID = 'user-ashish-01';

const messages = [
  { id: 'm1', senderId: 'user-priya-02',  text: 'Hey! How are you?',            time: '10:01' },
  { id: 'm2', senderId: 'user-ashish-01', text: 'Good! Just got to work.',       time: '10:02' },
  { id: 'm3', senderId: 'user-priya-02',  text: 'Nice! Busy day?',               time: '10:03' },
  { id: 'm4', senderId: 'user-ashish-01', text: 'Yeah, meetings all morning 😅', time: '10:04' },
  { id: 'm5', senderId: 'user-priya-02',  text: 'Haha good luck! Talk later.',   time: '10:05' },
  { id: 'm6', senderId: 'user-ashish-01', text: 'Thanks! ✌️',                   time: '10:05' },
];

function MessageBubble({ message }) {
  const isMe = message.senderId === MY_USER_ID;

  return (
    // alignItems pushes bubble to right (flex-end) or left (flex-start)
    <View style={[styles.bubbleRow, isMe ? styles.myRow : styles.theirRow]}>
      <View style={[styles.bubble, isMe ? styles.myBubble : styles.theirBubble]}>
        <Text style={styles.bubbleText}>{message.text}</Text>
        <Text style={styles.timeText}>{message.time}</Text>
      </View>
    </View>
  );
}

export default function App() {
  return (
    <View style={styles.screen}>

      {/* Header */}
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Priya Sharma</Text>
        <Text style={styles.headerSub}>online</Text>
      </View>

      {/* Message list */}
      <ScrollView
        style={styles.messageList}
        contentContainerStyle={styles.messageListContent}
      >
        {messages.map(msg => (
          <MessageBubble key={msg.id} message={msg} />
        ))}
      </ScrollView>

      {/* Input bar placeholder */}
      <View style={styles.inputBar}>
        <Text style={styles.inputPlaceholder}>Type a message</Text>
      </View>

    </View>
  );
}

const styles = StyleSheet.create({
  screen: { flex: 1, backgroundColor: '#ECE5DD' },

  // Header
  header: {
    backgroundColor: '#075E54',
    paddingTop: 48,
    paddingBottom: 12,
    paddingHorizontal: 16,
  },
  headerTitle: { color: '#fff', fontSize: 18, fontWeight: '700' },
  headerSub:   { color: '#b2dfdb', fontSize: 13, marginTop: 1 },

  // Message list
  messageList:        { flex: 1 },
  messageListContent: { paddingVertical: 8 },

  // Each bubble row — full width, aligned left or right
  bubbleRow:  { paddingHorizontal: 8, marginVertical: 2 },
  myRow:      { alignItems: 'flex-end' },    // my messages → right
  theirRow:   { alignItems: 'flex-start' },  // their messages → left

  // The bubble itself
  bubble: {
    maxWidth: '75%',
    paddingVertical: 6,
    paddingHorizontal: 10,
    borderRadius: 8,
  },
  myBubble:    { backgroundColor: '#DCF8C6' },  // green — my messages
  theirBubble: { backgroundColor: '#ffffff' },  // white — their messages

  bubbleText: { fontSize: 15, color: '#303030', lineHeight: 20 },
  timeText:   { fontSize: 11, color: '#999', alignSelf: 'flex-end', marginTop: 2 },

  // Input bar
  inputBar: {
    backgroundColor: '#fff',
    paddingVertical: 14,
    paddingHorizontal: 16,
    borderTopWidth: 1,
    borderTopColor: '#e0e0e0',
  },
  inputPlaceholder: { color: '#999', fontSize: 15 },
});

Run this on your phone. You should see a working message thread with green bubbles on the right for your messages and white bubbles on the left for Priya's — exactly like WhatsApp. The key insight is alignItems: 'flex-end' vs 'flex-start' on the row container.

What this taught you without you noticing
  • Conditional styles — [styles.bubble, isMe ? styles.myBubble : styles.theirBubble] applies different styles based on a condition. Style arrays are the standard way to combine and override styles.
  • contentContainerStyle — ScrollView has two style props: style (the outer container) and contentContainerStyle (the inner scrollable area). Use contentContainerStyle for padding inside the scroll area.
  • alignSelf — like alignItems but for a single child overriding the parent's alignment.
