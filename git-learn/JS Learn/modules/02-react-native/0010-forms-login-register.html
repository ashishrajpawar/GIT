Forms — Login & Register Screens

Controlled inputs · Validation · KeyboardAvoidingView · returnKeyType ~40 min Hands-on
Why this matters for your WhatsApp clone

The first two screens a user sees in your app are Login and Register. They need to type their phone number or email, a password, and tap a button. If the form is broken — keyboard hides the inputs, errors don't show clearly, tapping Next doesn't jump to the next field — users give up. This lesson builds both screens to match WhatsApp's onboarding style, with proper validation and keyboard handling on both iOS and Android.

1. Controlled inputs — connecting TextInput to state

A controlled input means the TextInput's value is always driven by a state variable. Every keystroke updates the state; the state drives the display. This is the standard pattern in React Native.

import { useState } from 'react';
import { View, TextInput, Text, StyleSheet } from 'react-native';

function LoginScreen() {
  const [email,    setEmail]    = useState('');
  const [password, setPassword] = useState('');

  return (
    <View>
      <TextInput
        style={styles.input}
        value={email}                    // driven by state
        onChangeText={setEmail}          // updates state on every keystroke
        placeholder="Email"
        keyboardType="email-address"
        autoCapitalize="none"
      />
      <TextInput
        style={styles.input}
        value={password}
        onChangeText={setPassword}
        placeholder="Password"
        secureTextEntry                  // hides characters
      />

      <Text>Email is: {email}</Text>
    </View>
  );
}
Why controlled inputs?

With controlled inputs, the state is always the single source of truth. When the user taps Login, you read email and password from state — you don't have to query the DOM or use refs. It also lets you validate in real time and clear the fields programmatically by calling setEmail('').

2. Jumping between fields — useRef and returnKeyType

On a real form, tapping "Next" on the keyboard should move focus to the next field — not dismiss the keyboard. This requires a ref on each input and returnKeyType to control the keyboard's return key label.

import { useState, useRef } from 'react';
import { View, TextInput, StyleSheet } from 'react-native';

function RegisterScreen() {
  const [name,     setName]     = useState('');
  const [email,    setEmail]    = useState('');
  const [password, setPassword] = useState('');

  // A ref gives you direct access to the TextInput component
  const emailRef    = useRef(null);
  const passwordRef = useRef(null);

  return (
    <View>
      <TextInput
        style={styles.input}
        value={name}
        onChangeText={setName}
        placeholder="Your name"
        returnKeyType="next"            // shows "Next" on the keyboard
        onSubmitEditing={() => emailRef.current?.focus()}  // move focus on Next
        blurOnSubmit={false}            // don't dismiss keyboard when tapping Next
      />
      <TextInput
        ref={emailRef}                  // attach the ref
        style={styles.input}
        value={email}
        onChangeText={setEmail}
        placeholder="Email"
        keyboardType="email-address"
        autoCapitalize="none"
        returnKeyType="next"
        onSubmitEditing={() => passwordRef.current?.focus()}
        blurOnSubmit={false}
      />
      <TextInput
        ref={passwordRef}
        style={styles.input}
        value={password}
        onChangeText={setPassword}
        placeholder="Password"
        secureTextEntry
        returnKeyType="done"            // last field: shows "Done" / dismisses keyboard
      />
    </View>
  );
}

The chain is: Name field → tap Next → emailRef.current.focus() → Email field gets focus → tap Next → passwordRef.current.focus() → Password field → tap Done → keyboard dismisses.

3. Keyboard-aware layout — KeyboardAvoidingView

When the keyboard appears, it covers the bottom half of the screen. If your inputs are near the bottom, they get hidden behind it. KeyboardAvoidingView solves this by pushing the content up.

import { KeyboardAvoidingView, Platform, ScrollView } from 'react-native';

function LoginScreen() {
  return (
    <KeyboardAvoidingView
      style={{ flex: 1 }}
      behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
      //        ↑ iOS needs 'padding' — adds padding equal to keyboard height
      //          Android needs 'height' — shrinks the view's height instead
    >
      <ScrollView
        contentContainerStyle={{ flexGrow: 1 }}
        keyboardShouldPersistTaps="handled"
        //                         ↑ lets you tap buttons while keyboard is open
      >
        {/* your form inputs go here */}
      </ScrollView>
    </KeyboardAvoidingView>
  );
}
Always use Platform.OS for behavior

'padding' on iOS, 'height' on Android. Using the wrong one causes the layout to jump or not move at all. This is one of the most common React Native gotchas — always check both platforms.

4. Form validation

Validate the inputs before sending them to Firebase. Do it in a plain JavaScript function that returns an errors object.

function validate(email, password, name = '') {
  const errors = {};

  if (name !== '' && name.trim().length < 2) {
    errors.name = 'Name must be at least 2 characters';
  }

  // Simple email check — Firebase gives a proper error if the format is wrong
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!email.trim()) {
    errors.email = 'Email is required';
  } else if (!emailRegex.test(email.trim())) {
    errors.email = 'Enter a valid email address';
  }

  if (!password) {
    errors.password = 'Password is required';
  } else if (password.length < 6) {
    errors.password = 'Password must be at least 6 characters';
  }

  return errors;   // empty object {} means no errors
}

// Usage inside a screen
function handleLogin() {
  const errors = validate(email, password);
  if (Object.keys(errors).length > 0) {
    setFormErrors(errors);   // show errors — don't submit
    return;
  }
  // All good — call Firebase Auth here (Module 3)
  console.log('Logging in:', email);
}

5. Displaying errors under each field

Show the error message directly under the input that failed. Clear the error for a field as soon as the user starts typing in it.

const [formErrors, setFormErrors] = useState({});

// Clear the error for this field as user types
<TextInput
  value={email}
  onChangeText={text => {
    setEmail(text);
    if (formErrors.email) {
      setFormErrors(prev => ({ ...prev, email: '' }));
    }
  }}
  style={[
    styles.input,
    formErrors.email && styles.inputError,   // red border on error
  ]}
/>

{/* Error text under the input */}
{formErrors.email ? (
  <Text style={styles.errorText}>{formErrors.email}</Text>
) : null}

// In styles:
// inputError: { borderColor: '#e53935' }
// errorText:  { color: '#e53935', fontSize: 12, marginTop: 2, marginLeft: 4 }

6. Loading state while waiting for Firebase

After the user taps Login, it takes a moment for Firebase to respond. Show a loading indicator on the button and disable it so the user can't tap twice.

import { ActivityIndicator } from 'react-native';

const [loading, setLoading] = useState(false);

async function handleLogin() {
  const errors = validate(email, password);
  if (Object.keys(errors).length > 0) {
    setFormErrors(errors);
    return;
  }

  setLoading(true);
  try {
    // await signInWithEmailAndPassword(auth, email, password);  // Module 3
    await new Promise(r => setTimeout(r, 1500));  // fake delay for now
    navigation.replace('Main');
  } catch (err) {
    setFormErrors({ general: 'Incorrect email or password' });
  } finally {
    setLoading(false);
  }
}

// Button with loading state
<Pressable
  style={[styles.button, loading && styles.buttonDisabled]}
  onPress={handleLogin}
  disabled={loading}
>
  {loading
    ? <ActivityIndicator color="#fff" />
    : <Text style={styles.buttonText}>LOG IN</Text>
  }
</Pressable>

7. Full working example — Login and Register screens

This is the complete Login and Register UI for your WhatsApp clone. The screens live in the root stack from Lesson 8 (outside the tab navigator, so there's no tab bar during onboarding). Replace your entire App.js with this.

import { useState, useRef } from 'react';
import { NavigationContainer } from '@react-navigation/native';
import { createNativeStackNavigator } from '@react-navigation/native-stack';
import { createBottomTabNavigator }   from '@react-navigation/bottom-tabs';
import {
  View, Text, TextInput, Pressable,
  StyleSheet, KeyboardAvoidingView, ScrollView,
  Platform, ActivityIndicator,
} from 'react-native';

const Stack = createNativeStackNavigator();
const Tab   = createBottomTabNavigator();

// ── Validation helper ─────────────────────────────────────────────────────────
function validate({ name, email, password, isRegister }) {
  const errors = {};
  if (isRegister && name.trim().length < 2) {
    errors.name = 'Name must be at least 2 characters';
  }
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  if (!email.trim()) {
    errors.email = 'Email is required';
  } else if (!emailRegex.test(email.trim())) {
    errors.email = 'Enter a valid email address';
  }
  if (!password) {
    errors.password = 'Password is required';
  } else if (password.length < 6) {
    errors.password = 'Password must be at least 6 characters';
  }
  return errors;
}

// ── Screen: Login ─────────────────────────────────────────────────────────────
function LoginScreen({ navigation }) {
  const [email,      setEmail]      = useState('');
  const [password,   setPassword]   = useState('');
  const [formErrors, setFormErrors] = useState({});
  const [loading,    setLoading]    = useState(false);

  const passwordRef = useRef(null);

  function clearError(field) {
    if (formErrors[field]) {
      setFormErrors(prev => ({ ...prev, [field]: '' }));
    }
  }

  async function handleLogin() {
    const errors = validate({ email, password, isRegister: false });
    if (Object.keys(errors).length > 0) {
      setFormErrors(errors);
      return;
    }
    setLoading(true);
    try {
      // TODO Module 3: await signInWithEmailAndPassword(auth, email, password)
      await new Promise(r => setTimeout(r, 1200));  // simulated network delay
      navigation.replace('Main');
    } catch {
      setFormErrors({ general: 'Incorrect email or password. Try again.' });
    } finally {
      setLoading(false);
    }
  }

  return (
    <KeyboardAvoidingView
      style={styles.flex}
      behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
    >
      <ScrollView
        contentContainerStyle={styles.formScroll}
        keyboardShouldPersistTaps="handled"
      >
        {/* Logo area */}
        <View style={styles.logoArea}>
          <View style={styles.logoCircle}>
            <Text style={styles.logoEmoji}>💬</Text>
          </View>
          <Text style={styles.appName}>WhatsApp</Text>
        </View>

        <Text style={styles.formTitle}>Log in to your account</Text>

        {/* General error (e.g. wrong password) */}
        {formErrors.general ? (
          <View style={styles.generalError}>
            <Text style={styles.generalErrorText}>{formErrors.general}</Text>
          </View>
        ) : null}

        {/* Email */}
        <Text style={styles.label}>Email</Text>
        <TextInput
          style={[styles.input, formErrors.email && styles.inputError]}
          value={email}
          onChangeText={t => { setEmail(t); clearError('email'); }}
          placeholder="you@example.com"
          placeholderTextColor="#aaa"
          keyboardType="email-address"
          autoCapitalize="none"
          autoCorrect={false}
          returnKeyType="next"
          onSubmitEditing={() => passwordRef.current?.focus()}
          blurOnSubmit={false}
        />
        {formErrors.email ? <Text style={styles.errorText}>{formErrors.email}</Text> : null}

        {/* Password */}
        <Text style={styles.label}>Password</Text>
        <TextInput
          ref={passwordRef}
          style={[styles.input, formErrors.password && styles.inputError]}
          value={password}
          onChangeText={t => { setPassword(t); clearError('password'); }}
          placeholder="At least 6 characters"
          placeholderTextColor="#aaa"
          secureTextEntry
          returnKeyType="done"
          onSubmitEditing={handleLogin}
        />
        {formErrors.password ? <Text style={styles.errorText}>{formErrors.password}</Text> : null}

        {/* Submit button */}
        <Pressable
          style={[styles.button, loading && styles.buttonDisabled]}
          onPress={handleLogin}
          disabled={loading}
        >
          {loading
            ? <ActivityIndicator color="#fff" />
            : <Text style={styles.buttonText}>LOG IN</Text>
          }
        </Pressable>

        {/* Switch to register */}
        <Pressable
          style={styles.switchLink}
          onPress={() => navigation.navigate('Register')}
        >
          <Text style={styles.switchText}>
            Don't have an account? <Text style={styles.switchTextBold}>Register</Text>
          </Text>
        </Pressable>
      </ScrollView>
    </KeyboardAvoidingView>
  );
}
