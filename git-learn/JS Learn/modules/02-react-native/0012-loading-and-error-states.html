React Native · Lesson 12

Loading & Error States

ActivityIndicator · Skeleton loaders · Empty states · Error banners · try/load/catch/finally ~35 min Hands-on
Why this matters for Token

Every screen in Token loads data — the token list fetches your tokens from the API, a thread loads its messages, the detail screen loads one token's rules. That data doesn't appear instantly. If you show nothing while it loads, the user thinks the app is broken. If you crash silently when the server is unreachable, the user gets a white screen with no explanation. This lesson teaches the three states every data-loading screen must handle: loading, error, and empty — and the single pattern you'll use for all of them.

1. The three states of every data screen

Any screen that loads data from a network or database is always in one of these states:

StateWhat happenedWhat to show
loadingRequest in flight, no data yetSpinner or skeleton
errorRequest failedError message + retry button
emptyRequest succeeded, zero resultsEmpty state illustration
dataRequest succeeded, data presentThe actual content

Model these as three pieces of state:

const [tokens,  setTokens]  = useState([]);       // the data
const [loading, setLoading] = useState(true);     // true while fetching
const [error,   setError]   = useState(null);     // null = no error, string = error message

2. The standard load pattern — try / finally

Always set loading = true before the fetch and loading = false in a finally block — not in try. finally runs whether the request succeeded or failed, so loading is always cleared.

useEffect(() => {
  async function loadTokens() {
    setLoading(true);
    setError(null);         // clear any previous error on retry
    try {
      // In A3 this becomes a call to the Token API:
      // const response = await api.get('/tokens');
      // Simulated network delay for now:
      await new Promise(r => setTimeout(r, 1500));
      setTokens([
        { id: '1', label: 'Flipkart delivery', code: 'KART-4KN9-RT2M', unread: 2 },
        { id: '2', label: 'Gym membership',    code: 'GYMX-7PQ8-VN3K', unread: 0 },
      ]);
    } catch (err) {
      setError('Could not load your tokens. Check your connection.');
    } finally {
      setLoading(false);    // always runs — clears the spinner
    }
  }

  loadTokens();
}, []);
Never put setLoading(false) in the try block

If you write setLoading(false) inside try, a thrown error will skip it and the spinner will spin forever. Always use finally.

3. ActivityIndicator — the built-in spinner

React Native's ActivityIndicator is the standard loading spinner. Use it for full-screen loading and for button loading states.

import { ActivityIndicator, View, StyleSheet } from 'react-native';

// Full-screen centred spinner
function LoadingScreen() {
  return (
    <View style={styles.centre}>
      <ActivityIndicator size="large" color="#075E54" />
    </View>
  );
}

// Inline — replacing a button label while a request is in flight
<Pressable style={styles.button} disabled={loading}>
  {loading
    ? <ActivityIndicator size="small" color="#fff" />
    : <Text style={styles.buttonText}>Send</Text>
  }
</Pressable>

const styles = StyleSheet.create({
  centre: { flex: 1, alignItems: 'center', justifyContent: 'center' },
});

4. Skeleton loaders — better than a blank spinner

A skeleton loader shows the shape of the content while it loads — grey placeholder blocks where the real data will appear. Use it for the token list. You don't need a library; build it with View and a subtle animated opacity.

import { useEffect, useRef } from 'react';
import { View, Animated, StyleSheet } from 'react-native';

// A single pulsing grey block
function SkeletonBlock({ width, height, style }) {
  const opacity = useRef(new Animated.Value(0.4)).current;

  useEffect(() => {
    Animated.loop(
      Animated.sequence([
        Animated.timing(opacity, { toValue: 1,   duration: 700, useNativeDriver: true }),
        Animated.timing(opacity, { toValue: 0.4, duration: 700, useNativeDriver: true }),
      ])
    ).start();
  }, []);

  return (
    <Animated.View
      style={[
        styles.skeleton,
        { width, height, borderRadius: height / 2 },
        { opacity },
        style,
      ]}
    />
  );
}

// A skeleton row that mimics a token list item
function TokenRowSkeleton() {
  return (
    <View style={styles.skeletonRow}>
      <SkeletonBlock width={52} height={52} style={{ borderRadius: 26 }} />
      <View style={styles.skeletonLines}>
        <SkeletonBlock width="60%" height={14} />
        <SkeletonBlock width="85%" height={12} style={{ marginTop: 8 }} />
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  skeleton:     { backgroundColor: '#e0e0e0' },
  skeletonRow:  { flexDirection: 'row', alignItems: 'center', paddingHorizontal: 16, paddingVertical: 12 },
  skeletonLines:{ flex: 1, marginLeft: 12 },
});

Render 5–6 skeleton rows while loading — the layout looks populated immediately and the transition to real data feels smooth.

5. Empty state — when the request succeeds but returns nothing

Don't confuse loading and empty. If the request succeeds and the array is empty, show an encouraging empty state — not a spinner and not an error.

// Inside your render logic:
if (loading) return <LoadingScreen />;
if (error)   return <ErrorScreen message={error} onRetry={loadTokens} />;

// Data loaded — but is there anything in it?
return (
  <FlatList
    data={tokens}
    keyExtractor={item => item.id}
    renderItem={({ item }) => <TokenRow token={item} />}
    ListEmptyComponent={
      <View style={styles.emptyState}>
        <Text style={styles.emptyIcon}>💬</Text>
        <Text style={styles.emptyTitle}>No tokens yet</Text>
        <Text style={styles.emptySub}>
          Start a conversation by tapping the pencil icon above.
        </Text>
      </View>
    }
  />
);

FlatList's ListEmptyComponent renders automatically when data is an empty array — you don't need an if check.

Try it yourself — this one is broken on purpose

The order of those guards is the whole lesson. Here they are in the tempting order — check for "nothing to show" first, since it reads naturally — run through the four moments of a real screen's life:

On the very first render there is no data yet, so the emptiness check fires and the user is told "No tokens yet" — a second before their twelve tokens appear. In a product about being in control of who can reach you, a flash of "you have nothing" is not a cosmetic glitch.

Why you will not see this on your own machine

On a fast connection against a local API the flash lasts a handful of milliseconds and you will never catch it. On a train, on a mid-range Android phone, it is on screen long enough to read. The bug is invisible in exactly the conditions you develop in.

The fix is an ordering rule, not a new state: an empty list is only empty once you have actually loaded it.

6. Error states — three patterns

Choose the right error UI for the context:

Full-screen error (data failed to load entirely)

function ErrorScreen({ message, onRetry }) {
  return (
    <View style={styles.centre}>
      <Text style={styles.errorIcon}>⚠️</Text>
      <Text style={styles.errorTitle}>Something went wrong</Text>
      <Text style={styles.errorMessage}>{message}</Text>
      <Pressable style={styles.retryButton} onPress={onRetry}>
        <Text style={styles.retryText}>Try again</Text>
      </Pressable>
    </View>
  );
}

Inline error (form field validation — covered in Lesson 10)

{formErrors.email ? (
  <Text style={styles.fieldError}>{formErrors.email}</Text>
) : null}

Toast / banner (background action failed — e.g. message send failed)

// A temporary banner that auto-hides after 3 seconds
function Toast({ message, visible }) {
  if (!visible) return null;
  return (
    <View style={styles.toast}>
      <Text style={styles.toastText}>{message}</Text>
    </View>
  );
}

// Usage — show on send failure, auto-hide with setTimeout
const [toastMessage, setToastMessage] = useState('');
const [toastVisible, setToastVisible] = useState(false);

function showToast(msg) {
  setToastMessage(msg);
  setToastVisible(true);
  setTimeout(() => setToastVisible(false), 3000);
}

// Triggered in a catch block:
// showToast('Message failed to send. Tap to retry.');
Which error UI to use when

Full-screen error: the main data the screen exists to show failed — there is nothing useful to display without it (the token list, a message thread).
Inline field error: a form input is invalid — always under the specific field.
Toast / banner: a background action failed but the user can keep using the screen (message failed to send, image upload failed).

7. Pull-to-refresh

Users expect to pull down on a list to refresh it. Wire it up with FlatList's refreshing and onRefresh props.

const [refreshing, setRefreshing] = useState(false);

async function onRefresh() {
  setRefreshing(true);
  try {
    // await api.getChats();
    await new Promise(r => setTimeout(r, 1000));
    setTokens([ /* updated data */ ]);
  } catch {
    showToast('Refresh failed. Check your connection.');
  } finally {
    setRefreshing(false);
  }
}

<FlatList
  data={tokens}
  refreshing={refreshing}     // shows the pull-to-refresh spinner
  onRefresh={onRefresh}       // called when user pulls down
  ...
/>

8. Full working example — the token list with all four states

This puts everything together: skeleton while loading, error screen with retry, empty state, and real data — plus pull-to-refresh and a toast for background failures. Replace your entire App.js with this.

import { useState, useEffect, useRef } from 'react';
import {
  View, Text, FlatList, Pressable,
  StyleSheet, Animated, ActivityIndicator,
} from 'react-native';

// ── Skeleton components ───────────────────────────────────────────────────────
function SkeletonBlock({ width, height, style }) {
  const opacity = useRef(new Animated.Value(0.4)).current;
  useEffect(() => {
    Animated.loop(
      Animated.sequence([
        Animated.timing(opacity, { toValue: 1,   duration: 700, useNativeDriver: true }),
        Animated.timing(opacity, { toValue: 0.4, duration: 700, useNativeDriver: true }),
      ])
    ).start();
  }, []);
  return (
    <Animated.View
      style={[{ backgroundColor: '#e0e0e0', borderRadius: height / 2 }, { width, height }, { opacity }, style]}
    />
  );
}

function TokenRowSkeleton() {
  return (
    <View style={styles.row}>
      <SkeletonBlock width={52} height={52} style={{ borderRadius: 26 }} />
      <View style={{ flex: 1, marginLeft: 12 }}>
        <SkeletonBlock width="55%" height={14} />
        <SkeletonBlock width="80%" height={12} style={{ marginTop: 8 }} />
      </View>
    </View>
  );
}

// ── Toast ─────────────────────────────────────────────────────────────────────
function Toast({ message, visible }) {
  if (!visible) return null;
  return (
    <View style={styles.toast}>
      <Text style={styles.toastText}>{message}</Text>
    </View>
  );
}

// ── Fake API — swap these for real calls in A3 ────────────────────────────────
let callCount = 0;
async function fetchChats() {
  await new Promise(r => setTimeout(r, 1500));
  callCount++;
  // Simulate a failure on the second load so you can see the error state
  if (callCount === 2) throw new Error('Network error');
  // Return empty array on the third load so you can see the empty state
  if (callCount === 3) return [];
  return [
    { id: '1', label: 'Flipkart delivery', code: 'KART-4KN9-RT2M',     time: '10:32',    unread: 2 },
    { id: '2', label: 'Gym membership',    code: 'GYMX-7PQ8-VN3K', time: '09:15',    unread: 0 },
    { id: '3', label: 'Flat viewing',      code: 'RENT-2WX7-HJ5D', time: 'Yesterday',unread: 5 },
  ];
}

// ── Main screen ───────────────────────────────────────────────────────────────
export default function App() {
  const [tokens,     setTokens]     = useState([]);
  const [loading,    setLoading]    = useState(true);
  const [error,      setError]      = useState(null);
  const [refreshing, setRefreshing] = useState(false);
  const [toast,      setToast]      = useState({ visible: false, message: '' });

  function showToast(message) {
    setToast({ visible: true, message });
    setTimeout(() => setToast({ visible: false, message: '' }), 3000);
  }

  async function loadTokens() {
    setLoading(true);
    setError(null);
    try {
      const data = await fetchChats();
      setTokens(data);
    } catch {
      setError('Could not load your tokens. Check your connection.');
    } finally {
      setLoading(false);
    }
  }

  async function onRefresh() {
    setRefreshing(true);
    try {
      const data = await fetchChats();
      setTokens(data);
    } catch {
      showToast('Refresh failed. Pull down to try again.');
    } finally {
      setRefreshing(false);
    }
  }

  useEffect(() => { loadTokens(); }, []);

  // ── State: loading ──────────────────────────────────────────────────────────
  if (loading) {
    return (
      <View style={styles.screen}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>My tokens</Text>
        </View>
        {[1,2,3,4,5].map(i => <TokenRowSkeleton key={i} />)}
      </View>
    );
  }

  // ── State: error ────────────────────────────────────────────────────────────
  if (error) {
    return (
      <View style={styles.screen}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>My tokens</Text>
        </View>
        <View style={styles.centre}>
          <Text style={styles.errorIcon}>⚠️</Text>
          <Text style={styles.errorTitle}>Something went wrong</Text>
          <Text style={styles.errorMessage}>{error}</Text>
          <Pressable style={styles.retryButton} onPress={loadTokens}>
            <Text style={styles.retryText}>Try again</Text>
          </Pressable>
          <Text style={styles.hintText}>(Tap retry twice to see the empty state)</Text>
        </View>
      </View>
    );
  }

  // ── State: data (may be empty) ──────────────────────────────────────────────
  return (
    <View style={styles.screen}>
      <View style={styles.header}>
        <Text style={styles.headerTitle}>My tokens</Text>
        <Text style={styles.headerSub}>{tokens.length} tokens</Text>
      </View>

      <FlatList
        data={tokens}
        keyExtractor={item => item.id}
        refreshing={refreshing}
        onRefresh={onRefresh}
        ItemSeparatorComponent={() => <View style={styles.sep} />}
        ListEmptyComponent={
          <View style={styles.emptyState}>
            <Text style={styles.emptyIcon}>💬</Text>
            <Text style={styles.emptyTitle}>No tokens yet</Text>
            <Text style={styles.emptySub}>
              Start a conversation by tapping the pencil icon.
            </Text>
            <Pressable style={styles.retryButton} onPress={loadTokens}>
              <Text style={styles.retryText}>Reload</Text>
            </Pressable>
          </View>
        }
        renderItem={({ item }) => (
          <Pressable
            style={({ pressed }) => [styles.row, pressed && styles.rowPressed]}
          >
            <View style={styles.avatarCircle}>
              <Text style={styles.avatarLetter}>{item.label[0]}</Text>
            </View>
            <View style={styles.middle}>
              <Text style={styles.name}>{item.label}</Text>
              <Text style={styles.preview} numberOfLines={1}>{item.code}</Text>
            </View>
            <View style={styles.right}>
              <Text style={[styles.time, item.unread > 0 && styles.timeGreen]}>
                {item.time}
              </Text>
              {item.unread > 0 && (
                <View style={styles.badge}>
                  <Text style={styles.badgeText}>{item.unread}</Text>
                </View>
              )}
            </View>
          </Pressable>
        )}
      />

      {/* Toast sits above everything else */}
      <Toast message={toast.message} visible={toast.visible} />
    </View>
  );
}

// ── Styles ────────────────────────────────────────────────────────────────────
const styles = StyleSheet.create({
  screen:        { flex: 1, backgroundColor: '#fff' },
  centre:        { flex: 1, alignItems: 'center', justifyContent: 'center', padding: 24 },
  header:        { backgroundColor: '#075E54', paddingTop: 48, paddingBottom: 12, paddingHorizontal: 16, flexDirection: 'row', alignItems: 'baseline', gap: 10 },
  headerTitle:   { color: '#fff', fontSize: 20, fontWeight: '700' },

Run this. The first load shows skeleton rows for 1.5 seconds, then real data appears. Pull down to refresh — on the second request it throws an error, showing the error screen with a retry button. Tap retry — the third request returns an empty array, showing the empty state. Tap Reload — the fourth request succeeds and data reappears. The cycle repeats, so you can see all four states as many times as you want.

This is the complete pattern for every data screen

The three state variables (loading, error, tokens) and the try / catch / finally structure in loadTokens are the same in every screen of your app. In A3 you replace the fake fetchChats() function with real API calls — the state management and UI stay identical.

Four states and one decision. Written as a plain function, it is the sort of thing you can enumerate completely — which is worth doing once, because every data screen in the app repeats it.

Anything unclear? Ask your teacher. Common issues: (1) Spinner spins forever — you put setLoading(false) inside the try block instead of finally; an error throws before it runs. (2) Skeleton doesn't animate — make sure you imported Animated from react-native and used useNativeDriver: true. (3) Pull-to-refresh spinner shows but data doesn't update — check that you called setTokens(data) inside onRefresh, not just inside loadTokens. (4) Toast shows but never disappears — confirm your setTimeout is calling setToast({ visible: false, ... }) with the right shape.
