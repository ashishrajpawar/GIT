Lesson 10

Arrays & Objects

Core JavaScript ~30 min read Beginner
Why this matters for your WhatsApp clone

Every piece of data in your app lives inside an array or an object. A chat thread is an array of message objects. Each message is an object with a sender, text, timestamp, and read status. A contacts list is an array of user objects. If you can work with arrays and objects confidently, you can model and manipulate every piece of your app's data.

1. Arrays — ordered lists of things

An array is an ordered list of values. You create one with square brackets [] and separate items with commas.

// An empty array
const messages = [];

// An array of strings — a list of chat names
const chatNames = ["Priya", "Rahul", "Family Group", "Work Team"];

// An array of numbers — message IDs
const messageIds = [101, 102, 103, 104];

// Arrays can hold any type — even mixed types (though you'll rarely need that)
const mixed = ["hello", 42, true, null];

Reading items by index

Each item in an array has a position called its index, starting at 0 (not 1).

const chatNames = ["Priya", "Rahul", "Family Group", "Work Team"];

console.log(chatNames[0]); // "Priya"    — first item
console.log(chatNames[1]); // "Rahul"    — second item
console.log(chatNames[3]); // "Work Team" — fourth item
console.log(chatNames[4]); // undefined  — doesn't exist
Arrays start at 0, not 1

This trips up almost every beginner. The first item is at index 0, the second at 1, and so on. An array with 4 items has valid indices 0, 1, 2, 3. Index 4 is undefined.

Array length

const chatNames = ["Priya", "Rahul", "Family Group", "Work Team"];
console.log(chatNames.length); // 4

// The last item is always at index length - 1
console.log(chatNames[chatNames.length - 1]); // "Work Team"

Adding and removing items

const messages = ["Hey!", "How are you?"];

// Add to the END
messages.push("I'm good, thanks!");
console.log(messages); // ["Hey!", "How are you?", "I'm good, thanks!"]

// Remove from the END
const last = messages.pop();
console.log(last);     // "I'm good, thanks!"
console.log(messages); // ["Hey!", "How are you?"]

// Add to the BEGINNING
messages.unshift("Hello first!");
console.log(messages); // ["Hello first!", "Hey!", "How are you?"]

// Remove from the BEGINNING
const first = messages.shift();
console.log(first);    // "Hello first!"
In your WhatsApp clone

When a new message arrives from Firebase, you'll use messages.push(newMessage) to append it to the chat array. React Native will then re-render the list to show it.

Looping over an array

The most common thing you'll do with an array is loop through it — to display every message, every contact, every notification.

const messages = [
  "Hey, are you free tonight?",
  "Yes! What time?",
  "Around 8pm?"
];

// for...of — cleanest way to loop
for (const message of messages) {
  console.log(message);
}
// "Hey, are you free tonight?"
// "Yes! What time?"
// "Around 8pm?"

// forEach — another common way
messages.forEach(function(message, index) {
  console.log(index + ": " + message);
});
// 0: Hey, are you free tonight?
// 1: Yes! What time?
// 2: Around 8pm?

The most useful array methods

These four methods — map, filter, find, and includes — will appear constantly in your React Native code.

// ── map: transform every item into something new ──────────────────────────
// Imagine you have raw message objects and want just the text strings
const rawMessages = [
  { sender: "Priya", text: "Ready?", read: true },
  { sender: "Ashish", text: "Yes!", read: false },
  { sender: "Priya", text: "Coming down now", read: false }
];

const textOnly = rawMessages.map(function(msg) {
  return msg.text;
});
console.log(textOnly); // ["Ready?", "Yes!", "Coming down now"]


// ── filter: keep only items that match a condition ────────────────────────
// Get only unread messages
const unread = rawMessages.filter(function(msg) {
  return msg.read === false;
});
console.log(unread.length); // 2 (the "Yes!" and "Coming down now" messages)


// ── find: get the FIRST item that matches (or undefined) ──────────────────
const firstUnread = rawMessages.find(function(msg) {
  return msg.read === false;
});
console.log(firstUnread.text); // "Yes!"


// ── includes: check if a value exists in the array ───────────────────────
const blockedUsers = ["user-123", "user-456"];
const incomingUser = "user-456";

if (blockedUsers.includes(incomingUser)) {
  console.log("This user is blocked — don't show their messages.");
}
map and filter are everywhere in React Native

In React Native you'll write messages.map(...) to turn each message object into a UI component. You'll write contacts.filter(...) to search your contact list as someone types. These two methods alone will be in almost every screen you build.

2. Objects — data with named properties

An object stores data as key–value pairs. Instead of accessing data by index (like arrays), you access it by name. You create an object with curly braces {}.

// A message object — this is exactly what a Firebase message document looks like
const message = {
  id:        "msg-001",
  sender:    "Priya",
  text:      "Hey! Still on for tonight?",
  timestamp: 1700000000000,
  read:      false
};

// Access properties with dot notation
console.log(message.sender);    // "Priya"
console.log(message.text);      // "Hey! Still on for tonight?"
console.log(message.read);      // false

// Or with bracket notation (useful when the key is in a variable)
const field = "sender";
console.log(message[field]);    // "Priya"

Updating and adding properties

const message = {
  id:   "msg-001",
  text: "Hey!",
  read: false
};

// Update an existing property
message.read = true;
console.log(message.read); // true

// Add a new property
message.deliveredAt = 1700000500000;
console.log(message.deliveredAt); // 1700000500000

Nested objects — objects inside objects

Real data is nested. A user has a profile. A message has a sender object. A chat has a list of participants.

const user = {
  id:     "user-ashish-01",
  name:   "Ashish",
  phone:  "+91 98765 43210",
  profile: {
    avatar:   "ashish-avatar.jpg",
    status:   "online",
    about:    "Available"
  },
  settings: {
    notifications: true,
    darkMode:      false
  }
};

// Access nested properties by chaining dots
console.log(user.profile.status);          // "online"
console.log(user.settings.notifications);  // true

// Update a nested property
user.profile.status = "busy";
console.log(user.profile.status); // "busy"

Checking if a property exists

const message = {
  id:   "msg-001",
  text: "Hello!",
  read: false
};

// Using 'in' operator
console.log("text" in message);        // true
console.log("deletedAt" in message);   // false

// Or check for undefined
console.log(message.deletedAt !== undefined); // false — property doesn't exist

Object.keys, Object.values, Object.entries

const message = {
  id:     "msg-001",
  sender: "Priya",
  text:   "Hey!",
  read:   false
};

// Get all keys as an array
console.log(Object.keys(message));
// ["id", "sender", "text", "read"]

// Get all values as an array
console.log(Object.values(message));
// ["msg-001", "Priya", "Hey!", false]

// Get [key, value] pairs
console.log(Object.entries(message));
// [["id","msg-001"], ["sender","Priya"], ["text","Hey!"], ["read",false]]

3. Arrays of objects — the real data shape of your app

In your WhatsApp clone, almost every list in the app is an array of objects: a chat list, a message thread, a contacts page. This is the most important pattern to get comfortable with.

// A chat thread — exactly what you'd get back from Firebase
const messages = [
  {
    id:        "msg-001",
    sender:    "Priya",
    senderId:  "user-priya-02",
    text:      "Hey! Did you see the match?",
    timestamp: 1700000000000,
    read:      true
  },
  {
    id:        "msg-002",
    sender:    "Ashish",
    senderId:  "user-ashish-01",
    text:      "Yes! What a game!",
    timestamp: 1700000060000,
    read:      true
  },
  {
    id:        "msg-003",
    sender:    "Priya",
    senderId:  "user-priya-02",
    text:      "I almost had a heart attack lol",
    timestamp: 1700000120000,
    read:      false
  }
];

// Loop and read — display every message
for (const msg of messages) {
  console.log(msg.sender + ": " + msg.text);
}

// filter — get unread messages only
const unread = messages.filter(function(msg) {
  return msg.read === false;
});
console.log("Unread count:", unread.length); // 1

// find — get message by ID (e.g. when user taps to reply)
const target = messages.find(function(msg) {
  return msg.id === "msg-002";
});
console.log("Found:", target.text); // "Yes! What a game!"

// map — transform to display format for UI
const displayItems = messages.map(function(msg) {
  return {
    label:    msg.sender,
    preview:  msg.text,
    isUnread: !msg.read
  };
});
console.log(displayItems);
This is your entire app's data model

Every screen in your WhatsApp clone is just rendering an array of objects. The chat list screen shows an array of chat objects. The message thread shows an array of message objects. The contacts page shows an array of user objects. Once this pattern clicks, building screens becomes mostly a question of: "what does the array look like, and how do I display each item?"

4. Copying objects and arrays — a critical gotcha

Objects and arrays are stored by reference, not by value. This means if you assign an object to a new variable, both variables point to the same object in memory — changing one changes the other.

// THE PROBLEM
const original = { sender: "Priya", text: "Hey!", read: false };
const copy = original; // copy points to the SAME object

copy.read = true;

console.log(original.read); // true — original was changed too!
console.log(copy.read);     // true

This causes subtle bugs. To make a true independent copy, use the spread operator ...:

// SAFE COPY with spread operator
const original = { sender: "Priya", text: "Hey!", read: false };
const copy = { ...original }; // creates a NEW object with the same values

copy.read = true;

console.log(original.read); // false — original is untouched
console.log(copy.read);     // true  — only copy changed

// Same pattern for arrays
const messages = ["msg-001", "msg-002", "msg-003"];
const messagesCopy = [...messages]; // new array, same values

messagesCopy.push("msg-004");
console.log(messages.length);      // 3 — original untouched
console.log(messagesCopy.length);  // 4
Spread only copies one level deep

If your object has nested objects inside it, spread only copies the top level. The nested objects are still shared. For now, just be aware of this — you'll encounter it when updating nested state in React Native.

5. A complete WhatsApp example

Let's simulate the data layer of the chat list screen — the screen that shows all your conversations with a preview of the last message and an unread count badge.

// ─── Data (what Firebase would return) ────────────────────────────────────

const chats = [
  {
    id:          "chat-001",
    participant: { name: "Priya Sharma", avatar: "priya.jpg", online: true },
    messages: [
      { id: "m1", sender: "Priya",  text: "Are you free tonight?",       read: true  },
      { id: "m2", sender: "Ashish", text: "Yes! 8pm?",                   read: true  },
      { id: "m3", sender: "Priya",  text: "Perfect, see you then",        read: false }
    ]
  },
  {
    id:          "chat-002",
    participant: { name: "Rahul Mehta", avatar: "rahul.jpg", online: false },
    messages: [
      { id: "m4", sender: "Rahul",  text: "Check this out!",              read: false },
      { id: "m5", sender: "Rahul",  text: "It's the new React Native docs", read: false }
    ]
  },
  {
    id:          "chat-003",
    participant: { name: "Mom", avatar: "mom.jpg", online: false },
    messages: [
      { id: "m6", sender: "Mom",    text: "Dinner at 7?",                 read: true  }
    ]
  }
];

// ─── Logic ────────────────────────────────────────────────────────────────

function buildChatListItems(chats) {
  return chats.map(function(chat) {
    const allMessages   = chat.messages;
    const lastMessage   = allMessages[allMessages.length - 1];
    const unreadCount   = allMessages.filter(function(m) { return !m.read; }).length;

    return {
      chatId:       chat.id,
      name:         chat.participant.name,
      online:       chat.participant.online,
      preview:      lastMessage.text,
      unreadCount:  unreadCount
    };
  });
}

// ─── Display (would be React Native components in your real app) ──────────

function renderChatList(items) {
  console.log("─── Chat List ──────────────────────────────");
  for (const item of items) {
    const unreadBadge = item.unreadCount > 0 ? " [" + item.unreadCount + " unread]" : "";
    const onlineDot   = item.online ? " ●" : "";
    console.log(item.name + onlineDot + unreadBadge);
    console.log("  " + item.preview);
  }
}

// ─── Run ──────────────────────────────────────────────────────────────────

const listItems = buildChatListItems(chats);
renderChatList(listItems);

// Output:
// ─── Chat List ──────────────────────────────
// Priya Sharma ● [1 unread]
//   Perfect, see you then
// Rahul Mehta [2 unread]
//   It's the new React Native docs
// Mom
//   Dinner at 7?

Paste this into your browser console (F12) and run it. Every line of that logic is just arrays and objects — the same patterns you just learned.
