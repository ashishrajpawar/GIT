Module 1

JavaScript Fundamentals

12 lessons + capstone ~6 hours Start here
Goal of this module

Learn the JavaScript you need to build Token. Every lesson ties its concept to something the product actually does — issuing a code, applying a rule, revoking access — and the module ends by building the token issuer for real, as the first commit in the Token repo.

Lessons

  1. What Is JavaScript?
  2. Data Types
  3. Functions
  4. Conditionals
  5. Loops
  6. Scope & Closures
  7. DOM & Browser APIs
  8. Events
  9. Promises & Async/Await
  10. Arrays & Objects
  11. Modern JavaScript (ES6+)
  12. Error Handling

Capstone

The Token Issuer — generate, store, apply rules, revoke. Three staged exercises that end in token/practice/01-token-issuer/, the first real code in the Token repo. No new syntax; everything from the twelve lessons above, used at once.
