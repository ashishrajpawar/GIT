Theming & Dark Mode

A11 — Lesson 2 of 5  |  ~40 min

Why this matters for Token: A privacy app signals trust through clean, consistent design. Users in India often use OLED phones where dark mode saves significant battery. Supporting system theme preference (and a manual override) isn't a luxury — it's expected. A scattered colour palette with hardcoded hex values makes this impossible to maintain. A theme system gives you one source of truth for every colour in the app.

The Problem with Hardcoded Colours

// Scattered across 30 files:
<View style={{ backgroundColor: '#fff' }}>
<Text style={{ color: '#333' }}>
<View style={{ borderColor: '#e0e0e0' }}>

To add dark mode, you'd have to find and conditionally replace every single one. Instead, define colours once and reference them everywhere through a context.

Building the Theme Context

// app/src/theme/ThemeContext.tsx
import { createContext, useContext, useState, useEffect, ReactNode } from 'react';
import { useColorScheme } from 'react-native';
import AsyncStorage from '@react-native-async-storage/async-storage';
import { colors, ThemeColors } from './colors';
import { spacing } from './spacing';
import { typography } from './typography';

type ThemeMode = 'light' | 'dark' | 'system';

interface ThemeContextValue {
  mode: ThemeMode;
  isDark: boolean;
  colors: ThemeColors;
  spacing: typeof spacing;
  typography: typeof typography;
  setMode: (mode: ThemeMode) => void;
}

const ThemeContext = createContext<ThemeContextValue | null>(null);

const STORAGE_KEY = 'token_theme_mode';

export function ThemeProvider({ children }: { children: ReactNode }) {
  const systemScheme = useColorScheme();
  const [mode, setModeState] = useState<ThemeMode>('system');

  useEffect(() => {
    AsyncStorage.getItem(STORAGE_KEY).then((stored) => {
      if (stored === 'light' || stored === 'dark' || stored === 'system') {
        setModeState(stored);
      }
    });
  }, []);

  const setMode = (newMode: ThemeMode) => {
    setModeState(newMode);
    AsyncStorage.setItem(STORAGE_KEY, newMode);
  };

  const isDark = mode === 'system'
    ? systemScheme === 'dark'
    : mode === 'dark';

  const value: ThemeContextValue = {
    mode,
    isDark,
    colors: isDark ? colors.dark : colors.light,
    spacing,
    typography,
    setMode,
  };

  return (
    <ThemeContext.Provider value={value}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme(): ThemeContextValue {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error('useTheme must be used within ThemeProvider');
  return ctx;
}

Wiring It Into the App

// app/App.tsx
import { GestureHandlerRootView } from 'react-native-gesture-handler';
import { ThemeProvider } from './src/theme/ThemeContext';
import { StatusBar } from 'expo-status-bar';
import { useTheme } from './src/theme/ThemeContext';
import { Navigation } from './src/navigation';

function ThemedApp() {
  const { isDark } = useTheme();
  return (
    <>
      <StatusBar style={isDark ? 'light' : 'dark'} />
      <Navigation />
    </>
  );
}

export default function App() {
  return (
    <GestureHandlerRootView style={{ flex: 1 }}>
      <ThemeProvider>
        <ThemedApp />
      </ThemeProvider>
    </GestureHandlerRootView>
  );
}

No StyleSheet.create for themed styles — you build them inline from context values. This avoids stale cached styles when the theme changes.

The Theme Picker Component

// app/src/components/ThemePicker.tsx
import { View, Text, Pressable, StyleSheet } from 'react-native';
import { useTheme } from '../theme/ThemeContext';

const OPTIONS: Array<{ label: string; value: 'light' | 'dark' | 'system' }> = [
  { label: '☀️ Light', value: 'light' },
  { label: '🌙 Dark', value: 'dark' },
  { label: '📱 System', value: 'system' },
];

export function ThemePicker() {
  const { mode, setMode, colors, spacing } = useTheme();

  return (
    <View style={{ flexDirection: 'row', gap: spacing.sm }}>
      {OPTIONS.map((option) => {
        const isActive = mode === option.value;
        return (
          <Pressable
            key={option.value}
            onPress={() => setMode(option.value)}
            style={[
              styles.chip,
              {
                backgroundColor: isActive ? colors.primary : colors.surface,
                borderColor: isActive ? colors.primary : colors.border,
              },
            ]}
          >
            <Text style={{
              color: isActive ? '#fff' : colors.text,
              fontSize: 14,
              fontWeight: isActive ? '600' : '400',
            }}>
              {option.label}
            </Text>
          </Pressable>
        );
      })}
    </View>
  );
}

const styles = StyleSheet.create({
  chip: {
    paddingVertical: 8,
    paddingHorizontal: 16,
    borderRadius: 20,
    borderWidth: 1,
  },
});

Animating Theme Transitions

An abrupt colour change feels jarring. Use Reanimated to smoothly transition background colours:

import Animated, {
  useAnimatedStyle,
  withTiming,
  useSharedValue,
  useDerivedValue,
} from 'react-native-reanimated';
import { useTheme } from '../theme/ThemeContext';

export function AnimatedBackground({ children }) {
  const { colors } = useTheme();

  const bgColor = useDerivedValue(() =>
    withTiming(colors.background, { duration: 300 })
  );

  const animatedStyle = useAnimatedStyle(() => ({
    backgroundColor: bgColor.value,
    flex: 1,
  }));

  return (
    <Animated.View style={animatedStyle}>
      {children}
    </Animated.View>
  );
}

Note: Reanimated can animate colour strings directly (it interpolates the RGB components). This works for backgroundColor, borderColor, and color.

Navigation Theming

React Navigation has its own theme system. Sync it with yours:

import { NavigationContainer, DefaultTheme, DarkTheme } from '@react-navigation/native';
import { useTheme } from '../theme/ThemeContext';

export function Navigation() {
  const { isDark, colors } = useTheme();

  const navTheme = {
    ...(isDark ? DarkTheme : DefaultTheme),
    colors: {
      ...(isDark ? DarkTheme.colors : DefaultTheme.colors),
      primary: colors.primary,
      background: colors.background,
      card: colors.surface,
      text: colors.text,
      border: colors.border,
    },
  };

  return (
    <NavigationContainer theme={navTheme}>
      {/* stacks and tabs */}
    </NavigationContainer>
  );
}

Common Mistakes

  • Hardcoding #fff / #000 alongside theme colours — everything visual must come from the theme. The one exception: shadows (which are always dark regardless of mode).
  • Using StyleSheet.create for themed styles — the styles are cached at create time and won't update when the theme changes. Use inline styles from useTheme(), or re-create the stylesheet inside a useMemo keyed on isDark.
  • Forgetting the StatusBar — dark text on a dark background makes the clock/battery invisible.
  • Not persisting the choice — if the user picks "Dark", it should survive an app restart. That's why we use AsyncStorage for the mode.
