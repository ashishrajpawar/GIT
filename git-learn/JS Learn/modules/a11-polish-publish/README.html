Module A11 — Polish & Publish

5 lessons  |  Track A (Mobile & Web Client)  |  Phase 7

The final stretch: Token works — it issues tokens, handles chat, does voice/video, runs on a real server. But users judge an app in the first 5 seconds. This module turns a working prototype into a polished, shippable product: smooth animations, consistent theming, reliable forms, proper environment management, and finally — submitting to the app stores.

Lessons

  1. Animations & Gestures — Reanimated, gesture-handler, swipe-to-revoke with confirmation, and why an exit animation is a claim the app must be able to keep
  2. Theming & Dark Mode — Light/dark toggle, theme context, consistent colours
  3. Forms & Validation — react-hook-form + zod, shared validation with backend
  4. Environment Config — app.config.js, expo-constants, EAS secrets, dev/staging/prod
  5. Store Submission — EAS Build and Submit, store declarations read off the schema, runtimeVersion and who actually receives an OTA, the two version counters

Prerequisites

  • All previous A-track modules (A2–A10) complete
  • Backend deployed (B9 Docker & Deployment)
  • Token app functional end-to-end
