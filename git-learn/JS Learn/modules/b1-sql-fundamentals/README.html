SQL Fundamentals

4 lessons Phase 2 — Backend Core
Module goal

Learn SQL from scratch against PostgreSQL — the database Token uses for all persistent data. After this module, you can create tables, write queries, enforce constraints, use transactions for atomicity, and leverage Postgres-specific features like JSONB and LISTEN/NOTIFY.

Lessons

  1. Tables, INSERT, SELECT — CREATE TABLE, INSERT, SELECT, WHERE, UPDATE, DELETE, aggregates
  2. Joins & Relationships — INNER JOIN, LEFT JOIN, foreign keys, GROUP BY, subqueries
  3. Indexes, Transactions, Constraints — CREATE INDEX, BEGIN/COMMIT, FOR UPDATE, CHECK, UNIQUE, NOT NULL
  4. Postgres Specifics — JSONB, arrays, LISTEN/NOTIFY, RETURNING, UPSERT, SQLite differences

After this module

You'll be able to:

  • Design tables with proper constraints and relationships
  • Write queries that join multiple tables
  • Use transactions to guarantee atomic operations (token redemption)
  • Store flexible rule payloads in JSONB
  • Set up real-time notifications with LISTEN/NOTIFY
  • Know the key differences between Postgres (server) and SQLite (mobile cache)
