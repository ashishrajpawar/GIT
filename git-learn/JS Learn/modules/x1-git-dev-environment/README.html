Git & Dev Environment

3 lessons Phase 1 — Foundation
Module goal

Set up the Token repo with git, push to GitHub, and configure the tooling (Node, ESLint, Prettier, TypeScript) that every future lesson depends on. After this module, you have a working repo with four folders and consistent dev tooling.

Lessons

  1. Git Fundamentals — init, add, commit, branch, merge, .gitignore
  2. GitHub Workflow — remote, push, pull, PRs, SSH keys
  3. Dev Environment — Node versioning, VS Code, ESLint, Prettier, monorepo tsconfig

After this module

You'll have the Token repo on GitHub with:

  • Four folders: app/, web/, api/, shared/
  • A .gitignore covering Node, Expo, and secrets
  • ESLint + Prettier configured and working
  • A base tsconfig with path aliases
  • VS Code settings for format-on-save
