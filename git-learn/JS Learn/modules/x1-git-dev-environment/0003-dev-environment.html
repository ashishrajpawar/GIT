Dev Environment

X1 — Lesson 3 of 3 ~50 min
Why this matters for Token

Token uses TypeScript across all four folders. Without consistent tooling — the same Node version, the same formatting rules, the same import paths — you'll spend more time fighting config than writing code. Set this up once, correctly, and it stays out of your way for the entire project.

Node.js version management

Different projects need different Node versions. A version manager lets you switch instantly without reinstalling. Use nvm (Node Version Manager):

# Install nvm (macOS/Linux — see nvm-windows for Windows)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash

# Windows: download nvm-windows from github.com/coreybutler/nvm-windows

# Install and use Node 20 LTS
nvm install 20
nvm use 20
nvm alias default 20

# Verify
node --version   # v20.x.x
npm --version    # 10.x.x

Create a .nvmrc file at the Token repo root so anyone (or any CI) knows which version to use:

20

Then nvm use (with no argument) reads .nvmrc and switches automatically.

VS Code setup

VS Code is the editor for this project. Install these extensions:

  • ESLint — shows errors inline as you type
  • Prettier - Code formatter — auto-formats on save
  • TypeScript + JavaScript — built-in, already there
  • GitLens — see who changed a line, inline blame

Create .vscode/settings.json in the Token repo so these settings apply to everyone who opens this project:

{
  "editor.formatOnSave": true,
  "editor.defaultFormatter": "esbenp.prettier-vscode",
  "editor.codeActionsOnSave": {
    "source.fixAll.eslint": "explicit"
  },
  "typescript.preferences.importModuleSpecifier": "relative"
}

ESLint — catching errors

ESLint finds bugs and bad patterns before you run the code. Install it at the repo root (it covers all four folders):

npm init -y
npm install -D eslint @typescript-eslint/parser @typescript-eslint/eslint-plugin

Create eslint.config.js (flat config — the new standard):

import tseslint from '@typescript-eslint/eslint-plugin';
import tsparser from '@typescript-eslint/parser';

export default [
  {
    files: ['**/*.ts', '**/*.tsx'],
    languageOptions: {
      parser: tsparser,
      parserOptions: {
        ecmaVersion: 'latest',
        sourceType: 'module',
      },
    },
    plugins: {
      '@typescript-eslint': tseslint,
    },
    rules: {
      'no-unused-vars': 'off',
      '@typescript-eslint/no-unused-vars': ['warn', { argsIgnorePattern: '^_' }],
      '@typescript-eslint/no-explicit-any': 'warn',
      'no-console': ['warn', { allow: ['warn', 'error'] }],
    },
  },
];

Prettier — consistent formatting

Prettier handles all formatting decisions so you never debate tabs vs spaces. Install and configure:

npm install -D prettier

Create .prettierrc:

{
  "semi": true,
  "singleQuote": true,
  "trailingComma": "all",
  "printWidth": 100,
  "tabWidth": 2
}

Create .prettierignore:

node_modules
dist
build
.expo

TypeScript config — the monorepo setup

Each folder has its own tsconfig.json that extends a shared base. This means consistent compiler settings everywhere, but each folder can customize (e.g. app/ needs React Native JSX, api/ doesn't).

Root tsconfig.base.json:

{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "moduleResolution": "bundler",
    "strict": true,
    "esModuleInterop": true,
    "skipLibCheck": true,
    "forceConsistentCasingInFileNames": true,
    "resolveJsonModule": true,
    "declaration": true,
    "declarationMap": true,
    "sourceMap": true,
    "paths": {
      "@token/shared/*": ["./shared/*"]
    }
  }
}

Then api/tsconfig.json:

{
  "extends": "../tsconfig.base.json",
  "compilerOptions": {
    "outDir": "./dist",
    "rootDir": "./src"
  },
  "include": ["src/**/*"]
}

And app/tsconfig.json:

{
  "extends": "../tsconfig.base.json",
  "compilerOptions": {
    "jsx": "react-native"
  }
}

The @token/shared/* path alias means any folder can import shared types with:

import { TokenCode, AccessRule } from '@token/shared/types';

Package.json scripts

Add useful scripts to the root package.json:

{
  "scripts": {
    "lint": "eslint . --ext .ts,.tsx",
    "format": "prettier --write .",
    "format:check": "prettier --check .",
    "typecheck": "tsc --noEmit -p app/tsconfig.json && tsc --noEmit -p api/tsconfig.json && tsc --noEmit -p web/tsconfig.json"
  }
}

Now npm run lint, npm run format, and npm run typecheck validate everything at once.
