Auth (Server)

3 lessons Phase 2 — Backend Core
Module goal

Build Token's authentication system from scratch — password hashing with argon2, JWT issuance with refresh token rotation, and rate limiting to prevent brute-force attacks. After this module, your API has secure user registration, login, session management, and protection against the most common auth attacks.

Lessons

  1. Password Hashing & Registration — argon2, never plaintext, registration/login routes
  2. JWT & Refresh Rotation — access/refresh tokens, rotation, requireAuth middleware, logout
  3. Rate Limiting — express-rate-limit, per-endpoint limits, account lockout, trust proxy

After this module

You'll have:

  • Secure registration with argon2 password hashing
  • Login that issues short-lived access + long-lived refresh tokens
  • A refresh endpoint with token rotation (detects theft)
  • A requireAuth middleware protecting all token routes
  • Rate limiting on auth endpoints (5 login attempts / 15 min)
  • Account lockout after 10 failed attempts

Phase 2 (Backend Core) is now complete.
