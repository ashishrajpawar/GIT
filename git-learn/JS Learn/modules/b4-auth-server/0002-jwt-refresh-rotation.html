JWT & Refresh Rotation

B4 — Lesson 2 of 3 ~55 min
Why this matters for Token

After login, the mobile app needs to make API requests without sending the password every time. JWTs (JSON Web Tokens) are the standard: the server issues a signed token, the client sends it with every request, the server verifies the signature without a database lookup. But JWTs can't be revoked once issued — so we pair a short-lived access token with a longer-lived refresh token that can be rotated and revoked.

How JWT works

A JWT has three parts separated by dots: header.payload.signature

// Header: algorithm and token type
{ "alg": "HS256", "typ": "JWT" }

// Payload: your data (claims)
{ "sub": "42", "email": "ashish@example.com", "iat": 1700000000, "exp": 1700000900 }

// Signature: HMAC of header + payload using your secret
// If anyone modifies the payload, the signature won't match → rejected

The server signs it with a secret. Anyone can READ the payload (it's just base64), but nobody can MODIFY it without the secret. The server verifies the signature on every request.

Access token + Refresh token pattern

Access Token Refresh Token
Lifetime 15 minutes 7 days
Stored in Memory (client) Secure storage (Keychain/Keystore)
Sent with Every API request (Authorization header) Only to /api/auth/refresh
Revocable? No (expires naturally) Yes (stored in DB, can be deleted)

The flow:

  1. User logs in → server issues access token + refresh token
  2. Client sends access token with every request
  3. Access token expires (15 min) → client sends refresh token to get a new pair
  4. Old refresh token is invalidated, new pair issued (rotation)
  5. If refresh token is stolen and used, rotation detects it (both tokens are invalid)

Issuing tokens on login

// api/src/services/auth.ts
import jwt from 'jsonwebtoken';
import { randomBytes } from 'crypto';
import { pool } from '../db/pool.js';

const ACCESS_SECRET = process.env.JWT_SECRET!;
const ACCESS_EXPIRY = '15m';
const REFRESH_EXPIRY_DAYS = 7;

interface TokenPayload {
  sub: string;  // user id
  email: string;
}

export function signAccessToken(user: { id: number; email: string }): string {
  return jwt.sign(
    { sub: String(user.id), email: user.email } as TokenPayload,
    ACCESS_SECRET,
    { expiresIn: ACCESS_EXPIRY }
  );
}

export async function createRefreshToken(userId: number): Promise<string> {
  const token = randomBytes(40).toString('hex');
  const expiresAt = new Date(Date.now() + REFRESH_EXPIRY_DAYS * 24 * 60 * 60 * 1000);

  await pool.query(
    `INSERT INTO refresh_tokens (user_id, token_hash, expires_at)
     VALUES ($1, $2, $3)`,
    [userId, hashToken(token), expiresAt]
  );

  return token;
}

function hashToken(token: string): string {
  const { createHash } = require('crypto');
  return createHash('sha256').update(token).digest('hex');
}

The refresh_tokens table

-- Migration: 005_refresh_tokens.sql
CREATE TABLE refresh_tokens (
  id          SERIAL PRIMARY KEY,
  user_id     INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  token_hash  TEXT NOT NULL UNIQUE,
  expires_at  TIMESTAMPTZ NOT NULL,
  created_at  TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  revoked_at  TIMESTAMPTZ
);

CREATE INDEX idx_refresh_tokens_user ON refresh_tokens(user_id);
CREATE INDEX idx_refresh_tokens_hash ON refresh_tokens(token_hash);

Store the hash of the refresh token, not the token itself. If the database is breached, attackers can't use the hashed values as refresh tokens.

Updated login route

router.post('/login', async (req, res, next) => {
  try {
    const { email, password } = loginSchema.parse(req.body);

    const { rows } = await pool.query(
      'SELECT id, email, display_name, password_hash FROM users WHERE email = $1',
      [email]
    );
    if (!rows[0]) throw ApiError.unauthorized('Invalid email or password');

    const valid = await argon2.verify(rows[0].password_hash, password);
    if (!valid) throw ApiError.unauthorized('Invalid email or password');

    const user = rows[0];
    const accessToken = signAccessToken(user);
    const refreshToken = await createRefreshToken(user.id);

    res.json({
      data: {
        user: { id: user.id, email: user.email, displayName: user.display_name },
        accessToken,
        refreshToken,
      },
      success: true,
    });
  } catch (err) { next(err); }
});

Refresh endpoint with rotation

router.post('/refresh', async (req, res, next) => {
  try {
    const { refreshToken } = req.body;
    if (!refreshToken) throw ApiError.unauthorized('Refresh token required');

    const tokenHash = hashToken(refreshToken);

    // Find the token in the database
    const { rows } = await pool.query(
      `SELECT rt.*, u.email, u.display_name
       FROM refresh_tokens rt
       JOIN users u ON rt.user_id = u.id
       WHERE rt.token_hash = $1 AND rt.revoked_at IS NULL AND rt.expires_at > NOW()`,
      [tokenHash]
    );

    if (!rows[0]) {
      // Token not found or revoked — possible theft. Revoke ALL user's tokens.
      await pool.query(
        `UPDATE refresh_tokens SET revoked_at = NOW()
         WHERE token_hash = $1 AND revoked_at IS NULL`,
        [tokenHash]
      );
      throw ApiError.unauthorized('Invalid refresh token');
    }

    const record = rows[0];

    // Rotation: revoke old token, issue new pair
    await pool.query(
      'UPDATE refresh_tokens SET revoked_at = NOW() WHERE id = $1',
      [record.id]
    );

    const newAccessToken = signAccessToken({ id: record.user_id, email: record.email });
    const newRefreshToken = await createRefreshToken(record.user_id);

    res.json({
      data: { accessToken: newAccessToken, refreshToken: newRefreshToken },
      success: true,
    });
  } catch (err) { next(err); }
});

Auth middleware — verifying access tokens

// api/src/middleware/auth.ts
import jwt from 'jsonwebtoken';
import { ApiError } from '../utils/api-error.js';

export function requireAuth(req, res, next) {
  const header = req.headers.authorization;
  if (!header?.startsWith('Bearer ')) {
    throw ApiError.unauthorized();
  }

  const token = header.slice(7);

  try {
    const payload = jwt.verify(token, process.env.JWT_SECRET!) as { sub: string; email: string };
    req.user = { id: parseInt(payload.sub, 10), email: payload.email };
    next();
  } catch (err) {
    if (err.name === 'TokenExpiredError') {
      throw ApiError.unauthorized('Token expired');
    }
    throw ApiError.unauthorized('Invalid token');
  }
}

Logout — revoking refresh tokens

router.post('/logout', requireAuth, async (req, res, next) => {
  try {
    // Revoke all refresh tokens for this user
    await pool.query(
      'UPDATE refresh_tokens SET revoked_at = NOW() WHERE user_id = $1 AND revoked_at IS NULL',
      [req.user.id]
    );
    res.json({ success: true });
  } catch (err) { next(err); }
});
