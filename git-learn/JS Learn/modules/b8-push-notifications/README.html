Push Notifications

Track B

Phase 6 — 1 lesson

Module goal: Deliver push notifications for incoming calls and messages when the app is closed. FCM + APNs via Expo Notifications — the only third-party dependency in the entire stack.

Lessons

  1. FCM + APNs via Expo

What you'll build

  • Server-side push notification dispatch using the Expo Push API
  • Client-side registration that stores push tokens in your users table
  • Notification payloads for incoming messages and calls
  • Tap-to-navigate handlers that open the right conversation or call screen
  • Badge count management across platforms

Prerequisites

  • B5 WebSocket — real-time delivery when the app is open
  • A7 Incoming Calls — call handling that push notifications wake up
