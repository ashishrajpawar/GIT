Track B

Token Engine

3 lessons • Phase 6

Module Goal

Build the server-side logic that enforces Token's rules. Generation, redemption validation, access rule evaluation, revocation propagation — the engine that makes the privacy promise real at the API level.

Lessons

  1. Token Generation & Redemption
  2. Access Rules Engine
  3. Revocation & Pause

What You'll Build

  • A generateTokenCode() function with collision retry using Node's crypto module
  • POST endpoints for creating and redeeming tokens, with full validation
  • A JSONB access rules engine that evaluates time windows, contact limits, and channel restrictions
  • Revocation and pause flows that propagate instantly to active WebSocket connections and calls
  • An audit trail for all token lifecycle events

Prerequisites

  • B2 — Schema Design (tokens table, JSONB rules column)
  • B4 — Auth Server (JWT issuance, middleware)
  • B5 — WebSocket (real-time connection management)
