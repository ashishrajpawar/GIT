Token Generation & Redemption

B7 — Lesson 1 of 3 • ~45 min

Why this matters for Token

A token code like MERC-8GH2-LP4X is the single point of contact between a user and the outside world. If generation is predictable, an attacker can guess codes. If redemption skips validation, revoked tokens still let people in. This lesson builds the server-side generation with collision retry and the redemption endpoint that creates conversations — the two most critical paths in the entire system.

Generating Secure Token Codes

Token codes must be short enough to speak aloud, yet random enough to resist brute-force. We use Node's crypto.randomBytes — not Math.random() — because cryptographic randomness is essential. 

// api/src/engine/generate.ts
import crypto from 'crypto';
import { pool } from '../db';

const CHARSET = 'ABCDEFGHJKLMNPQRSTUVWXYZ23456789'; // no 0/O/1/I/L
const SEGMENT_LENGTH = 4;
const SEGMENT_COUNT = 3;

function randomSegment(): string {
  const bytes = crypto.randomBytes(SEGMENT_LENGTH);
  let segment = '';
  for (let i = 0; i < SEGMENT_LENGTH; i++) {
    segment += CHARSET[bytes[i] % CHARSET.length];
  }
  return segment;
}

export function generateTokenCode(): string {
  const segments: string[] = [];
  for (let i = 0; i < SEGMENT_COUNT; i++) {
    segments.push(randomSegment());
  }
  return segments.join('-');
}

Collision Retry

Even with a large keyspace, collisions are theoretically possible. The generation function retries up to 5 times if a code already exists in the database. 

const MAX_RETRIES = 5;

export async function createUniqueCode(): Promise<string> {
  for (let attempt = 0; attempt < MAX_RETRIES; attempt++) {
    const code = generateTokenCode();
    const { rows } = await pool.query(
      'SELECT 1 FROM tokens WHERE code = $1',
      [code]
    );
    if (rows.length === 0) return code;
  }
  throw new Error('Failed to generate unique token code after retries');
}

POST /tokens — Creating a Token

The authenticated user creates a token, optionally setting expiry, max uses, and access rules. 

// api/src/routes/tokens.ts
import { Router } from 'express';
import { authenticate } from '../middleware/auth';
import { createUniqueCode } from '../engine/generate';
import { pool } from '../db';

const router = Router();

router.post('/tokens', authenticate, async (req, res) => {
  const userId = req.user.id;
  const { label, expires_at, max_uses, rules } = req.body;

  const code = await createUniqueCode();

  const { rows } = await pool.query(
    `INSERT INTO tokens (user_id, code, label, status, expires_at, max_uses, rules)
     VALUES ($1, $2, $3, 'active', $4, $5, $6)
     RETURNING id, code, label, status, expires_at, max_uses, created_at`,
    [userId, code, label || null, expires_at || null, max_uses || null, rules || '{}']
  );

  res.status(201).json({ token: rows[0] });
});

export default router;

POST /tokens/:code/redeem — The Redemption Endpoint

A holder visits tokn.app/t/CODE, enters a display name, and redeems the token. The server must validate status, expiry, and use count before creating a conversation. 

router.post('/tokens/:code/redeem', async (req, res) => {
  const { code } = req.params;
  const { holder_name } = req.body;

  if (!holder_name || holder_name.trim().length === 0) {
    return res.status(400).json({ error: 'holder_name is required' });
  }

  // Fetch token with row lock to prevent race conditions
  const { rows: tokenRows } = await pool.query(
    'SELECT * FROM tokens WHERE code = $1 FOR UPDATE',
    [code]
  );

  if (tokenRows.length === 0) {
    return res.status(404).json({ error: 'Token not found' });
  }

  const token = tokenRows[0];

  // Validation checks
  if (token.status !== 'active') {
    return res.status(403).json({ error: 'Token is not active' });
  }

  if (token.expires_at && new Date(token.expires_at) < new Date()) {
    return res.status(403).json({ error: 'Token has expired' });
  }

  if (token.max_uses !== null) {
    const { rows: countRows } = await pool.query(
      'SELECT COUNT(*) as cnt FROM conversations WHERE token_id = $1',
      [token.id]
    );
    if (parseInt(countRows[0].cnt) >= token.max_uses) {
      return res.status(403).json({ error: 'Token has reached maximum uses' });
    }
  }

  // Create conversation and holder entry
  const { rows: convRows } = await pool.query(
    `INSERT INTO conversations (token_id, holder_name, created_at)
     VALUES ($1, $2, NOW())
     RETURNING id`,
    [token.id, holder_name.trim()]
  );

  // Issue a holder JWT (no user account — just a session)
  const holderJwt = signHolderToken({
    conversationId: convRows[0].id,
    tokenId: token.id,
    holderName: holder_name.trim()
  });

  res.status(201).json({
    conversation_id: convRows[0].id,
    holder_token: holderJwt
  });
});

The Holder JWT

Holders do not have user accounts. They receive a short-lived JWT scoped to a single conversation. This JWT lets them send messages through that one channel without knowing who is on the other end. 

import jwt from 'jsonwebtoken';

interface HolderPayload {
  conversationId: number;
  tokenId: number;
  holderName: string;
}

export function signHolderToken(payload: HolderPayload): string {
  return jwt.sign(
    { ...payload, role: 'holder' },
    process.env.JWT_SECRET!,
    { expiresIn: '7d' }
  );
}

export function verifyHolderToken(token: string): HolderPayload & { role: string } {
  return jwt.verify(token, process.env.JWT_SECRET!) as any;
}

Keyspace Analysis

Understanding the math behind the code format: 

// CHARSET has 32 characters
// Each segment: 32^4 = 1,048,576 possibilities
// Three segments: 32^12 = 1,099,511,627,776 (~1.1 trillion)
// Even with 1 million active tokens, collision probability per attempt:
//   1,000,000 / 1,099,511,627,776 = 0.00000091 (negligible)
// 5 retries makes failure essentially impossible
