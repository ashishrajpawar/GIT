Revocation & Pause

B7 — Lesson 3 of 3 • ~45 min

Why this matters for Token

When a user revokes a token, ALL active sessions must end immediately. Not "on next request" — immediately. Active WebSocket conversations disconnect, ongoing calls hang up, pending messages are blocked. This is the nuclear option, and it must work flawlessly. Pause is softer — it temporarily rejects new actions but also drops existing connections. The difference: pause is reversible, revoke is permanent.

Status Transitions

A token has three statuses. The transitions are strictly controlled: 

// Valid status transitions:
// active  -> paused    (user pauses)
// active  -> revoked   (user revokes)
// paused  -> active    (user resumes)
// paused  -> revoked   (user revokes while paused)
// revoked -> (nothing) (permanent, cannot undo)

type TokenStatus = 'active' | 'paused' | 'revoked';

const VALID_TRANSITIONS: Record<TokenStatus, TokenStatus[]> = {
  active: ['paused', 'revoked'],
  paused: ['active', 'revoked'],
  revoked: []  // Terminal state — no way back
};

PATCH /tokens/:id — Status Update Endpoint

The endpoint validates the transition, updates the status, records an audit event, and then propagates to active connections. 

// api/src/routes/tokens.ts
router.patch('/tokens/:id', authenticate, async (req, res) => {
  const { id } = req.params;
  const { status } = req.body;
  const userId = req.user.id;

  if (!['active', 'paused', 'revoked'].includes(status)) {
    return res.status(400).json({ error: 'Invalid status' });
  }

  const client = await pool.connect();
  try {
    await client.query('BEGIN');

    // Fetch current token (owned by this user)
    const { rows: tokenRows } = await client.query(
      'SELECT * FROM tokens WHERE id = $1 AND user_id = $2 FOR UPDATE',
      [id, userId]
    );

    if (tokenRows.length === 0) {
      await client.query('ROLLBACK');
      return res.status(404).json({ error: 'Token not found' });
    }

    const token = tokenRows[0];
    const currentStatus = token.status as TokenStatus;

    // Validate transition
    if (!VALID_TRANSITIONS[currentStatus].includes(status)) {
      await client.query('ROLLBACK');
      return res.status(400).json({
        error: `Cannot transition from '${currentStatus}' to '${status}'`
      });
    }

    // Update status
    await client.query(
      'UPDATE tokens SET status = $1, updated_at = NOW() WHERE id = $2',
      [status, id]
    );

    // Record audit event
    await client.query(
      `INSERT INTO revocation_events (token_id, previous_status, new_status, created_at)
       VALUES ($1, $2, $3, NOW())`,
      [id, currentStatus, status]
    );

    await client.query('COMMIT');

    // Propagate to active connections (after commit — don't hold the transaction)
    if (status === 'revoked' || status === 'paused') {
      await propagateStatusChange(parseInt(id), status);
    }

    res.json({ token: { id, status, previous_status: currentStatus } });
  } catch (err) {
    await client.query('ROLLBACK');
    throw err;
  } finally {
    client.release();
  }
});

Propagation to Active WebSocket Connections

When a token is revoked or paused, every active WebSocket connection for that token's conversations must be notified and disconnected. 

// api/src/engine/propagate.ts
import { getSocketsByTokenId } from '../ws/registry';
import { endCallByTokenId } from '../signalling/calls';

export async function propagateStatusChange(
  tokenId: number,
  newStatus: 'paused' | 'revoked'
): Promise<void> {
  // 1. Find all active WebSocket connections for this token
  const sockets = getSocketsByTokenId(tokenId);

  const message = JSON.stringify({
    type: 'token_status_changed',
    status: newStatus,
    reason: newStatus === 'revoked'
      ? 'This token has been permanently revoked. Connection closed.'
      : 'This token has been paused. Connection closed temporarily.'
  });

  // 2. Notify each connected holder, then close
  for (const ws of sockets) {
    ws.send(message);
    ws.close(1000, `Token ${newStatus}`);
  }

  // 3. End any active calls through signalling
  await endCallByTokenId(tokenId, newStatus);

  // 4. Clean up the registry
  removeTokenFromRegistry(tokenId);
}

The Socket Registry

To propagate in real-time, we need a registry mapping token IDs to their active WebSocket connections. 

// api/src/ws/registry.ts
import { WebSocket } from 'ws';

// Maps tokenId -> Set of active WebSocket connections
const tokenSockets = new Map<number, Set<WebSocket>>();

export function registerSocket(tokenId: number, ws: WebSocket): void {
  if (!tokenSockets.has(tokenId)) {
    tokenSockets.set(tokenId, new Set());
  }
  tokenSockets.get(tokenId)!.add(ws);

  // Clean up on disconnect
  ws.on('close', () => {
    const sockets = tokenSockets.get(tokenId);
    if (sockets) {
      sockets.delete(ws);
      if (sockets.size === 0) {
        tokenSockets.delete(tokenId);
      }
    }
  });
}

export function getSocketsByTokenId(tokenId: number): Set<WebSocket> {
  return tokenSockets.get(tokenId) || new Set();
}

export function removeTokenFromRegistry(tokenId: number): void {
  tokenSockets.delete(tokenId);
}

Ending Active Calls

Voice/video calls use WebRTC. The signalling server must send a hangup signal to both peers when a token is revoked. 

// api/src/signalling/calls.ts
import { getActiveCallByTokenId } from './callRegistry';

export async function endCallByTokenId(
  tokenId: number,
  reason: 'paused' | 'revoked'
): Promise<void> {
  const activeCall = getActiveCallByTokenId(tokenId);
  if (!activeCall) return;

  // Send hangup signal to both peers
  const hangupMessage = JSON.stringify({
    type: 'call_ended',
    reason: `Token ${reason} — call terminated`,
    initiatedBy: 'system'
  });

  if (activeCall.callerSocket?.readyState === WebSocket.OPEN) {
    activeCall.callerSocket.send(hangupMessage);
  }
  if (activeCall.receiverSocket?.readyState === WebSocket.OPEN) {
    activeCall.receiverSocket.send(hangupMessage);
  }

  // Record call end in database
  await pool.query(
    `UPDATE calls SET ended_at = NOW(), end_reason = $1
     WHERE id = $2 AND ended_at IS NULL`,
    [`token_${reason}`, activeCall.id]
  );

  // Remove from active call registry
  removeActiveCall(activeCall.id);
}

Pause vs. Revoke — The Key Differences

// Comparison table as code comments:
//
// | Aspect              | Pause                    | Revoke                     |
// |---------------------|--------------------------|----------------------------|
// | Reversible?         | Yes (resume to active)   | No (permanent)             |
// | Active connections  | Dropped immediately      | Dropped immediately        |
// | New redemptions     | Blocked                  | Blocked                    |
// | New messages        | Blocked                  | Blocked                    |
// | Conversation data   | Retained                 | Retained (for audit)       |
// | Token visible in UI | Yes (with paused badge)  | Yes (with revoked badge)   |
// | Can reuse code?     | No (code stays reserved) | No (code stays reserved)   |
// | User intent         | "Not now, maybe later"   | "Never again"              |

The Audit Trail

Every status change is recorded. This gives the user a full history and supports any future dispute resolution. 

-- Migration: create revocation_events table
CREATE TABLE revocation_events (
  id            SERIAL PRIMARY KEY,
  token_id      INTEGER NOT NULL REFERENCES tokens(id),
  previous_status VARCHAR(10) NOT NULL,
  new_status    VARCHAR(10) NOT NULL,
  created_at    TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  metadata      JSONB DEFAULT '{}'
);

CREATE INDEX idx_revocation_events_token ON revocation_events(token_id);

-- Query: get full lifecycle of a token
SELECT
  re.previous_status,
  re.new_status,
  re.created_at,
  re.metadata
FROM revocation_events re
WHERE re.token_id = $1
ORDER BY re.created_at ASC;

Preventing Actions on Non-Active Tokens

The rules engine (lesson 2) handles per-action checks, but we also need a gate at the top of every handler: if the token is not active, reject immediately without even evaluating rules. 

// api/src/middleware/tokenActive.ts
export async function requireActiveToken(tokenId: number): Promise<void> {
  const { rows } = await pool.query(
    'SELECT status FROM tokens WHERE id = $1',
    [tokenId]
  );

  if (rows.length === 0) {
    throw new TokenError('Token not found', 404);
  }

  if (rows[0].status === 'paused') {
    throw new TokenError('Token is currently paused', 403);
  }

  if (rows[0].status === 'revoked') {
    throw new TokenError('Token has been permanently revoked', 403);
  }
}

// Usage in a handler:
async function handleIncomingMessage(tokenId, content) {
  await requireActiveToken(tokenId);        // Gate check
  const ruleCheck = await evaluateRules(tokenId, 'message');  // Rule check
  if (!ruleCheck.allowed) throw new RuleDeniedError(ruleCheck.reason);
  // ... proceed with message
}
