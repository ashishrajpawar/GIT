API Consumption

4 lessons Phase 3 — Client Meets Server
Module goal

Connect the mobile app and web page to the API you built. After this module, your app fetches real data from your server with a typed API client, handles loading/error/empty states gracefully, and supports infinite scroll pagination.

Lessons

  1. fetch & HTTP Fundamentals — requests, responses, status codes, headers, base URL
  2. API Client Layer — typed shared client, endpoint functions, error handling
  3. Loading, Empty & Error States — useApi hook, retry, AbortController, skeleton screens
  4. Pagination & Infinite Scroll — cursor pagination, FlatList onEndReached, inverted for chat

After this module

You'll have:

  • A typed API client in shared/ used by both app and web
  • Reusable hooks: useApi and usePaginatedApi
  • Loading spinners, error states with retry, and helpful empty states
  • Infinite scroll on the token list
  • Inverted pagination for message history
  • Request cancellation on navigation
