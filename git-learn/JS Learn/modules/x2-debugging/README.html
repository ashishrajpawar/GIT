Debugging

2 lessons Phase 1 — Foundation
Module goal

Learn to find and fix bugs systematically — on both the mobile client and the Node.js backend. These skills multiply everything else you learn: debugging fast means learning fast.

Lessons

  1. React Native Debugging — DevTools, console methods, network inspection, breakpoints, common patterns
  2. Node.js Debugging — --inspect, VS Code debugger, structured logging, stack traces, async errors

After this module

You'll be able to:

  • Inspect component state and props with React DevTools
  • See every network request your app makes
  • Set breakpoints and step through code in both the client and server
  • Read stack traces and identify the actual source of an error
  • Write structured logs that are useful in production
