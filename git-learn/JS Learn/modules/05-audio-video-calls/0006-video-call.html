Audio & Video Calls · Lesson 6

1:1 Video Call

Camera streams · RTCView · PiP layout · Flip camera · Video mute ~50 min Hands-on
Why this matters for your WhatsApp clone

You already proved voice calling works in Lesson 5. Now you'll add camera video — the remote person's face fills the screen while your own camera appears in a small draggable box in the corner, exactly like WhatsApp video calls. You'll also add the ability to flip between front and back cameras and turn video off while keeping audio running. This is the last piece before your app has feature parity with WhatsApp's core calling experience.

1. What changes from voice to video?

Surprisingly little. WebRTC treats audio and video the same way — they're both media tracks inside a stream. In Lesson 5 you asked for audio only:

// Voice call (Lesson 5)
const stream = await mediaDevices.getUserMedia({ audio: true, video: false });

// Video call (this lesson)
const stream = await mediaDevices.getUserMedia({
  audio: true,
  video: { facingMode: 'user' }   // 'user' = front camera, 'environment' = back
});

That one change gives you a stream with two tracks — an audio track and a video track. Add both to the peer connection, and WebRTC sends them together.

The other changes are all UI:

  • You need an <RTCView> component to display video streams
  • The remote stream fills the screen (full-screen background)
  • Your own camera shows in a small box in the corner (picture-in-picture)
  • You add a camera-flip button and a video-off toggle

2. RTCView — displaying video streams

react-native-webrtc provides a special component for rendering video:

import { RTCView } from 'react-native-webrtc';

// Display a stream's video
<RTCView
  streamURL={stream.toURL()}
  style={{ width: 300, height: 400 }}
  objectFit="cover"
  mirror={true}        // mirror the front camera (like a selfie)
  zOrder={0}           // controls stacking order (0 = behind, 1 = in front)
/>

Key props:

Prop What it does
streamURL The stream's URL string from stream.toURL()
objectFit "cover" fills the space (may crop), "contain" fits entirely (may letterbox)
mirror Flip horizontally — use for front camera so it looks natural
zOrder Stacking: 0 = behind other views, 1 = in front. Needed for PiP overlay

3. Camera permissions — Android and iOS

Video calls need both microphone AND camera access:

import { Platform, PermissionsAndroid } from 'react-native';

async function requestVideoCallPermissions() {
  if (Platform.OS === 'android') {
    const grants = await PermissionsAndroid.requestMultiple([
      PermissionsAndroid.PERMISSIONS.CAMERA,
      PermissionsAndroid.PERMISSIONS.RECORD_AUDIO,
    ]);
    const cameraOk = grants['android.permission.CAMERA'] === 'granted';
    const audioOk = grants['android.permission.RECORD_AUDIO'] === 'granted';
    return cameraOk && audioOk;
  }
  // iOS: permissions declared in Info.plist, system prompts automatically
  return true;
}

For iOS, add these to your app.json (inside expo.ios.infoPlist):

{
  "expo": {
    "ios": {
      "infoPlist": {
        "NSCameraUsageDescription": "Video calls require camera access",
        "NSMicrophoneUsageDescription": "Calls require microphone access"
      }
    }
  }
}

4. The picture-in-picture layout

WhatsApp's video call layout is simple: the remote video fills the entire screen, and your own camera is in a small box in the top-right corner. Here's the layout structure:

function VideoCallLayout({ localStreamURL, remoteStreamURL, isFrontCamera }) {
  return (
    <View style={{ flex: 1 }}>
      {/* Remote video — full screen background */}
      {remoteStreamURL ? (
        <RTCView
          streamURL={remoteStreamURL}
          style={StyleSheet.absoluteFill}
          objectFit="cover"
          zOrder={0}
        />
      ) : (
        <View style={[StyleSheet.absoluteFill, { backgroundColor: '#1a1a2e', justifyContent: 'center', alignItems: 'center' }]}>
          <Text style={{ color: '#FFF', fontSize: 18 }}>Waiting for video...</Text>
        </View>
      )}

      {/* Local video — small PiP box in top-right corner */}
      {localStreamURL && (
        <View style={pipStyles.container}>
          <RTCView
            streamURL={localStreamURL}
            style={pipStyles.video}
            objectFit="cover"
            mirror={isFrontCamera}
            zOrder={1}
          />
        </View>
      )}
    </View>
  );
}

const pipStyles = StyleSheet.create({
  container: {
    position: 'absolute',
    top: 60,
    right: 16,
    width: 120,
    height: 160,
    borderRadius: 12,
    overflow: 'hidden',
    borderWidth: 2,
    borderColor: '#FFFFFF',
    // iOS shadow
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 4 },
    shadowOpacity: 0.3,
    shadowRadius: 6,
    // Android shadow
    elevation: 8,
  },
  video: {
    flex: 1,
  },
});

Key decisions:

  • zOrder={0} on the remote view puts it behind everything else
  • zOrder={1} on the local view ensures it appears on top
  • mirror={isFrontCamera} only mirrors the front camera — when flipped to back camera, mirroring would look wrong
  • overflow: 'hidden' + borderRadius gives the PiP box rounded corners

5. Flipping the camera (front ↔ back)

WhatsApp has a flip-camera button. With react-native-webrtc, you switch cameras by stopping the current video track and getting a new one:

async function flipCamera(streamRef, pcRef, isFrontCamera, setIsFrontCamera) {
  // Get the current video track
  const currentTrack = streamRef.current.getVideoTracks()[0];
  if (!currentTrack) return;

  // Stop the old track
  currentTrack.stop();

  // Get a new stream with the other camera
  const newFacing = isFrontCamera ? 'environment' : 'user';
  const newStream = await mediaDevices.getUserMedia({
    audio: false,       // we already have the audio track running
    video: { facingMode: newFacing },
  });

  const newVideoTrack = newStream.getVideoTracks()[0];

  // Replace the track in the peer connection (keeps the same stream)
  const sender = pcRef.current.getSenders().find((s) => s.track?.kind === 'video');
  if (sender) {
    await sender.replaceTrack(newVideoTrack);
  }

  // Replace in the local stream (so RTCView updates)
  streamRef.current.removeTrack(currentTrack);
  streamRef.current.addTrack(newVideoTrack);

  setIsFrontCamera(!isFrontCamera);
}

Why replaceTrack? It swaps the video source without renegotiating the WebRTC connection. No new offer/answer, no interruption — the remote side just sees the camera angle change smoothly.

6. Toggling video off (audio-only mode)

Sometimes during a video call you want to turn off your camera but keep talking. Same pattern as muting audio — just disable the video track:

function toggleVideo(streamRef, isVideoOff, setIsVideoOff) {
  const videoTrack = streamRef.current?.getVideoTracks()[0];
  if (videoTrack) {
    videoTrack.enabled = isVideoOff;   // if currently off, re-enable
    setIsVideoOff(!isVideoOff);
  }
}

When your video is off, the remote side sees a black frame (or you can show an avatar placeholder). Your local PiP should also show an avatar or "Camera off" text:

{isVideoOff ? (
  <View style={[pipStyles.container, { backgroundColor: '#333', justifyContent: 'center', alignItems: 'center' }]}>
    <Text style={{ color: '#FFF', fontSize: 12 }}>Camera off</Text>
  </View>
) : (
  <View style={pipStyles.container}>
    <RTCView streamURL={localStreamURL} style={pipStyles.video} objectFit="cover" mirror={isFrontCamera} zOrder={1} />
  </View>
)}

7. Differences from the voice call code

Here's a summary of what changes from Lesson 5:

Area Voice Call (Lesson 5) Video Call (This Lesson)
getUserMedia { audio: true, video: false } { audio: true, video: { facingMode: 'user' } }
Permissions RECORD_AUDIO only RECORD_AUDIO + CAMERA
Display Avatar + name + timer Full-screen remote video + PiP local
Extra buttons Mute, Speaker, End Mute, Speaker, End + Flip Camera + Video Off
Remote stream Audio plays automatically Audio plays + video renders in RTCView
InCallManager start({ media: 'audio' }) start({ media: 'video' }) — routes audio to speaker by default

8. Storing the remote stream

In Lesson 5, you didn't need to render the remote audio — the phone plays it automatically. For video, you need to capture the remote stream and pass its URL to RTCView:

const [remoteStreamURL, setRemoteStreamURL] = useState(null);

// Inside your peer connection setup:
pc.ontrack = (event) => {
  // event.streams[0] contains the remote media stream
  const remoteStream = event.streams[0];
  setRemoteStreamURL(remoteStream.toURL());

  // Start InCallManager with video mode (uses speaker by default)
  InCallManager.start({ media: 'video' });
  InCallManager.setForceSpeakerphoneOn(true);
  setCallState('active');
};

Why media: 'video'? It tells InCallManager to route audio through the speaker (not earpiece) by default — you hold video calls at arm's length, not against your ear. The proximity sensor is still active so if you do hold it to your ear, it switches to earpiece.

9. The Firestore call document — type field

In your calls collection document, you now write type: 'video' instead of type: 'audio'. The callee uses this to decide whether to request camera permissions and show the video UI:

// Caller writes:
await setDoc(callRef, {
  callerId: user.uid,
  calleeId: contactUid,
  callerName: myName,
  type: 'video',            // ← changed from 'audio'
  status: 'ringing',
  offer: { type: offer.type, sdp: offer.sdp },
  answer: null,
  createdAt: serverTimestamp(),
});

// Callee reads:
onSnapshot(q, (snap) => {
  snap.docChanges().forEach((change) => {
    if (change.type === 'added') {
      const data = change.doc.data();
      if (data.type === 'video') {
        // Show video incoming call screen (with camera icon)
      } else {
        // Show voice incoming call screen
      }
    }
  });
});

10. Full runnable App.js — 1:1 Video Call

Copy this entire file and replace your App.js. It builds on the voice call from Lesson 5, adding: camera video, full-screen remote view, PiP local view, flip camera, and video toggle. Test with two phones.

// App.js — Full runnable example: 1:1 Video Call
import React, { useState, useEffect, useRef } from 'react';
import {
  View, Text, TextInput, Pressable, StyleSheet, Alert,
  Platform, PermissionsAndroid, Dimensions
} from 'react-native';
import {
  RTCPeerConnection, RTCSessionDescription, RTCIceCandidate,
  mediaDevices, RTCView
} from 'react-native-webrtc';
import InCallManager from 'react-native-incall-manager';

import { initializeApp } from 'firebase/app';
import { getAuth, onAuthStateChanged } from 'firebase/auth';
import {
  getFirestore, doc, setDoc, getDoc, updateDoc, addDoc,
  collection, query, where, onSnapshot, serverTimestamp
} from 'firebase/firestore';

// ─── Firebase config ────────────────────────────────────────────────
const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',
  authDomain: 'YOUR_PROJECT.firebaseapp.com',
  projectId: 'YOUR_PROJECT_ID',
  storageBucket: 'YOUR_PROJECT.appspot.com',
  messagingSenderId: '123456789',
  appId: '1:123456789:web:abcdef',
};
const app = initializeApp(firebaseConfig);
const auth = getAuth(app);
const db = getFirestore(app);

const ICE_SERVERS = {
  iceServers: [
    { urls: 'stun:stun.l.google.com:19302' },
    { urls: 'stun:stun1.l.google.com:19302' },
  ],
};

const { width: SCREEN_WIDTH, height: SCREEN_HEIGHT } = Dimensions.get('window');

// ─── Permissions ────────────────────────────────────────────────────
async function requestVideoPermissions() {
  if (Platform.OS === 'android') {
    const grants = await PermissionsAndroid.requestMultiple([
      PermissionsAndroid.PERMISSIONS.CAMERA,
      PermissionsAndroid.PERMISSIONS.RECORD_AUDIO,
    ]);
    const cameraOk = grants['android.permission.CAMERA'] === 'granted';
    const audioOk = grants['android.permission.RECORD_AUDIO'] === 'granted';
    return cameraOk && audioOk;
  }
  return true;

// ─── Call Timer Hook ────────────────────────────────────────────────
function useCallTimer(isActive) {
  const [seconds, setSeconds] = useState(0);
  useEffect(() => {
    if (!isActive) { setSeconds(0); return; }
    const i = setInterval(() => setSeconds((s) => s + 1), 1000);
    return () => clearInterval(i);
  }, [isActive]);
  const m = Math.floor(seconds / 60);
  const s = seconds % 60;
  return `${m.toString().padStart(2, '0')}:${s.toString().padStart(2, '0')}`;
}

// ─── Main App ───────────────────────────────────────────────────────
export default function App() {
  const [user, setUser] = useState(null);
  const [screen, setScreen] = useState('home');
  const [calleeUid, setCalleeUid] = useState('');
  const [contactName, setContactName] = useState('');
  const [callState, setCallState] = useState('idle');
  const [isMuted, setIsMuted] = useState(false);
  const [isSpeaker, setIsSpeaker] = useState(true);
  const [isVideoOff, setIsVideoOff] = useState(false);
  const [isFrontCamera, setIsFrontCamera] = useState(true);
  const [localStreamURL, setLocalStreamURL] = useState(null);
  const [remoteStreamURL, setRemoteStreamURL] = useState(null);
  const [incomingCall, setIncomingCall] = useState(null);

  const pcRef = useRef(null);
  const streamRef = useRef(null);
  const callIdRef = useRef(null);
  const unsubsRef = useRef([]);

  const timer = useCallTimer(callState === 'active');

  useEffect(() => {
    const unsub = onAuthStateChanged(auth, (u) => setUser(u));
    return unsub;
  }, []);

  // Listen for incoming calls
  useEffect(() => {
    if (!user) return;
    const q = query(
      collection(db, 'calls'),
      where('calleeId', '==', user.uid),
      where('status', '==', 'ringing')
    );
    const unsub = onSnapshot(q, (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') {
          const data = change.doc.data();
          setIncomingCall({ callId: change.doc.id, ...data });
          setContactName(data.callerName || 'Unknown');
          setScreen('incoming');
        }
      });
    });
    return unsub;
  }, [user]);

  // ── START VIDEO CALL ──
  async function handleStartCall() {
    if (!calleeUid.trim()) { Alert.alert('Error', 'Enter the other user\'s UID'); return; }
    const ok = await requestVideoPermissions();
    if (!ok) { Alert.alert('Permission denied', 'Camera and microphone access are required'); return; }

    setScreen('call');
    setCallState('calling');

    const pc = new RTCPeerConnection(ICE_SERVERS);
    pcRef.current = pc;

    // Get audio + video stream
    const stream = await mediaDevices.getUserMedia({
      audio: true,
      video: { facingMode: 'user' },
    });
    streamRef.current = stream;
    setLocalStreamURL(stream.toURL());
    setIsFrontCamera(true);

    // Add all tracks to peer connection
    stream.getTracks().forEach((track) => pc.addTrack(track, stream));

    // When remote stream arrives
    pc.ontrack = (event) => {
      if (event.streams && event.streams[0]) {
        setRemoteStreamURL(event.streams[0].toURL());
        InCallManager.start({ media: 'video' });
        InCallManager.setForceSpeakerphoneOn(true);
        setCallState('active');
      }
    };

    pc.oniceconnectionstatechange = () => {
      if (pc.iceConnectionState === 'connected') {
        InCallManager.start({ media: 'video' });
        setCallState('active');
      }
      if (pc.iceConnectionState === 'failed' || pc.iceConnectionState === 'closed') {
        handleEndCall();
      }
    };

    // Create Firestore call document
    const callRef = doc(collection(db, 'calls'));
    callIdRef.current = callRef.id;

    pc.onicecandidate = (e) => {
      if (e.candidate) {
        addDoc(collection(db, 'calls', callRef.id, 'callerCandidates'), e.candidate.toJSON());
      }
    };

    const offer = await pc.createOffer();
    await pc.setLocalDescription(offer);

    const myName = user.displayName || user.email || 'Caller';
    setContactName(calleeUid.substring(0, 12));

    // Try to get callee's display name
    const calleeSnap = await getDoc(doc(db, 'users', calleeUid.trim()));
    if (calleeSnap.exists()) setContactName(calleeSnap.data().displayName || calleeUid);

    await setDoc(callRef, {
      callerId: user.uid,
      calleeId: calleeUid.trim(),
      callerName: myName,
      type: 'video',
      status: 'ringing',
      offer: { type: offer.type, sdp: offer.sdp },
      answer: null,
      createdAt: serverTimestamp(),
    });

    // Listen for answer
    const unsubCall = onSnapshot(doc(db, 'calls', callRef.id), (snap) => {
      const data = snap.data();
      if (!data) return;
      if (data.answer && !pc.remoteDescription) {
        pc.setRemoteDescription(new RTCSessionDescription(data.answer));
      }
      if (data.status === 'ended' || data.status === 'declined') handleEndCall();
    });

    // Listen for callee ICE candidates
    const unsubCands = onSnapshot(collection(db, 'calls', callRef.id, 'calleeCandidates'), (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') {
          pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
        }
      });
    });

    unsubsRef.current = [unsubCall, unsubCands];

    // Timeout after 30 seconds of no answer
    setTimeout(async () => {
      const snap = await getDoc(doc(db, 'calls', callRef.id));
      if (snap.exists() && snap.data().status === 'ringing') {
        await updateDoc(doc(db, 'calls', callRef.id), { status: 'missed' });
        handleEndCall();
      }
    }, 30000);
  }

  // ── ANSWER CALL ──
  async function handleAnswerCall() {
    if (!incomingCall) return;
    const ok = await requestVideoPermissions();
    if (!ok) { Alert.alert('Permission denied', 'Camera and microphone access are required'); return; }

    setScreen('call');
    setCallState('connecting');

    const { callId, offer } = incomingCall;
    callIdRef.current = callId;

    const pc = new RTCPeerConnection(ICE_SERVERS);
    pcRef.current = pc;

    // Get audio + video
    const isVideo = incomingCall.type === 'video';
    const stream = await mediaDevices.getUserMedia({
      audio: true,
      video: isVideo ? { facingMode: 'user' } : false,
    });
    streamRef.current = stream;
    if (isVideo) setLocalStreamURL(stream.toURL());
    setIsFrontCamera(true);

    stream.getTracks().forEach((track) => pc.addTrack(track, stream));

    // When remote stream arrives
    pc.ontrack = (event) => {
      if (event.streams && event.streams[0]) {
        setRemoteStreamURL(event.streams[0].toURL());
        InCallManager.start({ media: 'video' });
        InCallManager.setForceSpeakerphoneOn(true);
        setCallState('active');
      }
    };

    pc.oniceconnectionstatechange = () => {
      if (pc.iceConnectionState === 'connected') {
        InCallManager.start({ media: 'video' });
        setCallState('active');
      }
      if (pc.iceConnectionState === 'failed') handleEndCall();
    };

    pc.onicecandidate = (e) => {
      if (e.candidate) {
        addDoc(collection(db, 'calls', callId, 'calleeCandidates'), e.candidate.toJSON());
      }
    };

    await pc.setRemoteDescription(new RTCSessionDescription(offer));
    const answer = await pc.createAnswer();
    await pc.setLocalDescription(answer);

    await updateDoc(doc(db, 'calls', callId), {
      answer: { type: answer.type, sdp: answer.sdp },
      status: 'active',
    });

    // Listen for caller ICE candidates
    const unsubCands = onSnapshot(collection(db, 'calls', callId, 'callerCandidates'), (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') {
          pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
        }
      });
    });

    // Listen for call status changes
    const unsubCall = onSnapshot(doc(db, 'calls', callId), (snap) => {
      const data = snap.data();
      if (data && data.status === 'ended') handleEndCall();
    });

    unsubsRef.current = [unsubCands, unsubCall];
    setIncomingCall(null);
  }

  // ── DECLINE ──
  async function handleDecline() {
    if (incomingCall) {
      await updateDoc(doc(db, 'calls', incomingCall.callId), { status: 'declined' });
    }
    setIncomingCall(null);
    setScreen('home');
    setCallState('idle');
  }

  // ── END CALL ──
  async function handleEndCall() {
    InCallManager.stop();
    pcRef.current?.close();
    pcRef.current = null;
    streamRef.current?.getTracks().forEach((t) => t.stop());
    streamRef.current = null;
    unsubsRef.current.forEach((u) => u());
    unsubsRef.current = [];

    if (callIdRef.current) {
      try { await updateDoc(doc(db, 'calls', callIdRef.current), { status: 'ended' }); } catch (e) {}
    }
    callIdRef.current = null;
    setCallState('idle');
    setIsMuted(false);
    setIsSpeaker(true);
    setIsVideoOff(false);
    setIsFrontCamera(true);
    setLocalStreamURL(null);
    setRemoteStreamURL(null);
    setScreen('home');
    setIncomingCall(null);
  }

  // ── MUTE AUDIO ──
  function handleToggleMute() {
    const track = streamRef.current?.getAudioTracks()[0];
    if (track) { track.enabled = isMuted; setIsMuted(!isMuted); }
  }

  // ── TOGGLE SPEAKER ──
  function handleToggleSpeaker() {
    InCallManager.setForceSpeakerphoneOn(!isSpeaker);
    setIsSpeaker(!isSpeaker);
  }

  // ── TOGGLE VIDEO ──
  function handleToggleVideo() {
    const track = streamRef.current?.getVideoTracks()[0];
    if (track) {
      track.enabled = isVideoOff;   // if off, re-enable
      setIsVideoOff(!isVideoOff);
    }
  }

  // ── FLIP CAMERA ──
  async function handleFlipCamera() {
    const currentTrack = streamRef.current?.getVideoTracks()[0];
    if (!currentTrack) return;

    currentTrack.stop();

    const newFacing = isFrontCamera ? 'environment' : 'user';
    const newStream = await mediaDevices.getUserMedia({
      audio: false,
      video: { facingMode: newFacing },
    });

    const sender = pcRef.current?.getSenders().find((s) => s.track?.kind === 'video');

    // Replace in local stream
    streamRef.current.removeTrack(currentTrack);
    streamRef.current.addTrack(newVideoTrack);
    setLocalStreamURL(streamRef.current.toURL());
    setIsFrontCamera(!isFrontCamera);
  }

    return (
      <View style={[styles.container, styles.center]}>
        <Text style={styles.infoText}>Please log in (Module 3 Lesson 2)</Text>
      </View>
    );
  }

  // HOME SCREEN
  if (screen === 'home') {
    return (
      <View style={styles.container}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>Video Call</Text>
          <Text style={styles.headerSub}>UID: {user.uid.substring(0, 16)}...</Text>
        </View>
        <View style={styles.homeContent}>
          <Text style={styles.label}>Call someone (paste their UID):</Text>
          <TextInput
            style={styles.input}
            value={calleeUid}
            onChangeText={setCalleeUid}
            placeholder="Other user's UID"

            <Text style={styles.callButtonText}>🎥 Video Call</Text>

        </View>
      </View>

  if (screen === 'incoming') {
    return (
      <View style={styles.callScreen}>
        <View style={styles.callInfo}>
          <View style={styles.bigAvatar}>
            <Text style={styles.bigAvatarText}>{contactName.charAt(0).toUpperCase()}</Text>
          </View>
          <Text style={styles.callName}>{contactName}</Text>
          <Text style={styles.callStatus}>
            {incomingCall?.type === 'video' ? 'Incoming video call...' : 'Incoming voice call...'}
          </Text>
        </View>

            <Text style={styles.btnIcon}>🎥</Text>
            <Text style={styles.btnLabel}>Accept</Text>
          </Pressable>
        </View>
      </View>

  }

  // ACTIVE / CALLING SCREEN — VIDEO
  return (
    <View style={{ flex: 1 }}>
      {/* Remote video — full screen */}
      {remoteStreamURL ? (
        <RTCView
          streamURL={remoteStreamURL}
          style={StyleSheet.absoluteFill}
          objectFit="cover"

        />
      ) : (
        <View style={[StyleSheet.absoluteFill, styles.callScreen]}>
          <View style={styles.callInfo}>
            <View style={styles.bigAvatar}>
              <Text style={styles.bigAvatarText}>{contactName.charAt(0).toUpperCase()}</Text>
            </View>
            <Text style={styles.callName}>{contactName}</Text>
            <Text style={styles.callStatus}>
              {callState === 'calling' && 'Calling...'}
              {callState === 'connecting' && 'Connecting...'}
            </Text>
          </View>
        </View>
      )}

      {/* Local video — PiP (top-right) */}
      {localStreamURL && !isVideoOff ? (
        <View style={styles.pip}>
          <RTCView
            streamURL={localStreamURL}
            style={{ flex: 1 }}
            objectFit="cover"
            mirror={isFrontCamera}
            zOrder={1}
          />
        </View>
      ) : (
        <View style={[styles.pip, styles.pipOff]}>
          <Text style={{ color: '#FFF', fontSize: 11 }}>Camera off</Text>
        </View>
      )}

      {/* Timer overlay (when connected) */}
      {callState === 'active' && (
        <View style={styles.timerOverlay}>
          <Text style={styles.timerText}>{contactName}</Text>
          <Text style={styles.timerSub}>{timer}</Text>
        </View>
      )}

      {/* Control buttons — bottom */}
      <View style={styles.controlBar}>
        <Pressable style={[styles.ctrlBtn, isVideoOff && styles.ctrlActive]} onPress={handleToggleVideo}>
          <Text style={styles.ctrlIcon}>{isVideoOff ? '📷' : '🎥'}</Text>
          <Text style={styles.ctrlLabel}>{isVideoOff ? 'Video On' : 'Video Off'}</Text>
        </Pressable>

        <Pressable style={[styles.ctrlBtn, isMuted && styles.ctrlActive]} onPress={handleToggleMute}>
          <Text style={styles.ctrlIcon}>{isMuted ? '🔇' : '🎤'}</Text>
          <Text style={styles.ctrlLabel}>{isMuted ? 'Unmute' : 'Mute'}</Text>
        </Pressable>

        <Pressable style={styles.ctrlBtn} onPress={handleFlipCamera}>
          <Text style={styles.ctrlIcon}>🔄</Text>
          <Text style={styles.ctrlLabel}>Flip</Text>
        </Pressable>

        <Pressable style={[styles.ctrlBtn, !isSpeaker && styles.ctrlActive]} onPress={handleToggleSpeaker}>
          <Text style={styles.ctrlIcon}>{isSpeaker ? '🔊' : '🔈'}</Text>
          <Text style={styles.ctrlLabel}>{isSpeaker ? 'Speaker' : 'Earpiece'}</Text>
        </Pressable>

        <Pressable style={styles.endCallBtn} onPress={handleEndCall}>
          <Text style={styles.ctrlIcon}>📵</Text>
          <Text style={styles.ctrlLabel}>End</Text>
        </Pressable>
      </View>
    </View>
  );
}

11. Testing your video call

  1. Run eas build --platform android --profile development (include camera permission)
  2. Install the dev build on two phones
  3. Log in as different Firebase users on each device
  4. Phone A: paste Phone B's UID and tap "Video Call"
  5. Phone B: sees incoming video call screen → tap "Accept"
  6. Both phones: remote face fills screen, your own face in PiP corner
  7. Tap Flip — camera switches to show what's in front of you
  8. Tap Video Off — your PiP shows "Camera off", remote side sees black
  9. Tap Mute — other side can't hear you
  10. Tap End — both phones return to home screen
You just built a full video call!

That's the exact same technology WhatsApp, Google Meet, and FaceTime use — peer-to-peer video streaming with WebRTC. No monthly fees, no SDK limits, works on both Android and iOS. Next up: handling incoming calls when the app is closed — push notifications that wake the phone and show a ringing screen.
