Incoming Calls on Android

FCM push · Foreground service · Full-screen intent · Heads-up notification ~55 min Hands-on
Why this matters for your WhatsApp clone

Right now your call only works if both users have the app open. But real WhatsApp calls wake the phone from sleep, show a full-screen ringing UI even when the phone is locked, and keep ringing until the user answers or it times out. On Android this requires Firebase Cloud Messaging (FCM) to push a signal to the callee's phone, plus a foreground service that displays the incoming call notification. This lesson wires all of that together so your app behaves like a real phone call — even when it's completely closed.

1. The problem: app is closed

In Lessons 5–6, the callee listens for incoming calls with a Firestore onSnapshot query. But that listener only runs while the app is in the foreground. When the app is killed or the phone is asleep, Firestore listeners stop — nobody is listening.

The solution on Android:

  1. Caller writes the call document to Firestore (same as before)
  2. A Cloud Function (server-side) detects the new call and sends an FCM data message to the callee's device
  3. The callee's device receives the FCM message even while the app is closed
  4. Your app starts a foreground service that shows a full-screen notification with Accept/Decline buttons
  5. When the user taps Accept, the app opens and connects the WebRTC call
Data messages vs Notification messages

FCM has two types: notification messages (Firebase shows them automatically, you can't customise) and data messages (silent, your code handles everything). For calls you MUST use data messages — you need full control to show a ringing UI, play a ringtone, and handle Accept/Decline.

2. Storing the FCM token

Each device has a unique FCM token. When a user logs in, save their token to Firestore so you can send them push messages:

// Install
npx expo install @react-native-firebase/app @react-native-firebase/messaging

// Rebuild (native code)
eas build --platform android --profile development
import messaging from '@react-native-firebase/messaging';
import { doc, updateDoc } from 'firebase/firestore';

async function saveFCMToken(uid) {
  // Request permission (Android 13+ requires POST_NOTIFICATIONS permission)
  const authStatus = await messaging().requestPermission();
  const enabled =
    authStatus === messaging.AuthorizationStatus.AUTHORIZED ||
    authStatus === messaging.AuthorizationStatus.PROVISIONAL;

  if (!enabled) {
    console.warn('Notification permission not granted');
    return;
  }

  // Get the device's FCM token
  const token = await messaging().getToken();
  console.log('FCM Token:', token);

  // Save it to the user's Firestore document
  await updateDoc(doc(db, 'users', uid), {
    fcmToken: token,
    platform: 'android',
  });

  // Listen for token refresh (happens occasionally)
  messaging().onTokenRefresh(async (newToken) => {
    await updateDoc(doc(db, 'users', uid), { fcmToken: newToken });
  });
}

Call saveFCMToken(user.uid) right after the user logs in (Module 3 Lesson 2).

3. The Cloud Function — sending the push

When a new call document is created in Firestore, a Cloud Function triggers and sends an FCM data message to the callee:

// functions/index.js — deployed to Firebase Cloud Functions
const functions = require('firebase-functions');
const admin = require('firebase-admin');
admin.initializeApp();

exports.onCallCreated = functions.firestore
  .document('calls/{callId}')
  .onCreate(async (snap, context) => {
    const callData = snap.data();
    const callId = context.params.callId;

    // Only send push for new calls that are ringing
    if (callData.status !== 'ringing') return null;

    // Get the callee's FCM token
    const calleeDoc = await admin.firestore()
      .collection('users')
      .doc(callData.calleeId)
      .get();

    if (!calleeDoc.exists) return null;
    const calleeToken = calleeDoc.data().fcmToken;
    if (!calleeToken) return null;

    // Send a DATA message (not a notification message)
    const message = {
      token: calleeToken,
      data: {
        type: 'incoming_call',
        callId: callId,
        callerName: callData.callerName || 'Unknown',
        callerId: callData.callerId,
        callType: callData.type,   // 'audio' or 'video'
      },
      android: {
        priority: 'high',   // Wake the device immediately
        ttl: 30000,         // Expire after 30 seconds (call timeout)
      },
    };

    try {
      await admin.messaging().send(message);
      console.log('Push sent to', callData.calleeId);
    } catch (error) {
      console.error('Push failed:', error);
    }

    return null;
  });

4. Receiving the FCM message in the app

On Android, FCM data messages are delivered to your app even when it's in the background. You handle them with setBackgroundMessageHandler:

// index.js (the app entry point, NOT App.js)
import messaging from '@react-native-firebase/messaging';
import notifee, { AndroidImportance, AndroidCategory } from '@notifee/react-native';

// This runs even when the app is killed
messaging().setBackgroundMessageHandler(async (remoteMessage) => {
  const data = remoteMessage.data;

  if (data.type === 'incoming_call') {
    await showIncomingCallNotification(data);
  }
});

async function showIncomingCallNotification(data) {
  // Create a notification channel for calls (high importance = heads-up + sound)
  const channelId = await notifee.createChannel({
    id: 'incoming_calls',
    name: 'Incoming Calls',
    importance: AndroidImportance.HIGH,
    sound: 'ringtone',        // Custom sound file in android/app/src/main/res/raw/
    vibration: true,
    vibrationPattern: [300, 500],
  });

  // Display a full-screen notification
  await notifee.displayNotification({
    title: `${data.callerName} is calling...`,
    body: data.callType === 'video' ? 'Incoming video call' : 'Incoming voice call',
    android: {
      channelId: channelId,
      category: AndroidCategory.CALL,
      importance: AndroidImportance.HIGH,
      fullScreenAction: {
        id: 'default',       // Opens the app in full-screen (even on lock screen)
      },
      actions: [
        {
          title: 'Decline',
          pressAction: { id: 'decline' },
        },
        {
          title: 'Accept',
          pressAction: { id: 'accept', launchActivity: 'default' },
        },
      ],
      ongoing: true,          // Can't be swiped away
      autoCancel: false,
      pressAction: { id: 'default', launchActivity: 'default' },
    },
    data: {
      callId: data.callId,
      callerName: data.callerName,
      callerId: data.callerId,
      callType: data.callType,
    },
  });
}

5. Installing Notifee for rich notifications

@notifee/react-native gives you full control over Android notifications — custom buttons, full-screen intents, sounds, and foreground services. It's free and maintained by the React Native Firebase team:

# Install
npx expo install @notifee/react-native

# Rebuild
eas build --platform android --profile development

Why not just use expo-notifications? Expo's library is great for simple notifications, but incoming calls need:

  • Full-screen intent — shows the call UI on the lock screen
  • Ongoing notification — can't be swiped away while ringing
  • Custom action buttons — Accept and Decline directly in the notification
  • Foreground service — keeps the ringtone playing
  • Category: CALL — Android treats it as a phone call (special priority)

Notifee handles all of these. expo-notifications does not.

6. Handling Accept/Decline button presses

When the user taps a notification action button, Notifee fires an event. Handle it to either accept or decline the call:

import notifee, { EventType } from '@notifee/react-native';

// Handle notification action presses (both foreground and background)
notifee.onBackgroundEvent(async ({ type, detail }) => {
  if (type === EventType.ACTION_PRESS) {
    const { pressAction, notification } = detail;
    const callId = notification?.data?.callId;

    if (pressAction.id === 'decline' && callId) {
      // Update Firestore to decline
      const { getFirestore, doc, updateDoc } = require('firebase/firestore');
      const db = getFirestore();
      await updateDoc(doc(db, 'calls', callId), { status: 'declined' });
      // Cancel the notification
      await notifee.cancelNotification(notification.id);
    }

    if (pressAction.id === 'accept' && callId) {
      // Cancel the notification — the app will open to the call screen
      await notifee.cancelNotification(notification.id);
      // The app will pick up the call via the Firestore listener
    }
  }

  if (type === EventType.DISMISSED) {
    // User swiped away (if ongoing is false)
    // Treat as decline
  }
});

// Foreground event handler (inside your App component)
useEffect(() => {
  const unsubscribe = notifee.onForegroundEvent(({ type, detail }) => {
    if (type === EventType.ACTION_PRESS) {
      const { pressAction, notification } = detail;
      if (pressAction.id === 'accept') {
        // Navigate to call screen with callId from notification.data
        const callId = notification?.data?.callId;
        // ... set state to show call screen
      }
      if (pressAction.id === 'decline') {
        // Decline the call
        const callId = notification?.data?.callId;
        // ... update Firestore
      }
    }
  });
  return unsubscribe;
}, []);

7. Full-screen intent — ringing on the lock screen

The fullScreenAction property makes Android show your app's call screen even when the phone is locked. This is how WhatsApp's incoming call appears over the lock screen:

android: {
  fullScreenAction: {
    id: 'default',
    launchActivity: 'default',   // Opens your app's main activity
  },
}

For this to work on Android 10+, you need to declare the permission in app.json:

{
  "expo": {
    "android": {
      "permissions": [
        "android.permission.USE_FULL_SCREEN_INTENT",
        "android.permission.POST_NOTIFICATIONS",
        "android.permission.FOREGROUND_SERVICE",
        "android.permission.VIBRATE",
        "android.permission.CAMERA",
        "android.permission.RECORD_AUDIO"
      ]
    }
  }
}

How it behaves:

  • Phone locked → full-screen call UI appears over the lock screen
  • Phone unlocked, app in background → heads-up notification drops down from the top
  • App in foreground → your Firestore listener catches it (same as Lessons 5–6)

8. Playing a ringtone with a foreground service

A foreground service keeps Android from killing your ringtone while the notification is showing. Notifee handles the service automatically when you set asForegroundService: true:

await notifee.displayNotification({
  title: `${callerName} is calling...`,
  body: 'Incoming voice call',
  android: {
    channelId: 'incoming_calls',
    category: AndroidCategory.CALL,
    asForegroundService: true,   // Keeps the process alive
    ongoing: true,
    fullScreenAction: { id: 'default' },
    actions: [
      { title: 'Decline', pressAction: { id: 'decline' } },
      { title: 'Accept', pressAction: { id: 'accept', launchActivity: 'default' } },
    ],
  },
});

// Register the foreground service task
notifee.registerForegroundService((notification) => {
  return new Promise((resolve) => {
    // This promise keeps the service running
    // Resolve it when the call ends or is answered/declined

    const unsubscribe = notifee.onForegroundEvent(({ type, detail }) => {
      if (
        type === EventType.ACTION_PRESS &&
        (detail.pressAction.id === 'accept' || detail.pressAction.id === 'decline')
      ) {
        resolve();  // Stop the foreground service
      }
    });

    // Auto-stop after 30 seconds (call timeout)
    setTimeout(() => resolve(), 30000);
  });
});

9. Cancelling the notification when the call ends

If the caller hangs up before the callee answers (or the 30-second timeout fires), you need to dismiss the notification:

// In your Firestore listener for the call document:
onSnapshot(doc(db, 'calls', callId), async (snap) => {
  const data = snap.data();
  if (!data) return;

  if (data.status === 'ended' || data.status === 'missed' || data.status === 'declined') {
    // Cancel the incoming call notification
    await notifee.cancelAllNotifications();
    // Stop the foreground service
    await notifee.stopForegroundService();
  }
});

10. Passing call data when the app opens

When the user taps Accept on the notification (or the full-screen intent opens the app), you need to know WHICH call to connect to. Check for this when the app starts:

import notifee from '@notifee/react-native';

// Check if the app was opened by a notification
async function getInitialCallData() {
  const initialNotification = await notifee.getInitialNotification();

  if (initialNotification) {
    const { notification, pressAction } = initialNotification;
    if (pressAction.id === 'accept' && notification.data?.callId) {
      return {
        callId: notification.data.callId,
        callerName: notification.data.callerName,
        callType: notification.data.callType,
      };
    }
  }
  return null;
}

// In your App component:
useEffect(() => {
  async function checkInitialCall() {
    const callData = await getInitialCallData();
    if (callData) {
      // Go straight to the call screen and answer
      setContactName(callData.callerName);
      setIncomingCall(callData);
      setScreen('call');
      // Auto-answer since user already tapped Accept
      handleAnswerCall(callData.callId);
    }
  }
  checkInitialCall();
}, []);

11. Android 13+ notification permission

Starting with Android 13 (API 33), apps must explicitly request the POST_NOTIFICATIONS permission. Without it, no notifications show at all:

import { Platform, PermissionsAndroid } from 'react-native';

async function requestNotificationPermission() {
  if (Platform.OS === 'android' && Platform.Version >= 33) {
    const granted = await PermissionsAndroid.request(
      PermissionsAndroid.PERMISSIONS.POST_NOTIFICATIONS
    );
    return granted === PermissionsAndroid.RESULTS.GRANTED;
  }
  return true;  // Below Android 13, no runtime permission needed
}

// Call this at app startup or after login
await requestNotificationPermission();

12. The complete flow — step by step

Here's exactly what happens when Priya calls Rahul and Rahul's phone is locked:

# What happens Where
1 Priya taps Call → writes call doc to Firestore Priya's phone
2 Cloud Function triggers → sends FCM data message to Rahul's token Firebase server
3 FCM wakes Rahul's device → setBackgroundMessageHandler runs Rahul's phone (background)
4 Notifee shows full-screen notification with ringtone Rahul's phone (lock screen)
5 Rahul sees caller name + Accept/Decline buttons Rahul's lock screen
6 Rahul taps Accept → app opens → connects WebRTC Rahul's phone (foreground)
7 Both phones are in the active call screen Both phones

// ─── Call Timer Hook ────────────────────────────────────────────────
function useCallTimer(isActive) {
  const [seconds, setSeconds] = useState(0);
  useEffect(() => {
    if (!isActive) { setSeconds(0); return; }
    const i = setInterval(() => setSeconds((s) => s + 1), 1000);
    return () => clearInterval(i);
  }, [isActive]);
  const m = Math.floor(seconds / 60);
  const s = seconds % 60;
  return `${m.toString().padStart(2, '0')}:${s.toString().padStart(2, '0')}`;
}

    };

    pc.oniceconnectionstatechange = () => {
      if (pc.iceConnectionState === 'connected') setCallState('active');
      if (pc.iceConnectionState === 'failed') handleEndCall();
    };

    const callRef = doc(collection(db, 'calls'));
    callIdRef.current = callRef.id;

    pc.onicecandidate = (e) => {
      if (e.candidate) addDoc(collection(db, 'calls', callRef.id, 'callerCandidates'), e.candidate.toJSON());
    };

    const offer = await pc.createOffer();
    await pc.setLocalDescription(offer);

    const myName = user.displayName || user.email || 'Caller';
    const calleeSnap = await getDoc(doc(db, 'users', calleeUid.trim()));
    setContactName(calleeSnap.exists() ? calleeSnap.data().displayName || calleeUid : calleeUid);

    await setDoc(callRef, {
      callerId: user.uid,
      calleeId: calleeUid.trim(),
      callerName: myName,
      type: 'video',
      status: 'ringing',
      offer: { type: offer.type, sdp: offer.sdp },
      answer: null,
      createdAt: serverTimestamp(),
    });

    const unsubCall = onSnapshot(doc(db, 'calls', callRef.id), (snap) => {
      const data = snap.data();
      if (!data) return;
      if (data.answer && !pc.remoteDescription) {
        pc.setRemoteDescription(new RTCSessionDescription(data.answer));
      }
      if (data.status === 'ended' || data.status === 'declined') handleEndCall();
    });

    const unsubCands = onSnapshot(collection(db, 'calls', callRef.id, 'calleeCandidates'), (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
      });
    });

    unsubsRef.current = [unsubCall, unsubCands];

    setTimeout(async () => {
      const snap = await getDoc(doc(db, 'calls', callRef.id));
      if (snap.exists() && snap.data().status === 'ringing') {
        await updateDoc(doc(db, 'calls', callRef.id), { status: 'missed' });
        handleEndCall();
      }
    }, 30000);
  }

  // ── ANSWER CALL ──
  async function handleAnswerCall() {
    if (!incomingCall) return;
    const ok = await requestAllPermissions();
    if (!ok) return;

    // ★ Cancel any lingering notification
    await notifee.cancelAllNotifications();

    setScreen('call');
    setCallState('connecting');

    const { callId, offer } = incomingCall;
    callIdRef.current = callId;

    const pc = new RTCPeerConnection(ICE_SERVERS);
    pcRef.current = pc;

    const isVideo = incomingCall.type === 'video';
    const stream = await mediaDevices.getUserMedia({
      audio: true,
      video: isVideo ? { facingMode: 'user' } : false,
    });
    streamRef.current = stream;
    if (isVideo) setLocalStreamURL(stream.toURL());

    stream.getTracks().forEach((track) => pc.addTrack(track, stream));

    pc.ontrack = (event) => {
      if (event.streams?.[0]) {
        setRemoteStreamURL(event.streams[0].toURL());
        InCallManager.start({ media: isVideo ? 'video' : 'audio' });
        if (isVideo) InCallManager.setForceSpeakerphoneOn(true);
        setCallState('active');
      }
    };

    pc.oniceconnectionstatechange = () => {
      if (pc.iceConnectionState === 'connected') setCallState('active');
      if (pc.iceConnectionState === 'failed') handleEndCall();
    };

    pc.onicecandidate = (e) => {
      if (e.candidate) addDoc(collection(db, 'calls', callId, 'calleeCandidates'), e.candidate.toJSON());
    };

    await pc.setRemoteDescription(new RTCSessionDescription(offer));
    const answer = await pc.createAnswer();
    await pc.setLocalDescription(answer);

    await updateDoc(doc(db, 'calls', callId), {
      answer: { type: answer.type, sdp: answer.sdp },
      status: 'active',
    });

    const unsubCands = onSnapshot(collection(db, 'calls', callId, 'callerCandidates'), (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
      });
    });

    const unsubCall = onSnapshot(doc(db, 'calls', callId), (snap) => {
      const data = snap.data();
      if (data && data.status === 'ended') handleEndCall();
    });

    unsubsRef.current = [unsubCands, unsubCall];
    setIncomingCall(null);
  }

  // ── DECLINE ──
  async function handleDecline() {
    if (incomingCall) {
      await updateDoc(doc(db, 'calls', incomingCall.callId), { status: 'declined' });
    }
    await notifee.cancelAllNotifications();
    setIncomingCall(null);
    setScreen('home');
    setCallState('idle');
  }

  // ── END CALL ──
  async function handleEndCall() {
    InCallManager.stop();
    pcRef.current?.close();
    pcRef.current = null;
    streamRef.current?.getTracks().forEach((t) => t.stop());
    streamRef.current = null;
    unsubsRef.current.forEach((u) => u());
    unsubsRef.current = [];
    if (callIdRef.current) {
      try { await updateDoc(doc(db, 'calls', callIdRef.current), { status: 'ended' }); } catch (e) {}
    }
    callIdRef.current = null;
    setCallState('idle');
    setIsMuted(false);
    setIsSpeaker(true);
    setIsVideoOff(false);
    setLocalStreamURL(null);
    setRemoteStreamURL(null);
    setScreen('home');
    setIncomingCall(null);
  }

  // ── CONTROLS ──
  function handleToggleMute() {
    const track = streamRef.current?.getAudioTracks()[0];
    if (track) { track.enabled = isMuted; setIsMuted(!isMuted); }
  }
  function handleToggleSpeaker() {
    InCallManager.setForceSpeakerphoneOn(!isSpeaker);
    setIsSpeaker(!isSpeaker);
  }
  function handleToggleVideo() {
    const track = streamRef.current?.getVideoTracks()[0];
    if (track) { track.enabled = isVideoOff; setIsVideoOff(!isVideoOff); }
  }
  async function handleFlipCamera() {
    const currentTrack = streamRef.current?.getVideoTracks()[0];
    if (!currentTrack) return;
    currentTrack.stop();
    const newFacing = isFrontCamera ? 'environment' : 'user';
    const newStream = await mediaDevices.getUserMedia({ audio: false, video: { facingMode: newFacing } });
    const newTrack = newStream.getVideoTracks()[0];
    const sender = pcRef.current?.getSenders().find((s) => s.track?.kind === 'video');
    if (sender) await sender.replaceTrack(newTrack);
    streamRef.current.removeTrack(currentTrack);
    streamRef.current.addTrack(newTrack);
    setLocalStreamURL(streamRef.current.toURL());
    setIsFrontCamera(!isFrontCamera);
  }

  // ── RENDER ──
  if (!user) {
    return (
      <View style={[styles.container, styles.center]}>
        <Text style={styles.infoText}>Please log in (Module 3 Lesson 2)</Text>
      </View>
    );
  }

  if (screen === 'home') {
    return (
      <View style={styles.container}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>Video Call</Text>
          <Text style={styles.headerSub}>UID: {user.uid.substring(0, 16)}...</Text>
        </View>
        <View style={styles.homeContent}>
          <Text style={styles.label}>Enter the other user's UID:</Text>
          <TextInput
            style={styles.input}
            value={calleeUid}
            onChangeText={setCalleeUid}
            placeholder="Paste UID here"
            autoCapitalize="none"
          />
          <Pressable style={styles.callButton} onPress={handleStartCall}>
            <Text style={styles.callButtonText}>🎥 Video Call</Text>
          </Pressable>
        </View>
      </View>
    );
  }

  if (screen === 'incoming') {
    return (
      <View style={styles.callScreen}>
        <View style={styles.callInfo}>
          <View style={styles.bigAvatar}>
            <Text style={styles.bigAvatarText}>{contactName.charAt(0).toUpperCase()}</Text>
          </View>
          <Text style={styles.callName}>{contactName}</Text>
          <Text style={styles.callStatus}>Incoming video call...</Text>
        </View>
        <View style={styles.incomingBtns}>
          <Pressable style={styles.declineBtn} onPress={handleDecline}>
            <Text style={styles.btnIcon}>✕</Text>
            <Text style={styles.btnLabel}>Decline</Text>
          </Pressable>
          <Pressable style={styles.acceptBtn} onPress={handleAnswerCall}>
            <Text style={styles.btnIcon}>🎥</Text>
            <Text style={styles.btnLabel}>Accept</Text>
          </Pressable>
        </View>
      </View>
    );
  }

  // ACTIVE VIDEO CALL SCREEN (same as Lesson 6)
  return (
    <View style={{ flex: 1 }}>
      {remoteStreamURL ? (
        <RTCView streamURL={remoteStreamURL} style={StyleSheet.absoluteFill} objectFit="cover" zOrder={0} />
      ) : (
        <View style={[StyleSheet.absoluteFill, styles.callScreen]}>
          <View style={styles.callInfo}>
            <View style={styles.bigAvatar}>
              <Text style={styles.bigAvatarText}>{contactName.charAt(0).toUpperCase()}</Text>
            </View>
            <Text style={styles.callName}>{contactName}</Text>
            <Text style={styles.callStatus}>
              {callState === 'calling' && 'Calling...'}
              {callState === 'connecting' && 'Connecting...'}
            </Text>
          </View>
        </View>
      )}
      {localStreamURL && !isVideoOff && (
        <View style={styles.pip}>
          <RTCView streamURL={localStreamURL} style={{ flex: 1 }} objectFit="cover" mirror={isFrontCamera} zOrder={1} />
        </View>
      )}
      {callState === 'active' && (
        <View style={styles.timerOverlay}>
          <Text style={styles.timerText}>{contactName}</Text>
          <Text style={styles.timerSub}>{timer}</Text>
        </View>
      )}
      <View style={styles.controlBar}>
        <Pressable style={[styles.ctrlBtn, isVideoOff && styles.ctrlActive]} onPress={handleToggleVideo}>
          <Text style={styles.ctrlIcon}>{isVideoOff ? '📷' : '🎥'}</Text>
        </Pressable>
        <Pressable style={[styles.ctrlBtn, isMuted && styles.ctrlActive]} onPress={handleToggleMute}>
          <Text style={styles.ctrlIcon}>{isMuted ? '🔇' : '🎤'}</Text>
        </Pressable>
        <Pressable style={styles.ctrlBtn} onPress={handleFlipCamera}>
          <Text style={styles.ctrlIcon}>🔄</Text>
        </Pressable>
        <Pressable style={styles.endCallBtn} onPress={handleEndCall}>
          <Text style={styles.ctrlIcon}>📵</Text>
        </Pressable>
      </View>
    </View>
  );
}

14. Testing incoming calls on Android

  1. Deploy the Cloud Function: firebase deploy --only functions
  2. Build and install the dev build on two phones
  3. Log in on both phones — check that fcmToken appears in each user's Firestore doc
  4. On Phone B: close the app completely (swipe it away from recents)
  5. On Phone A: call Phone B
  6. Phone B should show a full-screen notification (even if locked) with "Accept" and "Decline"
  7. Tap "Accept" — the app opens and the video call connects
  8. Test "Decline" — the notification disappears and Phone A sees "Declined"
  9. Test timeout — wait 30 seconds without answering; notification should disappear and call shows as "Missed"
Troubleshooting
  • No notification? — Check that POST_NOTIFICATIONS permission is granted (Settings → App → Notifications). Check that the FCM token is saved in Firestore.
  • Notification appears but no sound? — Make sure the "Incoming Calls" channel isn't muted in Android settings. Some devices (Xiaomi, Samsung) have extra battery optimization that blocks background services — whitelist your app.
  • Full-screen intent doesn't show on lock screen? — Some OEMs (Xiaomi, OPPO) require extra "Display over other apps" permission. Check Settings → Apps → Special access.
