Audio & Video Calls · Lesson 4

Signaling with Firebase

Firestore call docs · Offer/answer exchange · ICE candidates · Real-time listeners · Call lifecycle ~55 min Hands-on
Why this matters for your WhatsApp clone

In Lesson 1, you learned that WebRTC needs a "signaling channel" to exchange connection info before a call starts. This is the most critical piece of the puzzle — without signaling, two phones have no way to find each other. Your signaling channel is Firestore — the same database you already use for messages. When Priya calls Rahul, her phone writes an "offer" to a Firestore document; Rahul's phone listens for it in real time, writes an "answer" back, and both exchange ICE candidates through subcollections. Once connected, Firestore's job is done. This lesson builds the complete signaling system you'll use in Lessons 5–8.

1. The Firestore signaling data model

Each call gets its own document in a /calls collection. ICE candidates go into subcollections inside it:

// Firestore structure for one call:

/calls/{callId}
├── callerId: 'uid_priya'           // who initiated
├── calleeId: 'uid_rahul'           // who is being called
├── callerName: 'Priya'             // for display on incoming call screen
├── type: 'audio'                   // 'audio' or 'video'
├── status: 'ringing'               // lifecycle state
├── offer: {                        // SDP from caller
│     type: 'offer',
│     sdp: 'v=0\r\n...'
│   }
├── answer: null                    // SDP from callee (null until they answer)
├── createdAt: Timestamp
│
├── callerCandidates/               // subcollection
│     ├── {id}: { candidate: '...', sdpMid: '0', sdpMLineIndex: 0 }
│     ├── {id}: { candidate: '...', sdpMid: '0', sdpMLineIndex: 0 }
│     └── ...
│
└── calleeCandidates/               // subcollection
      ├── {id}: { candidate: '...', sdpMid: '0', sdpMLineIndex: 0 }
      └── ...

Why subcollections for ICE candidates?

  • ICE candidates arrive one at a time (not all at once) — you need to listen for each new one
  • Subcollections let you use onSnapshot to get notified as each candidate is added
  • A Firestore document has a 1MB size limit — with many candidates in an array, you'd risk hitting it

2. Call status lifecycle

The status field tracks where the call is in its lifecycle:

// Call status transitions:
'ringing'   → Caller created the offer, waiting for callee to answer
'active'    → Both sides connected, call is in progress
'ended'     → Call ended normally (someone hung up)
'missed'    → Callee didn't answer within timeout
'declined'  → Callee rejected the call

// Status flow:
// Caller creates call → status: 'ringing'
// Callee taps Answer → status: 'active'
// Either taps End    → status: 'ended'
// Callee taps Decline → status: 'declined'
// Timeout (30s)      → status: 'missed'

Both phones listen to the status field. When it changes to 'ended', both sides close the connection and clean up.

3. Caller side — creating the offer

When Priya taps "Call", her phone: creates an RTCPeerConnection, gets her audio stream, creates an offer, and writes it to Firestore:

import {
  RTCPeerConnection, RTCSessionDescription, mediaDevices
} from 'react-native-webrtc';
import {
  doc, setDoc, collection, addDoc, onSnapshot, serverTimestamp
} from 'firebase/firestore';

const ICE_SERVERS = {
  iceServers: [
    { urls: 'stun:stun.l.google.com:19302' },
    { urls: 'stun:stun1.l.google.com:19302' },
  ],
};

async function startCall(calleeId, callerName, callType) {
  // 1. Create RTCPeerConnection
  const pc = new RTCPeerConnection(ICE_SERVERS);

  // 2. Get local media stream
  const stream = await mediaDevices.getUserMedia({
    audio: true,
    video: callType === 'video',
  });

  // 3. Add tracks to the connection
  stream.getTracks().forEach((track) => {
    pc.addTrack(track, stream);
  });

  // 4. Create a call document in Firestore
  const callRef = doc(collection(db, 'calls'));
  const callId = callRef.id;

  // 5. Collect ICE candidates and write to Firestore
  pc.onicecandidate = (event) => {
    if (event.candidate) {
      addDoc(
        collection(db, 'calls', callId, 'callerCandidates'),
        event.candidate.toJSON()
      );
    }
  };

  // 6. Create the offer
  const offer = await pc.createOffer();
  await pc.setLocalDescription(offer);

  // 7. Write the call document with the offer
  await setDoc(callRef, {
    callerId: auth.currentUser.uid,
    calleeId: calleeId,
    callerName: callerName,
    type: callType,
    status: 'ringing',
    offer: { type: offer.type, sdp: offer.sdp },
    answer: null,
    createdAt: serverTimestamp(),
  });

  return { pc, localStream: stream, callId };
}

Step by step:

  1. Create the peer connection with STUN servers
  2. Get microphone (and camera for video calls)
  3. Attach tracks so the other person will hear/see you
  4. Generate a Firestore document for this call
  5. As ICE candidates are discovered, write each one to a subcollection
  6. Create the SDP offer (describes your capabilities)
  7. Write everything to Firestore — Rahul's phone is listening

4. Caller side — waiting for the answer

After writing the offer, Priya's phone listens for Rahul's answer and his ICE candidates:

function listenForAnswer(callId, pc) {
  // Listen for the answer to appear on the call document
  const callRef = doc(db, 'calls', callId);

  const unsubCall = onSnapshot(callRef, (snapshot) => {
    const data = snapshot.data();
    if (!data) return;

    // When answer arrives, set it as remote description
    if (data.answer && !pc.remoteDescription) {
      const answerDesc = new RTCSessionDescription(data.answer);
      pc.setRemoteDescription(answerDesc);
    }

    // Handle call status changes
    if (data.status === 'declined' || data.status === 'ended') {
      // Clean up — callee declined or call ended
      endCall(pc, callId);
    }
  });

  // Listen for callee's ICE candidates
  const unsubCandidates = onSnapshot(
    collection(db, 'calls', callId, 'calleeCandidates'),
    (snapshot) => {
      snapshot.docChanges().forEach((change) => {
        if (change.type === 'added') {
          const candidate = new RTCIceCandidate(change.doc.data());
          pc.addIceCandidate(candidate);
        }
      });
    }
  );

  return { unsubCall, unsubCandidates };
}

Key pattern: snapshot.docChanges() — this gives you only the NEW documents added since the last snapshot, not the entire collection. Perfect for ICE candidates that arrive one at a time.

5. Callee side — listening for incoming calls

Rahul's phone runs a listener that watches for new calls addressed to him:

import { collection, query, where, onSnapshot } from 'firebase/firestore';

function listenForIncomingCalls(myUid, onIncomingCall) {
  const q = query(
    collection(db, 'calls'),
    where('calleeId', '==', myUid),
    where('status', '==', 'ringing')
  );

  const unsub = onSnapshot(q, (snapshot) => {
    snapshot.docChanges().forEach((change) => {
      if (change.type === 'added') {
        const callData = change.doc.data();
        // Show incoming call UI
        onIncomingCall({
          callId: change.doc.id,
          ...callData,
        });
      }
    });
  });

  return unsub;
}

This runs when the app is open. When a new call document appears with calleeId matching Rahul and status: 'ringing', the incoming call screen shows up.

What about when the app is closed?

This Firestore listener only works when the app is open. For incoming calls when the app is closed, you need push notifications (Lesson 7 for Android, Lesson 8 for iOS). The push wakes the app, which then connects to Firestore to get the call details.

6. Callee side — answering the call

When Rahul taps "Answer", his phone: reads the offer, creates a peer connection, creates an answer, and writes it back:

async function answerCall(callId, callData) {
  // 1. Create RTCPeerConnection
  const pc = new RTCPeerConnection(ICE_SERVERS);

  // 2. Get local media stream
  const stream = await mediaDevices.getUserMedia({
    audio: true,
    video: callData.type === 'video',
  });

  // 3. Add tracks
  stream.getTracks().forEach((track) => {
    pc.addTrack(track, stream);
  });

  // 4. Collect ICE candidates → write to calleeCandidates subcollection
  pc.onicecandidate = (event) => {
    if (event.candidate) {
      addDoc(
        collection(db, 'calls', callId, 'calleeCandidates'),
        event.candidate.toJSON()
      );
    }
  };

  // 5. Set the offer as remote description
  const offerDesc = new RTCSessionDescription(callData.offer);
  await pc.setRemoteDescription(offerDesc);

  // 6. Create the answer
  const answer = await pc.createAnswer();
  await pc.setLocalDescription(answer);

  // 7. Write the answer to Firestore + update status
  await updateDoc(doc(db, 'calls', callId), {
    answer: { type: answer.type, sdp: answer.sdp },
    status: 'active',
  });

  // 8. Listen for caller's ICE candidates
  const unsubCandidates = onSnapshot(
    collection(db, 'calls', callId, 'callerCandidates'),
    (snapshot) => {
      snapshot.docChanges().forEach((change) => {
        if (change.type === 'added') {
          const candidate = new RTCIceCandidate(change.doc.data());
          pc.addIceCandidate(candidate);
        }
      });
    }
  );

  return { pc, localStream: stream, unsubCandidates };
}

The mirror of the caller flow:

  1. Same setup: create PC, get media, add tracks
  2. ICE candidates go to calleeCandidates (not callerCandidates)
  3. Set the OFFER as remoteDescription (from Firestore)
  4. Create an ANSWER (not an offer)
  5. Write the answer back + set status to 'active'
  6. Listen for CALLER's candidates (the other subcollection)

7. Receiving the remote stream

Both phones need to handle incoming audio/video from the other person. The ontrack event fires when remote tracks arrive:

// Set up BEFORE creating offer/answer:
function setupRemoteStream(pc, setRemoteStream) {
  pc.ontrack = (event) => {
    // event.streams[0] is the remote MediaStream
    if (event.streams && event.streams[0]) {
      setRemoteStream(event.streams[0]);
    }
  };
}

// In your component, use it with RTCView:
const [remoteStream, setRemoteStream] = useState(null);

// After creating pc:
setupRemoteStream(pc, setRemoteStream);

// In JSX:
// {remoteStream && (

// )}

When does ontrack fire? After both sides have exchanged offer/answer/candidates and the peer connection establishes. For audio calls, you won't see anything — the audio plays automatically through the phone speaker. For video calls, you render the stream in an RTCView.

8. Ending the call

When either person hangs up, you need to: close the connection, stop media tracks, update Firestore, and unsubscribe from listeners:

async function endCall(pc, localStream, callId, unsubs) {
  // 1. Close the peer connection
  if (pc) {
    pc.close();
  }

  // 2. Stop all media tracks (release mic/camera)
  if (localStream) {
    localStream.getTracks().forEach((track) => track.stop());
  }

  // 3. Update Firestore status
  await updateDoc(doc(db, 'calls', callId), {
    status: 'ended',
  });

  // 4. Unsubscribe from all Firestore listeners
  if (unsubs) {
    unsubs.forEach((unsub) => unsub());
  }
}

// Declining a call (callee side):
async function declineCall(callId) {
  await updateDoc(doc(db, 'calls', callId), {
    status: 'declined',
  });
}

Both phones must watch for status changes. When the caller updates status to 'ended', the callee's listener fires and triggers cleanup on their side too (and vice versa).

9. Connection state monitoring

WebRTC tells you when the connection state changes — use this to show "Connecting...", "Connected", or detect dropped calls:

function monitorConnection(pc, onStateChange) {
  // ICE connection state: tracks if the network path is working
  pc.oniceconnectionstatechange = () => {
    const state = pc.iceConnectionState;
    onStateChange(state);

    switch (state) {
      case 'checking':
        // Trying to connect...
        console.log('Finding connection path...');
        break;
      case 'connected':
        // Call is active!
        console.log('Connected! Audio/video flowing.');
        break;
      case 'completed':
        // Best path found and stable
        console.log('Connection optimized.');
        break;
      case 'disconnected':
        // Temporary loss — might recover
        console.log('Connection interrupted, trying to recover...');
        break;
      case 'failed':
        // Cannot connect — TURN might be needed
        console.log('Connection failed. Check network.');
        break;
      case 'closed':
        // Connection was closed intentionally
        console.log('Connection closed.');
        break;
    }
  };
}

Map these states to your call UI:

  • checking → show "Connecting..."
  • connected / completed → show call timer, hide "Connecting..."
  • disconnected → show "Reconnecting..." (wait a few seconds)
  • failed → show "Call failed" and end the call

11. Timeout for missed calls

If Rahul doesn't answer within 30 seconds, mark the call as missed:

function startRingingTimeout(callId, timeoutMs = 30000) {
  const timer = setTimeout(async () => {
    // Check if still ringing (might have been answered)
    const snap = await getDoc(doc(db, 'calls', callId));
    if (snap.exists() && snap.data().status === 'ringing') {
      await updateDoc(doc(db, 'calls', callId), {
        status: 'missed',
      });
    }
  }, timeoutMs);

  return timer; // Call clearTimeout(timer) if answered before timeout
}

12. Cleaning up call documents

Call documents and their subcollections build up over time. For a production app, you'd delete them after the call ends. A simple cleanup:

import { doc, deleteDoc, collection, getDocs } from 'firebase/firestore';

async function cleanupCallDoc(callId) {
  // Delete ICE candidate subcollections first
  const callerCands = await getDocs(collection(db, 'calls', callId, 'callerCandidates'));
  callerCands.forEach((docSnap) => deleteDoc(docSnap.ref));

  const calleeCands = await getDocs(collection(db, 'calls', callId, 'calleeCandidates'));
  calleeCands.forEach((docSnap) => deleteDoc(docSnap.ref));

  // Delete the call document
  await deleteDoc(doc(db, 'calls', callId));
}
When to clean up

Call cleanupCallDoc a few seconds after the call ends (use a setTimeout of 5–10 seconds to ensure both sides have read all necessary data). In production, a Cloud Function triggered by status changing to 'ended' would handle this automatically.

13. Full runnable App.js — Signaling test between two devices

Copy this entire file and replace your App.js. Open the app on two phones logged in as different users. Phone A enters Phone B's UID and taps "Call". Phone B sees the incoming call and taps "Answer". You'll hear each other (audio flows directly between phones).

// App.js — Full runnable example: Signaling with Firebase
import React, { useState, useEffect, useRef } from 'react';
import {
  View, Text, TextInput, Pressable, StyleSheet, Alert, Platform, PermissionsAndroid
} from 'react-native';
import {
  RTCPeerConnection, RTCSessionDescription, RTCIceCandidate, mediaDevices
} from 'react-native-webrtc';

import { initializeApp } from 'firebase/app';
import { getAuth, onAuthStateChanged } from 'firebase/auth';
import {
  getFirestore, doc, setDoc, getDoc, updateDoc, addDoc, deleteDoc, getDocs,
  collection, query, where, onSnapshot, serverTimestamp
} from 'firebase/firestore';

// ─── Firebase config ────────────────────────────────────────────────
const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',
  authDomain: 'YOUR_PROJECT.firebaseapp.com',
  projectId: 'YOUR_PROJECT_ID',
  storageBucket: 'YOUR_PROJECT.appspot.com',
  messagingSenderId: '123456789',
  appId: '1:123456789:web:abcdef',
};
const app = initializeApp(firebaseConfig);
const auth = getAuth(app);
const db = getFirestore(app);

const ICE_SERVERS = {
  iceServers: [
    { urls: 'stun:stun.l.google.com:19302' },
    { urls: 'stun:stun1.l.google.com:19302' },
  ],
};

// ─── Request permissions (Android) ──────────────────────────────────
async function requestPermissions() {
  if (Platform.OS === 'android') {
    const grants = await PermissionsAndroid.requestMultiple([
      PermissionsAndroid.PERMISSIONS.CAMERA,
      PermissionsAndroid.PERMISSIONS.RECORD_AUDIO,
    ]);
    return grants['android.permission.RECORD_AUDIO'] === 'granted';
  }
  return true;
}

// ─── Main App ───────────────────────────────────────────────────────
export default function App() {
  const [user, setUser] = useState(null);
  const [calleeUid, setCalleeUid] = useState('');
  const [callState, setCallState] = useState('idle');
  const [callId, setCallId] = useState(null);
  const [incomingCall, setIncomingCall] = useState(null);
  const [connectionState, setConnectionState] = useState('');

  const pcRef = useRef(null);
  const localStreamRef = useRef(null);
  const unsubsRef = useRef([]);

  useEffect(() => {
    const unsub = onAuthStateChanged(auth, (u) => setUser(u));
    return unsub;
  }, []);

  // Listen for incoming calls
  useEffect(() => {
    if (!user) return;

    const q = query(
      collection(db, 'calls'),
      where('calleeId', '==', user.uid),
      where('status', '==', 'ringing')
    );

    const unsub = onSnapshot(q, (snapshot) => {
      snapshot.docChanges().forEach((change) => {
        if (change.type === 'added') {
          setIncomingCall({ callId: change.doc.id, ...change.doc.data() });
          setCallState('incoming');
        }
      });
    });

    return unsub;
  }, [user]);

  // ── START CALL (Caller) ──
  async function handleStartCall() {
    if (!calleeUid.trim()) {
      Alert.alert('Error', 'Enter the other user\'s UID');
      return;
    }
    const ok = await requestPermissions();
    if (!ok) return;

    setCallState('calling');

    const pc = new RTCPeerConnection(ICE_SERVERS);
    pcRef.current = pc;

    // Monitor connection state
    pc.oniceconnectionstatechange = () => setConnectionState(pc.iceConnectionState);

    // Get audio
    const stream = await mediaDevices.getUserMedia({ audio: true, video: false });
    localStreamRef.current = stream;
    stream.getTracks().forEach((track) => pc.addTrack(track, stream));

    // Remote audio plays automatically
    pc.ontrack = () => setConnectionState('audio connected');

    // Create call document
    const callRef = doc(collection(db, 'calls'));
    const newCallId = callRef.id;
    setCallId(newCallId);

    // ICE candidates → Firestore
    pc.onicecandidate = (event) => {
      if (event.candidate) {
        addDoc(collection(db, 'calls', newCallId, 'callerCandidates'), event.candidate.toJSON());
      }
    };

    // Create offer
    const offer = await pc.createOffer();
    await pc.setLocalDescription(offer);

    // Write to Firestore
    const myName = user.displayName || user.email || 'Caller';
    await setDoc(callRef, {
      callerId: user.uid,
      calleeId: calleeUid.trim(),
      callerName: myName,
      type: 'audio',
      status: 'ringing',
      offer: { type: offer.type, sdp: offer.sdp },
      answer: null,
      createdAt: serverTimestamp(),
    });

    // Listen for answer
    const unsubCall = onSnapshot(doc(db, 'calls', newCallId), (snap) => {
      const data = snap.data();
      if (!data) return;

      if (data.answer && !pc.remoteDescription) {
        pc.setRemoteDescription(new RTCSessionDescription(data.answer));
        setCallState('active');
      }
      if (data.status === 'ended' || data.status === 'declined') {
        handleEndCall();
      }
    });

    // Listen for callee candidates
    const unsubCands = onSnapshot(
      collection(db, 'calls', newCallId, 'calleeCandidates'),
      (snap) => {
        snap.docChanges().forEach((change) => {
          if (change.type === 'added') {
            pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
          }
        });
      }
    );

    unsubsRef.current = [unsubCall, unsubCands];

    // Timeout after 30s
    setTimeout(async () => {
      const snap = await getDoc(doc(db, 'calls', newCallId));
      if (snap.exists() && snap.data().status === 'ringing') {
        await updateDoc(doc(db, 'calls', newCallId), { status: 'missed' });
        handleEndCall();
        Alert.alert('Missed', 'No answer');
      }
    }, 30000);
  }

  // ── ANSWER CALL (Callee) ──
  async function handleAnswerCall() {
    if (!incomingCall) return;
    const ok = await requestPermissions();
    if (!ok) return;

    setCallState('active');
    const { callId: incCallId, offer } = incomingCall;
    setCallId(incCallId);

    const pc = new RTCPeerConnection(ICE_SERVERS);
    pcRef.current = pc;

    pc.oniceconnectionstatechange = () => setConnectionState(pc.iceConnectionState);

    const stream = await mediaDevices.getUserMedia({ audio: true, video: false });
    localStreamRef.current = stream;
    stream.getTracks().forEach((track) => pc.addTrack(track, stream));

    pc.ontrack = () => setConnectionState('audio connected');

    pc.onicecandidate = (event) => {
      if (event.candidate) {
        addDoc(collection(db, 'calls', incCallId, 'calleeCandidates'), event.candidate.toJSON());
      }
    };

    await pc.setRemoteDescription(new RTCSessionDescription(offer));
    const answer = await pc.createAnswer();
    await pc.setLocalDescription(answer);

    await updateDoc(doc(db, 'calls', incCallId), {
      answer: { type: answer.type, sdp: answer.sdp },
      status: 'active',
    });

    // Listen for caller candidates
    const unsubCands = onSnapshot(
      collection(db, 'calls', incCallId, 'callerCandidates'),
      (snap) => {
        snap.docChanges().forEach((change) => {
          if (change.type === 'added') {
            pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
          }
        });
      }
    );

    // Listen for call end
    const unsubCall = onSnapshot(doc(db, 'calls', incCallId), (snap) => {
      const data = snap.data();
      if (data && data.status === 'ended') handleEndCall();
    });

    unsubsRef.current = [unsubCands, unsubCall];
    setIncomingCall(null);
  }

  // ── DECLINE CALL ──
  async function handleDecline() {
    if (incomingCall) {
      await updateDoc(doc(db, 'calls', incomingCall.callId), { status: 'declined' });
      setIncomingCall(null);
      setCallState('idle');
    }
  }

  // ── END CALL ──
  async function handleEndCall() {
    if (pcRef.current) {
      pcRef.current.close();
      pcRef.current = null;
    }
    if (localStreamRef.current) {
      localStreamRef.current.getTracks().forEach((t) => t.stop());
      localStreamRef.current = null;
    }
    unsubsRef.current.forEach((unsub) => unsub());
    unsubsRef.current = [];

    if (callId) {
      try {
        await updateDoc(doc(db, 'calls', callId), { status: 'ended' });
      } catch (e) {}
    }

    setCallState('idle');
    setCallId(null);
    setConnectionState('');
    setIncomingCall(null);
  }

  // ── RENDER ──
  if (!user) {
    return (
      <View style={[styles.container, styles.center]}>
        <Text style={styles.infoText}>Please log in (Module 3 Lesson 2)</Text>
      </View>
    );
  }

  return (
    <View style={styles.container}>
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Signaling Test</Text>
        <Text style={styles.headerSub}>Your UID: {user.uid.substring(0, 12)}...</Text>
      </View>

      <View style={styles.content}>
        {callState === 'idle' && (
          <View>
            <Text style={styles.label}>Enter the other user's UID:</Text>
            <TextInput
              style={styles.input}
              value={calleeUid}
              onChangeText={setCalleeUid}
              placeholder="Paste UID here"
              autoCapitalize="none"
            />
            <Pressable style={styles.callBtn} onPress={handleStartCall}>
              <Text style={styles.callBtnText}>📞 Start Audio Call</Text>
            </Pressable>
          </View>
        )}

        {callState === 'calling' && (
          <View style={styles.center}>
            <Text style={styles.statusText}>📞 Calling...</Text>
            <Text style={styles.subText}>Waiting for answer</Text>
            <Text style={styles.stateText}>ICE: {connectionState}</Text>
            <Pressable style={styles.endBtn} onPress={handleEndCall}>
              <Text style={styles.endBtnText}>End Call</Text>
            </Pressable>
          </View>
        )}

        {callState === 'incoming' && incomingCall && (
          <View style={styles.center}>
            <Text style={styles.statusText}>📲 Incoming Call</Text>
            <Text style={styles.subText}>From: {incomingCall.callerName}</Text>
            <View style={styles.btnRow}>
              <Pressable style={styles.answerBtn} onPress={handleAnswerCall}>
                <Text style={styles.answerBtnText}>Answer</Text>
              </Pressable>
              <Pressable style={styles.endBtn} onPress={handleDecline}>
                <Text style={styles.endBtnText}>Decline</Text>
              </Pressable>
            </View>
          </View>
        )}

        {callState === 'active' && (
          <View style={styles.center}>
            <Text style={styles.statusText}>🟢 Call Active</Text>
            <Text style={styles.stateText}>ICE: {connectionState}</Text>
            <Text style={styles.subText}>You should hear the other person!</Text>
            <Pressable style={styles.endBtn} onPress={handleEndCall}>
              <Text style={styles.endBtnText}>End Call</Text>
            </Pressable>
          </View>
        )}
      </View>
    </View>
  );
}
