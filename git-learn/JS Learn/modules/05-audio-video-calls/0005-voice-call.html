1:1 Voice Call

Call screen UI · Timer · Mute · Speaker · InCallManager · Call from chat ~55 min Hands-on
Why this matters for your WhatsApp clone

In Lesson 4, you proved that two phones can exchange audio via WebRTC + Firestore signaling. But it looked like a debug screen — just a text input and status text. This lesson builds the production call screen that WhatsApp users know: a big avatar, the contact's name, a call timer counting up, round buttons for mute/speaker/end, a proper incoming call screen with green Accept and red Decline buttons, and audio routing through the earpiece or speaker. By the end, you'll have a complete working voice call you could show to anyone.

1. Installing react-native-incall-manager

Phone calls have special audio requirements: the screen should stay on, audio should route through the earpiece (not the loud speaker), and the proximity sensor should turn off the screen when you hold the phone to your ear. react-native-incall-manager handles all of this:

# Install
npx expo install react-native-incall-manager

# Rebuild (native library)
eas build --platform android --profile development

What it gives you:

  • Audio routing — earpiece vs speaker vs bluetooth
  • Proximity sensor — screen turns off when phone is near your ear
  • Keep screen awake — prevents sleep during a call
  • Ringtone/ringback — play sounds for incoming/outgoing calls
import InCallManager from 'react-native-incall-manager';

// Start when call connects
InCallManager.start({ media: 'audio' });

// Toggle speaker
InCallManager.setSpeakerphoneOn(true);   // loud speaker
InCallManager.setSpeakerphoneOn(false);  // earpiece

// Stop when call ends
InCallManager.stop();

2. The call timer

WhatsApp shows "00:12" counting up once the call connects. A simple hook:

function useCallTimer(isActive) {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    if (!isActive) {
      setSeconds(0);
      return;
    }

    const interval = setInterval(() => {
      setSeconds((s) => s + 1);
    }, 1000);

    return () => clearInterval(interval);
  }, [isActive]);

  // Format as MM:SS
  const minutes = Math.floor(seconds / 60);
  const secs = seconds % 60;
  const display = `${minutes.toString().padStart(2, '0')}:${secs.toString().padStart(2, '0')}`;

  return display;
}

7. The useVoiceCall hook — encapsulating all WebRTC logic

To keep the call screen clean, wrap all the WebRTC + signaling logic in a custom hook:

function useVoiceCall(calleeUid, isCaller) {
  const [callState, setCallState] = useState('idle'); // idle|calling|incoming|active|ended
  const [callId, setCallId] = useState(null);
  const [isMuted, setIsMuted] = useState(false);
  const [isSpeaker, setIsSpeaker] = useState(false);

  const pcRef = useRef(null);
  const streamRef = useRef(null);
  const unsubsRef = useRef([]);

  // Start a call (caller)
  async function startCall() {
    setCallState('calling');
    // ... all the signaling code from Lesson 4
    // Sets up pc, gets stream, creates offer, writes to Firestore
    // Listens for answer
  }

  // Answer a call (callee)
  async function answerCall(incomingCallData) {
    setCallState('active');
    // ... setRemoteDescription, createAnswer, write to Firestore
  }

  // Toggle mute
  function toggleMute() {
    const audioTrack = streamRef.current?.getAudioTracks()[0];
    if (audioTrack) {
      audioTrack.enabled = isMuted;
      setIsMuted(!isMuted);
    }
  }

  // Toggle speaker
  function toggleSpeaker() {
    InCallManager.setSpeakerphoneOn(!isSpeaker);
    setIsSpeaker(!isSpeaker);
  }

  // End call
  async function endCall() {
    InCallManager.stop();
    pcRef.current?.close();
    streamRef.current?.getTracks().forEach((t) => t.stop());
    unsubsRef.current.forEach((u) => u());
    if (callId) {
      await updateDoc(doc(db, 'calls', callId), { status: 'ended' });
    }
    setCallState('ended');
  }

  return {
    callState, callId, isMuted, isSpeaker,
    startCall, answerCall, toggleMute, toggleSpeaker, endCall,
  };
}

8. Saving call history

WhatsApp's Calls tab shows a log of all calls. Save each call to a collection:

async function saveCallToHistory(callId, callData, duration) {
  // Save for the caller
  await addDoc(collection(db, 'users', callData.callerId, 'callHistory'), {
    callId: callId,
    otherUid: callData.calleeId,
    otherName: callData.calleeName || 'Unknown',
    type: callData.type,
    direction: 'outgoing',
    status: callData.status,   // 'ended', 'missed', 'declined'
    duration: duration,        // seconds
    timestamp: serverTimestamp(),
  });

  // Save for the callee
  await addDoc(collection(db, 'users', callData.calleeId, 'callHistory'), {
    callId: callId,
    otherUid: callData.callerId,
    otherName: callData.callerName,
    type: callData.type,
    direction: 'incoming',
    status: callData.status,
    duration: duration,
    timestamp: serverTimestamp(),
  });
}

9. Full runnable App.js — Production voice call screen

Copy this entire file and replace your App.js. It provides the complete voice call experience: outgoing call screen → ringing → active call with timer/mute/speaker → end. Test with two phones logged in as different users.

// App.js — Full runnable example: 1:1 Voice Call
import React, { useState, useEffect, useRef } from 'react';
import {
  View, Text, TextInput, Pressable, StyleSheet, Alert,
  Platform, PermissionsAndroid
} from 'react-native';
import {
  RTCPeerConnection, RTCSessionDescription, RTCIceCandidate, mediaDevices
} from 'react-native-webrtc';
import InCallManager from 'react-native-incall-manager';

import { initializeApp } from 'firebase/app';
import { getAuth, onAuthStateChanged } from 'firebase/auth';
import {
  getFirestore, doc, setDoc, getDoc, updateDoc, addDoc,
  collection, query, where, onSnapshot, serverTimestamp
} from 'firebase/firestore';

// ─── Firebase config ────────────────────────────────────────────────
const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',
  authDomain: 'YOUR_PROJECT.firebaseapp.com',
  projectId: 'YOUR_PROJECT_ID',
  storageBucket: 'YOUR_PROJECT.appspot.com',
  messagingSenderId: '123456789',
  appId: '1:123456789:web:abcdef',
};
const app = initializeApp(firebaseConfig);
const auth = getAuth(app);
const db = getFirestore(app);

const ICE_SERVERS = {
  iceServers: [
    { urls: 'stun:stun.l.google.com:19302' },
    { urls: 'stun:stun1.l.google.com:19302' },
  ],
};

// ─── Permissions ────────────────────────────────────────────────────
async function requestPermissions() {
  if (Platform.OS === 'android') {
    const grants = await PermissionsAndroid.requestMultiple([
      PermissionsAndroid.PERMISSIONS.RECORD_AUDIO,
    ]);
    return grants['android.permission.RECORD_AUDIO'] === 'granted';
  }
  return true;
}

// ─── Call Timer Hook ────────────────────────────────────────────────
function useCallTimer(isActive) {
  const [seconds, setSeconds] = useState(0);
  useEffect(() => {
    if (!isActive) { setSeconds(0); return; }
    const i = setInterval(() => setSeconds((s) => s + 1), 1000);
    return () => clearInterval(i);
  }, [isActive]);
  const m = Math.floor(seconds / 60);
  const s = seconds % 60;
  return `${m.toString().padStart(2, '0')}:${s.toString().padStart(2, '0')}`;
}

// ─── Main App ───────────────────────────────────────────────────────
export default function App() {
  const [user, setUser] = useState(null);
  const [screen, setScreen] = useState('home');
  const [calleeUid, setCalleeUid] = useState('');
  const [contactName, setContactName] = useState('');
  const [callState, setCallState] = useState('idle');
  const [isMuted, setIsMuted] = useState(false);
  const [isSpeaker, setIsSpeaker] = useState(false);
  const [incomingCall, setIncomingCall] = useState(null);

  const pcRef = useRef(null);
  const streamRef = useRef(null);
  const callIdRef = useRef(null);
  const unsubsRef = useRef([]);

  const timer = useCallTimer(callState === 'active');

  useEffect(() => {
    const unsub = onAuthStateChanged(auth, (u) => setUser(u));
    return unsub;
  }, []);

  // Listen for incoming calls
  useEffect(() => {
    if (!user) return;
    const q = query(
      collection(db, 'calls'),
      where('calleeId', '==', user.uid),
      where('status', '==', 'ringing')
    );
    const unsub = onSnapshot(q, (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') {
          const data = change.doc.data();
          setIncomingCall({ callId: change.doc.id, ...data });
          setContactName(data.callerName || 'Unknown');
          setScreen('incoming');
        }
      });
    });
    return unsub;
  }, [user]);

  // ── START CALL ──
  async function handleStartCall() {
    if (!calleeUid.trim()) { Alert.alert('Error', 'Enter UID'); return; }
    const ok = await requestPermissions();
    if (!ok) return;

    setScreen('call');
    setCallState('calling');

    const pc = new RTCPeerConnection(ICE_SERVERS);
    pcRef.current = pc;

    const stream = await mediaDevices.getUserMedia({ audio: true, video: false });
    streamRef.current = stream;
    stream.getTracks().forEach((track) => pc.addTrack(track, stream));

    pc.ontrack = () => {
      InCallManager.start({ media: 'audio' });
      setCallState('active');
    };

    pc.oniceconnectionstatechange = () => {
      if (pc.iceConnectionState === 'connected') {
        InCallManager.start({ media: 'audio' });
        setCallState('active');
      }
      if (pc.iceConnectionState === 'failed' || pc.iceConnectionState === 'closed') {
        handleEndCall();
      }
    };

    const callRef = doc(collection(db, 'calls'));
    callIdRef.current = callRef.id;

    pc.onicecandidate = (e) => {
      if (e.candidate) addDoc(collection(db, 'calls', callRef.id, 'callerCandidates'), e.candidate.toJSON());
    };

    const offer = await pc.createOffer();
    await pc.setLocalDescription(offer);

    const myName = user.displayName || user.email || 'Caller';
    setContactName(calleeUid.substring(0, 12));

    // Try to get callee name
    const calleeSnap = await getDoc(doc(db, 'users', calleeUid.trim()));
    if (calleeSnap.exists()) setContactName(calleeSnap.data().displayName || calleeUid);

    await setDoc(callRef, {
      callerId: user.uid,
      calleeId: calleeUid.trim(),
      callerName: myName,
      type: 'audio',
      status: 'ringing',
      offer: { type: offer.type, sdp: offer.sdp },
      answer: null,
      createdAt: serverTimestamp(),
    });

    const unsubCall = onSnapshot(doc(db, 'calls', callRef.id), (snap) => {
      const data = snap.data();
      if (!data) return;
      if (data.answer && !pc.remoteDescription) {
        pc.setRemoteDescription(new RTCSessionDescription(data.answer));
      }
      if (data.status === 'ended' || data.status === 'declined') handleEndCall();
    });

    const unsubCands = onSnapshot(collection(db, 'calls', callRef.id, 'calleeCandidates'), (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
      });
    });

    unsubsRef.current = [unsubCall, unsubCands];

    setTimeout(async () => {
      const snap = await getDoc(doc(db, 'calls', callRef.id));
      if (snap.exists() && snap.data().status === 'ringing') {
        await updateDoc(doc(db, 'calls', callRef.id), { status: 'missed' });
        handleEndCall();
      }
    }, 30000);
  }

  // ── ANSWER CALL ──
  async function handleAnswerCall() {
    if (!incomingCall) return;
    const ok = await requestPermissions();
    if (!ok) return;

    setScreen('call');
    setCallState('connecting');

    const { callId, offer } = incomingCall;
    callIdRef.current = callId;

    const pc = new RTCPeerConnection(ICE_SERVERS);
    pcRef.current = pc;

    const stream = await mediaDevices.getUserMedia({ audio: true, video: false });
    streamRef.current = stream;
    stream.getTracks().forEach((track) => pc.addTrack(track, stream));

    pc.ontrack = () => {
      InCallManager.start({ media: 'audio' });
      setCallState('active');
    };

    pc.oniceconnectionstatechange = () => {
      if (pc.iceConnectionState === 'connected') {
        InCallManager.start({ media: 'audio' });
        setCallState('active');
      }
      if (pc.iceConnectionState === 'failed') handleEndCall();
    };

    pc.onicecandidate = (e) => {
      if (e.candidate) addDoc(collection(db, 'calls', callId, 'calleeCandidates'), e.candidate.toJSON());
    };

    await pc.setRemoteDescription(new RTCSessionDescription(offer));
    const answer = await pc.createAnswer();
    await pc.setLocalDescription(answer);

    await updateDoc(doc(db, 'calls', callId), {
      answer: { type: answer.type, sdp: answer.sdp },
      status: 'active',
    });

    const unsubCands = onSnapshot(collection(db, 'calls', callId, 'callerCandidates'), (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
      });
    });

    const unsubCall = onSnapshot(doc(db, 'calls', callId), (snap) => {
      const data = snap.data();
      if (data && data.status === 'ended') handleEndCall();
    });

    unsubsRef.current = [unsubCands, unsubCall];
    setIncomingCall(null);
  }

  // ── DECLINE ──
  async function handleDecline() {
    if (incomingCall) {
      await updateDoc(doc(db, 'calls', incomingCall.callId), { status: 'declined' });
    }
    setIncomingCall(null);
    setScreen('home');
    setCallState('idle');
  }

  // ── END CALL ──
  async function handleEndCall() {
    InCallManager.stop();
    pcRef.current?.close();
    pcRef.current = null;
    streamRef.current?.getTracks().forEach((t) => t.stop());
    streamRef.current = null;
    unsubsRef.current.forEach((u) => u());
    unsubsRef.current = [];

    if (callIdRef.current) {
      try { await updateDoc(doc(db, 'calls', callIdRef.current), { status: 'ended' }); } catch (e) {}
    }
    callIdRef.current = null;
    setCallState('idle');
    setIsMuted(false);
    setIsSpeaker(false);
    setScreen('home');
    setIncomingCall(null);
  }

  // ── MUTE / SPEAKER ──
  function handleToggleMute() {
    const track = streamRef.current?.getAudioTracks()[0];
    if (track) { track.enabled = isMuted; setIsMuted(!isMuted); }
  }

  function handleToggleSpeaker() {
    InCallManager.setSpeakerphoneOn(!isSpeaker);
    setIsSpeaker(!isSpeaker);
  }

  // ── RENDER ──
  if (!user) {
    return (
      <View style={[styles.container, styles.center]}>
        <Text style={styles.infoText}>Please log in (Module 3 Lesson 2)</Text>
      </View>
    );
  }

  // HOME SCREEN
  if (screen === 'home') {
    return (
      <View style={styles.container}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>Voice Call</Text>
          <Text style={styles.headerSub}>UID: {user.uid.substring(0, 16)}...</Text>
        </View>
        <View style={styles.homeContent}>
          <Text style={styles.label}>Call someone (paste their UID):</Text>
          <TextInput
            style={styles.input}
            value={calleeUid}
            onChangeText={setCalleeUid}
            placeholder="Other user's UID"
            autoCapitalize="none"
          />
          <Pressable style={styles.callButton} onPress={handleStartCall}>
            <Text style={styles.callButtonText}>📞 Voice Call</Text>
          </Pressable>
        </View>
      </View>
    );
  }

  // INCOMING CALL SCREEN
  if (screen === 'incoming') {
    return (
      <View style={styles.callScreen}>
        <View style={styles.callInfo}>
          <View style={styles.bigAvatar}>
            <Text style={styles.bigAvatarText}>{contactName.charAt(0).toUpperCase()}</Text>
          </View>
          <Text style={styles.callName}>{contactName}</Text>
          <Text style={styles.callStatus}>Incoming voice call...</Text>
        </View>
        <View style={styles.incomingBtns}>
          <Pressable style={styles.declineBtn} onPress={handleDecline}>
            <Text style={styles.btnIcon}>✕</Text>
            <Text style={styles.btnLabel}>Decline</Text>
          </Pressable>
          <Pressable style={styles.acceptBtn} onPress={handleAnswerCall}>
            <Text style={styles.btnIcon}>📞</Text>
            <Text style={styles.btnLabel}>Accept</Text>
          </Pressable>
        </View>
      </View>
    );
  }

  // ACTIVE / CALLING SCREEN
  return (
    <View style={styles.callScreen}>
      <View style={styles.callInfo}>
        <View style={styles.bigAvatar}>
          <Text style={styles.bigAvatarText}>{contactName.charAt(0).toUpperCase()}</Text>
        </View>
        <Text style={styles.callName}>{contactName}</Text>
        <Text style={styles.callStatus}>
          {callState === 'calling' && 'Calling...'}
          {callState === 'connecting' && 'Connecting...'}
          {callState === 'active' && timer}
        </Text>
      </View>

      <View style={styles.controls}>
        <Pressable
          style={[styles.ctrlBtn, isMuted && styles.ctrlActive]}
          onPress={handleToggleMute}
        >
          <Text style={styles.ctrlIcon}>{isMuted ? '🔇' : '🎤'}</Text>
          <Text style={styles.ctrlLabel}>{isMuted ? 'Unmute' : 'Mute'}</Text>
        </Pressable>

        <Pressable
          style={[styles.ctrlBtn, isSpeaker && styles.ctrlActive]}
          onPress={handleToggleSpeaker}
        >
          <Text style={styles.ctrlIcon}>{isSpeaker ? '🔊' : '🔈'}</Text>
          <Text style={styles.ctrlLabel}>{isSpeaker ? 'Earpiece' : 'Speaker'}</Text>
        </Pressable>

        <Pressable style={styles.endCallBtn} onPress={handleEndCall}>
          <Text style={styles.ctrlIcon}>📵</Text>
          <Text style={styles.ctrlLabel}>End</Text>
        </Pressable>
      </View>
    </View>
  );
}

10. Testing your voice call

  1. Install the app on two phones (or phone + emulator with mic)
  2. Log in as different Firebase users on each device
  3. On Phone A: copy Phone B's UID and paste it in the input
  4. Phone A taps "Voice Call"
  5. Phone B sees incoming call screen with Phone A's name
  6. Phone B taps "Accept"
  7. Both phones show active call screen with timer counting
  8. Speak — you should hear each other
  9. Test Mute — other side goes silent
  10. Test Speaker — audio switches to loudspeaker
  11. Tap End — both phones return to home
