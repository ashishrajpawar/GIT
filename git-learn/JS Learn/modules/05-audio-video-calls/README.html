Module 5

Audio & Video Calls

8 lessons — complete ~2 weeks Unlocks after Module 4
Goal of this module

Build real voice and video calling using WebRTC — the exact same technology WhatsApp, Signal, Google Meet, and FaceTime are built on. No third-party SDK. Works on both Android and iOS. Free forever.

How it works

WebRTC creates a direct peer-to-peer connection between two phones so audio and video data flows straight between them — not through your server. This is why WhatsApp calls are end-to-end encrypted by default.

Your stack for calls:

Piece What it does Tool
WebRTC The actual audio/video stream react-native-webrtc
Signaling Exchanges connection info before the call starts Firebase Firestore (already in your stack)
STUN server Helps phones find each other's IP across routers Google's free STUN (stun.l.google.com)
TURN server Relay fallback when direct P2P fails coturn — free, open source, self-hosted
EAS Build required — not Expo Go

react-native-webrtc includes native code (C++ for Android, Objective-C for iOS). The standard Expo Go app cannot run native modules. You will use EAS Build — Expo's cloud build service — to produce a custom development build that includes WebRTC. You keep all Expo benefits; you just run one command to build instead of scanning a QR code.

Android vs iOS — what's different

Android iOS
Call while app open Works with WebRTC Works with WebRTC
Incoming call (app closed) FCM push + foreground service VoIP push (APNs) + CallKit
Native call screen UI Custom (you build it) CallKit (system UI, required by Apple)
Publishing cost $25 one-time (Play Store) $99/year (Apple Developer)
