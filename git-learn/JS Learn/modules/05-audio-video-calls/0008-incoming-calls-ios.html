Audio & Video Calls · Lesson 8

Incoming Calls on iOS

CallKit · VoIP push · APNs · react-native-callkeep · Native call screen ~60 min Hands-on
Why this matters for your WhatsApp clone

Apple requires all VoIP apps to use CallKit. If you don't, Apple will reject your app from the App Store. CallKit gives you the native iOS call screen — the same green/red slide-to-answer UI that regular phone calls use. Combined with VoIP push notifications (a special type of APNs push), your app can wake from a completely closed state and show the incoming call screen instantly — even faster than regular push notifications. This is how WhatsApp, Signal, and Telegram handle calls on iPhone.

1. How iOS incoming calls differ from Android

Android (Lesson 7) iOS (This Lesson)
Push type FCM data message VoIP push (APNs)
Call UI Custom notification (you build it) System CallKit UI (Apple builds it)
Wake from killed FCM + foreground service VoIP push wakes app instantly
Mandatory? No (but strongly recommended) Yes — Apple rejects apps without CallKit
Lock screen Full-screen intent Native call screen (slide to answer)
Integrations None built-in Recents app, Contacts, Siri ("Call Rahul on WhatsApp")
VoIP push is special

Regular APNs push notifications may be delayed or batched by iOS to save battery. VoIP push is a separate, high-priority channel — it wakes your app immediately, even if the app was force-quit. Apple only allows VoIP push for actual call notifications (not chat messages). If you misuse it, Apple will revoke your VoIP push certificate.

2. What is CallKit?

CallKit is Apple's framework that integrates your VoIP app with the native phone experience:

  • Native incoming call screen — the same green slide-to-answer UI as regular calls
  • Recents integration — your calls appear in the Phone app's Recents tab
  • Do Not Disturb — respects the user's DND settings and favourites
  • Car Bluetooth — incoming calls work through CarPlay and car audio
  • Siri — "Hey Siri, call Rahul on WhatsApp"
  • Audio session management — iOS automatically pauses music, handles interruptions

You don't build a custom incoming call screen on iOS — Apple gives you the system one. Your app only controls what happens after the user answers.

4. Setting up CallKit in your app

Initialize CallKit when your app starts:

import RNCallKeep from 'react-native-callkeep';

// Call this once at app startup
async function setupCallKit() {
  const options = {
    ios: {
      appName: 'WhatsApp Clone',
      supportsVideo: true,
      maximumCallGroups: 1,
      maximumCallsPerCallGroup: 1,
      ringtoneSound: 'ringtone.caf',   // Custom sound in iOS bundle
    },
    android: {
      alertTitle: 'Permissions required',
      alertDescription: 'This app needs phone account access',
    },
  };

  try {
    await RNCallKeep.setup(options);
    RNCallKeep.setAvailable(true);   // Tell iOS your app is ready for calls
  } catch (error) {
    console.error('CallKit setup failed:', error);
  }
}

5. VoIP push certificate — Apple Developer setup

VoIP push uses a separate certificate from regular push notifications. Here's how to get it:

  1. Log in to developer.apple.com/account
  2. Go to Certificates, Identifiers & Profiles
  3. Click + to create a new certificate
  4. Select VoIP Services Certificate
  5. Choose your app's App ID (the Bundle Identifier from your app.json)
  6. Generate and download the .cer file
  7. Double-click to install it in Keychain Access
  8. Export as .p12 from Keychain Access (you'll need this for your server)
Apple Developer account required

You need an Apple Developer account ($99/year) to create VoIP push certificates and publish to the App Store. This is the same account you need for publishing (Module 6). There is no free alternative for VoIP push.

6. Getting the VoIP push token

Just like FCM tokens on Android, each iOS device has a VoIP push token. Save it to Firestore:

import RNCallKeep from 'react-native-callkeep';
import { Platform } from 'react-native';
import VoipPushNotification from 'react-native-voip-push-notification';

async function registerVoIPPush(uid) {
  if (Platform.OS !== 'ios') return;

  // Register for VoIP push
  VoipPushNotification.requestPermissions();

  VoipPushNotification.addEventListener('register', async (token) => {
    console.log('VoIP push token:', token);
    // Save to Firestore
    await updateDoc(doc(db, 'users', uid), {
      voipToken: token,
      platform: 'ios',
    });
  });

  // This fires when a VoIP push arrives
  VoipPushNotification.addEventListener('notification', (notification) => {
    const callId = notification.callId;
    const callerName = notification.callerName;
    const callType = notification.callType;
    const uuid = notification.uuid;   // Unique call identifier

    // Display the native CallKit incoming call screen
    RNCallKeep.displayIncomingCall(
      uuid,
      callerName,           // Handle (shown on call screen)
      callerName,           // Display name
      'generic',            // Handle type
      callType === 'video'  // Has video
    );
  });
}

7. The Cloud Function — sending VoIP push to iOS

Your Cloud Function (from Lesson 7) needs to detect iOS users and send a VoIP push instead of FCM. Apple's VoIP push uses HTTP/2 to api.push.apple.com:

// functions/index.js — updated to handle both Android and iOS
const functions = require('firebase-functions');
const admin = require('firebase-admin');
const apn = require('apn');   // npm install apn
admin.initializeApp();

// Configure APNs provider (VoIP push)
const apnProvider = new apn.Provider({
  cert: './certs/voip_cert.pem',     // Your VoIP certificate
  key: './certs/voip_key.pem',       // Your VoIP private key
  production: false,                  // true for App Store builds
});

exports.onCallCreated = functions.firestore
  .document('calls/{callId}')
  .onCreate(async (snap, context) => {
    const callData = snap.data();
    const callId = context.params.callId;
    if (callData.status !== 'ringing') return null;

    // Get callee's info
    const calleeDoc = await admin.firestore()
      .collection('users')
      .doc(callData.calleeId)
      .get();

    if (!calleeDoc.exists) return null;
    const calleeData = calleeDoc.data();

    if (calleeData.platform === 'ios' && calleeData.voipToken) {
      // ── iOS: Send VoIP push via APNs ──
      const notification = new apn.Notification();
      notification.topic = 'com.yourapp.bundleid.voip';  // Bundle ID + ".voip"
      notification.expiry = Math.floor(Date.now() / 1000) + 30;
      notification.pushType = 'voip';
      notification.priority = 10;   // Immediate delivery
      notification.payload = {
        callId: callId,
        callerName: callData.callerName || 'Unknown',
        callerId: callData.callerId,
        callType: callData.type,
        uuid: generateUUID(),   // Unique ID for CallKit
      };

      await apnProvider.send(notification, calleeData.voipToken);
      console.log('VoIP push sent to iOS device');

    } else if (calleeData.fcmToken) {
      // ── Android: Send FCM data message (same as Lesson 7) ──
      await admin.messaging().send({
        token: calleeData.fcmToken,
        data: {
          type: 'incoming_call',
          callId: callId,
          callerName: callData.callerName || 'Unknown',
          callerId: callData.callerId,
          callType: callData.type,
        },
        android: { priority: 'high', ttl: 30000 },
      });
      console.log('FCM push sent to Android device');
    }

    return null;
  });

function generateUUID() {
  return 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'.replace(/[xy]/g, (c) => {
    const r = Math.random() * 16 | 0;
    const v = c === 'x' ? r : (r & 0x3 | 0x8);
    return v.toString(16);
  });
}

8. Handling CallKit events

When the user interacts with the native call screen (answer, end, mute), CallKit fires events. Handle them to connect your WebRTC call:

import RNCallKeep from 'react-native-callkeep';

function setupCallKitListeners(navigation) {

  // User tapped ANSWER on the native call screen
  RNCallKeep.addEventListener('answerCall', ({ callUUID }) => {
    console.log('Call answered:', callUUID);
    // Navigate to your call screen and start WebRTC
    // The callId is stored when displayIncomingCall was called
    connectWebRTCCall(callUUID);
  });

  // User tapped END (decline or hang up)
  RNCallKeep.addEventListener('endCall', ({ callUUID }) => {
    console.log('Call ended:', callUUID);
    // Decline or end the call in Firestore
    declineOrEndCall(callUUID);
  });

  // User toggled mute from the native call screen
  RNCallKeep.addEventListener('didPerformSetMutedCallAction', ({ muted, callUUID }) => {
    // Mute/unmute the audio track
    const track = streamRef.current?.getAudioTracks()[0];
    if (track) track.enabled = !muted;
  });

  // User toggled hold
  RNCallKeep.addEventListener('didToggleHoldCallAction', ({ hold, callUUID }) => {
    // Pause/resume the stream
    streamRef.current?.getTracks().forEach((t) => { t.enabled = !hold; });
  });

  // Audio route changed (speaker/earpiece/bluetooth)
  RNCallKeep.addEventListener('didChangeAudioRoute', ({ output }) => {
    console.log('Audio route:', output);  // 'Speaker', 'Receiver', 'Bluetooth'
  });
}

9. Reporting call state to CallKit

You must tell CallKit when the call connects, ends, or fails — otherwise the native UI won't update correctly:

// When WebRTC connects (ICE state = connected):
RNCallKeep.reportConnectedOutgoingCallWithUUID(callUUID);
// or for incoming:
RNCallKeep.reportConnectingOutgoingCallWithUUID(callUUID);

// When the call ends (from either side):
RNCallKeep.endCall(callUUID);

// When starting an outgoing call (shows "Calling..." in native UI):
RNCallKeep.startCall(callUUID, contactName, contactName, 'generic', hasVideo);

// When the remote side answers your outgoing call:
RNCallKeep.reportConnectedOutgoingCallWithUUID(callUUID);

Important: If you don't call RNCallKeep.endCall(), the native call screen will stay visible even after your app's call ends. Always call it in your handleEndCall function.

8 Both phones are in the active call Both phones

11. Mapping callUUID to callId

CallKit uses UUIDs to identify calls. Your Firestore uses callId document IDs. You need a mapping between them so you know which Firestore call to answer when CallKit fires answerCall:

// Simple in-memory map — works because the app is alive during the call
const callMap = {};   // { uuid: callId }

// When VoIP push arrives and you display the call:
VoipPushNotification.addEventListener('notification', (notification) => {
  const uuid = notification.uuid || generateUUID();
  const callId = notification.callId;

  // Store the mapping
  callMap[uuid] = callId;

  RNCallKeep.displayIncomingCall(uuid, notification.callerName, notification.callerName, 'generic', notification.callType === 'video');
});

// When user answers:
RNCallKeep.addEventListener('answerCall', async ({ callUUID }) => {
  const callId = callMap[callUUID];
  if (callId) {
    // Fetch call doc and connect WebRTC (same as Lesson 6 handleAnswerCall)
    const callSnap = await getDoc(doc(db, 'calls', callId));
    if (callSnap.exists()) {
      await answerWebRTCCall(callId, callSnap.data());
    }
  }
});

// When call ends — clean up
RNCallKeep.addEventListener('endCall', async ({ callUUID }) => {
  const callId = callMap[callUUID];
  if (callId) {
    await updateDoc(doc(db, 'calls', callId), { status: 'declined' });
    delete callMap[callUUID];
  }
});

12. Platform-aware code — handling both Android and iOS

Your final app needs to handle both platforms. Here's the pattern:

import { Platform } from 'react-native';

async function registerForPush(uid) {
  if (Platform.OS === 'android') {
    // Android: save FCM token (Lesson 7)
    await saveFCMToken(uid);
  } else {
    // iOS: register VoIP push + save token
    await registerVoIPPush(uid);
  }
}

// In your App startup:
useEffect(() => {
  if (user) {
    registerForPush(user.uid);
    if (Platform.OS === 'ios') {
      setupCallKit();
      setupCallKitListeners();
    }
  }
}, [user]);

For outgoing calls on iOS, also integrate with CallKit:

async function handleStartCall() {
  // ... existing code to create offer and write to Firestore ...

  if (Platform.OS === 'ios') {
    // Tell CallKit about the outgoing call
    const uuid = generateUUID();
    callMap[uuid] = callRef.id;
    RNCallKeep.startCall(uuid, contactName, contactName, 'generic', true);

    // When WebRTC connects:
    pc.oniceconnectionstatechange = () => {
      if (pc.iceConnectionState === 'connected') {
        RNCallKeep.reportConnectedOutgoingCallWithUUID(uuid);
        setCallState('active');
      }
    };
  }
}

13. Full runnable App.js — iOS incoming calls with CallKit

This example focuses on the iOS-specific CallKit integration. It builds on Lesson 7's code, adding VoIP push handling and CallKit. Copy both files.

index.js — Entry point (handles both platforms)

// index.js — App entry point with platform-specific call handling
import { AppRegistry, Platform } from 'react-native';
import App from './App';

if (Platform.OS === 'android') {
  // Android: FCM background handler (same as Lesson 7)
  const messaging = require('@react-native-firebase/messaging').default;
  const notifee = require('@notifee/react-native').default;
  const { AndroidImportance, AndroidCategory, EventType } = require('@notifee/react-native');

  messaging().setBackgroundMessageHandler(async (remoteMessage) => {
    const data = remoteMessage.data;
    if (data?.type === 'incoming_call') {
      const channelId = await notifee.createChannel({
        id: 'incoming_calls', name: 'Incoming Calls',
        importance: AndroidImportance.HIGH, vibration: true,
      });
      await notifee.displayNotification({
        title: data.callerName || 'Incoming Call',
        body: data.callType === 'video' ? 'Incoming video call' : 'Incoming voice call',
        android: {
          channelId, category: AndroidCategory.CALL,
          asForegroundService: true, ongoing: true,
          fullScreenAction: { id: 'default', launchActivity: 'default' },
          actions: [
            { title: 'Decline', pressAction: { id: 'decline' } },
            { title: 'Accept', pressAction: { id: 'accept', launchActivity: 'default' } },
          ],
        },
        data: { callId: data.callId, callerName: data.callerName, callType: data.callType },
      });
    }
  });

  notifee.onBackgroundEvent(async ({ type, detail }) => {
    if (type === EventType.ACTION_PRESS && detail.pressAction.id === 'decline') {
      const callId = detail.notification?.data?.callId;
      if (callId) {
        const { getFirestore, doc, updateDoc } = require('firebase/firestore');
        const db = getFirestore();
        await updateDoc(doc(db, 'calls', callId), { status: 'declined' });
      }
      await notifee.cancelAllNotifications();
    }
  });

  notifee.registerForegroundService(() => new Promise((resolve) => setTimeout(resolve, 30000)));
}

if (Platform.OS === 'ios') {
  // iOS: VoIP push handler
  const VoipPushNotification = require('react-native-voip-push-notification').default;
  const RNCallKeep = require('react-native-callkeep').default;

  // Must register early (before app renders)
  VoipPushNotification.requestPermissions();

  VoipPushNotification.addEventListener('notification', (notification) => {
    const uuid = notification.uuid || generateUUID();
    const callerName = notification.callerName || 'Unknown';
    const hasVideo = notification.callType === 'video';

    // Show native iOS call screen
    RNCallKeep.displayIncomingCall(uuid, callerName, callerName, 'generic', hasVideo);

    // Store mapping for later (app-level storage)
    global.__incomingCallMap = global.__incomingCallMap || {};
    global.__incomingCallMap[uuid] = {
      callId: notification.callId,
      callerName: callerName,
      callType: notification.callType,
    };
  });

  function generateUUID() {
    return 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'.replace(/[xy]/g, (c) => {
      const r = Math.random() * 16 | 0;
      return (c === 'x' ? r : (r & 0x3 | 0x8)).toString(16);
    });
  }
}

App.js — Main component with CallKit integration

// App.js — Video call with CallKit support (iOS) + Notifee (Android)
import React, { useState, useEffect, useRef } from 'react';
import {
  View, Text, TextInput, Pressable, StyleSheet, Alert, Platform
} from 'react-native';
import {
  RTCPeerConnection, RTCSessionDescription, RTCIceCandidate,
  mediaDevices, RTCView
} from 'react-native-webrtc';
import InCallManager from 'react-native-incall-manager';
import RNCallKeep from 'react-native-callkeep';

import { initializeApp } from 'firebase/app';
import { getAuth, onAuthStateChanged } from 'firebase/auth';
import {
  getFirestore, doc, setDoc, getDoc, updateDoc, addDoc,
  collection, query, where, onSnapshot, serverTimestamp
} from 'firebase/firestore';

// ─── Firebase config ────────────────────────────────────────────────
const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',
  authDomain: 'YOUR_PROJECT.firebaseapp.com',
  projectId: 'YOUR_PROJECT_ID',
  storageBucket: 'YOUR_PROJECT.appspot.com',
  messagingSenderId: '123456789',
  appId: '1:123456789:web:abcdef',
};
const app = initializeApp(firebaseConfig);
const auth = getAuth(app);
const db = getFirestore(app);

const ICE_SERVERS = {
  iceServers: [
    { urls: 'stun:stun.l.google.com:19302' },
    { urls: 'stun:stun1.l.google.com:19302' },
  ],
};

// ─── CallKit Setup (iOS only) ──────────────────────────────────────
async function initCallKit() {
  if (Platform.OS !== 'ios') return;
  await RNCallKeep.setup({
    ios: {
      appName: 'WhatsApp Clone',
      supportsVideo: true,
      maximumCallGroups: 1,
      maximumCallsPerCallGroup: 1,
    },
  });
  RNCallKeep.setAvailable(true);
}

// ─── Call Timer ─────────────────────────────────────────────────────
function useCallTimer(isActive) {
  const [seconds, setSeconds] = useState(0);
  useEffect(() => {
    if (!isActive) { setSeconds(0); return; }
    const i = setInterval(() => setSeconds((s) => s + 1), 1000);
    return () => clearInterval(i);
  }, [isActive]);
  const m = Math.floor(seconds / 60);
  const s = seconds % 60;
  return `${m.toString().padStart(2, '0')}:${s.toString().padStart(2, '0')}`;
}

// ─── Main App ───────────────────────────────────────────────────────
export default function App() {
  const [user, setUser] = useState(null);
  const [screen, setScreen] = useState('home');
  const [calleeUid, setCalleeUid] = useState('');
  const [contactName, setContactName] = useState('');
  const [callState, setCallState] = useState('idle');
  const [isMuted, setIsMuted] = useState(false);
  const [localStreamURL, setLocalStreamURL] = useState(null);
  const [remoteStreamURL, setRemoteStreamURL] = useState(null);
  const [incomingCall, setIncomingCall] = useState(null);

  const pcRef = useRef(null);
  const streamRef = useRef(null);
  const callIdRef = useRef(null);
  const callUUIDRef = useRef(null);
  const unsubsRef = useRef([]);

  const timer = useCallTimer(callState === 'active');

  // Auth + CallKit init
  useEffect(() => {
    initCallKit();
    const unsub = onAuthStateChanged(auth, (u) => setUser(u));
    return unsub;
  }, []);

  // ★ iOS CallKit event listeners
  useEffect(() => {
    if (Platform.OS !== 'ios') return;

    // User answered from native call screen
    const answerListener = RNCallKeep.addEventListener('answerCall', async ({ callUUID }) => {
      const callMap = global.__incomingCallMap || {};
      const callInfo = callMap[callUUID];
      if (callInfo) {
        callUUIDRef.current = callUUID;
        setContactName(callInfo.callerName);
        // Fetch call data and answer
        const callSnap = await getDoc(doc(db, 'calls', callInfo.callId));
        if (callSnap.exists()) {
          setIncomingCall({ callId: callInfo.callId, ...callSnap.data() });
          setScreen('call');
          // handleAnswerCall will be triggered by the state change
        }
        delete callMap[callUUID];
      }
    });

    // User declined from native call screen
    const endListener = RNCallKeep.addEventListener('endCall', async ({ callUUID }) => {
      const callMap = global.__incomingCallMap || {};
      const callInfo = callMap[callUUID];
      if (callInfo) {
        await updateDoc(doc(db, 'calls', callInfo.callId), { status: 'declined' });
        delete callMap[callUUID];
      }
      // Also end any active call
      handleEndCall();
    });

    // User toggled mute from native UI
    const muteListener = RNCallKeep.addEventListener('didPerformSetMutedCallAction', ({ muted }) => {
      const track = streamRef.current?.getAudioTracks()[0];
      if (track) { track.enabled = !muted; setIsMuted(muted); }
    });

    return () => {
      answerListener?.remove?.();
      endListener?.remove?.();
      muteListener?.remove?.();
    };
  }, []);

  // Firestore listener for incoming calls (foreground fallback)
  useEffect(() => {
    if (!user) return;
    const q = query(
      collection(db, 'calls'),
      where('calleeId', '==', user.uid),
      where('status', '==', 'ringing')
    );
    const unsub = onSnapshot(q, (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') {
          const data = change.doc.data();
          setIncomingCall({ callId: change.doc.id, ...data });
          setContactName(data.callerName || 'Unknown');

          if (Platform.OS === 'ios') {
            // Show native call screen (if not already shown by VoIP push)
            const uuid = generateUUID();
            callUUIDRef.current = uuid;
            global.__incomingCallMap = global.__incomingCallMap || {};
            global.__incomingCallMap[uuid] = { callId: change.doc.id, callerName: data.callerName, callType: data.type };
            RNCallKeep.displayIncomingCall(uuid, data.callerName, data.callerName, 'generic', data.type === 'video');
          } else {
            setScreen('incoming');
          }
        }
      });
    });
    return unsub;
  }, [user]);

  // ── START CALL ──
  async function handleStartCall() {
    if (!calleeUid.trim()) { Alert.alert('Error', 'Enter UID'); return; }

    setScreen('call');
    setCallState('calling');

    const pc = new RTCPeerConnection(ICE_SERVERS);
    pcRef.current = pc;

    const stream = await mediaDevices.getUserMedia({ audio: true, video: { facingMode: 'user' } });
    streamRef.current = stream;
    setLocalStreamURL(stream.toURL());
    stream.getTracks().forEach((track) => pc.addTrack(track, stream));

    // iOS: report outgoing call to CallKit
    if (Platform.OS === 'ios') {
      const uuid = generateUUID();
      callUUIDRef.current = uuid;
      RNCallKeep.startCall(uuid, contactName || calleeUid, contactName || calleeUid, 'generic', true);
    }

    pc.ontrack = (event) => {
      if (event.streams?.[0]) {
        setRemoteStreamURL(event.streams[0].toURL());
        InCallManager.start({ media: 'video' });
        setCallState('active');
        // Tell CallKit the call connected
        if (Platform.OS === 'ios' && callUUIDRef.current) {
          RNCallKeep.reportConnectedOutgoingCallWithUUID(callUUIDRef.current);
        }
      }
    };

    pc.oniceconnectionstatechange = () => {
      if (pc.iceConnectionState === 'failed') handleEndCall();
    };

    const callRef = doc(collection(db, 'calls'));
    callIdRef.current = callRef.id;

    pc.onicecandidate = (e) => {
      if (e.candidate) addDoc(collection(db, 'calls', callRef.id, 'callerCandidates'), e.candidate.toJSON());
    };

    const offer = await pc.createOffer();
    await pc.setLocalDescription(offer);

    const myName = user.displayName || user.email || 'Caller';
    const calleeSnap = await getDoc(doc(db, 'users', calleeUid.trim()));
    setContactName(calleeSnap.exists() ? calleeSnap.data().displayName || calleeUid : calleeUid);

    await setDoc(callRef, {
      callerId: user.uid,
      calleeId: calleeUid.trim(),
      callerName: myName,
      type: 'video',
      status: 'ringing',
      offer: { type: offer.type, sdp: offer.sdp },
      answer: null,
      createdAt: serverTimestamp(),
    });

    const unsubCall = onSnapshot(doc(db, 'calls', callRef.id), (snap) => {
      const data = snap.data();
      if (!data) return;
      if (data.answer && !pc.remoteDescription) pc.setRemoteDescription(new RTCSessionDescription(data.answer));
      if (data.status === 'ended' || data.status === 'declined') handleEndCall();
    });

    const unsubCands = onSnapshot(collection(db, 'calls', callRef.id, 'calleeCandidates'), (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
      });
    });

    unsubsRef.current = [unsubCall, unsubCands];

    setTimeout(async () => {
      const snap = await getDoc(doc(db, 'calls', callRef.id));
      if (snap.exists() && snap.data().status === 'ringing') {
        await updateDoc(doc(db, 'calls', callRef.id), { status: 'missed' });
        handleEndCall();
      }
    }, 30000);
  }

  // ── ANSWER CALL ──
  async function handleAnswerCall() {
    if (!incomingCall) return;
    setScreen('call');
    setCallState('connecting');

    const { callId, offer } = incomingCall;
    callIdRef.current = callId;

    const pc = new RTCPeerConnection(ICE_SERVERS);
    pcRef.current = pc;

    const stream = await mediaDevices.getUserMedia({ audio: true, video: { facingMode: 'user' } });
    streamRef.current = stream;
    setLocalStreamURL(stream.toURL());
    stream.getTracks().forEach((track) => pc.addTrack(track, stream));

    pc.ontrack = (event) => {
      if (event.streams?.[0]) {
        setRemoteStreamURL(event.streams[0].toURL());
        InCallManager.start({ media: 'video' });
        setCallState('active');
      }
    };

    pc.oniceconnectionstatechange = () => {
      if (pc.iceConnectionState === 'failed') handleEndCall();
    };

    pc.onicecandidate = (e) => {
      if (e.candidate) addDoc(collection(db, 'calls', callId, 'calleeCandidates'), e.candidate.toJSON());
    };

    await pc.setRemoteDescription(new RTCSessionDescription(offer));
    const answer = await pc.createAnswer();
    await pc.setLocalDescription(answer);

    await updateDoc(doc(db, 'calls', callId), {
      answer: { type: answer.type, sdp: answer.sdp },
      status: 'active',
    });

    const unsubCands = onSnapshot(collection(db, 'calls', callId, 'callerCandidates'), (snap) => {
      snap.docChanges().forEach((change) => {
        if (change.type === 'added') pc.addIceCandidate(new RTCIceCandidate(change.doc.data()));
      });
    });

    const unsubCall = onSnapshot(doc(db, 'calls', callId), (snap) => {
      const data = snap.data();
      if (data && data.status === 'ended') handleEndCall();
    });

    unsubsRef.current = [unsubCands, unsubCall];
    setIncomingCall(null);
  }

  // ── END CALL ──
  async function handleEndCall() {
    InCallManager.stop();
    pcRef.current?.close();
    pcRef.current = null;
    streamRef.current?.getTracks().forEach((t) => t.stop());
    streamRef.current = null;
    unsubsRef.current.forEach((u) => u());
    unsubsRef.current = [];

    if (callIdRef.current) {
      try { await updateDoc(doc(db, 'calls', callIdRef.current), { status: 'ended' }); } catch (e) {}
    }

    // ★ Tell CallKit the call ended
    if (Platform.OS === 'ios' && callUUIDRef.current) {
      RNCallKeep.endCall(callUUIDRef.current);
      callUUIDRef.current = null;
    }

    callIdRef.current = null;
    setCallState('idle');
    setIsMuted(false);
    setLocalStreamURL(null);
    setRemoteStreamURL(null);
    setScreen('home');
    setIncomingCall(null);
  }

  // ── DECLINE (Android in-app UI) ──
  async function handleDecline() {
    if (incomingCall) {
      await updateDoc(doc(db, 'calls', incomingCall.callId), { status: 'declined' });
    }
    if (Platform.OS === 'ios' && callUUIDRef.current) {
      RNCallKeep.endCall(callUUIDRef.current);
      callUUIDRef.current = null;
    }
    setIncomingCall(null);
    setScreen('home');
    setCallState('idle');
  }

  // ── MUTE ──
  function handleToggleMute() {
    const track = streamRef.current?.getAudioTracks()[0];
    if (track) { track.enabled = isMuted; setIsMuted(!isMuted); }
    // CallKit reflects mute state automatically via didPerformSetMutedCallAction
  }

  // ── RENDER ──
  if (!user) {
    return (
      <View style={[styles.container, styles.center]}>
        <Text style={styles.infoText}>Please log in (Module 3 Lesson 2)</Text>
      </View>
    );
  }

  if (screen === 'home') {
    return (
      <View style={styles.container}>
        <View style={styles.header}>
          <Text style={styles.headerTitle}>Video Call</Text>
          <Text style={styles.headerSub}>UID: {user.uid.substring(0, 16)}...</Text>
        </View>
        <View style={styles.homeContent}>
          <Text style={styles.label}>Enter the other user's UID:</Text>
          <TextInput
            style={styles.input}
            value={calleeUid}
            onChangeText={setCalleeUid}
            placeholder="Paste UID here"
            autoCapitalize="none"
          />
          <Pressable style={styles.callButton} onPress={handleStartCall}>
            <Text style={styles.callButtonText}>🎥 Video Call</Text>
          </Pressable>
        </View>
      </View>
    );
  }

  // Incoming screen (Android only — iOS uses native CallKit UI)
  if (screen === 'incoming') {
    return (
      <View style={styles.callScreen}>
        <View style={styles.callInfo}>
          <View style={styles.bigAvatar}>
            <Text style={styles.bigAvatarText}>{contactName.charAt(0).toUpperCase()}</Text>
          </View>
          <Text style={styles.callName}>{contactName}</Text>
          <Text style={styles.callStatus}>Incoming video call...</Text>
        </View>
        <View style={styles.incomingBtns}>
          <Pressable style={styles.declineBtn} onPress={handleDecline}>
            <Text style={styles.btnIcon}>✕</Text>
            <Text style={styles.btnLabel}>Decline</Text>
          </Pressable>
          <Pressable style={styles.acceptBtn} onPress={handleAnswerCall}>
            <Text style={styles.btnIcon}>🎥</Text>
            <Text style={styles.btnLabel}>Accept</Text>
          </Pressable>
        </View>
      </View>
    );
  }

  // ACTIVE VIDEO CALL
  return (
    <View style={{ flex: 1 }}>
      {remoteStreamURL ? (
        <RTCView streamURL={remoteStreamURL} style={StyleSheet.absoluteFill} objectFit="cover" zOrder={0} />
      ) : (
        <View style={[StyleSheet.absoluteFill, styles.callScreen]}>
          <View style={styles.callInfo}>
            <View style={styles.bigAvatar}>
              <Text style={styles.bigAvatarText}>{contactName.charAt(0).toUpperCase()}</Text>
            </View>
            <Text style={styles.callName}>{contactName}</Text>
            <Text style={styles.callStatus}>
              {callState === 'calling' && 'Calling...'}
              {callState === 'connecting' && 'Connecting...'}
            </Text>
          </View>
        </View>
      )}
      {localStreamURL && (
        <View style={styles.pip}>
          <RTCView streamURL={localStreamURL} style={{ flex: 1 }} objectFit="cover" mirror={true} zOrder={1} />
        </View>
      )}
      {callState === 'active' && (
        <View style={styles.timerOverlay}>
          <Text style={styles.timerText}>{contactName}</Text>
          <Text style={styles.timerSub}>{timer}</Text>
        </View>
      )}
      <View style={styles.controlBar}>
        <Pressable style={[styles.ctrlBtn, isMuted && styles.ctrlActive]} onPress={handleToggleMute}>
          <Text style={styles.ctrlIcon}>{isMuted ? '🔇' : '🎤'}</Text>
        </Pressable>
        <Pressable style={styles.endCallBtn} onPress={handleEndCall}>
          <Text style={styles.ctrlIcon}>📵</Text>
        </Pressable>
      </View>
    </View>
  );
}

function generateUUID() {
  return 'xxxxxxxx-xxxx-4xxx-yxxx-xxxxxxxxxxxx'.replace(/[xy]/g, (c) => {
    const r = Math.random() * 16 | 0;
    return (c === 'x' ? r : (r & 0x3 | 0x8)).toString(16);
  });
}

14. Testing incoming calls on iOS

  1. Prerequisites: Apple Developer account, VoIP push certificate created (Section 5)
  2. Deploy the updated Cloud Function: firebase deploy --only functions
  3. Build for iOS: eas build --platform ios --profile development
  4. Install the dev build on two iPhones (or iPhone + Android)
  5. Log in on both — check that voipToken appears in the iOS user's Firestore doc
  6. On the iPhone: close the app completely (swipe up from app switcher)
  7. From the other phone: call the iPhone
  8. The iPhone shows the native iOS call screen — green Accept, red Decline
  9. Slide to answer → your app opens and video connects
  10. Check the Phone app's Recents — your call appears there
Testing gotchas
  • Simulator won't work — VoIP push and CallKit require a physical iPhone
  • Development vs Production — Use the sandbox APNs endpoint (api.sandbox.push.apple.com) for dev builds, production endpoint for App Store builds
  • Token changes — The VoIP token can change between builds. Always re-save on app start.
  • Must report call within 10 seconds — If your VoIP push handler doesn't call displayIncomingCall within ~10 seconds, iOS will terminate your app and may throttle future pushes
