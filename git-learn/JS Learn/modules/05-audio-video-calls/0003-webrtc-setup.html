react-native-webrtc Setup

Install · Permissions · Config plugin · mediaDevices · Camera preview ~45 min Hands-on
Why this matters for your WhatsApp clone

react-native-webrtc is the library that gives your React Native app access to the WebRTC engine — the same engine compiled into Chrome, Firefox, and every major calling app. It provides the RTCPeerConnection, mediaDevices, and RTCView components you need to capture microphone audio, stream video from the camera, and establish peer-to-peer connections. This lesson installs the library, configures native permissions on both Android and iOS, verifies the camera/mic work, and builds a simple camera preview screen — proving your custom dev build can access the hardware.

1. Installing react-native-webrtc

Install the library and its Expo config plugin:

# Install react-native-webrtc
npx expo install react-native-webrtc

# This adds to your package.json:
# "react-native-webrtc": "^118.x.x"

After installing, you must rebuild because this is a native library:

# Rebuild your development build (includes the new native code)
eas build --platform android --profile development

# And/or for iOS:
eas build --platform ios --profile development
Rebuild required!

This is one of those times you MUST rebuild (Lesson 2, Section 9). react-native-webrtc contains C++ and Objective-C code that must be compiled into the app binary. Your old dev build won't have it — you need a fresh one.

2. Configure the Expo plugin

Add the WebRTC config plugin to your app.json. This automatically sets up all native permissions and build settings:

// app.json — add to the "plugins" array
{
  "expo": {
    "plugins": [
      "expo-dev-client",
      [
        "react-native-webrtc",
        {
          "cameraPermission": "WhatsApp Clone needs camera access for video calls",
          "microphonePermission": "WhatsApp Clone needs microphone access for calls"
        }
      ]
    ]
  }
}

The config plugin handles all the native setup that you'd otherwise need to do manually:

  • Android: adds CAMERA, RECORD_AUDIO, MODIFY_AUDIO_SETTINGS permissions to AndroidManifest.xml
  • iOS: adds NSCameraUsageDescription and NSMicrophoneUsageDescription to Info.plist
  • Both: configures the native WebRTC framework linking

3. What react-native-webrtc gives you

The library exports everything you need for WebRTC calls:

import {
  RTCPeerConnection,      // The main connection object
  RTCSessionDescription,  // Wraps offer/answer SDP strings
  RTCIceCandidate,        // Wraps ICE candidate data
  mediaDevices,           // Access camera and microphone
  RTCView,               // Component to display video streams
  MediaStream,           // Represents an audio/video stream
} from 'react-native-webrtc';

How these map to the call flow from Lesson 1:

Call step API used
Capture mic/camera mediaDevices.getUserMedia()
Create connection new RTCPeerConnection(config)
Create offer/answer pc.createOffer() / pc.createAnswer()
Set descriptions pc.setLocalDescription() / pc.setRemoteDescription()
Add ICE candidates pc.addIceCandidate()
Display remote video <RTCView streamURL={...} />

4. Requesting camera and microphone permissions

Before accessing the camera or mic, you must request runtime permission from the user. On both platforms, this shows a system dialog the first time:

import { PermissionsAndroid, Platform } from 'react-native';

async function requestMediaPermissions() {
  if (Platform.OS === 'android') {
    const grants = await PermissionsAndroid.requestMultiple([
      PermissionsAndroid.PERMISSIONS.CAMERA,
      PermissionsAndroid.PERMISSIONS.RECORD_AUDIO,
    ]);

    const cameraGranted = grants['android.permission.CAMERA'] === 'granted';
    const micGranted = grants['android.permission.RECORD_AUDIO'] === 'granted';

    if (!cameraGranted || !micGranted) {
      Alert.alert('Permissions needed', 'Camera and microphone are required for calls');
      return false;
    }
    return true;
  }

  // iOS: permissions are requested automatically by mediaDevices.getUserMedia()
  // The permission strings in app.json control what the dialog says
  return true;
}

Platform difference:

  • Android: You must explicitly request permissions using PermissionsAndroid before calling getUserMedia
  • iOS: The system automatically shows the permission dialog when getUserMedia is called for the first time. The strings in app.json (NSCameraUsageDescription) are what appear in the dialog.

5. Getting the local media stream

mediaDevices.getUserMedia() activates the camera and/or microphone and returns a MediaStream object:

import { mediaDevices } from 'react-native-webrtc';

// Audio only (voice call)
async function getAudioStream() {
  const stream = await mediaDevices.getUserMedia({
    audio: true,
    video: false,
  });
  return stream; // Contains one audio track
}

// Audio + Video (video call)
async function getVideoStream() {
  const stream = await mediaDevices.getUserMedia({
    audio: true,
    video: {
      facingMode: 'user',     // front camera
      width: { ideal: 1280 },
      height: { ideal: 720 },
      frameRate: { ideal: 30 },
    },
  });
  return stream; // Contains one audio track + one video track
}

// Switch between front/back camera
async function switchCamera(currentStream) {
  const videoTrack = currentStream.getVideoTracks()[0];
  videoTrack._switchCamera(); // react-native-webrtc helper method
}

MediaStream anatomy:

  • A stream contains tracks — separate channels for audio and video
  • stream.getAudioTracks() → array of audio tracks (usually 1)
  • stream.getVideoTracks() → array of video tracks (usually 1)
  • Each track can be enabled/disabled independently (mute mic, turn off camera)

6. Displaying video with RTCView

RTCView is a React Native component that renders a video stream — like an <Image> but for live video:

import { RTCView } from 'react-native-webrtc';

// Display the local camera preview
function LocalVideoPreview({ stream }) {
  if (!stream) return null;

  return (
    <RTCView
      streamURL={stream.toURL()}
      style={styles.localVideo}
      objectFit="cover"
      mirror={true}   // mirror front camera (like a selfie)
      zOrder={1}      // render above other views
    />
  );
}

// Display the remote person's video
function RemoteVideo({ stream }) {
  if (!stream) return null;

  return (
    <RTCView
      streamURL={stream.toURL()}
      style={styles.remoteVideo}
      objectFit="cover"
      mirror={false}  // don't mirror remote video
      zOrder={0}
    />
  );
}

RTCView props:

  • streamURL — the stream's URL string (call stream.toURL())
  • objectFit — 'cover' fills the frame (may crop), 'contain' shows everything (may letterbox)
  • mirror — flip horizontally (use for front camera so it looks natural like a mirror)
  • zOrder — stacking order (higher = on top). Important for picture-in-picture layout.

7. Controlling tracks — mute and camera off

WhatsApp lets you mute your mic or turn off your camera mid-call. This is done by enabling/disabling individual tracks:

// Mute/unmute microphone
function toggleMute(stream, isMuted) {
  const audioTrack = stream.getAudioTracks()[0];
  if (audioTrack) {
    audioTrack.enabled = !isMuted; // false = muted, true = unmuted
  }
}

// Turn camera on/off
function toggleCamera(stream, isOff) {
  const videoTrack = stream.getVideoTracks()[0];
  if (videoTrack) {
    videoTrack.enabled = !isOff; // false = camera off, true = camera on
  }
}

// Stop all tracks (end the call — release hardware)
function stopAllTracks(stream) {
  stream.getTracks().forEach((track) => {
    track.stop();  // releases camera/mic hardware
  });
}

Important: track.enabled = false keeps the track in the stream but sends silence/black frames. track.stop() permanently releases the hardware — you'd need to call getUserMedia again to restart.

8. Enumerating available devices

Some phones have multiple cameras (front, back, wide-angle). You can list them:

import { mediaDevices } from 'react-native-webrtc';

async function listDevices() {
  const devices = await mediaDevices.enumerateDevices();

  const cameras = devices.filter((d) => d.kind === 'videoinput');
  const mics = devices.filter((d) => d.kind === 'audioinput');

  console.log('Cameras:', cameras.length); // Usually 2 (front + back)
  console.log('Microphones:', mics.length); // Usually 1

  // Each device has:
  // { deviceId: '0', kind: 'videoinput', label: 'Front Camera' }
  return { cameras, mics };
}

In practice, you'll mostly use the facingMode constraint and _switchCamera() helper rather than selecting devices by ID.

9. Full runnable App.js — Camera preview with controls

Copy this entire file and replace your App.js. It shows your camera preview with buttons to: switch camera (front/back), toggle mute, toggle camera on/off. This proves your custom dev build has WebRTC working correctly.

// App.js — Full runnable example: WebRTC Camera Preview
import React, { useState, useEffect, useRef } from 'react';
import {
  View, Text, Pressable, StyleSheet, Alert, Platform, PermissionsAndroid
} from 'react-native';
import {
  mediaDevices,
  RTCView,
} from 'react-native-webrtc';

// ─── Request permissions ────────────────────────────────────────────
async function requestPermissions() {
  if (Platform.OS === 'android') {
    const grants = await PermissionsAndroid.requestMultiple([
      PermissionsAndroid.PERMISSIONS.CAMERA,
      PermissionsAndroid.PERMISSIONS.RECORD_AUDIO,
    ]);
    const camera = grants['android.permission.CAMERA'] === 'granted';
    const mic = grants['android.permission.RECORD_AUDIO'] === 'granted';
    if (!camera || !mic) {
      Alert.alert('Permissions needed', 'Camera and microphone are required');
      return false;
    }
  }
  return true;
}

// ─── Main App ───────────────────────────────────────────────────────
export default function App() {
  const [localStream, setLocalStream] = useState(null);
  const [isMuted, setIsMuted] = useState(false);
  const [isCameraOff, setIsCameraOff] = useState(false);
  const [isFrontCamera, setIsFrontCamera] = useState(true);
  const [deviceInfo, setDeviceInfo] = useState('');

  useEffect(() => {
    startCamera();
    return () => {
      // Cleanup: stop all tracks on unmount
      if (localStream) {
        localStream.getTracks().forEach((track) => track.stop());
      }
    };
  }, []);

  async function startCamera() {
    const hasPermission = await requestPermissions();
    if (!hasPermission) return;

    try {
      const stream = await mediaDevices.getUserMedia({
        audio: true,
        video: {
          facingMode: 'user',
          width: { ideal: 1280 },
          height: { ideal: 720 },
          frameRate: { ideal: 30 },
        },
      });
      setLocalStream(stream);

      // List devices for info display
      const devices = await mediaDevices.enumerateDevices();
      const cameras = devices.filter((d) => d.kind === 'videoinput');
      const mics = devices.filter((d) => d.kind === 'audioinput');
      setDeviceInfo(`${cameras.length} camera(s), ${mics.length} mic(s)`);
    } catch (err) {
      Alert.alert('Error', `Failed to access camera: ${err.message}`);
    }
  }

  function handleToggleMute() {
    if (!localStream) return;
    const audioTrack = localStream.getAudioTracks()[0];
    if (audioTrack) {
      audioTrack.enabled = isMuted; // toggle
      setIsMuted(!isMuted);
    }
  }

  function handleToggleCamera() {
    if (!localStream) return;
    const videoTrack = localStream.getVideoTracks()[0];
    if (videoTrack) {
      videoTrack.enabled = isCameraOff; // toggle
      setIsCameraOff(!isCameraOff);
    }
  }

  function handleSwitchCamera() {
    if (!localStream) return;
    const videoTrack = localStream.getVideoTracks()[0];
    if (videoTrack) {
      videoTrack._switchCamera();
      setIsFrontCamera(!isFrontCamera);
    }
  }

  function handleStopAll() {
    if (!localStream) return;
    localStream.getTracks().forEach((track) => track.stop());
    setLocalStream(null);
  }

  return (
    <View style={styles.container}>
      {/* Header */}
      <View style={styles.header}>
        <Text style={styles.headerTitle}>WebRTC Camera Test</Text>
        <Text style={styles.headerSub}>{deviceInfo || 'Loading...'}</Text>
      </View>

      {/* Video preview */}
      <View style={styles.videoContainer}>
        {localStream ? (
          <RTCView
            streamURL={localStream.toURL()}
            style={styles.video}
            objectFit="cover"
            mirror={isFrontCamera}
          />
        ) : (
          <View style={styles.noVideo}>
            <Text style={styles.noVideoText}>
              {isCameraOff ? 'Camera is off' : 'Starting camera...'}
            </Text>
          </View>
        )}

        {/* Status indicators */}
        <View style={styles.statusBar}>
          <Text style={styles.statusText}>
            🎤 {isMuted ? 'Muted' : 'Active'}
          </Text>
          <Text style={styles.statusText}>
            📷 {isCameraOff ? 'Off' : (isFrontCamera ? 'Front' : 'Back')}
          </Text>
        </View>
      </View>

      {/* Controls */}
      <View style={styles.controls}>
        <Pressable
          style={[styles.controlBtn, isMuted && styles.controlBtnActive]}
          onPress={handleToggleMute}
        >
          <Text style={styles.controlIcon}>{isMuted ? '🔇' : '🎤'}</Text>
          <Text style={styles.controlLabel}>{isMuted ? 'Unmute' : 'Mute'}</Text>
        </Pressable>

        <Pressable
          style={[styles.controlBtn, isCameraOff && styles.controlBtnActive]}
          onPress={handleToggleCamera}
        >
          <Text style={styles.controlIcon}>{isCameraOff ? '📷' : '🚫'}</Text>
          <Text style={styles.controlLabel}>{isCameraOff ? 'Camera On' : 'Camera Off'}</Text>
        </Pressable>

        <Pressable style={styles.controlBtn} onPress={handleSwitchCamera}>
          <Text style={styles.controlIcon}>🔄</Text>
          <Text style={styles.controlLabel}>Switch</Text>
        </Pressable>

        <Pressable style={[styles.controlBtn, styles.endBtn]} onPress={handleStopAll}>
          <Text style={styles.controlIcon}>📵</Text>
          <Text style={styles.controlLabel}>Stop</Text>
        </Pressable>
      </View>

      {/* Info */}
      <View style={styles.infoBox}>
        <Text style={styles.infoTitle}>What this proves:</Text>
        <Text style={styles.infoText}>✅ react-native-webrtc is installed correctly</Text>
        <Text style={styles.infoText}>✅ Camera permission granted</Text>
        <Text style={styles.infoText}>✅ Microphone permission granted</Text>
        <Text style={styles.infoText}>✅ Custom dev build includes native WebRTC code</Text>
        <Text style={styles.infoText}>✅ Ready for peer-to-peer calls (next lesson)</Text>
      </View>
    </View>
  );
}

10. Testing checklist

After rebuilding and running this App.js, verify each item:

  1. ✅ App opens without crashing (native WebRTC code is linked correctly)
  2. ✅ Permission dialog appears for camera and microphone
  3. ✅ Video preview shows your face (front camera)
  4. ✅ "Switch" button flips to back camera and back
  5. ✅ "Mute" button silences mic (status text changes)
  6. ✅ "Camera Off" button shows black screen (status changes)
  7. ✅ "Stop" button releases hardware (preview disappears)
  8. ✅ Device info shows "2 camera(s), 1 mic(s)" (typical phone)

If all 8 items pass, your WebRTC setup is complete and you're ready to build actual calls in Lesson 4.

Common issue: black screen on Android emulator

Android emulators often don't have a real camera. Test on a physical device. If you must use an emulator, enable the "Virtual Scene" camera in AVD settings — it provides a simulated camera feed.
