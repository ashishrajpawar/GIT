Device Security & Storage

Track A

Phase 6 — 2 lessons

Module goal: Secure sensitive data on the device and add biometric app lock. After this module, tokens and keys are in the OS keychain (not plain AsyncStorage), and the app requires fingerprint/Face ID to open.

Lessons

  1. Secure Storage
  2. Biometric App Lock

What you'll build

  • Migration of sensitive data (JWT, refresh tokens, encryption keys) from AsyncStorage to SecureStore
  • A secure storage wrapper with graceful fallback and error handling
  • Biometric lock screen using expo-local-authentication
  • Settings UI to enable/disable biometric lock and configure timeout
  • Protection against background app snapshots revealing sensitive content

Prerequisites

  • A4 Auth Client — the JWT tokens you'll move into SecureStore
  • A5 Core Token Features — the token data that needs protection
