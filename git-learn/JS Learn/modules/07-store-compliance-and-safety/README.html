Module 7: Store Compliance & Safety

6 lessons • ~2 weeks • Build these BEFORE submitting to the stores

Why this module exists: Messaging apps are the #1 most-rejected category on both stores. Apple Guideline 1.2 and Google's User Generated Content policy require block/report features. Missing any of these lessons means your app gets rejected — no exceptions.

Lessons

  1. Block & Report Users

    Block a user (hide messages, prevent contact), report a user or message, Firestore reports collection, block list in Settings, unblock flow, UI for "This user is blocked" state.

  2. Content Moderation System

    Firestore reports collection schema, admin review workflow, auto-hide content after N reports, what to tell Apple/Google when they ask "how do you moderate?", moderation policy document.

  3. Forgot Password & Account Security

    Firebase sendPasswordResetEmail(), password reset UI flow, login attempt limiting (lock after 5 failures), re-authentication before sensitive actions (delete account, change email), secure session handling.

  4. Age Gate & Consent Flows

    Date-of-birth screen at signup, blocking under-13 users, iOS App Tracking Transparency prompt (expo-tracking-transparency), GDPR consent toggle for EU users, conditional Firebase Analytics initialization.

  5. Data Export & Terms of Service

    "Download My Data" button in Settings (query user's Firestore docs → JSON → share sheet), writing a minimal Terms of Service, hosting it alongside privacy policy, linking in both store dashboards.

  6. Pre-Submission Checklist & Demo Accounts

    Creating two demo accounts with pre-populated chat history, writing Apple reviewer notes, verifying all declared background modes, IPv6 STUN/TURN verification, airplane mode testing, final walkthrough of both store dashboards.

Prerequisites

  • Module 6 complete (app is built, polished, and ready to submit)
  • Privacy policy hosted (Module 6 Lesson 4)
  • Firebase project running with Auth + Firestore + Storage

By the end of this module you will have

  • Block/report system that satisfies Apple Guideline 1.2 and Google UGC policy
  • Age verification and consent flows for GDPR and COPPA
  • Working password reset and account security measures
  • Data export feature (required by GDPR)
  • Terms of Service document hosted and linked
  • Two demo accounts ready for Apple reviewers
  • Confidence that your app will pass review on first submission
