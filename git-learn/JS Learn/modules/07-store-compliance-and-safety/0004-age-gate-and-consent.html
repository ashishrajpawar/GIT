Age Gate & Consent Flows

Date-of-birth · COPPA · ATT prompt · GDPR consent · Conditional analytics ~55 min Hands-on
Why this matters for your WhatsApp clone

Two laws govern how apps handle young users and personal data: COPPA (Children's Online Privacy Protection Act — US) prohibits collecting data from children under 13 without parental consent, and GDPR (General Data Protection Regulation — EU) requires explicit consent before collecting any personal data. Apple also requires an App Tracking Transparency (ATT) prompt if you use analytics that can track across apps. Violating these isn't just a store rejection — it's a legal fine ($50,000+ per COPPA violation, up to 4% of global revenue for GDPR). This lesson adds the gates and consent screens that keep you compliant.

1. The three consent requirements

Requirement Who it protects What you must do
COPPA Children under 13 (US) Block sign-up or get parental consent
GDPR Everyone in the EU Get explicit consent before collecting/processing data
ATT (Apple) All iOS users Ask permission before tracking across apps (analytics)

The simplest strategy for a messaging app: block under-13 entirely (no parental consent flow needed), show a GDPR consent screen for EU users, and show the ATT prompt on iOS before initializing analytics.

2. Age gate — date of birth at sign-up

Add a date-of-birth picker as the first step of registration, before email/password. If the user is under 13, stop them from proceeding:

import { useState } from 'react';
import { View, Text, Pressable, Platform, StyleSheet } from 'react-native';
import DateTimePicker from '@react-native-community/datetimepicker';

function AgeGateScreen({ navigation }) {
  const [dateOfBirth, setDateOfBirth] = useState(null);
  const [showPicker, setShowPicker] = useState(false);
  const [tooYoung, setTooYoung] = useState(false);

  function calculateAge(birthday) {
    const today = new Date();
    let age = today.getFullYear() - birthday.getFullYear();
    const monthDiff = today.getMonth() - birthday.getMonth();
    if (monthDiff < 0 || (monthDiff === 0 && today.getDate() < birthday.getDate())) {
      age--;
    }
    return age;
  }

  function handleDateChange(event, selectedDate) {
    setShowPicker(Platform.OS === 'ios'); // iOS keeps picker open
    if (selectedDate) {
      setDateOfBirth(selectedDate);
      setTooYoung(false);
    }
  }

  function handleContinue() {
    if (!dateOfBirth) return;

    const age = calculateAge(dateOfBirth);

    if (age < 13) {
      setTooYoung(true);
      return;
    }

    // Age is valid — proceed to registration
    navigation.navigate('Register', { dateOfBirth: dateOfBirth.toISOString() });
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Verify your age</Text>
      <Text style={styles.subtitle}>
        You must be at least 13 years old to create an account.
      </Text>

      <Pressable style={styles.dateButton} onPress={() => setShowPicker(true)}>
        <Text style={styles.dateButtonText}>
          {dateOfBirth
            ? dateOfBirth.toLocaleDateString()
            : 'Select your date of birth'}
        </Text>
      </Pressable>

      {showPicker && (
        <DateTimePicker
          value={dateOfBirth || new Date(2005, 0, 1)}
          mode="date"
          display={Platform.OS === 'ios' ? 'spinner' : 'default'}
          maximumDate={new Date()}
          minimumDate={new Date(1920, 0, 1)}
          onChange={handleDateChange}
        />
      )}

      {tooYoung && (
        <View style={styles.blockedMessage}>
          <Text style={styles.blockedTitle}>Sorry, you cannot sign up</Text>
          <Text style={styles.blockedText}>
            You must be at least 13 years old to use this app.
            This is required by law (COPPA).
          </Text>
        </View>
      )}

      {!tooYoung && (
        <Pressable
          style={[styles.continueButton, !dateOfBirth && styles.buttonDisabled]}
          onPress={handleContinue}
          disabled={!dateOfBirth}
        >
          <Text style={styles.continueText}>Continue</Text>
        </Pressable>
      )}
    </View>
  );
}

Important: Don't store the date of birth unless you have a specific reason. Just verify the age and proceed. Storing birthdates creates additional GDPR obligations around sensitive personal data.

5. GDPR consent — asking EU users for permission

GDPR requires you to get explicit, informed consent before collecting personal data from EU users. Show this screen right after registration (before the user enters the app):

import { useState } from 'react';
import { View, Text, Pressable, ScrollView, Switch, Linking, StyleSheet } from 'react-native';
import { doc, updateDoc } from 'firebase/firestore';
import { auth, db } from './firebaseConfig';

  const [analyticsConsent, setAnalyticsConsent] = useState(false);
  const [crashReportConsent, setCrashReportConsent] = useState(false);

  async function handleAccept() {
    // Store consent choices in user's Firestore profile
    await updateDoc(doc(db, 'users', auth.currentUser.uid), {
      consent: {

        crashReports: crashReportConsent,
        consentDate: new Date().toISOString(),

  return (
    <ScrollView style={styles.container} contentContainerStyle={styles.content}>
      <Text style={styles.title}>Your Privacy Matters</Text>
      <Text style={styles.intro}>
        We need your permission to collect certain data. You can change these
        choices later in Settings.
      </Text>

      {/* Essential — always on, not toggleable */}
      <View style={styles.consentRow}>
        <View style={styles.consentInfo}>
          <Text style={styles.consentLabel}>Essential Data</Text>
          <Text style={styles.consentDescription}>
            Your email, display name, and messages. Required for the app to function.

6. When to show the consent screen

Show GDPR consent only to users who haven't consented yet. Check after login:

import { useEffect, useState } from 'react';
import { doc, getDoc } from 'firebase/firestore';
import { auth, db } from './firebaseConfig';

function useNeedsConsent() {
  const [needsConsent, setNeedsConsent] = useState(false);
  const [checking, setChecking] = useState(true);

  useEffect(() => {
    async function check() {
      const userDoc = await getDoc(doc(db, 'users', auth.currentUser.uid));
      const userData = userDoc.data();

      // Show consent if they haven't consented yet, or if consent version changed
      const consent = userData?.consent;
      if (!consent || consent.consentVersion !== '1.0') {
        setNeedsConsent(true);
      }

      setChecking(false);
    }
    check();
  }, []);

  return { needsConsent, checking };
}

// In your main navigation logic after login:
function AppNavigator() {
  const { needsConsent, checking } = useNeedsConsent();

  if (checking) return <LoadingScreen />;

  return (
    <Stack.Navigator>
      {needsConsent ? (
        <Stack.Screen name="Consent" component={ConsentScreen} />
      ) : (
        <Stack.Screen name="Main" component={MainTabs} />
      )}
    </Stack.Navigator>
  );
}

Should you show this to ALL users or just EU? The safest approach is to show it to everyone. Detecting EU location is unreliable (users travel, use VPNs). WhatsApp shows privacy consent to all users globally. It's simpler and covers you legally worldwide.

7. Conditional analytics initialization

The most important part: don't initialize analytics until consent is given. If you start Firebase Analytics before consent, you're already violating GDPR:

import { getAnalytics, setAnalyticsCollectionEnabled } from 'firebase/analytics';
import { getDoc, doc } from 'firebase/firestore';
import { auth, db } from './firebaseConfig';

let analyticsInstance = null;

async function initializeAnalyticsIfConsented() {
  const userDoc = await getDoc(doc(db, 'users', auth.currentUser.uid));
  const consent = userDoc.data()?.consent;

  if (consent?.analytics) {
    // User consented — enable analytics
    const { getAnalytics } = await import('firebase/analytics');
    analyticsInstance = getAnalytics();
    setAnalyticsCollectionEnabled(analyticsInstance, true);
  }
}

// For crash reporting (Crashlytics / Sentry)
async function initializeCrashReportsIfConsented() {
  const userDoc = await getDoc(doc(db, 'users', auth.currentUser.uid));
  const consent = userDoc.data()?.consent;

  if (consent?.crashReports) {
    // Initialize your crash reporter here
    // e.g., Sentry.init({...}) or crashlytics().setCrashlyticsCollectionEnabled(true)
  }
}

// Call after login + consent check:
async function onUserReady() {
  await initializeAnalyticsIfConsented();
  await initializeCrashReportsIfConsented();
}

Key principle: Essential data (messages, auth, profile) does NOT require separate consent — it's necessary for the app to function. Analytics and crash reports DO require consent because they're not essential to the core messaging feature.

8. iOS App Tracking Transparency (ATT)

If your app uses any form of cross-app tracking (advertising IDs, certain analytics), iOS requires you to show the ATT prompt. Even if you only use Firebase Analytics (which does use the IDFA on iOS), you must show this prompt:

# Install the tracking transparency library
npx expo install expo-tracking-transparency

Add it to your app.json plugins:

{
  "expo": {
    "plugins": [
      [
        "expo-tracking-transparency",
        {
          "userTrackingPermission": "This app uses anonymous analytics to improve your experience. Your data is never shared with advertisers."
        }
      ]
    ]
  }
}

Show the prompt before initializing analytics:

import { useEffect, useState } from 'react';
import { Platform } from 'react-native';
import { requestTrackingPermissionsAsync, getTrackingPermissionsAsync } from 'expo-tracking-transparency';

function useTrackingPermission() {
  const [canTrack, setCanTrack] = useState(false);
  const [asked, setAsked] = useState(false);

  useEffect(() => {
    async function checkTracking() {
      // Only relevant on iOS
      if (Platform.OS !== 'ios') {
        setCanTrack(true); // Android doesn't have ATT
        setAsked(true);
        return;
      }

      // Check if already granted
      const { status } = await getTrackingPermissionsAsync();

      if (status === 'granted') {
        setCanTrack(true);
        setAsked(true);
      } else if (status === 'undetermined') {
        // Haven't asked yet — request permission
        const { status: newStatus } = await requestTrackingPermissionsAsync();
        setCanTrack(newStatus === 'granted');
        setAsked(true);
      } else {
        // Denied or restricted
        setCanTrack(false);
        setAsked(true);
      }
    }

    checkTracking();
  }, []);

  return { canTrack, asked };
}

Integrate with your analytics initialization:

async function initializeAnalytics() {
  // 1. Check GDPR consent
  const userDoc = await getDoc(doc(db, 'users', auth.currentUser.uid));
  const consent = userDoc.data()?.consent;

  if (!consent?.analytics) return; // No GDPR consent — don't track

  // 2. Check ATT (iOS only)
  if (Platform.OS === 'ios') {
    const { status } = await getTrackingPermissionsAsync();
    if (status !== 'granted') return; // No ATT permission — don't track
  }

  // 3. Both consents given — safe to initialize
  const analytics = getAnalytics();
  setAnalyticsCollectionEnabled(analytics, true);
}

9. When NOT to show the ATT prompt

You do NOT need the ATT prompt if:

  • You don't use any analytics at all (no Firebase Analytics, no Mixpanel, nothing)
  • You only use server-side analytics (counting messages in Cloud Functions)
  • You only use Crashlytics without any IDFA collection

You DO need it if:

  • You use Firebase Analytics (it collects IDFA by default on iOS)
  • You use any advertising SDK
  • You use attribution/marketing tools (Adjust, AppsFlyer, Branch)

Recommendation for your WhatsApp clone: If you're not running ads and don't need user-level analytics, skip Firebase Analytics entirely and avoid the ATT prompt complexity. Use Crashlytics for crash reports (doesn't require ATT) and count messages/users server-side in Cloud Functions.

10. Privacy settings screen — changing consent later

GDPR requires users to be able to withdraw consent at any time. Add a Privacy section to Settings:

import { useState, useEffect } from 'react';
import { View, Text, Switch, Pressable, Alert, StyleSheet } from 'react-native';
import { doc, onSnapshot, updateDoc } from 'firebase/firestore';
import { auth, db } from './firebaseConfig';

function PrivacySettingsScreen() {
  const [consent, setConsent] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    const unsub = onSnapshot(doc(db, 'users', auth.currentUser.uid), (snap) => {
      setConsent(snap.data()?.consent || null);
      setLoading(false);
    });
    return unsub;
  }, []);

  async function updateConsent(field, value) {
    await updateDoc(doc(db, 'users', auth.currentUser.uid), {
      [`consent.${field}`]: value,
      'consent.consentDate': new Date().toISOString(),
    });

    // If turning off analytics, disable collection immediately
    if (field === 'analytics' && !value) {
      const { getAnalytics, setAnalyticsCollectionEnabled } = await import('firebase/analytics');
      setAnalyticsCollectionEnabled(getAnalytics(), false);
    }
  }

  if (loading) return <Text style={styles.loading}>Loading...</Text>;

  return (
    <View style={styles.container}>
      <Text style={styles.sectionTitle}>Data Collection</Text>
      <Text style={styles.sectionNote}>
        You can control what data we collect. Essential data (messages, profile)
        cannot be disabled as it's required for the app to work.
      </Text>

      <View style={styles.row}>
        <View style={styles.rowInfo}>
          <Text style={styles.rowLabel}>Essential Data</Text>
          <Text style={styles.rowDescription}>Messages, profile, contacts</Text>
        </View>
        <Text style={styles.alwaysOn}>Always on</Text>
      </View>

      <View style={styles.row}>
        <View style={styles.rowInfo}>
          <Text style={styles.rowLabel}>Usage Analytics</Text>
          <Text style={styles.rowDescription}>
            Anonymous usage patterns to improve the app
          </Text>
        </View>
        <Switch
          value={consent?.analytics || false}
          onValueChange={(val) => updateConsent('analytics', val)}
          trackColor={{ true: '#25D366' }}
        />
      </View>

      <View style={styles.row}>
        <View style={styles.rowInfo}>
          <Text style={styles.rowLabel}>Crash Reports</Text>
          <Text style={styles.rowDescription}>
            Automatic error reports to help fix bugs
          </Text>
        </View>
        <Switch
          value={consent?.crashReports || false}
          onValueChange={(val) => updateConsent('crashReports', val)}
          trackColor={{ true: '#25D366' }}
        />
      </View>

      <Text style={styles.footnote}>
        Changes take effect immediately. You can change these at any time.
      </Text>
    </View>
  );
}

11. The complete sign-up flow with age gate and consent

Here's the full registration journey with all gates in place:

Login Screen
    ├── "Forgot Password?" → ForgotPasswordScreen
    └── "Sign Up" → AgeGateScreen
                        ↓ (age ≥ 13)
                   RegisterScreen
                        ↓ (account created)
                   ConsentScreen
                        ↓ (consent saved)
                   MainTabs (app)

If the user is under 13, they're blocked at the AgeGate and never reach Register. If they're 13+ but refuse all optional consent, they still enter the app — only analytics/crash reports are disabled.

12. Full runnable example — age gate + consent integrated

import { useState, useEffect } from 'react';
import {
  View, Text, Pressable, Switch, ScrollView, Platform, Alert, StyleSheet
} from 'react-native';
import DateTimePicker from '@react-native-community/datetimepicker';
import { initializeApp } from 'firebase/app';
import {
  getAuth, createUserWithEmailAndPassword
} from 'firebase/auth';
import {
  getFirestore, doc, setDoc, getDoc, serverTimestamp
} from 'firebase/firestore';

const app = initializeApp({ /* your config */ });
const auth = getAuth(app);
const db = getFirestore(app);

// ─── Age Calculation ────────────────────────────────────────
function calculateAge(birthday) {
  const today = new Date();
  let age = today.getFullYear() - birthday.getFullYear();
  const m = today.getMonth() - birthday.getMonth();
  if (m < 0 || (m === 0 && today.getDate() < birthday.getDate())) age--;
  return age;
}

// ─── Screen 1: Age Gate ─────────────────────────────────────
function AgeGateScreen({ onPass }) {
  const [dob, setDob] = useState(null);
  const [showPicker, setShowPicker] = useState(false);
  const [blocked, setBlocked] = useState(false);

  function handleDateChange(event, date) {
    setShowPicker(Platform.OS === 'ios');
    if (date) { setDob(date); setBlocked(false); }
  }

  function handleContinue() {
    if (!dob) return;
    if (calculateAge(dob) < 13) {
      setBlocked(true);
      return;

      <Text style={styles.heading}>How old are you?</Text>

      </Pressable>

      {showPicker && (
        <DateTimePicker
          value={dob || new Date(2005, 0, 1)}
          mode="date"
          display={Platform.OS === 'ios' ? 'spinner' : 'default'}

      {blocked && (
        <View style={styles.blockedBox}>

  );
}

// ─── Screen 2: Register ─────────────────────────────────────
function RegisterScreen({ onRegister }) {
  const [email, setEmail] = useState('');
  const [name, setName] = useState('');
  const [password, setPassword] = useState('');
  const [loading, setLoading] = useState(false);

  async function handleRegister() {
    if (!email.trim() || !name.trim() || !password) return;
    if (password.length < 8) {
      Alert.alert('Weak password', 'Use at least 8 characters.');
      return;
    }

    setLoading(true);
    try {
      const { user } = await createUserWithEmailAndPassword(auth, email.trim(), password);

      await setDoc(doc(db, 'users', user.uid), {
        uid: user.uid,
        displayName: name.trim(),
        email: email.trim().toLowerCase(),
        photoURL: null,
        about: 'Hey there! I am using WhatsApp',
        online: true,
        lastSeen: serverTimestamp(),
        createdAt: serverTimestamp(),
        blockedUsers: [],
        reportCount: 0,
        isBanned: false,
        isHidden: false,
      });

      onRegister();
    } catch (err) {
      Alert.alert('Error', err.message);
    } finally {
      setLoading(false);
    }
  }

  return (
    <View style={styles.screen}>
      <Text style={styles.heading}>Create your account</Text>

      <View style={styles.inputContainer}>
        <Text style={styles.inputLabel}>Display name</Text>
        <View style={styles.inputBox}>

Apple Age rating questionnaire 12+ (user-generated content, messaging)
Apple Does the app collect data from children? No — age gate blocks under-13
Apple ATT prompt shown before tracking? Yes (if using analytics); or N/A (if no analytics)
Google Target audience includes under-13? No — minimum age is 13

14. Common mistakes to avoid

  • Don't store date of birth unless you need it — just verify age ≥ 13 and move on. Storing it creates additional GDPR obligations.
  • Don't pre-check the analytics toggle — GDPR requires consent to be "freely given," which means the default must be OFF.
  • Don't block users from using the app if they refuse analytics — that's coercion, not consent. Only essential data can be mandatory.
  • Don't initialize Firebase Analytics in your app config file — import it conditionally only after consent is confirmed.
  • Don't forget the consent version number — when you start collecting new data later, bump the version so existing users see the updated consent screen.
