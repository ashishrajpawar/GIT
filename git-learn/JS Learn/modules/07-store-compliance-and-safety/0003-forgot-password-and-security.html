Store Compliance · Lesson 3

Forgot Password & Account Security

Password reset · Login lockout · Re-authentication · Email change · Secure flows ~50 min Hands-on
Why this matters for your WhatsApp clone

Apple reviewers test your login flow. They'll try wrong passwords, look for a "Forgot Password" link, and verify it actually sends an email. If it's missing, that's a rejection. Beyond the store, your real users will forget passwords — it happens constantly. And without login attempt limiting, anyone can brute-force their way into accounts. This lesson builds the complete authentication security layer: password reset, lockout after failed attempts, re-authentication for dangerous actions, and email change flow.

1. Password reset — how Firebase handles it

Firebase Auth has built-in password reset. Here's the flow:

User taps "Forgot Password?"
       ↓
App calls sendPasswordResetEmail(auth, email)
       ↓
Firebase sends a reset link to that email
       ↓
User opens the email, clicks the link
       ↓
Firebase shows a reset form (hosted by Firebase)
       ↓
User types a new password → done
       ↓
User logs in with the new password

You don't need to build the reset form — Firebase hosts it for you. You only need to:

  1. Add a "Forgot Password?" button on your login screen
  2. Show a text input for their email
  3. Call sendPasswordResetEmail
  4. Show a success message telling them to check their inbox

2. The Forgot Password screen

import { useState } from 'react';
import { View, Text, TextInput, Pressable, Alert, StyleSheet } from 'react-native';
import { sendPasswordResetEmail } from 'firebase/auth';
import { auth } from './firebaseConfig';

function ForgotPasswordScreen({ navigation }) {
  const [email, setEmail] = useState('');
  const [loading, setLoading] = useState(false);
  const [sent, setSent] = useState(false);

  async function handleReset() {
    const trimmedEmail = email.trim().toLowerCase();

    if (!trimmedEmail) {
      Alert.alert('Enter your email', 'Please type the email you used to sign up.');
      return;
    }

    setLoading(true);
    try {
      await sendPasswordResetEmail(auth, trimmedEmail);
      setSent(true);
    } catch (error) {
      // Don't reveal whether the email exists (security best practice)
      // Show the same success message regardless
      setSent(true);
    } finally {
      setLoading(false);
    }
  }

  if (sent) {
    return (
      <View style={styles.container}>
        <Text style={styles.successIcon}>✓</Text>
        <Text style={styles.successTitle}>Check your email</Text>
        <Text style={styles.successMessage}>
          If an account exists for {email.trim()}, we've sent a password reset link.
          Check your inbox (and spam folder).
        </Text>
        <Pressable style={styles.backButton} onPress={() => navigation.goBack()}>
          <Text style={styles.backText}>Back to Login</Text>
        </Pressable>
      </View>
    );
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Reset your password</Text>
      <Text style={styles.subtitle}>
        Enter the email address you used to create your account.
        We'll send you a link to reset your password.
      </Text>

      <TextInput
        style={styles.input}
        placeholder="Email address"
        value={email}
        onChangeText={setEmail}
        keyboardType="email-address"
        autoCapitalize="none"
        autoCorrect={false}
      />

      <Pressable
        style={[styles.resetButton, loading && styles.buttonDisabled]}
        onPress={handleReset}
        disabled={loading}
      >
        <Text style={styles.resetText}>
          {loading ? 'Sending...' : 'Send Reset Link'}
        </Text>
      </Pressable>

      <Pressable style={styles.cancelLink} onPress={() => navigation.goBack()}>
        <Text style={styles.cancelText}>Back to Login</Text>
      </Pressable>
    </View>
  );
}

Security note: Notice that in the catch block, we show the same "check your email" message even if the email doesn't exist. This prevents attackers from discovering which emails are registered (called "email enumeration").

4. Login attempt limiting — preventing brute force

Without rate limiting, someone could try thousands of password combinations. Firebase Auth has some built-in protection (it temporarily blocks an IP after many failures), but you should add your own client-side lockout for better UX:

import { useState, useRef } from 'react';
import { signInWithEmailAndPassword } from 'firebase/auth';
import { auth } from './firebaseConfig';

const MAX_ATTEMPTS = 5;
const LOCKOUT_DURATION_MS = 60 * 1000; // 1 minute

function useLoginWithLockout() {
  const [attempts, setAttempts] = useState(0);
  const [lockedUntil, setLockedUntil] = useState(null);
  const [error, setError] = useState(null);
  const [loading, setLoading] = useState(false);

  function isLocked() {
    if (!lockedUntil) return false;
    if (Date.now() >= lockedUntil) {
      // Lockout expired — reset
      setLockedUntil(null);
      setAttempts(0);
      return false;
    }
    return true;
  }

  function getRemainingSeconds() {
    if (!lockedUntil) return 0;
    return Math.ceil((lockedUntil - Date.now()) / 1000);
  }

  async function login(email, password) {
    if (isLocked()) {
      setError(`Too many attempts. Try again in ${getRemainingSeconds()} seconds.`);
      return null;
    }

    setLoading(true);
    setError(null);

    try {
      const result = await signInWithEmailAndPassword(auth, email, password);
      setAttempts(0); // Reset on success
      return result.user;
    } catch (err) {
      const newAttempts = attempts + 1;
      setAttempts(newAttempts);

      if (newAttempts >= MAX_ATTEMPTS) {
        const lockExpiry = Date.now() + LOCKOUT_DURATION_MS;
        setLockedUntil(lockExpiry);
        setError(`Account locked for 60 seconds. Too many failed attempts.`);
      } else {
        const remaining = MAX_ATTEMPTS - newAttempts;
        setError(getErrorMessage(err.code, remaining));
      }
      return null;
    } finally {
      setLoading(false);
    }
  }

  return { login, error, loading, isLocked: isLocked(), getRemainingSeconds };
}

function getErrorMessage(code, remainingAttempts) {
  switch (code) {
    case 'auth/wrong-password':
    case 'auth/invalid-credential':
      return `Incorrect password. ${remainingAttempts} attempt${remainingAttempts !== 1 ? 's' : ''} remaining.`;
    case 'auth/user-not-found':
      return 'No account found with this email.';
    case 'auth/too-many-requests':
      return 'Too many attempts. Please try again later.';
    case 'auth/invalid-email':
      return 'Please enter a valid email address.';
    default:
      return 'Login failed. Please check your credentials.';
  }
}

5. Using the lockout hook in the Login screen

function LoginScreen({ navigation }) {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const { login, error, loading, isLocked, getRemainingSeconds } = useLoginWithLockout();
  const [lockTimer, setLockTimer] = useState(0);

  // Update timer every second when locked
  useEffect(() => {
    if (!isLocked) return;
    const interval = setInterval(() => {
      const secs = getRemainingSeconds();
      setLockTimer(secs);
      if (secs <= 0) setLockTimer(0);
    }, 1000);
    return () => clearInterval(interval);
  }, [isLocked]);

  async function handleLogin() {
    if (!email.trim() || !password) return;
    const user = await login(email.trim(), password);
    if (user) {
      navigation.replace('Main');
    }
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Welcome back</Text>

      <TextInput
        style={styles.input}
        placeholder="Email"
        value={email}
        onChangeText={setEmail}
        keyboardType="email-address"
        autoCapitalize="none"
        editable={!isLocked}
      />

      <TextInput
        style={styles.input}
        placeholder="Password"
        value={password}
        onChangeText={setPassword}
        secureTextEntry
        editable={!isLocked}
      />

      <Pressable onPress={() => navigation.navigate('ForgotPassword')}>
        <Text style={styles.forgotLink}>Forgot password?</Text>
      </Pressable>

      {error && <Text style={styles.errorText}>{error}</Text>}

      {isLocked && lockTimer > 0 && (
        <View style={styles.lockoutBanner}>
          <Text style={styles.lockoutText}>
            Account locked. Try again in {lockTimer}s
          </Text>
        </View>
      )}

      <Pressable
        style={[styles.loginButton, (loading || isLocked) && styles.buttonDisabled]}
        onPress={handleLogin}
        disabled={loading || isLocked}
      >
        <Text style={styles.loginText}>
          {loading ? 'Logging in...' : 'Log In'}
        </Text>
      </Pressable>
    </View>
  );
}

6. Why both client-side AND server-side lockout?

Layer What it does Limitation
Client-side (your code) Shows countdown, disables inputs, gives clear feedback A determined attacker can bypass by modifying the app
Firebase built-in Blocks IP address after excessive failures You can't control the threshold or duration
Firestore counter (advanced) Tracks attempts per email, enforced in security rules More complex to implement — save for Module 8

For store approval, client-side + Firebase built-in is enough. Apple reviewers see the lockout message, and Firebase handles the actual security. You don't need a custom server-side solution for launch.

7. Re-authentication — protecting sensitive actions

Some actions are so dangerous that the user should prove their identity again, even if they're already logged in. Firebase calls this "re-authentication":

  • Delete account — permanent, irreversible
  • Change email — affects login credentials
  • Change password — affects login credentials

Firebase will throw auth/requires-recent-login if you try these without re-authenticating. Here's the pattern:

import {
  reauthenticateWithCredential,
  EmailAuthProvider,
  deleteUser,
  updateEmail,
  updatePassword
} from 'firebase/auth';
import { auth } from './firebaseConfig';

async function reauthenticate(currentPassword) {
  const user = auth.currentUser;
  const credential = EmailAuthProvider.credential(user.email, currentPassword);
  await reauthenticateWithCredential(user, credential);
}

// Delete account (requires re-auth)
async function deleteAccount(currentPassword) {
  await reauthenticate(currentPassword);
  // Delete Firestore data first (from Module 6 Lesson 4)
  await deleteUserData(auth.currentUser.uid);
  // Then delete the Auth account
  await deleteUser(auth.currentUser);
}

// Change email (requires re-auth)
async function changeEmail(currentPassword, newEmail) {
  await reauthenticate(currentPassword);
  await updateEmail(auth.currentUser, newEmail);
}

// Change password (requires re-auth)
async function changePassword(currentPassword, newPassword) {
  await reauthenticate(currentPassword);
  await updatePassword(auth.currentUser, newPassword);
}

8. Re-authentication dialog component

Build a reusable modal that asks for the current password before performing a sensitive action:

import { useState } from 'react';
import { View, Text, TextInput, Pressable, Modal, Alert, StyleSheet } from 'react-native';

function ReauthDialog({ visible, onClose, onConfirm, actionLabel }) {
  const [password, setPassword] = useState('');
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState(null);

  async function handleConfirm() {
    if (!password) {
      setError('Please enter your password.');
      return;
    }

    setLoading(true);
    setError(null);

    try {
      await onConfirm(password);
      setPassword('');
      onClose();
    } catch (err) {
      if (err.code === 'auth/wrong-password' || err.code === 'auth/invalid-credential') {
        setError('Incorrect password. Please try again.');
      } else {
        setError('Something went wrong. Please try again.');
      }
    } finally {
      setLoading(false);
    }
  }

  function handleClose() {
    setPassword('');
    setError(null);
    onClose();
  }

  return (
    <Modal visible={visible} transparent animationType="fade">
      <View style={styles.overlay}>
        <View style={styles.dialog}>
          <Text style={styles.dialogTitle}>Confirm your identity</Text>
          <Text style={styles.dialogMessage}>
            Enter your current password to {actionLabel}.
          </Text>

          <TextInput
            style={styles.dialogInput}
            placeholder="Current password"
            value={password}
            onChangeText={setPassword}
            secureTextEntry
            autoFocus
          />

          {error && <Text style={styles.dialogError}>{error}</Text>}

          <View style={styles.dialogButtons}>
            <Pressable style={styles.dialogCancel} onPress={handleClose}>
              <Text style={styles.dialogCancelText}>Cancel</Text>
            </Pressable>
            <Pressable
              style={[styles.dialogConfirm, loading && styles.buttonDisabled]}
              onPress={handleConfirm}
              disabled={loading}
            >
              <Text style={styles.dialogConfirmText}>
                {loading ? 'Verifying...' : 'Confirm'}
              </Text>
            </Pressable>
          </View>
        </View>
      </View>
    </Modal>
  );
}

9. Change email flow

Users might need to change their email. This requires re-authentication because it changes their login credentials:

import { useState } from 'react';
import { View, Text, TextInput, Pressable, Alert, StyleSheet } from 'react-native';
import { reauthenticateWithCredential, EmailAuthProvider, verifyBeforeUpdateEmail } from 'firebase/auth';
import { doc, updateDoc } from 'firebase/firestore';
import { auth, db } from './firebaseConfig';

function ChangeEmailScreen({ navigation }) {
  const [newEmail, setNewEmail] = useState('');
  const [password, setPassword] = useState('');
  const [loading, setLoading] = useState(false);

  async function handleChangeEmail() {
    if (!newEmail.trim() || !password) {
      Alert.alert('Fill all fields', 'Enter your new email and current password.');
      return;
    }

    setLoading(true);
    try {
      // Step 1: Re-authenticate
      const credential = EmailAuthProvider.credential(auth.currentUser.email, password);
      await reauthenticateWithCredential(auth.currentUser, credential);

      // Step 2: Send verification to new email (Firebase requires this)
      await verifyBeforeUpdateEmail(auth.currentUser, newEmail.trim());

      // Step 3: Update Firestore profile (after verification is confirmed)
      // Note: The email in Auth updates only AFTER the user clicks the verification link
      Alert.alert(
        'Verification sent',
        `We sent a verification link to ${newEmail.trim()}. Your email will update after you click the link.`,
        [{ text: 'OK', onPress: () => navigation.goBack() }]
      );
    } catch (error) {
      switch (error.code) {
        case 'auth/wrong-password':
        case 'auth/invalid-credential':
          Alert.alert('Error', 'Incorrect password.');
          break;
        case 'auth/email-already-in-use':
          Alert.alert('Error', 'This email is already registered to another account.');
          break;
        case 'auth/invalid-email':
          Alert.alert('Error', 'Please enter a valid email address.');
          break;
        default:
          Alert.alert('Error', 'Could not change email. Please try again.');
      }
    } finally {
      setLoading(false);
    }
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Change Email</Text>
      <Text style={styles.currentEmail}>
        Current: {auth.currentUser.email}
      </Text>

      <TextInput
        style={styles.input}
        placeholder="New email address"
        value={newEmail}
        onChangeText={setNewEmail}
        keyboardType="email-address"
        autoCapitalize="none"
      />

      <TextInput
        style={styles.input}
        placeholder="Current password (to confirm)"
        value={password}
        onChangeText={setPassword}
        secureTextEntry
      />

      <Pressable
        style={[styles.saveButton, loading && styles.buttonDisabled]}
        onPress={handleChangeEmail}
        disabled={loading}
      >
        <Text style={styles.saveText}>
          {loading ? 'Processing...' : 'Change Email'}
        </Text>
      </Pressable>
    </View>
  );
}

Why verifyBeforeUpdateEmail? Firebase requires the new email to be verified before the change takes effect. This prevents someone from changing their email to an address they don't own.

10. Change password flow

import { useState } from 'react';
import { View, Text, TextInput, Pressable, Alert, StyleSheet } from 'react-native';
import { reauthenticateWithCredential, EmailAuthProvider, updatePassword } from 'firebase/auth';
import { auth } from './firebaseConfig';

function ChangePasswordScreen({ navigation }) {
  const [currentPassword, setCurrentPassword] = useState('');
  const [newPassword, setNewPassword] = useState('');
  const [confirmPassword, setConfirmPassword] = useState('');
  const [loading, setLoading] = useState(false);

  async function handleChangePassword() {
    // Validation
    if (!currentPassword || !newPassword || !confirmPassword) {
      Alert.alert('Fill all fields', 'Please complete every field.');
      return;
    }

    if (newPassword.length < 8) {
      Alert.alert('Weak password', 'New password must be at least 8 characters.');
      return;
    }

    if (newPassword !== confirmPassword) {
      Alert.alert('Mismatch', 'New passwords do not match.');
      return;
    }

    if (newPassword === currentPassword) {
      Alert.alert('Same password', 'New password must be different from current password.');
      return;
    }

    setLoading(true);
    try {
      // Re-authenticate
      const credential = EmailAuthProvider.credential(auth.currentUser.email, currentPassword);
      await reauthenticateWithCredential(auth.currentUser, credential);

      // Update password
      await updatePassword(auth.currentUser, newPassword);

      Alert.alert(
        'Password updated',
        'Your password has been changed successfully.',
        [{ text: 'OK', onPress: () => navigation.goBack() }]
      );
    } catch (error) {
      if (error.code === 'auth/wrong-password' || error.code === 'auth/invalid-credential') {
        Alert.alert('Error', 'Current password is incorrect.');
      } else if (error.code === 'auth/weak-password') {
        Alert.alert('Error', 'New password is too weak. Use at least 8 characters with letters and numbers.');
      } else {
        Alert.alert('Error', 'Could not change password. Please try again.');
      }
    } finally {
      setLoading(false);
    }
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Change Password</Text>

      <TextInput
        style={styles.input}
        placeholder="Current password"
        value={currentPassword}
        onChangeText={setCurrentPassword}
        secureTextEntry
      />

      <TextInput
        style={styles.input}
        placeholder="New password (min 8 characters)"
        value={newPassword}
        onChangeText={setNewPassword}
        secureTextEntry
      />

      <TextInput
        style={styles.input}
        placeholder="Confirm new password"
        value={confirmPassword}
        onChangeText={setConfirmPassword}
        secureTextEntry
      />

      <Pressable
        style={[styles.saveButton, loading && styles.buttonDisabled]}
        onPress={handleChangePassword}
        disabled={loading}
      >
        <Text style={styles.saveText}>
          {loading ? 'Updating...' : 'Update Password'}
        </Text>
      </Pressable>
    </View>
  );
}

11. Password strength indicator

Help users create strong passwords with a visual indicator:

function getPasswordStrength(password) {
  let score = 0;

  if (password.length >= 8) score++;
  if (password.length >= 12) score++;
  if (/[a-z]/.test(password) && /[A-Z]/.test(password)) score++;
  if (/[0-9]/.test(password)) score++;
  if (/[^a-zA-Z0-9]/.test(password)) score++;

  if (score <= 1) return { label: 'Weak', color: '#dc3545', width: '20%' };
  if (score <= 2) return { label: 'Fair', color: '#fd7e14', width: '40%' };
  if (score <= 3) return { label: 'Good', color: '#ffc107', width: '60%' };
  if (score <= 4) return { label: 'Strong', color: '#28a745', width: '80%' };
  return { label: 'Very Strong', color: '#075E54', width: '100%' };
}

function PasswordStrengthBar({ password }) {

        ]} />
      </View>
      <Text style={[styles.strengthLabel, { color: strength.color }]}>
        {strength.label}
      </Text>

  );
}

12. Full runnable example — complete auth security flow

This App.js shows the Login screen with lockout, Forgot Password, and a Settings screen with change password, change email, and delete account (all with re-authentication):

import { useState, useEffect } from 'react';
import {
  View, Text, TextInput, Pressable, Alert, Modal,
  KeyboardAvoidingView, Platform, StyleSheet
} from 'react-native';
import { initializeApp } from 'firebase/app';
import {
  getAuth, signInWithEmailAndPassword, sendPasswordResetEmail,
  reauthenticateWithCredential, EmailAuthProvider,
  updatePassword, deleteUser, signOut
} from 'firebase/auth';
import { getFirestore, doc, deleteDoc } from 'firebase/firestore';

const app = initializeApp({ /* your config */ });
const auth = getAuth(app);
const db = getFirestore(app);

// ─── Constants ──────────────────────────────────────────────
const MAX_ATTEMPTS = 5;
const LOCKOUT_MS = 60000;

// ─── Login Screen with Lockout ──────────────────────────────
function LoginScreen({ onLogin, onForgot }) {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const [error, setError] = useState(null);
  const [loading, setLoading] = useState(false);
  const [attempts, setAttempts] = useState(0);
  const [lockedUntil, setLockedUntil] = useState(null);
  const [countdown, setCountdown] = useState(0);

  useEffect(() => {
    if (!lockedUntil) return;
    const interval = setInterval(() => {
      const remaining = Math.ceil((lockedUntil - Date.now()) / 1000);
      if (remaining <= 0) {
        setLockedUntil(null);
        setAttempts(0);
        setCountdown(0);
        setError(null);
      } else {
        setCountdown(remaining);
      }
    }, 1000);
    return () => clearInterval(interval);
  }, [lockedUntil]);

  const isLocked = lockedUntil && Date.now() < lockedUntil;

  async function handleLogin() {
    if (isLocked) return;
    if (!email.trim() || !password) {
      setError('Please enter email and password.');
      return;
    }

    setLoading(true);
    setError(null);

    try {
      await signInWithEmailAndPassword(auth, email.trim(), password);
      onLogin();
    } catch (err) {
      const newAttempts = attempts + 1;
      setAttempts(newAttempts);

      if (newAttempts >= MAX_ATTEMPTS) {
        setLockedUntil(Date.now() + LOCKOUT_MS);
        setError('Too many failed attempts. Locked for 60 seconds.');
      } else {
        const left = MAX_ATTEMPTS - newAttempts;
        setError(`Incorrect credentials. ${left} attempt${left > 1 ? 's' : ''} remaining.`);
      }
    } finally {
      setLoading(false);
    }
  }

  return (
    <KeyboardAvoidingView
      style={styles.container}
      behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
    >
      <Text style={styles.appTitle}>WhatsApp Clone</Text>
      <Text style={styles.subtitle}>Log in to continue</Text>

      <TextInput
        style={styles.input}
        placeholder="Email"
        value={email}
        onChangeText={setEmail}
        keyboardType="email-address"
        autoCapitalize="none"
        editable={!isLocked}
      />
      <TextInput
        style={styles.input}
        placeholder="Password"
        value={password}
        onChangeText={setPassword}
        secureTextEntry
        editable={!isLocked}
      />

      <Pressable onPress={onForgot}>
        <Text style={styles.forgotLink}>Forgot password?</Text>
      </Pressable>

      {error && <Text style={styles.errorText}>{error}</Text>}
      {isLocked && <Text style={styles.lockText}>Try again in {countdown}s</Text>}

      <Pressable
        style={[styles.primaryButton, (loading || isLocked) && styles.buttonDisabled]}
        onPress={handleLogin}
        disabled={loading || isLocked}
      >
        <Text style={styles.primaryButtonText}>
          {loading ? 'Logging in...' : 'Log In'}
        </Text>
      </Pressable>
    </KeyboardAvoidingView>
  );
}

// ─── Forgot Password Screen ────────────────────────────────
function ForgotPasswordScreen({ onBack }) {
  const [email, setEmail] = useState('');
  const [sent, setSent] = useState(false);
  const [loading, setLoading] = useState(false);

  async function handleReset() {
    if (!email.trim()) {
      Alert.alert('Enter your email');
      return;
    }
    setLoading(true);
    try {
      await sendPasswordResetEmail(auth, email.trim());
    } catch (e) {
      // Silent — don't reveal if email exists
    }
    setSent(true);
    setLoading(false);
  }

  if (sent) {
    return (
      <View style={styles.container}>
        <Text style={styles.successIcon}>✓</Text>
        <Text style={styles.title}>Check your inbox</Text>
        <Text style={styles.message}>
          If an account exists for {email.trim()}, a reset link has been sent.
        </Text>
        <Pressable style={styles.secondaryButton} onPress={onBack}>
          <Text style={styles.secondaryButtonText}>Back to Login</Text>
        </Pressable>
      </View>
    );
  }

  return (
    <View style={styles.container}>
      <Text style={styles.title}>Reset Password</Text>
      <Text style={styles.message}>
        Enter your email and we'll send a reset link.
      </Text>
      <TextInput
        style={styles.input}
        placeholder="Email address"
        value={email}
        onChangeText={setEmail}
        keyboardType="email-address"
        autoCapitalize="none"
      />
      <Pressable
        style={[styles.primaryButton, loading && styles.buttonDisabled]}
        onPress={handleReset}
        disabled={loading}
      >
        <Text style={styles.primaryButtonText}>
          {loading ? 'Sending...' : 'Send Reset Link'}
        </Text>
      </Pressable>
      <Pressable style={styles.secondaryButton} onPress={onBack}>
        <Text style={styles.secondaryButtonText}>Back to Login</Text>
      </Pressable>
    </View>
  );
}

// ─── Settings Screen (Account Security) ────────────────────
function SettingsScreen({ onLogout }) {
  const [showReauth, setShowReauth] = useState(false);
  const [reauthAction, setReauthAction] = useState(null);
  const [newPass, setNewPass] = useState('');
  const [confirmPass, setConfirmPass] = useState('');
  const [showChangePassword, setShowChangePassword] = useState(false);

  function handleDeleteAccount() {
    Alert.alert(
      'Delete Account Permanently?',
      'All your messages, profile, and data will be permanently deleted. This cannot be undone.',
      [
        { text: 'Cancel', style: 'cancel' },
        {
          text: 'Delete Forever',
          style: 'destructive',
          onPress: () => { setReauthAction('delete'); setShowReauth(true); },
        },
      ]
    );
  }

  async function onReauthConfirm(password) {
    const credential = EmailAuthProvider.credential(auth.currentUser.email, password);
    await reauthenticateWithCredential(auth.currentUser, credential);

    if (reauthAction === 'delete') {
      await deleteDoc(doc(db, 'users', auth.currentUser.uid));
      await deleteUser(auth.currentUser);
    } else if (reauthAction === 'changePassword') {
      if (newPass.length < 8) throw new Error('Password too short');
      if (newPass !== confirmPass) throw new Error('Passwords do not match');
      await updatePassword(auth.currentUser, newPass);
      Alert.alert('Success', 'Password updated.');
      setShowChangePassword(false);
      setNewPass('');
      setConfirmPass('');
    }
  }

  return (
    <View style={styles.settingsContainer}>
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Account Security</Text>
      </View>

      <Pressable
        style={styles.settingsRow}
        onPress={() => setShowChangePassword(!showChangePassword)}
      >
        <Text style={styles.settingsLabel}>Change Password</Text>
      </Pressable>

      {showChangePassword && (
        <View style={styles.expandedSection}>
          <TextInput
            style={styles.input}
            placeholder="New password (min 8 chars)"
            value={newPass}
            onChangeText={setNewPass}
            secureTextEntry
          />
          <TextInput
            style={styles.input}
            placeholder="Confirm new password"
            value={confirmPass}
            onChangeText={setConfirmPass}
            secureTextEntry
          />
          <Pressable
            style={styles.primaryButton}
            onPress={() => { setReauthAction('changePassword'); setShowReauth(true); }}
          >
            <Text style={styles.primaryButtonText}>Update Password</Text>
          </Pressable>
        </View>
      )}

      <Pressable style={styles.settingsRow} onPress={onLogout}>
        <Text style={styles.settingsLabel}>Log Out</Text>
      </Pressable>

      <Pressable style={styles.settingsRow} onPress={handleDeleteAccount}>
        <Text style={[styles.settingsLabel, { color: '#dc3545' }]}>Delete Account</Text>
      </Pressable>

      {/* Re-auth dialog */}
      <Modal visible={showReauth} transparent animationType="fade">
        <View style={styles.overlay}>
          <View style={styles.dialog}>
            <Text style={styles.dialogTitle}>Confirm your password</Text>
            <ReauthInput onConfirm={onReauthConfirm} onCancel={() => setShowReauth(false)} />
          </View>
        </View>
      </Modal>
    </View>
  );
}

function ReauthInput({ onConfirm, onCancel }) {
  const [pass, setPass] = useState('');
  const [error, setError] = useState(null);
  const [loading, setLoading] = useState(false);

  async function submit() {
    setLoading(true);
    setError(null);
    try {
      await onConfirm(pass);
      setPass('');
    } catch (e) {
      setError(e.code === 'auth/wrong-password' || e.code === 'auth/invalid-credential'
        ? 'Incorrect password.'
        : e.message || 'Error. Try again.');
    } finally {
      setLoading(false);
    }
  }

  return (
    <View>
      <TextInput
        style={styles.input}
        placeholder="Current password"
        value={pass}
        onChangeText={setPass}
        secureTextEntry
        autoFocus
      />
      {error && <Text style={styles.errorText}>{error}</Text>}
      <View style={styles.dialogButtons}>
        <Pressable style={styles.secondaryButton} onPress={onCancel}>
          <Text style={styles.secondaryButtonText}>Cancel</Text>
        </Pressable>
        <Pressable
          style={[styles.primaryButton, loading && styles.buttonDisabled]}
          onPress={submit}
          disabled={loading}
        >
          <Text style={styles.primaryButtonText}>
            {loading ? 'Verifying...' : 'Confirm'}
          </Text>
        </Pressable>
      </View>
    </View>
  );
}

// ─── App (screen routing) ───────────────────────────────────
export default function App() {
  const [screen, setScreen] = useState('login'); // login | forgot | settings

  if (screen === 'forgot') {
    return <ForgotPasswordScreen onBack={() => setScreen('login')} />;
  }

  if (screen === 'settings') {
    return (
      <SettingsScreen
        onLogout={async () => {
          await signOut(auth);
          setScreen('login');
        }}
      />
    );
  }

  return (
    <LoginScreen
      onLogin={() => setScreen('settings')}
      onForgot={() => setScreen('forgot')}
    />
  );
}

13. What Apple reviewers test

During review, Apple's team will:

  • Enter a wrong password several times — expect to see a lockout message or rate limit
  • Look for a "Forgot Password?" link — expect it to be clearly visible
  • Tap "Forgot Password" and enter the demo account email — expect a success message (even though they won't check their email)
  • Try to delete the account — expect a confirmation + password re-entry

All of these are now handled by the code in this lesson.
