App Icon & Splash Screen

Icon sizes · Adaptive icons · Splash screen · app.json config · EAS assets ~40 min Hands-on
Why this matters for your WhatsApp clone

The app icon is the first thing anyone sees — in the app store listing, on the home screen, in notifications. A blurry or badly-cropped icon makes your app look amateur before anyone opens it. The splash screen is the second thing they see — the branded screen that shows while the app loads. Together, these two assets tell the user "this is a real, professional app" within the first 2 seconds. Expo makes this surprisingly easy — one image, one config, and it generates everything for both platforms.

1. What you need to create

For a complete app, you need three image assets:

Asset Size Format Notes
App icon 1024 × 1024 px PNG (no transparency for iOS) Expo generates all smaller sizes automatically
Adaptive icon (Android) 1024 × 1024 px PNG with transparency Foreground layer only — background is a colour
Splash screen 1284 × 2778 px PNG Largest iPhone size; Expo resizes for all devices

You can create these with any design tool — Figma (free), Canva, or even a simple drawing app. For a WhatsApp clone, your icon could be a white phone icon on a green (#25D366) background.

2. Designing your app icon

Rules for a good app icon:

  • Simple — recognizable at 29×29px (smallest iOS size). No text, no fine detail.
  • One focal element — WhatsApp uses a phone handset inside a speech bubble.
  • Bold colours — your brand green (#25D366) as background, white icon on top.
  • No transparency on iOS — Apple fills transparent areas with black. Always fill the full square.
  • Round safe zone — Android may crop your icon into a circle. Keep important content within the inner 66% of the image.

A simple WhatsApp-clone icon design:

3. Android adaptive icons

Since Android 8, icons use a two-layer system called adaptive icons:

  • Background layer — a solid colour or image that fills the full shape
  • Foreground layer — your logo/icon with transparent padding around it

Android then applies whatever shape the device uses — circle, rounded square, squircle, teardrop — by masking these layers. The icon can even animate slightly when you long-press it.

┌──────────────────────────┐
│  Background: #25D366     │  ← Solid green (or a gradient image)
│  ┌──────────────────┐    │
│  │                  │    │
│  │    Foreground    │    │  ← White phone icon with padding
│  │    (transparent  │    │     Must stay within inner 66%
│  │     background)  │    │
│  │                  │    │
│  └──────────────────┘    │
└──────────────────────────┘

The safe zone: Android crops adaptive icons differently per device. Your foreground content must stay within a circle that's 66% of the total image (the inner 680×680 pixels of a 1024×1024 image). Anything outside may get cropped.

4. Configuring icons in app.json

Expo makes icon configuration a one-time setup in app.json:

{
  "expo": {
    "name": "WhatsApp Clone",
    "slug": "whatsapp-clone",
    "icon": "./assets/icon.png",
    "ios": {
      "icon": "./assets/icon.png",
      "supportsTablet": false
    },
    "android": {
      "icon": "./assets/icon.png",
      "adaptiveIcon": {
        "foregroundImage": "./assets/adaptive-icon.png",
        "backgroundColor": "#25D366"
      }
    }
  }
}

What Expo generates from your single 1024×1024 icon:

Platform Sizes generated
iOS 20, 29, 40, 58, 60, 76, 80, 87, 120, 152, 167, 180, 1024 px
Android mdpi (48), hdpi (72), xhdpi (96), xxhdpi (144), xxxhdpi (192), Play Store (512)

You provide ONE image. Expo generates all of them during the build. No manual resizing needed.

5. The splash screen

The splash screen shows while your app loads JavaScript. On a slow device this can be 1–3 seconds. Without it, the user sees a white flash. With it, they see your brand immediately:

┌─────────────────────────┐
│                         │
│                         │
│                         │
│         ┌───┐           │
│         │ 📞│           │  ← Your logo (centred)
│         └───┘           │
│                         │
│      WhatsApp Clone     │  ← Optional text (baked into the image)
│                         │
│                         │
│                         │
└─────────────────────────┘
    Background: #075E54
    (Dark green, like WhatsApp's real splash)

Design tips:

  • Use your dark green (#075E54) as background — matches the app's header
  • Place your icon in the centre — keep it small (about 200×200px in the design)
  • Don't put important content near the edges — devices crop differently
  • Keep the file size small — it loads before anything else

6. Configuring the splash screen in app.json

{
  "expo": {
    "splash": {
      "image": "./assets/splash.png",
      "resizeMode": "contain",
      "backgroundColor": "#075E54"
    },
    "ios": {
      "splash": {
        "image": "./assets/splash.png",
        "resizeMode": "contain",
        "backgroundColor": "#075E54"
      }
    },
    "android": {
      "splash": {
        "image": "./assets/splash.png",
        "resizeMode": "contain",
        "backgroundColor": "#075E54"
      }
    }
  }
}

resizeMode options:

  • "contain" — scales the image to fit within the screen (shows background colour around it). Best for logos.
  • "cover" — scales the image to fill the screen (may crop edges). Best for full-bleed images.
  • "native" — uses the platform's native splash implementation (most reliable for fast launch).

7. expo-splash-screen — controlling when it hides

By default, the splash screen disappears as soon as your app renders. But if you're loading fonts, fetching auth state, or checking Firestore, you want to keep it visible until your app is actually ready:

npx expo install expo-splash-screen
import * as SplashScreen from 'expo-splash-screen';

// Prevent the splash from auto-hiding
SplashScreen.preventAutoHideAsync();

export default function App() {
  const [isReady, setIsReady] = useState(false);

  useEffect(() => {
    async function prepare() {
      try {
        // Load fonts, check auth state, etc.
        await loadFonts();
        await checkAuthState();
      } catch (e) {
        console.warn(e);
      } finally {
        setIsReady(true);
      }
    }
    prepare();
  }, []);

  useEffect(() => {
    if (isReady) {
      // Hide the splash screen once everything is loaded
      SplashScreen.hideAsync();
    }
  }, [isReady]);

  if (!isReady) return null;   // Still loading — splash is visible

  return (
    <NavigationContainer>
      {/* Your app */}
    </NavigationContainer>
  );
}

Why this matters: Without this, the user sees the splash → white flash (while loading) → app. With it, they see splash → app directly. Much more professional.

9. Testing your icon and splash

Quick test (development):

# The splash and icon show in the Expo Go app during development
npx expo start

Full test (EAS build):

# Build a preview APK to verify the icon on Android
eas build --platform android --profile preview

# Build for iOS simulator to check icon + splash
eas build --platform ios --profile preview

What to check:

  • Icon looks correct on home screen (not blurry, not cropped)
  • Icon looks correct in app drawer/settings
  • Splash background colour matches — no white flash
  • Splash image is centred and not stretched
  • On Android: long-press the icon and see the adaptive animation

10. Common mistakes to avoid

Mistake What happens Fix
Transparent iOS icon Apple fills transparency with black Fill entire 1024×1024 with colour
Content too close to edge (Android) Gets cropped on circular icon devices Keep content within inner 66% circle
Splash backgroundColor wrong Visible colour mismatch at edges Match backgroundColor to image background exactly
Huge splash image file Slow first launch Compress PNG (under 500KB ideal)
Text in icon Unreadable at small sizes (29px) Use a symbol/shape only — no text

12. Creating your icon — step by step with Figma (free)

  1. Go to figma.com and create a free account
  2. Create a new file → Frame → set to 1024 × 1024
  3. Fill the frame with #25D366 (your lightGreen)
  4. Add a white shape in the centre (a phone icon or speech bubble)
  5. Keep the shape within the inner 680 × 680 area (for Android safe zone)
  6. Export as PNG → this is your icon.png
  7. Duplicate, make the background transparent → export as adaptive-icon.png
  8. Create a new frame 1284 × 2778, fill with #075E54 (darkGreen)
  9. Place a smaller version of your icon in the centre
  10. Export as PNG → this is your splash.png
Pro tip: Figma community templates

Search Figma Community for "app icon template" or "expo icon template" — many free templates have the safe zone guides already drawn for you. Just drop your design inside the guides.
