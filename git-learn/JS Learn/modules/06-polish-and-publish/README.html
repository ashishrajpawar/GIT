Module 6

Polish & Publish

6 lessons — complete ~2 weeks Final module
Goal of this module

Make the app feel polished and ship it to both the Google Play Store and the Apple App Store. By the end, your WhatsApp clone will be a real, downloadable app on both platforms.

What you need before publishing

Android iOS
Developer account Google Play Console — $25 one-time Apple Developer Program — $99/year
Build tool EAS Build → produces .aab file EAS Build → produces .ipa file (Mac required for signing)
Review time Usually 1–3 days Usually 1–3 days (stricter guidelines)
Key requirement Privacy policy URL required Privacy policy + detailed permissions justification
iOS note — Mac or cloud build

iOS app signing officially requires a Mac. With EAS Build, Expo's cloud does the build for you — so you can publish to iOS without owning a Mac. You just need the Apple Developer account.
