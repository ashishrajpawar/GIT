Polish & Publish · Lesson 1

UI Polish

StatusBar · Typography · Spacing system · Animations · Dark mode prep ~45 min Hands-on
Why this matters for your WhatsApp clone

Your app already works — chats, calls, status, everything. But there's a gap between "it works" and "it feels professional." Real WhatsApp has consistent spacing, smooth transitions, proper status bar handling, and a design that looks intentional on every screen. This lesson takes your working app and makes it feel like something a user would download from the store and keep using. No new features — just making what you have feel right.

1. The WhatsApp design system — colours and constants

Create a single file for all shared values. This prevents inconsistency — every screen pulls from the same source:

// src/theme.js — Single source of truth for your design

export const COLORS = {
  // Primary
  darkGreen: '#075E54',      // Headers, primary actions
  lightGreen: '#25D366',     // Send button, online dots, FAB
  bubbleGreen: '#DCF8C6',    // Sent message bubbles
  chatBg: '#ECE5DD',         // Chat screen background
  white: '#FFFFFF',          // Received bubbles, card backgrounds

  // Grays
  gray100: '#F7F8FA',        // List backgrounds
  gray200: '#E8E8E8',        // Borders, separators
  gray500: '#667781',        // Secondary text, timestamps
  gray700: '#3B4A54',        // Primary text
  gray900: '#111B21',        // Titles, headers

  // Status
  blue: '#53BDEB',           // Read receipts (double blue tick)
  red: '#FF3B30',            // Missed call, delete actions

  // Call screens
  callBg: '#1a1a2e',         // Dark call background
};

export const SPACING = {
  xs: 4,
  sm: 8,
  md: 12,
  lg: 16,
  xl: 20,
  xxl: 24,
};

export const FONT = {
  regular: { fontSize: 14, color: COLORS.gray700 },
  small: { fontSize: 12, color: COLORS.gray500 },
  title: { fontSize: 17, fontWeight: '600', color: COLORS.gray900 },
  header: { fontSize: 20, fontWeight: 'bold', color: COLORS.white },
  caption: { fontSize: 11, color: COLORS.gray500 },
};

export const SHADOW = {
  // iOS
  shadowColor: '#000',
  shadowOffset: { width: 0, height: 2 },
  shadowOpacity: 0.1,
  shadowRadius: 4,
  // Android
  elevation: 3,
};

Now every screen imports from this file:

import { COLORS, SPACING, FONT, SHADOW } from '../theme';

// Instead of hardcoding '#075E54' everywhere:
style={{ backgroundColor: COLORS.darkGreen }}

2. StatusBar — matching the header colour

WhatsApp makes the status bar (where the clock and battery icons are) match its dark green header. Without this, you get an ugly white or black bar above your green header:

import { StatusBar, Platform } from 'react-native';

// In your App or root navigator:
<StatusBar
  barStyle="light-content"          // White text/icons on dark background
  backgroundColor={COLORS.darkGreen}  // Android only — colours the bar itself
  translucent={false}               // Android: don't overlap content
/>

Platform differences:

  • iOS: The status bar is transparent by default — it overlaps your content. Use barStyle to set text colour.
  • Android: The status bar has its own background colour. Set backgroundColor to match your header.

For screens with different backgrounds (like the dark call screen):

// In the call screen component:
<StatusBar barStyle="light-content" backgroundColor="#1a1a2e" />

// In a white settings screen:
<StatusBar barStyle="dark-content" backgroundColor="#FFFFFF" />

3. Safe area handling — notches and home indicators

Modern phones have notches (iPhone) and rounded corners that can clip your content. Use react-native-safe-area-context to respect these areas:

npx expo install react-native-safe-area-context
import { SafeAreaView, useSafeAreaInsets } from 'react-native-safe-area-context';
import { SafeAreaProvider } from 'react-native-safe-area-context';

// Wrap your entire app:
export default function App() {
  return (
    <SafeAreaProvider>
      <NavigationContainer>
        {/* ... */}
      </NavigationContainer>
    </SafeAreaProvider>
  );
}

// In a screen that needs custom headers:
function ChatListScreen() {
  const insets = useSafeAreaInsets();

  return (
    <View style={{ flex: 1 }}>
      <View style={[styles.header, { paddingTop: insets.top + 12 }]}>
        <Text style={FONT.header}>WhatsApp</Text>
      </View>
      {/* ... */}
    </View>
  );
}

This ensures your header text never hides behind the notch on iPhone 14/15 or the camera hole on Samsung/Pixel phones.

4. Consistent spacing with a system

WhatsApp uses consistent multiples for spacing. Instead of guessing pixel values, use your SPACING constants:

// ❌ Inconsistent — every screen uses different values
style={{ padding: 15, marginBottom: 7, marginTop: 22 }}

// ✅ Consistent — always multiples of your spacing scale
style={{ padding: SPACING.lg, marginBottom: SPACING.sm, marginTop: SPACING.xl }}

Apply this pattern across your app:

Element Spacing Value
Screen horizontal padding SPACING.lg 16px
Space between list items SPACING.xs 4px (separator line handles the visual gap)
Internal card padding SPACING.md 12px
Avatar to text gap SPACING.md 12px
Section spacing SPACING.xxl 24px

5. Typography — making text feel right

WhatsApp uses specific font sizes and weights for different types of text. Here's the hierarchy:

// Chat list item
<View style={styles.chatRow}>
  <Text style={FONT.title}>Priya</Text>             {/* Name: 17px, semibold */}
  <Text style={FONT.regular}>Hey, are you free?</Text>  {/* Preview: 14px, gray */}
  <Text style={FONT.caption}>10:34 AM</Text>         {/* Timestamp: 11px, light gray */}
</View>

// Message bubble
<View style={styles.bubble}>
  <Text style={{ fontSize: 15, color: '#000' }}>Message text here</Text>
  <Text style={{ fontSize: 11, color: COLORS.gray500 }}>09:41</Text>
</View>

// Header
<Text style={FONT.header}>Chats</Text>               {/* 20px, bold, white */}

Typography rules WhatsApp follows:

  • Names are always semibold (fontWeight: '600')
  • Message previews and body text are regular weight
  • Timestamps and metadata are smaller and lighter in colour
  • Never use more than 3 different font sizes on one screen
  • Line height: for multi-line text, use lineHeight: fontSize * 1.4

6. Separator lines and list polish

WhatsApp's chat list has subtle separator lines that don't stretch full-width — they start after the avatar. This tiny detail makes it look professional:

function ChatSeparator() {
  return (
    <View style={separatorStyles.container}>
      <View style={separatorStyles.line} />
    </View>
  );
}

const separatorStyles = StyleSheet.create({
  container: {
    paddingLeft: 72,           // Avatar (50px) + left padding (16px) + gap (6px)
  },
  line: {
    height: StyleSheet.hairlineWidth,  // Thinnest possible line (0.5px on retina)
    backgroundColor: COLORS.gray200,
  },
});

// Use in FlatList:
<FlatList
  data={chats}
  renderItem={renderChatRow}
  ItemSeparatorComponent={ChatSeparator}
  keyExtractor={(item) => item.id}
/>

StyleSheet.hairlineWidth gives you the thinnest line the device can render — 0.5px on retina screens. It looks crisp, not blurry.

7. Pressable feedback — ripples and opacity

When a user taps a chat row, they need visual feedback. Without it, the app feels unresponsive:

import { Pressable, Platform } from 'react-native';

function ChatRow({ chat, onPress }) {
  return (
    <Pressable
      onPress={onPress}
      style={({ pressed }) => [
        styles.row,
        pressed && Platform.OS === 'ios' && { opacity: 0.7 },
      ]}
      android_ripple={{ color: 'rgba(0,0,0,0.1)' }}
    >
      {/* Row content */}
    </Pressable>
  );
}

Platform differences:

  • Android: Uses Material Design ripple effect — set via android_ripple
  • iOS: Uses opacity dimming — set via the pressed state in the style function

8. Smooth animations with LayoutAnimation

When a new message appears or a chat moves to the top of the list, it should animate — not just pop into place. React Native's LayoutAnimation is the easiest way:

import { LayoutAnimation, Platform, UIManager } from 'react-native';

// Enable on Android (one-time, in your App startup):
if (Platform.OS === 'android' && UIManager.setLayoutAnimationEnabledExperimental) {
  UIManager.setLayoutAnimationEnabledExperimental(true);
}

// Before any state update that changes the list:
function addNewMessage(message) {
  LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut);
  setMessages((prev) => [...prev, message]);
}

// Chat list reorder (new message moves chat to top):
function onNewMessage(chatId) {
  LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut);
  setChats((prev) => {
    const chat = prev.find((c) => c.id === chatId);
    const rest = prev.filter((c) => c.id !== chatId);
    return [{ ...chat, lastMessageTime: Date.now() }, ...rest];
  });
}

For more control over timing:

LayoutAnimation.configureNext({
  duration: 200,
  update: { type: LayoutAnimation.Types.easeInEaseOut },
  create: { type: LayoutAnimation.Types.easeIn, property: LayoutAnimation.Properties.opacity },
  delete: { type: LayoutAnimation.Types.easeOut, property: LayoutAnimation.Properties.opacity },
});

9. Floating Action Button (FAB)

WhatsApp has a green circular button in the bottom-right corner for starting a new chat. Here's the polished version:

function FloatingActionButton({ onPress }) {
  return (
    <Pressable
      style={({ pressed }) => [
        fabStyles.button,
        pressed && fabStyles.pressed,
      ]}
      onPress={onPress}
    >
      <Text style={fabStyles.icon}>💬</Text>
    </Pressable>
  );
}

const fabStyles = StyleSheet.create({
  button: {
    position: 'absolute',
    bottom: 24,
    right: 20,
    width: 56,
    height: 56,
    borderRadius: 16,          // WhatsApp uses slightly rounded square, not circle
    backgroundColor: COLORS.lightGreen,
    justifyContent: 'center',
    alignItems: 'center',
    // Shadow
    shadowColor: '#000',
    shadowOffset: { width: 0, height: 4 },
    shadowOpacity: 0.25,
    shadowRadius: 8,
    elevation: 6,
  },
  pressed: {
    transform: [{ scale: 0.92 }],
    elevation: 2,
  },
  icon: {
    fontSize: 24,
  },
});

10. Empty states

When a list has no data (no chats yet, no calls, no status updates), show a helpful empty state instead of a blank white screen:

function EmptyChats() {
  return (
    <View style={emptyStyles.container}>
      <Text style={emptyStyles.emoji}>💬</Text>
      <Text style={emptyStyles.title}>No chats yet</Text>
      <Text style={emptyStyles.subtitle}>
        Tap the button below to start a conversation
      </Text>
    </View>
  );
}

const emptyStyles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    alignItems: 'center',
    paddingHorizontal: 40,
  },
  emoji: { fontSize: 48, marginBottom: SPACING.lg },
  title: { ...FONT.title, marginBottom: SPACING.sm },
  subtitle: { ...FONT.regular, textAlign: 'center', color: COLORS.gray500 },
});

// Use in FlatList:
<FlatList
  data={chats}
  renderItem={renderChatRow}
  ListEmptyComponent={EmptyChats}
/>

11. Full runnable App.js — Polished chat list screen

This example shows a production-quality chat list with all the polish techniques from this lesson applied: proper StatusBar, safe area handling, consistent spacing, typography hierarchy, separators, press feedback, FAB, and empty state.

// App.js — Polished chat list with UI polish techniques
import React, { useState } from 'react';
import {
  View, Text, FlatList, Pressable, StyleSheet, StatusBar,
  Platform, Image, LayoutAnimation, UIManager,
} from 'react-native';
import { SafeAreaProvider, useSafeAreaInsets } from 'react-native-safe-area-context';

// Enable LayoutAnimation on Android
if (Platform.OS === 'android' && UIManager.setLayoutAnimationEnabledExperimental) {
  UIManager.setLayoutAnimationEnabledExperimental(true);
}

// ─── Design System ──────────────────────────────────────────────────
const COLORS = {
  darkGreen: '#075E54',
  lightGreen: '#25D366',
  bubbleGreen: '#DCF8C6',
  chatBg: '#ECE5DD',
  white: '#FFFFFF',
  gray100: '#F7F8FA',
  gray200: '#E8E8E8',
  gray500: '#667781',
  gray700: '#3B4A54',
  gray900: '#111B21',
  blue: '#53BDEB',
};

const SPACING = { xs: 4, sm: 8, md: 12, lg: 16, xl: 20, xxl: 24 };

// ─── Sample Data ────────────────────────────────────────────────────
const SAMPLE_CHATS = [
  { id: '1', name: 'Priya', message: 'See you at 6!', time: '10:34 AM', unread: 2, online: true },
  { id: '2', name: 'Rahul', message: 'The meeting is confirmed for Thursday', time: '9:12 AM', unread: 0, online: false },
  { id: '3', name: 'Team WhatsApp', message: 'Ashish: Pushed the latest build', time: 'Yesterday', unread: 5, online: false },
  { id: '4', name: 'Neha', message: '📷 Photo', time: 'Yesterday', unread: 0, online: true },
  { id: '5', name: 'Dev Group', message: 'Rahul: Can someone review my PR?', time: 'Monday', unread: 0, online: false },
];

// ─── Components ─────────────────────────────────────────────────────
function Avatar({ name, online }) {
  return (
    <View style={styles.avatarContainer}>
      <View style={styles.avatar}>
        <Text style={styles.avatarText}>{name.charAt(0).toUpperCase()}</Text>
      </View>
      {online && <View style={styles.onlineDot} />}
    </View>
  );
}

function ChatRow({ chat, onPress }) {
  return (
    <Pressable
      onPress={onPress}
      style={({ pressed }) => [
        styles.chatRow,
        pressed && Platform.OS === 'ios' && { opacity: 0.7 },
      ]}
      android_ripple={{ color: 'rgba(0,0,0,0.08)' }}
    >
      <Avatar name={chat.name} online={chat.online} />
      <View style={styles.chatContent}>
        <View style={styles.chatTop}>
          <Text style={styles.chatName} numberOfLines={1}>{chat.name}</Text>
          <Text style={[styles.chatTime, chat.unread > 0 && { color: COLORS.lightGreen }]}>
            {chat.time}
          </Text>
        </View>
        <View style={styles.chatBottom}>
          <Text style={styles.chatMessage} numberOfLines={1}>{chat.message}</Text>
          {chat.unread > 0 && (
            <View style={styles.unreadBadge}>
              <Text style={styles.unreadText}>{chat.unread}</Text>
            </View>
          )}
        </View>
      </View>
    </Pressable>
  );
}

function ChatSeparator() {
  return (
    <View style={styles.separatorContainer}>
      <View style={styles.separatorLine} />
    </View>
  );
}

function EmptyChats() {
  return (
    <View style={styles.emptyContainer}>
      <Text style={styles.emptyEmoji}>💬</Text>
      <Text style={styles.emptyTitle}>No chats yet</Text>
      <Text style={styles.emptySubtitle}>Tap the button below to start a conversation</Text>
    </View>
  );
}

function FAB({ onPress }) {
  return (
    <Pressable
      style={({ pressed }) => [styles.fab, pressed && styles.fabPressed]}
      onPress={onPress}
    >
      <Text style={styles.fabIcon}>💬</Text>
    </Pressable>
  );
}

// ─── Main App ───────────────────────────────────────────────────────
function ChatListScreen() {
  const insets = useSafeAreaInsets();
  const [chats, setChats] = useState(SAMPLE_CHATS);

  function handleChatPress(chatId) {
    // Mark as read with animation
    LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut);
    setChats((prev) =>
      prev.map((c) => (c.id === chatId ? { ...c, unread: 0 } : c))
    );
  }

  function handleNewChat() {
    // Simulate new chat arriving at top
    LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut);
    const newChat = {
      id: String(Date.now()),
      name: 'New Contact',
      message: 'Hey! Just added you',
      time: 'Just now',
      unread: 1,
      online: true,
    };
    setChats((prev) => [newChat, ...prev]);
  }

  return (
    <View style={styles.container}>
      <StatusBar barStyle="light-content" backgroundColor={COLORS.darkGreen} />

      {/* Header */}
      <View style={[styles.header, { paddingTop: insets.top + SPACING.md }]}>
        <Text style={styles.headerTitle}>WhatsApp</Text>
        <View style={styles.headerActions}>
          <Pressable style={styles.headerBtn}>
            <Text style={styles.headerIcon}>🔍</Text>
          </Pressable>
          <Pressable style={styles.headerBtn}>
            <Text style={styles.headerIcon}>⋮</Text>
          </Pressable>
        </View>
      </View>

      {/* Chat list */}
      <FlatList
        data={chats}
        renderItem={({ item }) => (
          <ChatRow chat={item} onPress={() => handleChatPress(item.id)} />
        )}
        keyExtractor={(item) => item.id}
        ItemSeparatorComponent={ChatSeparator}
        ListEmptyComponent={EmptyChats}
        contentContainerStyle={chats.length === 0 && { flex: 1 }}
      />

      {/* FAB */}
      <FAB onPress={handleNewChat} />
    </View>
  );
}

export default function App() {
  return (
    <SafeAreaProvider>
      <ChatListScreen />
    </SafeAreaProvider>
  );
}

12. Checklist: applying polish across all screens

Go through each screen in your app and check:

Check What to look for
☐ StatusBar Correct barStyle and backgroundColor on every screen
☐ Safe areas Nothing hidden behind notch or home indicator
☐ Colours All from COLORS constant — no hardcoded hex strings
☐ Spacing All from SPACING — consistent multiples everywhere
☐ Typography Max 3 sizes per screen, proper hierarchy
☐ Press feedback Every tappable element gives visual feedback
☐ Empty states ListEmptyComponent on every FlatList
☐ Separators Consistent divider lines between list items
