Firestore — Real-Time Messages

Messages sub-collection · addDoc · onSnapshot · updateDoc · unread counts ~50 min Hands-on
Why this matters for your WhatsApp clone

The message thread in Lesson 14 used setTimeout to fake replies — messages vanished when the app closed and nobody else could see them. This lesson replaces all of that with Firestore. When you send a message it is written to Firestore instantly. The recipient's phone receives it in real time via onSnapshot. The chat list updates with the new preview. Unread counts increment for the recipient and clear when they open the thread. This is the core of a real messaging app.

1. The messages sub-collection

Each message is a document in the messages sub-collection inside its chat:

// Firestore path: /chats/{chatId}/messages/{messageId}
{
  text:      'Hey! Are you free this weekend?',
  senderId:  'uid_priya',           // matches auth.currentUser.uid
  createdAt: Timestamp,             // serverTimestamp() — used for ordering
  read:      false,                 // true once the recipient opens the thread
}

The parent /chats/{chatId} document (from Lesson 3) also needs updating every time a message is sent — its lastMessage, lastMessageAt, and unreadCounts fields drive the chat list preview.

2. Sending a message — addDoc + updateDoc

Sending one message requires two Firestore writes: add the message document, then update the parent chat document.

import {
  collection, addDoc, doc, updateDoc,
  serverTimestamp, increment,
} from 'firebase/firestore';
import { db, auth } from './firebase';

async function sendMessage(chatId, members, text) {
  const myUid = auth.currentUser.uid;
  const trimmed = text.trim();
  if (!trimmed) return;

  // 1. Add the message to the sub-collection
  await addDoc(collection(db, 'chats', chatId, 'messages'), {
    text:      trimmed,
    senderId:  myUid,
    createdAt: serverTimestamp(),
    read:      false,
  });

  // 2. Update the parent chat document
  //    — increment unread count for every member who is NOT me
  const unreadUpdates = {};
  members.forEach(uid => {
    if (uid !== myUid) {
      unreadUpdates[`unreadCounts.${uid}`] = increment(1);
      //                                     ↑ atomic increment — safe under concurrent writes
    }
  });

  await updateDoc(doc(db, 'chats', chatId), {
    lastMessage:   trimmed,
    lastMessageAt: serverTimestamp(),
    lastSenderId:  myUid,
    ...unreadUpdates,
  });
}
increment() — safe concurrent counting

increment(1) tells Firestore to add 1 to the current value atomically on the server. If you read the count first, add 1 in JS, and write it back, two simultaneous sends from different devices would overwrite each other and one would be lost. increment(1) avoids this race condition entirely — Firestore handles the arithmetic on the server.

3. Listening for messages — onSnapshot on the sub-collection

Set up a live listener on the messages sub-collection when the thread screen mounts. Order by createdAt ascending — oldest first — because the FlatList is inverted (item [0] shows at the bottom).

import {
  collection, query, orderBy, onSnapshot,
} from 'firebase/firestore';
import { db, auth } from './firebase';

useEffect(() => {
  if (!chatId) return;

  const q = query(
    collection(db, 'chats', chatId, 'messages'),
    orderBy('createdAt', 'asc')   // oldest first → inverted FlatList shows newest at bottom
  );

  const unsubscribe = onSnapshot(q,
    (snapshot) => {
      const msgs = snapshot.docs.map(doc => ({
        id:        doc.id,
        ...doc.data(),
        // createdAt may briefly be null (pending serverTimestamp) — guard it
        time: doc.data().createdAt
          ? formatTimestamp(doc.data().createdAt)
          : '',
      }));
      setMessages(msgs);
      setLoading(false);
    },
    (err) => {
      console.error(err);
      setError('Could not load messages.');
      setLoading(false);
    }
  );

  return unsubscribe;
}, [chatId]);
createdAt is briefly null after you send

When you call addDoc with serverTimestamp(), Firestore immediately fires the local onSnapshot with a pending write — the document appears instantly in your UI but createdAt is null until the server confirms the timestamp. Always guard: doc.data().createdAt ? formatTimestamp(...) : ''. The real timestamp arrives in the next snapshot a fraction of a second later.

4. Marking messages as read

When the user opens a thread, mark all unread messages as read and reset their unread count to zero. Do this in a useEffect that fires when the screen mounts.

import {
  collection, query, where, getDocs,
  writeBatch, doc, updateDoc,
} from 'firebase/firestore';
import { db, auth } from './firebase';

async function markAsRead(chatId) {
  const myUid = auth.currentUser.uid;

  // 1. Reset my unread count on the chat document
  await updateDoc(doc(db, 'chats', chatId), {
    [`unreadCounts.${myUid}`]: 0,
  });

  // 2. Mark all unread messages (sent by others) as read
  //    Use a batch write — one network round-trip for many documents
  const unreadQuery = query(
    collection(db, 'chats', chatId, 'messages'),
    where('read', '==', false),
    where('senderId', '!=', myUid)    // only messages sent BY others
  );

  const snapshot = await getDocs(unreadQuery);
  if (snapshot.empty) return;

  const batch = writeBatch(db);
  snapshot.docs.forEach(msgDoc => {
    batch.update(msgDoc.ref, { read: true });
  });
  await batch.commit();
}
writeBatch — one round-trip for many writes

A batch groups multiple writes into a single network request. If you had 50 unread messages and called updateDoc 50 times in a loop, that's 50 round-trips. writeBatch sends all 50 in one request. Batches are also atomic — either all writes succeed or none do.

5. Formatting Firestore Timestamps

Firestore Timestamp objects are not JavaScript Date objects — call .toDate() to convert.

function formatTimestamp(ts) {
  if (!ts) return '';
  const date = ts.toDate();   // Firestore Timestamp → JS Date
  return date.toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' });
}

function formatDateLabel(ts) {
  if (!ts) return 'Today';
  const date = ts.toDate();
  const now  = new Date();
  const diff = now - date;
  const day  = 86400000;
  if (diff < day)    return 'Today';
  if (diff < day*2)  return 'Yesterday';
  return date.toLocaleDateString([], { weekday: 'long', month: 'short', day: 'numeric' });
}

6. Optimistic UI — show the message immediately

Firestore's local cache means onSnapshot fires almost instantly after addDoc — the message appears before the server confirms it. This is called an optimistic update and is built into Firestore's SDK. You get it for free: just call addDoc and the message appears in the UI immediately.

The send flow is:

  1. User taps Send
  2. addDoc writes to Firestore — SDK puts it in the local cache immediately
  3. onSnapshot fires with the cached version — message appears on screen
  4. Firestore syncs to the server in the background
  5. onSnapshot fires again with the confirmed server version (timestamps filled in)

From the user's perspective: the message appears the instant they tap Send, just like WhatsApp.

7. Full working example — MessageThreadScreen with real Firestore

This replaces the MessageThreadScreen from Lesson 14. The UI is identical — the only changes are the data source (Firestore instead of local state) and the send function (addDoc instead of setMessages). Drop this in alongside the ChatListScreen from Lesson 3.

import { useState, useEffect } from 'react';
import {
  View, Text, FlatList, TextInput, Pressable,
  StyleSheet, KeyboardAvoidingView, Platform, Keyboard,
  ActivityIndicator,
} from 'react-native';
import {
  collection, query, orderBy, onSnapshot,
  addDoc, doc, updateDoc, getDocs,
  where, writeBatch, serverTimestamp, increment,

import { db, auth } from './firebase';

// ── Helpers ───────────────────────────────────────────────────────────────────
function formatTime(ts) {
  if (!ts) return '';
  return ts.toDate().toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' });
}

function formatDateLabel(ts) {
  if (!ts) return '';
  const date = ts.toDate();
  const diff = new Date() - date;
  const day  = 86400000;
  if (diff < day)   return 'Today';
  if (diff < day*2) return 'Yesterday';
  return date.toLocaleDateString([], { weekday: 'long', month: 'short', day: 'numeric' });
}

function insertDateSeparators(messages) {
  const result = [];
  let lastLabel = null;
  for (const msg of messages) {
    const label = formatDateLabel(msg.createdAt);
    if (label && label !== lastLabel) {
      result.push({ id: `sep-${label}-${msg.id}`, type: 'separator', label });
      lastLabel = label;
    }
    result.push({ ...msg, type: 'message' });
  }
  return result;
}

// ── Components ────────────────────────────────────────────────────────────────
function DateSeparator({ label }) {
  return (
    <View style={styles.dateSepRow}>
      <View style={styles.dateSepPill}>
        <Text style={styles.dateSepText}>{label}</Text>
      </View>
    </View>
  );
}

function MessageBubble({ message }) {
  const myUid = auth.currentUser?.uid;
  const isMe  = message.senderId === myUid;
  return (
    <View style={[styles.bubbleRow, isMe ? styles.rowRight : styles.rowLeft]}>
      <View style={[styles.bubble, isMe ? styles.bubbleMe : styles.bubbleThem]}>
        <Text style={styles.bubbleText}>{message.text}</Text>
        <View style={styles.bubbleMeta}>
          <Text style={styles.bubbleTime}>{formatTime(message.createdAt)}</Text>
          {isMe && (
            <Text style={[styles.ticks, message.read && styles.ticksRead]}>
              {message.read ? '✓✓' : '✓'}
            </Text>
          )}
        </View>
      </View>
    </View>
  );
}

// ── MessageThreadScreen ───────────────────────────────────────────────────────
export function MessageThreadScreen({ route, navigation }) {
  const {
    chatId   = '',
    chatName = 'Chat',
    isGroup  = false,
    members  = [],
  } = route.params ?? {};

  const [messages,  setMessages]  = useState([]);
  const [inputText, setInputText] = useState('');
  const [loading,   setLoading]   = useState(true);
  const [error,     setError]     = useState(null);
  const [sending,   setSending]   = useState(false);

  const myUid = auth.currentUser?.uid;

  // Hide default navigation header — we use a custom green one
  useEffect(() => {
    navigation.setOptions({ headerShown: false });
  }, []);

  // Mark messages as read when screen mounts
  useEffect(() => {
    if (!chatId || !myUid) return;

    async function markRead() {
      try {
        // Reset unread count
        await updateDoc(doc(db, 'chats', chatId), {
          [`unreadCounts.${myUid}`]: 0,
        });
        // Batch-update unread messages
        const snap = await getDocs(query(
          collection(db, 'chats', chatId, 'messages'),
          where('read',     '==', false),
          where('senderId', '!=', myUid)
        ));
        if (!snap.empty) {
          const batch = writeBatch(db);
          snap.docs.forEach(d => batch.update(d.ref, { read: true }));
          await batch.commit();
        }
      } catch (e) {
        console.warn('markRead error:', e.message);
      }
    }

    markRead();
  }, [chatId, myUid]);

  // Live messages listener
  useEffect(() => {
    if (!chatId) return;

    const q = query(
      collection(db, 'chats', chatId, 'messages'),
      orderBy('createdAt', 'asc')
    );

    const unsubscribe = onSnapshot(q,
      (snapshot) => {
        setMessages(snapshot.docs.map(d => ({ id: d.id, ...d.data() })));
        setLoading(false);
      },
      (err) => {
        console.error(err);
        setError('Could not load messages.');
        setLoading(false);
      }
    );

    return unsubscribe;
  }, [chatId]);

  // Send a message
  async function handleSend() {
    const text = inputText.trim();
    if (!text || !chatId || !myUid) return;

    setInputText('');
    Keyboard.dismiss();
    setSending(true);

    try {
      // 1. Write the message
      await addDoc(collection(db, 'chats', chatId, 'messages'), {
        text,
        senderId:  myUid,
        createdAt: serverTimestamp(),
        read:      false,
      });

      // 2. Update the chat document preview + increment others' unread
      const unreadUpdates = {};
      members.forEach(uid => {
        if (uid !== myUid) unreadUpdates[`unreadCounts.${uid}`] = increment(1);
      });

      await updateDoc(doc(db, 'chats', chatId), {
        lastMessage:   text,
        lastMessageAt: serverTimestamp(),
        lastSenderId:  myUid,
        ...unreadUpdates,
      });
    } catch (e) {
      console.error('Send error:', e.message);
      // Restore the text so the user can retry
      setInputText(text);
    } finally {
      setSending(false);
    }
  }

  const displayItems = insertDateSeparators(messages);

  // ── Loading ─────────────────────────────────────────────────────────────────
  if (loading) {
    return (
      <View style={styles.screen}>
        <View style={styles.header}>
          <Pressable onPress={() => navigation.goBack()} style={styles.backBtn}>
            <Text style={styles.backArrow}>←</Text>
          </Pressable>
          <Text style={styles.headerName}>{chatName}</Text>
        </View>
        <View style={styles.centre}>
          <ActivityIndicator size="large" color="#075E54" />
        </View>
      </View>
    );
  }

  // ── Error ───────────────────────────────────────────────────────────────────
  if (error) {
    return (
      <View style={styles.screen}>
        <View style={styles.header}>
          <Pressable onPress={() => navigation.goBack()} style={styles.backBtn}>
            <Text style={styles.backArrow}>←</Text>
          </Pressable>
          <Text style={styles.headerName}>{chatName}</Text>
        </View>
        <View style={styles.centre}>
          <Text style={styles.errorText}>{error}</Text>
        </View>
      </View>
    );
  }

  // ── Main ────────────────────────────────────────────────────────────────────
  return (
    <KeyboardAvoidingView
      style={styles.screen}
      behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
    >
      {/* Header */}
      <View style={styles.header}>
        <Pressable onPress={() => navigation.goBack()} style={styles.backBtn}>
          <Text style={styles.backArrow}>←</Text>
        </Pressable>
        <View style={styles.avatarSmall}>
          <Text style={styles.avatarLetter}>{chatName[0]?.toUpperCase()}</Text>
        </View>
        <View style={styles.headerInfo}>
          <Text style={styles.headerName}>{chatName}</Text>
          <Text style={styles.headerStatus}>{isGroup ? 'Group' : 'online'}</Text>
        </View>
        <View style={styles.headerActions}>
          <Pressable style={styles.headerIcon}>
            <Text style={{ fontSize: 20 }}>📹</Text>
          </Pressable>
          <Pressable style={styles.headerIcon}>
            <Text style={{ fontSize: 20 }}>📞</Text>
          </Pressable>
        </View>
      </View>

      {/* Message list */}
      <FlatList
        data={displayItems}
        keyExtractor={item => item.id}
        inverted
        style={styles.messageList}
        contentContainerStyle={styles.messageListContent}
        keyboardShouldPersistTaps="handled"
        ListEmptyComponent={
          <View style={styles.emptyThread}>
            <Text style={styles.emptyThreadText}>
              No messages yet. Say hello! 👋
            </Text>
          </View>
        }
        renderItem={({ item }) =>
          item.type === 'separator'
            ? <DateSeparator label={item.label} />
            : <MessageBubble message={item} />
        }
      />

      {/* Input bar */}
      <View style={styles.inputBar}>
        <Pressable style={styles.attachBtn}>
          <Text style={{ fontSize: 22 }}>📎</Text>
        </Pressable>
        <TextInput
          style={styles.textInput}
          value={inputText}
          onChangeText={setInputText}
          placeholder="Message"
          placeholderTextColor="#aaa"
          multiline
          maxHeight={120}
          returnKeyType="default"
          paddingTop={Platform.OS === 'ios' ? 10 : undefined}
        />
        <Pressable
          style={[styles.sendButton, (!inputText.trim() || sending) && styles.sendButtonDisabled]}
          onPress={handleSend}
          disabled={!inputText.trim() || sending}
        >
          {sending
            ? <ActivityIndicator size="small" color="#fff" />
            : <Text style={styles.sendIcon}>➤</Text>
          }
        </Pressable>
      </View>

    </KeyboardAvoidingView>
  );
}

8. What the full data flow looks like

Here is the complete journey of one message from Priya to Ashish:

  1. Priya types "See you Saturday!" and taps Send
  2. addDoc writes /chats/abc123/messages/msg999 to Firestore (SDK caches locally — instant)
  3. Priya's onSnapshot fires — her thread shows the message immediately with a single grey tick
  4. updateDoc sets lastMessage, lastMessageAt, and increments unreadCounts.uid_ashish
  5. Ashish's chat list onSnapshot fires — "See you Saturday!" appears as the preview, unread badge shows 1
  6. Ashish opens the thread — his onSnapshot fires and the message appears
  7. markAsRead runs: sets unreadCounts.uid_ashish = 0, sets msg999.read = true
  8. Priya's onSnapshot receives the read: true update — her tick turns blue ✓✓

Anything unclear? Ask your teacher. Common issues: (1) Messages appear twice — you have two onSnapshot listeners running; check that your useEffect returns the unsubscribe function and that you don't call onSnapshot outside of useEffect. (2) Sent message shows no time for a moment — this is the pending serverTimestamp(); the guard createdAt ? formatTime(createdAt) : '' handles it. (3) Unread count doesn't clear — check that markAsRead uses the correct field path `unreadCounts.${myUid}` with a backtick template string, not a nested object. (4) Other user's messages don't appear — confirm both users are logged in with real Firebase accounts (not the same test account) and that both have access to the same chatId passed via route params.
