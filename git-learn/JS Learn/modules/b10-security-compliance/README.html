Security & Compliance

Track B

Phase 7 — 2 lessons

Module goal: Harden the Token backend against common attacks and implement the requirements of India's Digital Personal Data Protection Act (DPDP, 2023). Token is a privacy product — security and legal compliance aren't features to add later, they're the foundation the product stands on.

Lessons

  1. Security Hardening
  2. India's DPDP Act

What you'll build

  • Parameterised queries enforced everywhere — zero SQL injection surface
  • Secrets management: environment variables, rotation strategy, no committed secrets
  • CORS configuration that restricts access to your known clients
  • CSP, HSTS, and other security headers via helmet
  • Input sanitisation and output encoding for stored user content
  • DPDP-compliant consent flow (purpose-limited, granular, revocable)
  • Data portability endpoint (machine-readable export of user data)
  • Account deletion that actually deletes — not soft-delete forever

Prerequisites

  • B3 Node & HTTP Server — the Express/Fastify server you're hardening
  • B4 Auth Server — JWT and password hashing you'll audit
  • B9 Docker & Deployment — environment variable management in production
