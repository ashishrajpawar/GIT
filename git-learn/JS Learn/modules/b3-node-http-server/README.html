Node & HTTP Server

4 lessons Phase 2 — Backend Core
Module goal

Build Token's API server — from the Node.js runtime through Express routing to a fully validated REST API with proper error handling. After this module, you have a running API that the mobile app and web page can talk to.

Lessons

  1. Node.js Fundamentals — event loop, modules, env vars, crypto, process lifecycle
  2. Express/Fastify Setup — routing, middleware, Router, error handling, DB connection
  3. REST API Design — resources, methods, status codes, pagination, response envelopes
  4. Input Validation & Error Handling — Zod schemas, validation middleware, error layers

After this module

You'll have:

  • A running Express server in api/src/server.ts
  • Full CRUD routes for tokens with real database queries
  • Cursor-based pagination
  • Zod validation schemas shared between client and server
  • A three-layer error handling strategy (validation, business logic, catch-all)
  • Parameterized queries (SQL injection prevention)
