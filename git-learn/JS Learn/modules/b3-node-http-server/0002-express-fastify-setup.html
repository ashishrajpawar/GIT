Express/Fastify Setup

B3 — Lesson 2 of 4 ~50 min
Why this matters for Token

The raw http module makes you manually parse URLs, read request bodies, handle routing, and format responses. A framework handles all of that so you can focus on Token's logic: issuing tokens, validating rules, routing messages. We'll use Express — the most widely-used Node framework — because its ecosystem and documentation are unmatched for learning.

Why Express?

Express gives you:

  • Routing — map URL paths + HTTP methods to handler functions
  • Middleware — functions that process every request (parsing, logging, auth)
  • Request/Response helpers — req.params, req.body, res.json()
  • Ecosystem — thousands of middleware packages for common tasks
npm install express
npm install -D @types/express

Basic Express server

// api/src/server.ts
import 'dotenv/config';
import express from 'express';

const app = express();
const PORT = parseInt(process.env.PORT || '3000', 10);

// Built-in middleware: parse JSON request bodies
app.use(express.json());

// Health check
app.get('/health', (req, res) => {
  res.json({ status: 'ok' });
});

// Start the server
app.listen(PORT, () => {
  console.log(`Token API running on http://localhost:${PORT}`);
});

Routing

Express routes match a method + path to a handler function:

// GET /api/tokens — list tokens
app.get('/api/tokens', (req, res) => { ... });

// GET /api/tokens/:code — get one token by code
app.get('/api/tokens/:code', (req, res) => {
  const { code } = req.params;  // URL parameter
  // ...
});

// POST /api/tokens — create a new token
app.post('/api/tokens', (req, res) => {
  const { label, maxUses } = req.body;  // JSON body
  // ...
});

// PATCH /api/tokens/:code — update a token
app.patch('/api/tokens/:code', (req, res) => { ... });

// DELETE /api/tokens/:code — revoke a token
app.delete('/api/tokens/:code', (req, res) => { ... });

Route parameters

// :code becomes req.params.code
app.get('/api/tokens/:code', (req, res) => {
  console.log(req.params.code);  // "MERC-8GH2-LP4X"
});

// Query parameters: /api/tokens?status=active&limit=10
app.get('/api/tokens', (req, res) => {
  console.log(req.query.status);  // "active"
  console.log(req.query.limit);   // "10" (always string!)
});

Middleware

Middleware are functions that run before your route handler. They can:

  • Modify the request (add user info after auth)
  • Short-circuit the response (reject unauthorized requests)
  • Pass control to the next middleware/handler with next()
// Logging middleware — runs on every request
app.use((req, res, next) => {
  console.log(`${req.method} ${req.url}`);
  next();  // pass to the next handler
});

// CORS middleware — allow the web client to call the API
import cors from 'cors';
app.use(cors({
  origin: process.env.WEB_URL || 'http://localhost:5173',
  credentials: true,
}));

// JSON body parser (built-in)
app.use(express.json({ limit: '1mb' }));

Route-specific middleware

// Auth middleware — only applies to routes that need it
function requireAuth(req, res, next) {
  const token = req.headers.authorization?.replace('Bearer ', '');
  if (!token) {
    return res.status(401).json({ error: 'Authentication required' });
  }
  // verify JWT, attach user to request...
  req.user = verifiedUser;
  next();
}

// Apply to specific routes:
app.get('/api/tokens', requireAuth, (req, res) => {
  // req.user is available here
});

// Or to a group of routes:
const apiRouter = express.Router();
apiRouter.use(requireAuth);
apiRouter.get('/tokens', ...);
apiRouter.post('/tokens', ...);
app.use('/api', apiRouter);

Organizing routes with Router

For Token's API, split routes into separate files:

// api/src/routes/tokens.ts
import { Router } from 'express';

const router = Router();

router.get('/', async (req, res) => {
  // List user's tokens
});

router.get('/:code', async (req, res) => {
  // Get single token
});

router.post('/', async (req, res) => {
  // Create token
});

router.patch('/:code', async (req, res) => {
  // Update token
});

router.delete('/:code', async (req, res) => {
  // Revoke token
});

export default router;
// api/src/server.ts
import tokenRoutes from './routes/tokens.js';
import messageRoutes from './routes/messages.js';

app.use('/api/tokens', tokenRoutes);
app.use('/api/messages', messageRoutes);

Error handling

Express has a special 4-argument middleware for errors:

// Error handler — must be LAST app.use()
app.use((err, req, res, next) => {
  console.error(err.stack);

  const status = err.status || 500;
  const message = err.status ? err.message : 'Internal server error';

  res.status(status).json({
    error: message,
    ...(process.env.NODE_ENV === 'development' && { stack: err.stack }),
  });
});

Throw errors in route handlers to trigger it:

router.get('/:code', async (req, res, next) => {
  try {
    const token = await findTokenByCode(req.params.code);
    if (!token) {
      const err = new Error('Token not found');
      err.status = 404;
      throw err;
    }
    res.json(token);
  } catch (err) {
    next(err);  // passes to the error handler
  }
});

Token API folder structure

api/
  src/
    server.ts           ← app setup, middleware, listen
    routes/
      tokens.ts         ← /api/tokens routes
      messages.ts       ← /api/messages routes
      redeem.ts         ← /api/redeem (public, no auth)
    middleware/
      auth.ts           ← JWT verification
      error-handler.ts  ← global error handler
    services/
      tokens.ts         ← business logic (DB queries)
      messages.ts
    db/
      pool.ts           ← Postgres connection pool
  migrations/
  .env
  package.json
  tsconfig.json

Separation of concerns: routes handle HTTP (status codes, parsing), services handle business logic (DB queries, validation). Routes call services — services know nothing about HTTP.

Connecting to Postgres

// api/src/db/pool.ts
import pg from 'pg';

export const pool = new pg.Pool({
  connectionString: process.env.DATABASE_URL,
  max: 20,  // connection pool size
});

// Test the connection on startup
pool.query('SELECT NOW()').then(() => {
  console.log('Database connected');
}).catch(err => {
  console.error('Database connection failed:', err.message);
  process.exit(1);
});
// Using it in a service
import { pool } from '../db/pool.js';

export async function getTokenByCode(code: string) {
  const { rows } = await pool.query(
    'SELECT * FROM tokens WHERE code = $1',
    [code]
  );
  return rows[0] || null;
}
Always use parameterized queries

Never concatenate user input into SQL strings: `SELECT * FROM tokens WHERE code = '${code}'`. This allows SQL injection — an attacker can delete your entire database. Always use $1 parameters.
