Production at Scale · Lesson 7

Testing Your App

Jest · Unit tests · Component tests · Firebase Emulator · QA checklist ~60 min Hands-on
Why this matters for your WhatsApp clone

You've added dozens of features — messaging, calls, groups, notifications, offline support. Every time you fix a bug or add something new, you risk breaking something that already works. Without tests, the only way to know is to manually tap through every screen on every update. Tests catch these regressions automatically in seconds. WhatsApp has thousands of automated tests — that's how they ship updates to 2 billion users without breaking existing features.

1. Types of tests and what to use each for

TypeWhat it testsSpeedTools
Unit tests Individual functions (pure logic) ~1ms each Jest
Component tests UI components render and respond to interaction ~50ms each React Native Testing Library
Integration tests App code + Firebase working together ~500ms each Firebase Emulator + Jest
Manual QA Full flows on a real device Minutes Your eyes + checklist

The testing pyramid: Write many unit tests (fast, cheap), some component tests (medium), few integration tests (slow, expensive), and a focused manual QA checklist for things only humans can judge.

3. Unit testing utility functions

Start with the easiest tests — pure functions with no dependencies. Your WhatsApp clone has several:

// src/utils/formatTime.js
export function formatMessageTime(timestamp) {
  if (!timestamp) return '';
  const date = timestamp.toDate ? timestamp.toDate() : new Date(timestamp);
  return date.toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' });
}

export function formatLastSeen(timestamp) {
  if (!timestamp) return 'unknown';
  const date = timestamp.toDate ? timestamp.toDate() : new Date(timestamp);
  const now = new Date();
  const diffMs = now - date;
  const diffMins = Math.floor(diffMs / 60000);

  if (diffMins < 1) return 'just now';
  if (diffMins < 60) return `${diffMins} min ago`;
  if (diffMins < 1440) return `${Math.floor(diffMins / 60)} hours ago`;
  return date.toLocaleDateString();
}

export function truncateText(text, maxLength = 100) {
  if (!text) return '';
  if (text.length <= maxLength) return text;
  return text.substring(0, maxLength - 3) + '...';
}

export function validateMessage(text) {
  const trimmed = (text || '').trim();
  if (trimmed.length === 0) return { valid: false, error: 'Message is empty' };
  if (trimmed.length > 4096) return { valid: false, error: 'Message too long' };
  return { valid: true, text: trimmed };
}
// src/utils/formatTime.test.js
import { formatLastSeen, truncateText, validateMessage } from './formatTime';

describe('formatLastSeen', () => {
  test('returns "just now" for timestamps less than 1 minute ago', () => {
    const thirtySecondsAgo = new Date(Date.now() - 30000);
    expect(formatLastSeen(thirtySecondsAgo)).toBe('just now');
  });

  test('returns minutes for timestamps less than 1 hour ago', () => {
    const tenMinutesAgo = new Date(Date.now() - 600000);
    expect(formatLastSeen(tenMinutesAgo)).toBe('10 min ago');
  });

  test('returns hours for timestamps less than 1 day ago', () => {
    const threeHoursAgo = new Date(Date.now() - 10800000);
    expect(formatLastSeen(threeHoursAgo)).toBe('3 hours ago');
  });

  test('returns "unknown" for null/undefined', () => {
    expect(formatLastSeen(null)).toBe('unknown');
    expect(formatLastSeen(undefined)).toBe('unknown');
  });
});

describe('truncateText', () => {
  test('returns full text if under max length', () => {
    expect(truncateText('Hello Priya', 100)).toBe('Hello Priya');
  });

  test('truncates and adds ellipsis if over max length', () => {
    const long = 'A'.repeat(200);
    const result = truncateText(long, 100);
    expect(result.length).toBe(100);
    expect(result.endsWith('...')).toBe(true);
  });

  test('handles empty/null input', () => {
    expect(truncateText('')).toBe('');
    expect(truncateText(null)).toBe('');
  });
});

describe('validateMessage', () => {
  test('rejects empty messages', () => {
    expect(validateMessage('')).toEqual({ valid: false, error: 'Message is empty' });
    expect(validateMessage('   ')).toEqual({ valid: false, error: 'Message is empty' });
  });

  test('rejects messages over 4096 characters', () => {
    const longMsg = 'A'.repeat(4097);
    expect(validateMessage(longMsg)).toEqual({ valid: false, error: 'Message too long' });
  });

  test('accepts valid messages and trims whitespace', () => {
    expect(validateMessage('  Hello Priya!  ')).toEqual({
      valid: true,
      text: 'Hello Priya!',
    });
  });

  test('accepts message at exactly 4096 characters', () => {
    const maxMsg = 'A'.repeat(4096);
    expect(validateMessage(maxMsg).valid).toBe(true);
  });
});

4. Component tests with React Native Testing Library

Component tests verify that your UI renders correctly and responds to user interaction — without needing a real phone.

// src/components/MessageBubble.js
import React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export function MessageBubble({ message, isMine }) {
  const isPending = !message.createdAt;

  return (
    <View
      style={[styles.bubble, isMine ? styles.mine : styles.theirs]}
      testID="message-bubble"
    >
      <Text testID="message-text">{message.text}</Text>

      {isMine && (
        <Text testID="message-status">
          {isPending ? '🕐' : '✓✓'}
        </Text>
      )}

}

function formatTime(timestamp) {
  if (!timestamp?.toDate) return '';

// src/components/SendBar.test.js
import React from 'react';
import { render, screen, fireEvent } from '@testing-library/react-native';
import { SendBar } from './SendBar';

describe('SendBar', () => {
  test('calls onSend with trimmed text when send is pressed', () => {
    const mockSend = jest.fn();
    render(<SendBar onSend={mockSend} />);

    const input = screen.getByPlaceholderText('Type a message');
    fireEvent.changeText(input, '  Hello Priya!  ');

    const sendBtn = screen.getByTestId('send-button');
    fireEvent.press(sendBtn);

    expect(mockSend).toHaveBeenCalledWith('Hello Priya!');
  });

  test('does not call onSend for empty messages', () => {
    const mockSend = jest.fn();
    render(<SendBar onSend={mockSend} />);

    const sendBtn = screen.getByTestId('send-button');
    fireEvent.press(sendBtn);

    expect(mockSend).not.toHaveBeenCalled();
  });

  test('clears input after successful send', () => {
    const mockSend = jest.fn();
    render(<SendBar onSend={mockSend} />);

    const input = screen.getByPlaceholderText('Type a message');
    fireEvent.changeText(input, 'Hello');
    fireEvent.press(screen.getByTestId('send-button'));

    expect(input.props.value).toBe('');

  test('disables send button while sending', () => {
    render(<SendBar onSend={jest.fn()} sending={true} />);

5. Integration tests with Firebase Emulator

Integration tests verify that your app code works correctly with real Firebase — but using the local emulator so you don't affect production data.

// __tests__/integration/messaging.test.js
import { initializeTestEnvironment, assertSucceeds, assertFails }
  from '@firebase/rules-unit-testing';
import { collection, addDoc, getDocs, query, orderBy, serverTimestamp }
  from 'firebase/firestore';

let testEnv;
let priyaDb, rahulDb;

beforeAll(async () => {
  testEnv = await initializeTestEnvironment({
    projectId: 'test-whatsapp-clone',
    firestore: {
      rules: require('fs').readFileSync('firestore.rules', 'utf8'),
      host: 'localhost',
      port: 8080,
    },
  });
});

beforeEach(async () => {
  await testEnv.clearFirestore();

  // Set up a chat between Priya and Rahul
  await testEnv.withSecurityRulesDisabled(async (context) => {
    const db = context.firestore();
    await db.doc('chats/chat1').set({
      participants: ['priya123', 'rahul456'],
      lastMessage: '',
      lastMessageAt: null,
    });
  });

  priyaDb = testEnv.authenticatedContext('priya123').firestore();
  rahulDb = testEnv.authenticatedContext('rahul456').firestore();
});

afterAll(async () => {
  await testEnv.cleanup();
});

describe('Messaging', () => {
  test('participant can send a message to their chat', async () => {
    await assertSucceeds(
      addDoc(collection(priyaDb, 'chats/chat1/messages'), {
        senderId: 'priya123',
        text: 'Hello Rahul!',
        createdAt: serverTimestamp(),
      })
    );
  });

  test('participant cannot impersonate another user', async () => {
    await assertFails(
      addDoc(collection(priyaDb, 'chats/chat1/messages'), {
        senderId: 'rahul456', // Priya trying to send as Rahul
        text: 'Fake message',
        createdAt: serverTimestamp(),
      })
    );
  });

  test('non-participant cannot read messages', async () => {
    const strangerDb = testEnv.authenticatedContext('stranger789').firestore();

    await assertFails(
      getDocs(collection(strangerDb, 'chats/chat1/messages'))
    );
  });

  test('messages are ordered by createdAt', async () => {
    // Send messages with slight delay
    await addDoc(collection(priyaDb, 'chats/chat1/messages'), {
      senderId: 'priya123',
      text: 'First message',
      createdAt: serverTimestamp(),
    });

    await addDoc(collection(rahulDb, 'chats/chat1/messages'), {
      senderId: 'rahul456',
      text: 'Second message',
      createdAt: serverTimestamp(),
    });

    const q = query(
      collection(priyaDb, 'chats/chat1/messages'),
      orderBy('createdAt', 'asc')
    );
    const snapshot = await getDocs(q);
    const messages = snapshot.docs.map(d => d.data().text);

    expect(messages).toEqual(['First message', 'Second message']);
  });

  test('message text cannot exceed 4096 characters', async () => {
    await assertFails(
      addDoc(collection(priyaDb, 'chats/chat1/messages'), {
        senderId: 'priya123',
        text: 'A'.repeat(4097),
        createdAt: serverTimestamp(),
      })
    );
  });
});

6. Mocking Firebase for unit/component tests

For unit and component tests you don't want to run the emulator — it's too slow. Instead, mock Firebase:

// __mocks__/firebase/firestore.js
// This file automatically replaces 'firebase/firestore' in all tests

export const getFirestore = jest.fn(() => ({}));
export const collection = jest.fn();
export const doc = jest.fn();
export const addDoc = jest.fn(() => Promise.resolve({ id: 'mock-id' }));
export const getDocs = jest.fn(() => Promise.resolve({ docs: [], size: 0 }));
export const onSnapshot = jest.fn((query, callback) => {
  // Immediately fire with empty snapshot
  callback({ docs: [], docChanges: () => [] });
  return jest.fn(); // unsubscribe function
});
export const query = jest.fn();
export const orderBy = jest.fn();
export const limit = jest.fn();
export const where = jest.fn();
export const serverTimestamp = jest.fn(() => ({ _type: 'serverTimestamp' }));
export const writeBatch = jest.fn(() => ({
  set: jest.fn(),
  update: jest.fn(),
  delete: jest.fn(),
  commit: jest.fn(() => Promise.resolve()),
}));
// __mocks__/firebase/auth.js
export const getAuth = jest.fn(() => ({
  currentUser: { uid: 'test-user-123', email: 'test@example.com' },
}));
export const signInWithEmailAndPassword = jest.fn(() =>
  Promise.resolve({ user: { uid: 'test-user-123' } })
);
export const signOut = jest.fn(() => Promise.resolve());

With these mocks in place, your component tests run in milliseconds without needing Firebase at all.

7. Manual QA checklist

Automated tests can't catch everything — visual glitches, "feels wrong" interactions, and complex multi-device flows need human testing. Use this checklist before every release:

Critical path (test every release)

7Turn on airplane mode → send message → turn off → message delivers☐

8. What to test before every release

// Add to package.json scripts:
{
  "scripts": {
    "test": "jest",
    "test:watch": "jest --watch",
    "test:coverage": "jest --coverage",
    "test:integration": "firebase emulators:exec 'npx jest __tests__/integration/ --forceExit'",
    "prerelease": "npm run test && npm run test:integration"
  }
}

Release testing flow

  1. npm run prerelease — runs all automated tests
  2. Fix any failures (don't ship with failing tests!)
  3. Build with EAS: eas build --platform all
  4. Install on a test device (both iOS and Android)
  5. Run through the manual QA checklist above
  6. If everything passes → submit to stores
Start small, grow over time

You don't need 100% test coverage on day one. Start with: (1) tests for utility functions (easiest), (2) tests for the MessageBubble component (most reused), and (3) one integration test for send-message flow. Add more tests whenever you fix a bug — write a test that would have caught it, then fix it. Over time your test suite grows organically.

9. Full working example — testable app structure

Here's how to structure your app so it's easy to test — logic separated from UI, components accept props instead of reaching into Firebase directly.

// App.js — Testable Architecture Demo
// Key pattern: separate logic (hooks/utils) from presentation (components)
// This makes components testable without Firebase mocks

import React, { useState, useEffect } from 'react';
import {
  View, Text, TextInput, FlatList, Pressable,
  StyleSheet, Alert, ActivityIndicator, Platform,
  KeyboardAvoidingView,
} from 'react-native';
import { initializeApp } from 'firebase/app';
import { getAuth, signInWithEmailAndPassword } from 'firebase/auth';
import {
  getFirestore, collection, doc, query, orderBy,
  limit, onSnapshot, serverTimestamp, writeBatch,
} from 'firebase/firestore';

// ─── Firebase config ───────────────────────────
const firebaseConfig = {
  apiKey: 'YOUR_API_KEY',
  authDomain: 'your-app.firebaseapp.com',
  projectId: 'your-app',
  storageBucket: 'your-app.appspot.com',
  messagingSenderId: '123456789',
  appId: '1:123456789:web:abc123',
};

const app = initializeApp(firebaseConfig);
const auth = getAuth(app);
const db = getFirestore(app);

const COLORS = {
  darkGreen: '#075E54',
  lightGreen: '#25D366',
  bubbleGreen: '#DCF8C6',
  chatBg: '#ECE5DD',
  white: '#FFFFFF',
};

// ─── TESTABLE UTILITY FUNCTIONS ────────────────
// These are pure functions — easy to unit test!

export function validateMessage(text) {
  const trimmed = (text || '').trim();
  if (trimmed.length === 0) return { valid: false, error: 'Message is empty' };
  if (trimmed.length > 4096) return { valid: false, error: 'Message too long (max 4096)' };
  return { valid: true, text: trimmed };
}

export function formatMessageTime(timestamp) {
  if (!timestamp) return 'Sending...';
  const date = timestamp.toDate ? timestamp.toDate() : new Date(timestamp);
  return date.toLocaleTimeString([], { hour: '2-digit', minute: '2-digit' });
}

export function getMessageStatus(message, userId) {
  if (message.senderId !== userId) return null; // not my message
  if (!message.createdAt) return 'pending';
  return 'sent';
}

// ─── TESTABLE COMPONENTS ───────────────────────
// These accept data via props — no Firebase dependency inside!

export function MessageBubble({ text, time, status, isMine }) {
  return (
    <View
      style={[styles.bubble, isMine ? styles.myBubble : styles.theirBubble]}
      testID="message-bubble"
    >
      <Text style={styles.messageText} testID="message-text">{text}</Text>
      <View style={styles.metaRow}>
        <Text style={styles.timeText} testID="message-time">{time}</Text>
        {status && (
          <Text testID="message-status">
            {status === 'pending' ? '🕐' : '✓✓'}
          </Text>
        )}
      </View>
    </View>
  );
}

export function SendBar({ onSend, sending }) {
  const [input, setInput] = useState('');

  const handlePress = () => {
    const result = validateMessage(input);
    if (!result.valid) return;
    onSend(result.text);
    setInput('');
  };

  return (
    <View style={styles.inputBar}>
      <TextInput
        style={styles.input}
        value={input}
        onChangeText={setInput}
        placeholder="Type a message"
        maxLength={4096}
        multiline
        testID="message-input"
      />
      <Pressable
        style={[styles.sendBtn, sending && { opacity: 0.5 }]}
        onPress={handlePress}
        disabled={sending}
        testID="send-button"
        accessibilityState={{ disabled: sending }}
      >
        {sending
          ? <ActivityIndicator color={COLORS.white} size="small" />
          : <Text style={styles.sendText}>Send</Text>
        }
      </Pressable>
    </View>
  );
}

// ─── HOOK (connects Firebase to components) ────
function useMessages(chatId) {
  const [messages, setMessages] = useState([]);

  useEffect(() => {
    const q = query(
      collection(db, 'chats', chatId, 'messages'),
      orderBy('createdAt', 'desc'),
      limit(50)
    );
    const unsubscribe = onSnapshot(q, (snapshot) => {
      setMessages(snapshot.docs.map(d => ({ id: d.id, ...d.data() })));
    });
    return unsubscribe;
  }, [chatId]);

  return messages;
}

// ─── SCREEN (wires hook data to testable components) ──
function ChatScreen({ chatId }) {
  const messages = useMessages(chatId);
  const [sending, setSending] = useState(false);
  const userId = auth.currentUser?.uid;

  const handleSend = async (text) => {
    setSending(true);
    try {
      const batch = writeBatch(db);
      const msgRef = doc(collection(db, 'chats', chatId, 'messages'));
      batch.set(msgRef, {
        senderId: userId,
        text,
        createdAt: serverTimestamp(),
      });
      await batch.commit();
    } catch (error) {
      Alert.alert('Send failed', error.message);
    } finally {
      setSending(false);
    }
  };

  return (
    <KeyboardAvoidingView
      style={styles.container}
      behavior={Platform.OS === 'ios' ? 'padding' : 'height'}
    >
      <View style={styles.header}>
        <Text style={styles.headerTitle}>Priya</Text>
      </View>

      <FlatList
        data={messages}
        renderItem={({ item }) => (
          <MessageBubble
            text={item.text}
            time={formatMessageTime(item.createdAt)}
            status={getMessageStatus(item, userId)}
            isMine={item.senderId === userId}
          />
        )}
        keyExtractor={(item) => item.id}
        inverted
        style={styles.messageList}
      />

      <SendBar onSend={handleSend} sending={sending} />
    </KeyboardAvoidingView>
  );
}

// ─── Main App ─────────────────────────────────
export default function App() {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    signInWithEmailAndPassword(auth, 'reviewer@yourapp.com', 'ReviewTest2026!')
      .then((cred) => setUser(cred.user))
      .catch((err) => Alert.alert('Login failed', err.message))
      .finally(() => setLoading(false));

}

10. Key takeaways

  • Testing pyramid: many unit tests, some component tests, few integration tests
  • Jest + jest-expo — the standard test runner for Expo projects
  • Unit test pure functions first — formatTime, validateMessage, truncateText
  • React Native Testing Library — test components by what the user sees (text, testID)
  • Firebase Emulator for integration tests — real rules, fake data, no production risk
  • Mock Firebase for fast component tests — components shouldn't care where data comes from
  • Separate logic from UI — pure functions + dumb components = easy testing
  • Manual QA checklist before every release — 18 checks covering critical paths and edge cases
  • Test when you fix bugs — write the test first, then fix the code; prevents regressions
