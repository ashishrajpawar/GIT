Module 8: Production at Scale

8 lessons • ~3 weeks • Build these before/after your first real users

Why this module exists: Your app works for 5 testers. But at 1,000+ users, messages load slowly, Firestore bills explode, crashes go unnoticed, and attackers spam your database. This module makes the app survive real-world load.

Lessons

  1. Firestore Security Rules (Complete)

    Field-type and size validation, rate-limiting writes (max 1 msg/sec/user), Storage rules (file size caps, allowed MIME types), protecting the users collection, testing rules with Firebase Emulator, deploying rules safely.

  2. Pagination & Data Limits

    Cursor-based pagination for messages (startAfter + limit), paginated chat list, infinite scroll combined with a real-time tail listener, Firestore read cost awareness, document count limits.

  3. Offline Support & Network Handling

    Enabling Firestore persistence, @react-native-community/netinfo for network state detection, offline queue for pending messages, "Connecting..." UI indicator, conflict resolution when two devices edit the same document.

  4. Cloud Functions — Server-Side Logic

    Firebase Cloud Functions setup (Node.js), server-triggered push notifications on new message (replacing client-side sends), server-side group membership validation, scheduled cleanup (expired statuses, stale push tokens, old reports).

  5. Error Recovery & Retry Logic

    Exponential backoff for failed requests, retry queue for unsent messages (with UI indicator), graceful degradation when Firebase is unreachable, ErrorBoundary component for crash isolation, user-facing error messages that help.

  6. Monitoring & Crash Reporting

    Firebase Crashlytics setup (or Sentry), logging strategy (what to log, what not to), Firebase Performance monitoring, basic analytics (DAU, messages/day), setting up alerts for error spikes, reading crash reports.

  7. Testing Your App

    Jest setup with Expo, unit testing utility functions, React Native Testing Library for component tests, Firebase Emulator for integration tests, manual QA checklist, what to test before every release.

  8. Media Compression & Storage Optimization

    Compress images before upload (expo-image-manipulator), video compression strategies, thumbnail generation, Firebase Storage cost management, CDN caching headers, cleaning up orphaned files.

Prerequisites

  • Module 7 complete (app passes store review)
  • App is live (or about to go live) with real users
  • Firebase Blaze plan (required for Cloud Functions)

By the end of this module you will have

  • Security rules that prevent abuse and invalid data
  • An app that handles 10,000+ messages per chat without crashing
  • Seamless offline experience with automatic sync
  • Server-side logic handling notifications and cleanup
  • Automatic crash reporting and performance monitoring
  • A testing strategy that catches bugs before users do
  • Optimized media handling that keeps storage costs low
