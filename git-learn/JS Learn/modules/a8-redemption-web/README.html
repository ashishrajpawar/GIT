Track A

Redemption Web Page

4 lessons Phase 5 — The Second Client
Module goal

Build the browser-based redemption experience at tokn.app/t/CODE. After this module, a token holder can redeem a token, chat, and even make voice/video calls — entirely from a web browser, without installing the mobile app. This is Vite + React, NOT React Native Web.

Lessons

  1. Vite + React Project Setup

    Project structure in web/, shared types, environment config, Tailwind CSS, deployment as a container on the same Coolify VPS.

  2. Token Redemption Flow

    Enter code or land via URL, identify yourself (nickname), connect to the conversation, server-side validation.

  3. Browser WebRTC & WebSocket

    Native browser APIs — no React Native libraries. Same signalling protocol, same TURN server, different API surface.

  4. No-App-Installed Experience

    Full functionality without the mobile app — chat, voice, video all work in the browser. Progressive enhancement when the app IS installed.

What you'll build

  • web/src/pages/Redeem.tsx — the main redemption page
  • web/src/pages/Chat.tsx — browser-based chat interface
  • web/src/lib/ws.ts — WebSocket client (browser native API)
  • web/src/lib/webrtc.ts — WebRTC wrapper (browser native API)
  • web/vite.config.ts — build configuration
  • web/Dockerfile — container deployment

Prerequisites

  • B5 — WebSocket Server (same server, browser WS client)
  • B6 — WebRTC Signalling (same signalling, browser WebRTC)
  • A5 — Core Token Features (redemption endpoint exists)
