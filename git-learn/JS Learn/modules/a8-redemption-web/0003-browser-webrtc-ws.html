Browser WebRTC & WebSocket

A8 — Lesson 3 of 4 ~60 min
Why this matters for Token

The browser has native WebSocket and WebRTC APIs — no npm packages needed. The same signalling protocol you built for the mobile app works here, but the API surface is different (no react-native-webrtc). The holder in their browser can text-chat via WebSocket and make voice/video calls via native RTCPeerConnection — all without installing anything.

Browser WebSocket — native API

In the mobile app, you might use a library for WebSocket. In the browser, it's built in:

// web/src/lib/ws.ts
const WS_URL = import.meta.env.VITE_WS_URL;

export function createWebSocketClient(holderJwt: string) {
  // Connect with auth token as query param
  const ws = new WebSocket(\`\${WS_URL}/ws?token=\${holderJwt}\`);

  ws.onopen = () => {
    console.log('WebSocket connected');
  };

  ws.onmessage = (event) => {
    const message = JSON.parse(event.data);
    console.log('Received:', message);
  };

  ws.onerror = (error) => {
    console.error('WebSocket error:', error);
  };

  ws.onclose = (event) => {
    console.log('WebSocket closed:', event.code, event.reason);
  };

  return ws;
}

Same protocol, different API

The signalling protocol (message format) is identical between mobile and web. The difference is only the API surface:

// Mobile (react-native) — same protocol, library wrapper
import { io } from 'socket.io-client';
const socket = io(WS_URL, { auth: { token: jwt } });
socket.on('message', handler);
socket.emit('message', payload);

// Browser (native) — same protocol, native API
const ws = new WebSocket(\`\${WS_URL}/ws?token=\${jwt}\`);
ws.onmessage = (event) => handler(JSON.parse(event.data));
ws.send(JSON.stringify(payload));
Key insight

If your server uses a raw WebSocket library (like the ws package), both clients speak the same wire protocol natively. If your server uses Socket.IO, the browser client also needs the Socket.IO client library. For Token, we recommend raw WebSocket on the server — then the browser needs zero dependencies.

Complete WebSocket module for the web app

// web/src/lib/ws.ts
type MessageHandler = (message: any) => void;
type ConnectionHandler = () => void;

interface WSClient {
  send: (type: string, payload: any) => void;
  onMessage: (handler: MessageHandler) => void;
  onConnect: (handler: ConnectionHandler) => void;
  onDisconnect: (handler: ConnectionHandler) => void;
  disconnect: () => void;
  reconnect: () => void;
}

export function createWSClient(url: string, token: string): WSClient {
  let ws: WebSocket | null = null;
  let messageHandlers: MessageHandler[] = [];
  let connectHandlers: ConnectionHandler[] = [];
  let disconnectHandlers: ConnectionHandler[] = [];
  let reconnectTimer: number | null = null;
  let attempt = 0;

  function connect() {
    ws = new WebSocket(\`\${url}/ws?token=\${token}\`);

    ws.onopen = () => {
      attempt = 0;
      connectHandlers.forEach(h => h());
    };

    ws.onmessage = (event) => {
      try {
        const msg = JSON.parse(event.data);
        messageHandlers.forEach(h => h(msg));
      } catch (e) {
        console.error('Failed to parse WS message:', e);
      }
    };

    ws.onclose = () => {
      disconnectHandlers.forEach(h => h());
      scheduleReconnect();
    };

    ws.onerror = () => {
      ws?.close();
    };
  }

  function scheduleReconnect() {
    if (reconnectTimer) return;
    attempt++;
    const delay = Math.min(1000 * Math.pow(2, attempt), 30000);
    reconnectTimer = window.setTimeout(() => {
      reconnectTimer = null;
      connect();
    }, delay);
  }

  connect();

  return {
    send(type, payload) {
      if (ws?.readyState === WebSocket.OPEN) {
        ws.send(JSON.stringify({ type, ...payload }));
      }
    },
    onMessage(handler) { messageHandlers.push(handler); },
    onConnect(handler) { connectHandlers.push(handler); },
    onDisconnect(handler) { disconnectHandlers.push(handler); },
    disconnect() {
      if (reconnectTimer) clearTimeout(reconnectTimer);
      ws?.close();
    },
    reconnect() {
      ws?.close();
      connect();
    },
  };
}

Browser WebRTC — native RTCPeerConnection

The browser has WebRTC built in. No library needed — just the standard APIs:

// The three key browser APIs for WebRTC:
// 1. RTCPeerConnection — manages the peer connection
// 2. navigator.mediaDevices.getUserMedia() — camera/mic access
// 3. MediaStream / MediaStreamTrack — audio/video tracks

Getting media permissions

// Request microphone + camera
async function getLocalMedia(video: boolean = true) {
  try {
    const stream = await navigator.mediaDevices.getUserMedia({
      audio: true,
      video: video ? { facingMode: 'user', width: 640, height: 480 } : false,
    });
    return stream;
  } catch (err: any) {
    if (err.name === 'NotAllowedError') {
      throw new Error('Camera/mic permission denied. Check browser settings.');
    }
    if (err.name === 'NotFoundError') {
      throw new Error('No camera or microphone found on this device.');
    }
    throw err;
  }
}
Browser-specific: HTTPS required

navigator.mediaDevices.getUserMedia() only works on HTTPS origins (or localhost for development). If you try to access it on plain HTTP, the API simply won't exist. This is a browser security requirement — not an issue in React Native.

Complete WebRTC module for the browser

// web/src/lib/webrtc.ts
import { createWSClient } from './ws';

interface CallOptions {
  wsClient: ReturnType<typeof createWSClient>;
  conversationId: string;
  localVideoEl: HTMLVideoElement | null;
  remoteVideoEl: HTMLVideoElement | null;
  onCallEnd: () => void;
}

export async function startCall(options: CallOptions, withVideo: boolean) {
  const { wsClient, conversationId, localVideoEl, remoteVideoEl, onCallEnd } = options;

  // 1. Get local media
  const localStream = await navigator.mediaDevices.getUserMedia({
    audio: true,
    video: withVideo ? { facingMode: 'user' } : false,
  });

  // Show local preview
  if (localVideoEl && withVideo) {
    localVideoEl.srcObject = localStream;
    localVideoEl.muted = true; // prevent echo
    await localVideoEl.play();
  }

  // 2. Create peer connection
  const pc = new RTCPeerConnection({
    iceServers: [
      { urls: 'stun:stun.l.google.com:19302' },
      // Add your TURN server for NAT traversal
      // { urls: 'turn:turn.tokn.app:3478', username: '...', credential: '...' }
    ],
  });

  // 3. Add local tracks to the connection
  localStream.getTracks().forEach(track => {
    pc.addTrack(track, localStream);
  });

  // 4. Handle remote tracks
  pc.ontrack = (event) => {
    if (remoteVideoEl) {
      remoteVideoEl.srcObject = event.streams[0];
      remoteVideoEl.play().catch(() => {
        // Autoplay blocked — need user interaction
        console.warn('Autoplay blocked, user must tap to hear audio');
      });
    }
  };

  // 5. ICE candidate exchange via signalling
  pc.onicecandidate = (event) => {
    if (event.candidate) {
      wsClient.send('ice-candidate', {
        conversationId,
        candidate: event.candidate.toJSON(),
      });
    }
  };

  // 6. Create and send offer
  const offer = await pc.createOffer();
  await pc.setLocalDescription(offer);
  wsClient.send('call-offer', {
    conversationId,
    sdp: offer.sdp,
    type: offer.type,
    withVideo,
  });

  // 7. Listen for answer and ICE candidates
  wsClient.onMessage((msg) => {
    if (msg.type === 'call-answer') {
      pc.setRemoteDescription(new RTCSessionDescription({
        type: 'answer',
        sdp: msg.sdp,
      }));
    }
    if (msg.type === 'ice-candidate') {
      pc.addIceCandidate(new RTCIceCandidate(msg.candidate));
    }
    if (msg.type === 'call-end') {
      endCall();
    }
  });

  // Cleanup function
  function endCall() {
    localStream.getTracks().forEach(t => t.stop());
    pc.close();
    onCallEnd();
  }

  pc.onconnectionstatechange = () => {
    if (pc.connectionState === 'disconnected' || pc.connectionState === 'failed') {
      endCall();
    }
  };

  return { pc, localStream, endCall };
}

Differences from React Native WebRTC

Aspect React Native (mobile) Browser (web)
Library react-native-webrtc Native — no library
Media access mediaDevices.getUserMedia() (from lib) navigator.mediaDevices.getUserMedia()
Video display <RTCView> component <video> HTML element with srcObject
Permission prompt OS-level dialog Browser-level dialog (site settings)
HTTPS requirement Not required (native) Required (except localhost)
Autoplay policy No restrictions May need user gesture to play audio/video
Background behavior Foreground service keeps call alive Tab must stay active (or use Web Workers)

Handling autoplay policies

Browsers block autoplay of media with audio. When a remote stream arrives, .play() might fail:

// The safe pattern for playing remote media
async function playRemoteStream(videoEl: HTMLVideoElement, stream: MediaStream) {
  videoEl.srcObject = stream;

  try {
    await videoEl.play();
  } catch (err: any) {
    if (err.name === 'NotAllowedError') {
      // Autoplay blocked — show a "Tap to unmute" button
      // This happens if the user hasn't interacted with the page yet
      showUnmuteButton(() => videoEl.play());
    }
  }
}

function showUnmuteButton(onTap: () => void) {
  const btn = document.createElement('button');
  btn.textContent = 'Tap to hear audio';
  btn.className = 'fixed bottom-4 left-1/2 -translate-x-1/2 bg-blue-600 text-white px-4 py-2 rounded';
  btn.onclick = () => {
    onTap();
    btn.remove();
  };
  document.body.appendChild(btn);
}
Why this matters

On the mobile app, audio just plays. In browsers, Chrome and Safari require a user gesture (click, tap) before audio can play. Since the holder already clicked "Start Conversation" on the redeem page, audio should work for calls they initiate. But incoming calls may need a "Tap to answer" prompt.

Reconnection and cleanup

// React hook for WebSocket lifecycle
import { useEffect, useRef } from 'react';

export function useWebSocket(url: string, token: string | null) {
  const clientRef = useRef<ReturnType<typeof createWSClient> | null>(null);

  useEffect(() => {
    if (!token) return;

    const client = createWSClient(url, token);
    clientRef.current = client;

    return () => {
      // Cleanup on unmount or token change
      client.disconnect();
      clientRef.current = null;
    };
  }, [url, token]);

  return clientRef;
}
