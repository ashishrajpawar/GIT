Auth on the Client

3 lessons Phase 3 — Client Meets Server
Module goal

Connect the mobile app's auth to the server you built in B4. After this module, users can register, login, and stay authenticated — with silent token refresh, secure storage, and automatic logout when sessions expire.

Lessons

  1. JWT Flow — Login, Signup, Token Storage — expo-secure-store, login/register screens, session restoration
  2. Auth Context & Protected Routes — createContext, useAuth hook, conditional navigation
  3. Handling 401s & Logout — silent refresh, retry-after-refresh, deduplication, force logout

After this module

You'll have:

  • Login and Register screens connected to the API
  • Refresh token stored in hardware-encrypted SecureStore
  • AuthContext providing user state to all components
  • Automatic navigation: Login stack when unauthenticated, Main stack when authenticated
  • Silent token refresh that retries failed requests transparently
  • Force logout when refresh tokens are revoked
