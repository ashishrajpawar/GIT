Chat & Real-time

3 lessons Phase 4 — Real-time
Module goal

Connect the mobile app to the WebSocket server you built in B5. After this module, users can send and receive messages in real time, see delivery status (sent/delivered/read), and watch typing indicators — all over your own WebSocket infrastructure, not Firebase.

Lessons

  1. WebSocket Basics on the Client

    Connecting to your WS server, authenticating, auto-reconnecting with exponential backoff, and managing connection state.

  2. Message Thread UI

    The chat screen: sending and receiving messages, optimistic updates, delivery status checkmarks, and infinite scroll for history.

  3. Typing Indicators & Presence

    Showing "typing..." with debounce, online/offline dots, "last seen" display, and managing ephemeral UI state.

What you'll build

  • app/src/ws/connection.ts — WebSocket singleton with reconnection logic
  • app/src/ws/useWebSocket.ts — React hook exposing connection state
  • app/src/screens/MessageThread.tsx — chat interface with FlatList
  • app/src/screens/ConversationList.tsx — inbox showing all active conversations
  • app/src/components/MessageBubble.tsx — individual message with status
  • app/src/components/TypingIndicator.tsx — animated "typing..." display

Prerequisites

  • B5 — WebSocket Server (the server you're connecting to)
  • A4 — Auth on the Client (JWT for WebSocket auth)
  • A3 — API Consumption (REST fallback for message history)
