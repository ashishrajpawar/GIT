An Event With No Subject

C8 — Lesson 1 of 2  |  ~50 min

Why this matters for Token

You need to know whether people are creating tokens, whether QR sharing is used more than typing a code into a form, whether anybody ever opens the rules screen. Without that you are building on guesses.

And Token is a product whose entire pitch is that it does not accumulate a record of who contacted whom. The ordinary way to answer those questions is to build exactly such a record, one event at a time, with a user id on every row — which is what every analytics tutorial shows you, because for most products it is fine.

So the row with a user id on it is not a small extra. It reopens a decision two modules away, and the person who adds it will be adding a column, not making a decision.

2 · Build the key from the allow-list, not from the event

c7/0001 made this argument about log lines and it is the same argument here, with a different consequence at the end of it.

The difference is not the output on this event. It is what happens on the day somebody adds a field upstream: the allow-list version is unchanged, and the other one quietly starts grouping by something new.

An allow-list is the only kind of filter that is still correct after code you did not write has changed. A deny-list — "strip userId and phoneHash" — is a list of the mistakes somebody has already thought of.

3 · Cardinality is identifiability

c7/0003 settled this as a cost argument: a label with one value per user turns one time series into a million, and that is a bill. It also recorded the sentence this lesson depends on — the cardinality rule and the privacy rule coincide — and warned about exactly the way that convenience misleads:

Somebody who knows only the cost argument will add a cheap label with fifty values that still singles a person out.

Neither city nor device_model is an identifier. Together, in a country where most towns have very few users of a new app, they can be. That is why the budget is on the cell count as well as on any single dimension.

4 · A cell of one is a person

A report saying "Android, revoked a token, 1" has published a fact about an individual, and it did so through a table of aggregates that nobody would call personal data.

The standard answer is a floor: any cell below a minimum is not reported. Pick the floor deliberately — it is the size of the smallest group you are willing to describe.

5 · Suppressing one cell suppresses nothing

Now the part that is genuinely counter-intuitive, and the reason a naive implementation of the previous section is worse than not bothering.

A suppressed cell is recoverable by subtraction whenever everything else is visible. So the rule has a second half: if exactly one cell would be suppressed, suppress the smallest remaining one as well. Two hidden cells leave a sum with two unknowns, which is a genuine hiding place.

This costs you a real number — the second cell was above the floor and was fine to publish. Accept it. A privacy control that is defeated by one subtraction is not a control, and is worse than none because it is believed.

6 · Sometimes the honest output is no number

The complement rule needs somewhere to hide. If the whole report has one cell and that cell is below the floor, there is no second cell to suppress, and publishing the total republishes the thing you just hid.

The right answer is to report the suppression and withhold the total. It is unsatisfying, and it is the same shape as c7/0003 refusing to return an error rate of zero for a window with no traffic: the function will not invent a number it cannot honestly produce, even though a number is what the caller wanted.

7 · What is not in this module, and why

No vendor SDK. Not Google Analytics, not Mixpanel, not Amplitude, not Firebase — and the last of those is out of scope for the whole project anyway.

The reason is narrower than "third parties are bad". A mobile analytics SDK collects a device identifier, and it does so on initialisation, which is normally before your consent screen has rendered. That is not a setting you missed. It is what the library is for, and it means the first thing your privacy product does on first launch is send an identifier to somebody else.

Self-hosting has a cost and it is the same one C7 recorded: you now operate the thing that watches the thing. Another container, another table, another backup.

8 · Broken on purpose

A Map is not an array and has no sort. Array.from(counts) or a spread gives you the entries as pairs, at which point the comparator above is right — and the ordering matters here for a reason beyond tidiness, because "the smallest remaining cell" is a question you can only answer once the cells are in order.
