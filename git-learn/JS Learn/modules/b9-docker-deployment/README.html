Docker & Deployment

Track B

Phase 7 — 3 lessons

Module goal: Package the Token API and redemption web page as Docker containers, deploy them to a VPS with Coolify, and set up monitoring so you know when things break. After this module your app is live on the internet with automatic TLS, Postgres backups, and structured logging.

Lessons

  1. Docker Fundamentals
  2. Coolify Setup
  3. Logs, Backups & Monitoring

What you'll build

  • Multi-stage Dockerfiles for api/ and web/
  • A Docker Compose file for local development (API + Postgres + Redis)
  • Production deployment on a VPS using Coolify with git-push deploys
  • Automatic TLS certificates via Coolify's built-in Let's Encrypt integration
  • Structured JSON logging with request correlation IDs
  • Automated Postgres backups with pg_dump
  • Basic uptime alerting via health check endpoints

Prerequisites

  • B3 Node & HTTP Server — the API you're deploying
  • B4 Auth Server — JWT and secrets that need environment variables
  • A8 Redemption Web Page — the second container you're deploying
