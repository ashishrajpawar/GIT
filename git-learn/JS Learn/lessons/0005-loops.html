Lesson 5

Loops

Foundations ~20 min read Beginner
Why this matters for your app

Your WhatsApp clone's chat screen holds an array of messages — maybe 50, maybe 500. A loop is how you go through every single one to display it on screen, count the unread ones, find a specific message, or pick out everything from a particular sender. Without loops, you'd have to write out every step by hand. With loops, ten lines of code handles ten thousand messages just as easily as ten.

The for loop — the classic counter

The for loop is the most familiar loop in programming. You control it with three parts written inside parentheses, separated by semicolons:

  • init — set up a counter variable before the loop starts
  • condition — check whether to keep going; if it's true, run the body; if false, stop
  • increment — update the counter after each run through the body
// Anatomy: for (init; condition; increment) { body }

for (let i = 0; i < 3; i++) {
  console.log("Step", i);
}
// Step 0
// Step 1
// Step 2

Now let's use it to iterate over an array of messages by index. The array has .length items, so you run while i < messages.length:

const messages = [
  { sender: "Ali",  text: "Hey! Coming tonight?" },
  { sender: "Sara", text: "On my way!"            },
  { sender: "Ali",  text: "Great, see you soon"   }
];

for (let i = 0; i < messages.length; i++) {
  console.log(`[${i}] ${messages[i].sender}: ${messages[i].text}`);
}
// [0] Ali: Hey! Coming tonight?
// [1] Sara: On my way!
// [2] Ali: Great, see you soon
Infinite loops — don't forget to increment

If you forget the increment (i++), the condition is never met and the loop runs forever, freezing your app. Always double-check that your counter actually moves toward the stopping condition.

// DANGER — this never stops:
for (let i = 0; i < 5; /* forgot i++ */) {
  console.log(i); // prints 0 forever
}
In your WhatsApp clone

The index-based for loop is useful when you need the position number alongside the item — for example, to number each message in a debug log, or to compare neighbouring messages to decide whether to show a timestamp divider between them.

The for...of loop — the modern way

The for...of loop is a cleaner way to go through every item in an array when you don't need the index number. It directly hands you each item in turn:

const contacts = ["Ali", "Sara", "Ravi", "Priya"];

for (const contact of contacts) {
  console.log(`Contact: ${contact}`);
}
// Contact: Ali
// Contact: Sara
// Contact: Ravi
// Contact: Priya

It works just as well with arrays of objects — the variable becomes the whole object on each iteration:

const messages = [
  { sender: "Ali",  text: "Hey!",         isRead: true  },
  { sender: "Sara", text: "On my way!",   isRead: false },
  { sender: "Ali",  text: "See you soon", isRead: false }
];

for (const msg of messages) {
  console.log(`${msg.sender} says: ${msg.text}`);
}
// Ali says: Hey!
// Sara says: On my way!
// Ali says: See you soon
In your WhatsApp clone

for...of is the preferred loop when you just need to do something for each item and don't need the index. Prefer it over the classic for loop in most day-to-day situations — it's shorter, harder to get wrong, and reads more like plain English: "for each message in messages, do this".

The while loop — when you don't know how many times

A while loop keeps running as long as a condition is true. You use it when you don't know upfront how many iterations you'll need — the loop just keeps going until something changes.

// Anatomy: while (condition) { body }

let unread = 5;

while (unread > 0) {
  console.log(`${unread} unread message(s) remaining`);
  unread--;   // must change the variable, or this loops forever!
}
// 5 unread message(s) remaining
// 4 unread message(s) remaining
// 3 unread message(s) remaining
// 2 unread message(s) remaining
// 1 unread message(s) remaining

A realistic messaging example: imagine you're pulling messages from a queue one by one until the queue is empty:

const incomingQueue = ["Hi!", "Are you there?", "Call me back"];

while (incomingQueue.length > 0) {
  const nextMessage = incomingQueue.shift(); // removes and returns the first item
  console.log(`Processing message: "${nextMessage}"`);
}
// Processing message: "Hi!"
// Processing message: "Are you there?"
// Processing message: "Call me back"
While loops and infinite loops

The same danger applies as with for loops. If your condition never becomes false, the loop runs forever. Always make sure something inside the loop moves you towards the stopping condition — in the queue example above, .shift() shrinks the array on every iteration until it's empty.

In your WhatsApp clone

You'll use while when the exit condition depends on something that changes as you work — retrying a failed network request a limited number of times, or processing a live queue of incoming socket events until it drains.

Array methods — loops in disguise (and the most important ones)

Modern JavaScript gives you four array methods that each do a specific kind of loop internally. In React Native you'll use these far more than raw for loops, because they're concise, expressive, and composable.

forEach — do something for each item

forEach runs a function once for every item in the array. Use it when you want a side effect — logging, updating the screen, triggering a network call — for each item:

const messages = [
  { sender: "Ali",  text: "Hey!"        },
  { sender: "Sara", text: "On my way!"  },
  { sender: "Ravi", text: "Be there at 7" }
];

messages.forEach(function(msg) {
  console.log(`${msg.sender}: ${msg.text}`);
});
// Ali: Hey!
// Sara: On my way!
// Ravi: Be there at 7

The modern shorthand uses an arrow function (=>), which you'll see everywhere in React Native code:

messages.forEach(msg => {
  console.log(`${msg.sender}: ${msg.text}`);
});
forEach does not return a new array

forEach is for side effects only — it always returns undefined. Do not use it when you need a transformed or filtered result. Use map or filter instead (see below).

map — transform each item into something new

map creates a brand-new array by applying a function to every item. The original array is untouched. Use it when you want to reshape your data:

const messages = [
  { sender: "Ali",  text: "Hey!",         isRead: true  },
  { sender: "Sara", text: "On my way!",   isRead: false },
  { sender: "Ravi", text: "Be there at 7", isRead: false }
];

// Extract just the text from each message object
const texts = messages.map(msg => msg.text);
console.log(texts);
// ["Hey!", "On my way!", "Be there at 7"]

// Build a display-friendly summary string for each message
const previews = messages.map(msg => `${msg.sender}: ${msg.text}`);
console.log(previews);
// ["Ali: Hey!", "Sara: On my way!", "Ravi: Be there at 7"]
In your WhatsApp clone

In React Native, map is how you turn your array of message objects into an array of <MessageBubble /> components to render on screen. Something like: messages.map(msg => <MessageBubble key={msg.id} data={msg} />). You will write this pattern hundreds of times.

filter — keep only the items that match a condition

filter creates a new array containing only the items for which your function returns true. Everything else is left out:

const messages = [
  { sender: "Ali",  text: "Hey!",          isRead: true  },
  { sender: "Sara", text: "On my way!",    isRead: false },
  { sender: "Ali",  text: "See you soon",  isRead: false },
  { sender: "Ravi", text: "Be there at 7", isRead: true  }
];

// Keep only unread messages
const unread = messages.filter(msg => msg.isRead === false);
console.log(unread.length); // 2

// Keep only messages from Ali
const fromAli = messages.filter(msg => msg.sender === "Ali");
console.log(fromAli.length); // 2
In your WhatsApp clone

You'll use filter for the unread badge count, for showing only media messages in the gallery view, for searching messages by keyword, and for hiding deleted messages from the thread.

find — get the first item that matches

find returns the first item for which your function returns true. It stops as soon as it finds a match. If nothing matches, it returns undefined.

const contacts = [
  { id: 1, name: "Ali",  phone: "+91 98000 00001" },
  { id: 2, name: "Sara", phone: "+91 98000 00002" },
  { id: 3, name: "Ravi", phone: "+91 98000 00003" }
];

// Find a contact by name
const sara = contacts.find(contact => contact.name === "Sara");
console.log(sara);
// { id: 2, name: "Sara", phone: "+91 98000 00002" }

// Find a contact by id
const contact3 = contacts.find(contact => contact.id === 3);
console.log(contact3.name); // "Ravi"

// What if no match?
const nobody = contacts.find(contact => contact.name === "Priya");
console.log(nobody); // undefined
In your WhatsApp clone

You'll use find when you need a specific item — look up a contact by their phone number when a message arrives, find the chat thread for a conversation ID, or locate a message by its ID when the user taps "Reply".

Combining loops with conditionals

Loops and if statements work together constantly. The classic pattern: loop through everything, use a condition to decide what to do with each item.

Count unread messages

const messages = [
  { sender: "Ali",  text: "Hey!",          isRead: true  },
  { sender: "Sara", text: "On my way!",    isRead: false },
  { sender: "Ali",  text: "See you soon",  isRead: false },
  { sender: "Ravi", text: "Be there at 7", isRead: false }
];

let unreadCount = 0;

for (const msg of messages) {
  if (msg.isRead === false) {
    unreadCount++;
  }
}

console.log(`You have ${unreadCount} unread messages.`);
// You have 3 unread messages.

Find all messages from a specific sender

const messagesFromAli = [];

for (const msg of messages) {
  if (msg.sender === "Ali") {
    messagesFromAli.push(msg);
  }
}

console.log(`Messages from Ali: ${messagesFromAli.length}`);
// Messages from Ali: 2

Note: both of these examples could also be written with filter. The loop + if pattern is good to understand, but when you just need a count or a subset, filter is shorter. Use whatever is clearest for the situation.

In your WhatsApp clone

The unread count is what drives the badge number on a chat thread in your app's home screen. Your code will loop through messages, count the unread ones, and pass that number to the badge component. This exact pattern runs in every messaging app in the world.

Putting it all together — a complete WhatsApp example

Here are three utility functions you'd genuinely write in your chat app. They use the loop patterns from this lesson:

// Sample messages array — this is the shape of real chat data
const messages = [
  { id: 1, sender: "Ali",  text: "Hey! Coming tonight?",    isRead: true,  timestamp: "10:30" },
  { id: 2, sender: "Ashish", text: "Yes, definitely!",      isRead: true,  timestamp: "10:31" },
  { id: 3, sender: "Ali",  text: "Great. Bring snacks.",    isRead: false, timestamp: "10:32" },
  { id: 4, sender: "Sara", text: "I'll be late by 10 min.", isRead: false, timestamp: "10:45" },
  { id: 5, sender: "Ali",  text: "No worries, see you all!", isRead: false, timestamp: "10:46" }
];

// 1. Count how many messages are unread
function countUnread(messages) {
  return messages.filter(msg => msg.isRead === false).length;
}

console.log(countUnread(messages)); // 3

// 2. Get all messages from a specific sender
function getMessagesFrom(messages, sender) {
  return messages.filter(msg => msg.sender === sender);
}

const aliMessages = getMessagesFrom(messages, "Ali");
console.log(`Ali sent ${aliMessages.length} messages.`); // Ali sent 3 messages.

// 3. Get preview text for unread messages (sender + first 20 chars of text)
function getUnreadPreviews(messages) {
  return messages
    .filter(msg => msg.isRead === false)
    .map(msg => ({
      sender: msg.sender,
      preview: msg.text.length > 20
        ? msg.text.slice(0, 20) + "..."
        : msg.text,
      timestamp: msg.timestamp
    }));
}

const previews = getUnreadPreviews(messages);
previews.forEach(p => {
  console.log(`[${p.timestamp}] ${p.sender}: ${p.preview}`);
});
// [10:32] Ali: Great. Bring snacks.
// [10:45] Sara: I'll be late by 10 ...
// [10:46] Ali: No worries, see you ...

A few things to notice in getUnreadPreviews:

  • It chains .filter() then .map() — the output of filter flows directly into map. This chaining pattern is everywhere in real React Native code.
  • msg.text.slice(0, 20) trims the text to 20 characters — the same trick WhatsApp uses for notification previews.
  • The ternary operator (condition ? valueIfTrue : valueIfFalse) decides whether to trim — this is conditionals inside a loop, working together.
In your WhatsApp clone

These three functions are real production code, not toys. countUnread drives the badge number. getMessagesFrom powers a "search by contact" feature. getUnreadPreviews builds the notification payload. Save this block — you will use variations of it.
