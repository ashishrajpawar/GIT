# Mission: JavaScript for Building a Mobile App

## Why
Build a fully functional WhatsApp clone mobile app using React Native — with real-time chat, audio/video calls, and group messaging. This is a personal project the user wants to ship from scratch.

## Success looks like
- Understand JavaScript well enough to write React Native components confidently
- Build a working chat screen with real-time messages
- Implement user authentication (sign up / log in)
- Add audio and video calling using WebRTC (react-native-webrtc) — same tech WhatsApp uses, no third-party SDK
- Support group chats and contacts
- Publish the app to both Android (Play Store) and iOS (App Store)

## Constraints
- Complete beginner at JavaScript — foundations must come first
- Learning solo, at own pace
- Framework: React Native with Expo (EAS Build for native modules like WebRTC)
- Calls require EAS Build — not compatible with plain Expo Go

## Out of scope
- Backend infrastructure design (will use Firebase as managed backend)
- Advanced algorithms or computer science theory
